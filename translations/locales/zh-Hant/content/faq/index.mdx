## 這個分區會放什麼

FAQ 分區用於集中收納以下內容：

- 啟動和執行時的特殊說明
- 來自 Index 並適合沉澱為長期文章的使用 tips
- 與平台、發行管道、封裝方式或內建執行環境相關的相容性提示
- 適合做成獨立說明頁的常見疑難排解入口

如果你想系統瀏覽 HagiCode 的日常使用建議，請閱讀 [HagiCode 使用 Tips](/faq/tips)。如果你想確認 Desktop 使用哪個外部 Node、Agent CLI 安裝在哪裡，或提示找不到 Node 時該怎麼辦，請閱讀 [Desktop 如何使用你的 Node 環境](/faq/desktop-node-environment)。如果你想了解各個 Agent CLI 與 HagiCode 的關係，以及為什麼推薦搭配使用，請閱讀 [Claude Vs HagiCode](/faq/claude-vs-hagicode)、[Copilot Vs HagiCode](/faq/copilot-vs-hagicode)、[Codex Vs HagiCode](/faq/codex-vs-hagicode)、[Gemini Vs HagiCode](/faq/gemini-vs-hagicode)、[OpenCode Vs HagiCode](/faq/opencode-vs-hagicode)、[Hermes Vs HagiCode](/faq/hermes-vs-hagicode)、[DeepAgents Vs HagiCode](/faq/deepagents-vs-hagicode)、[Kimi Vs HagiCode](/faq/kimi-vs-hagicode)、[CodeBuddy Vs HagiCode](/faq/codebuddy-vs-hagicode)、[QoderCLI Vs HagiCode](/faq/qoder-vs-hagicode) 以及 [Kiro Vs HagiCode](/faq/kiro-vs-hagicode)。如果你想了解 HagiCode 為什麼沒有上架 Steam，請閱讀 [為什麼 HagiCode 沒有上架 Steam](/faq/steam-distribution-status)。
