## 概述

### 什麼是豆包語音輸入

豆包語音輸入是 HagiCode 整合的語音辨識功能，底層使用位元組跳動豆包開放平台的服務。你開口說話，系統會把語音轉成文字。產品還會結合目前專案的上下文，協助辨識領域詞彙和技術術語。

### 主要應用場景

在 HagiCode 裡，下列場景更適合直接用語音輸入：

- **快速輸入提案**：無須打字，直接口述即可快速建立和提交提案，大幅提升效率
- **提供評註**：在程式碼審查或文件評審時，用語音快速新增評註和回饋意見
- **回答訊息**：在對話和討論中，用語音快速回覆訊息，打字不再是負擔
- **長篇內容創作**：快速產生專案文件、技術說明、會議記錄等長篇內容

### 它帶來的實際好處

- **深度整合與上下文感知**：HagiCode 深度整合豆包語音辨識，自動利用目前專案的上下文（如程式碼結構、技術堆疊、領域術語），為語音辨識提供精準的領域詞彙辨識，技術術語辨識準確率顯著提升
- **免費試用時長**：豆包平台提供 20 小時免費辨識時長，零門檻體驗語音輸入
- **速度極快**：即時辨識，說話的同時即可看到文字，無須等待
- **準確率高**：基於豆包先進的語音辨識模型，搭配專案上下文，辨識結果精準可靠
- **無縫整合**：直接整合在 HagiCode 的訊息輸入框中，無須切換應用程式
- **使用便捷**：點擊麥克風即可開始，簡單直覺

## 快速開始

### 前置條件

在使用豆包語音輸入功能之前，你需要：

1. **取得豆包開放平台帳號**
   - 造訪 [豆包語音辨識控制台](https://console.volcengine.com/speech/service/10038)
   - 註冊或登入帳號

2. **建立應用並取得憑證**
   - 在平台上建立語音辨識應用
   - 取得 `APP ID` 和 `Access Token`

3. **確保網路連線**
   - 語音辨識服務需要網路連線
   - 確保你的裝置能夠連上豆包 API 服務

### 基本使用流程

以下是使用豆包語音輸入的基本步驟：

1. 取得 `APP ID` 和 `Access Token`
2. 在產品中設定語音辨識
3. 測試 API Key
4. 找到語音輸入框
5. 點擊麥克風按鈕
6. 授權麥克風權限
7. 開始錄音
8. 即時查看辨識結果
9. 點擊停止錄音
10. 完成文字插入

## 技術要求

### HTTP 環境

豆包語音輸入功能需要在 HTTP/HTTPS 環境下執行。

| 環境 | 支援情況 | 說明 |
|------|----------|------|
| **localhost** | ✓ | 本機開發環境（http://localhost 或 http://127.0.0.1） |
| **HTTPS 遠端伺服器** | ✓ | 部署到外網且使用 HTTPS 的 Web 應用 |
| **HTTP 遠端伺服器** | ✗ | 部署到外網但使用 HTTP 的 Web 應用 |
| **file:// 協定** | ✗ | 不支援直接開啟 HTML 檔案 |

:::caution
豆包語音輸入功能存在以下限制：
1. **外網部署必須使用 HTTPS**：由於瀏覽器安全限制，從外網存取時必須使用 HTTPS 協定才能取得麥克風權限
2. **本機位址無限制**：使用 `localhost` 或 `127.0.0.1` 時，HTTP 和 HTTPS 都支援
3. **file:// 協定不支援**：`file://` 協定環境下無法使用麥克風和 WebSocket 連線
:::

### Desktop 版本

HagiCode 的 Desktop 版本內建了 HTTP 環境，完全支援語音輸入功能。你可以直接使用語音辨識，無須額外設定。

### Host 模式

本機 Host 模式支援語音輸入功能：
- 使用 `localhost` 或 `127.0.0.1` 時，HTTP 和 HTTPS 都支援
- 部署到外網時，必須使用 HTTPS

## 設定步驟

### 取得 APP ID

1. 造訪 [豆包語音辨識控制台](https://console.volcengine.com/speech/service/10038)
2. 登入或註冊帳號
3. 進入控制台，建立新的語音辨識應用
4. 在應用詳情頁面，找到並複製 `APP ID`

### 取得 Access Token

1. 在豆包開放平台的控制台中
2. 進入你的語音辨識應用
3. 找到 API 金鑰管理區域
4. 產生或複製 `Access Token`

:::note
請妥善保管你的 `Access Token`，不要將其洩露給他人。如需更換，可以在豆包開放平台重新產生。
:::

### 在產品中設定

1. 開啟 HagiCode 應用程式
2. 進入 **設定** → **語音辨識設定**
3. 在設定表單中填寫以下資訊：
   - **Provider**：選擇 `doubao`（豆包）
   - **APP ID**：貼上你從豆包平台取得的 APP ID
   - **Access Token**：貼上你從豆包平台取得的 Access Token
4. （選填）根據需要調整其他設定參數
5. 點擊 **測試 API Key** 按鈕驗證設定
6. 設定驗證成功後會自動儲存到瀏覽器本機

### 測試 API Key

設定完成後，建議測試 API Key 是否有效：

1. 點擊 **測試 API Key** 按鈕
2. 系統會呼叫測試介面驗證你的設定
3. 如果設定正確，會顯示成功提示
4. 如果設定錯誤，會顯示錯誤訊息，請檢查以下內容：
   - APP ID 和 Access Token 是否正確
   - 網路連線是否正常
   - Access Token 是否已過期

:::tip
如果測試失敗，請先檢查網路連線是否正常，然後確認豆包開放平台的 API 金鑰是否有效且未過期。
:::

## 使用方法

### 找到語音輸入位置

在 HagiCode 中，帶有麥克風圖示的文字輸入框都支援語音輸入。這些元件通常被稱為 `VoiceTextArea`。

常見的語音輸入位置包括：
- 訊息輸入框
- 文字編輯區域
- 需要輸入文字的各種表單欄位

### 啟動語音辨識

1. 找到帶麥克風圖示的輸入框
2. 點擊麥克風按鈕
3. 瀏覽器會請求麥克風權限
4. 點擊 **允許** 授權麥克風存取

:::note
如果你之前已經授權過麥克風，瀏覽器可能不會再次請求權限。如需檢查或變更權限設定，可以在瀏覽器網址列左側的鎖形圖示中查看。
:::

### 錄音狀態說明

授權成功後，語音辨識會自動啟動，你可以看到：

- **波形動畫**：麥克風按鈕內會顯示動態的聲波波形，表示正在錄音
- **時長顯示**：按鈕下方會顯示目前錄音時長
- **即時辨識**：辨識出的文字會暫時顯示在游標位置

### 即時辨識結果顯示

在錄音過程中，語音辨識引擎會即時將你的語音轉換為文字：

- 辨識出的文字會以灰色暫時顯示在輸入框中
- 隨著你的說話，辨識結果會不斷更新
- 支援普通話辨識，準確率較高

:::tip
為了獲得更好的辨識效果，建議：
- 在安靜的環境下使用
- 說話清晰、語速適中
- 避免背景噪音干擾
:::

### 停止辨識

要停止語音辨識，你可以：

1. **點擊麥克風按鈕**：再次點擊按鈕可停止錄音
2. **點擊輸入框**：點擊輸入框的其他區域也會停止錄音

停止後，辨識的最終文字會被正式插入到輸入框中，你可以繼續編輯或傳送。
