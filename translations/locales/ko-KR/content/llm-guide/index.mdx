## 대규모 언어 모델 가이드가 필요한 이유

코드 생성 상황에서는 모델마다 안정성, 속도, 코드 품질, 비용에서 차이가 뚜렷합니다. 이 분류는 통일된 비교 틀을 제공하여 프로젝트 단계별로 모델을 빠르게 고를 수 있도록 돕습니다.

## 권장 읽기 순서

1. 먼저 「[HagiCode에서 사용하는 모델의 비교 및 평가](./model-comparison-evaluation/)」를 읽고 비교 기준을 파악합니다.
2. 프로젝트 목표(품질 우선/비용 우선/속도 우선)에 따라 후보 모델을 고릅니다.
3. 본문의 갱신 시점과 상황 설명을 참고하여 결론이 해당 작업에도 여전히 적용되는지 확인합니다.

## 유지 관리 원칙

- 모델 능력에 뚜렷한 변화가 있을 때마다 평가 결론을 갱신합니다.
- 최소한 매달 한 번 테스트 시점과 결론의 적용 범위를 다시 검토합니다.
- 중국어와 영어 문서의 절 구조를 일치시킵니다.
