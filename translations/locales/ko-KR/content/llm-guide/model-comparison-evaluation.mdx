## 평가 범위와 방법

- **평가 목표**: HagiCode 프로젝트의 실제 연동 경험을 바탕으로 모델 선택 참고 자료를 제공합니다.
- **테스트 작업 유형**: 프런트엔드 컴포넌트 구현, 백엔드 API 리팩터링, 테스트 케이스 보완, 문서 생성.
- **평가 기준**: 효율 완성도(작업을 안정적으로 끝낼 수 있는지)와 가성비(비용 + 중국 내 이용 가능성).

## 테스트 시점과 상황 설명

- **최근 테스트 시점**: 2026-03-08
- **테스트 기간**: 2026-03-01 ~ 2026-03-08
- **표본 설명**: HagiCode 팀의 실제 개발 작업에 대한 주관적 평가이며, 업체의 공식 벤치마크를 대변하는 것은 아닙니다.
- **적용 한계**: 결론은 주로 이 프로젝트의 현재 워크플로와 엔지니어링 제약에 적용되며, 일반적인 결론과 같지 않습니다.

## 이 문서는 실제로 테스트한 모델만 다룹니다

다음 모델은 모두 우리가 프로젝트에 실제로 연동하여 사용해 본 모델입니다.

- GLM 4.7
- GLM 5
- Qwen 3.5
- Qwen Code Next
- GPT 5.3 Codex
- GPT 5.4
- Minimax M2.5

## 모델 비교 개요(실측)

| 모델 이름 | 테스트 시점 | 효율 완성도 | 가성비 | 주요 체감 |
|---------|---------|-----------|--------|---------|
| GPT 5.4 | 2026-03-08 | 매우 높음 | 중상 | 요구를 안정적으로 넘어서며 엔지니어링 실무와 구현 품질이 모두 뛰어남 |
| GPT 5.3 Codex | 2026-03-08 | 매우 높음 | 중상 | 요구 범위 안에서 완성도가 높고 엔지니어링 산출물의 품질이 우수함 |
| GLM 5 | 2026-03-08 | 높음 | 높음 | 작업을 비교적 순조롭게 끝낼 수 있고 종합 성능이 안정적임 |
| GLM 4.7 | 2026-03-08 | 높음 | 매우 높음 | 요구를 비교적 순조롭게 끝낼 수 있고 비용 관리에 더 유리함 |
| Minimax M2.5 | 2026-03-08 | 중상 | 최고 | 대부분의 목표를 달성하지만 코드 닫기 오류가 생기기 쉬움 |
| Qwen 3.5 / Code Next | 2026-03-08 | 중 | 중상 | 우리 상황에서는 완성도가 상대적으로 뒤처짐 |

## 효율 완성도 평가(저자 추천 순서)

"작업 완성 품질 + 엔지니어링 실무 효과" 기준으로 정렬했습니다.

1. GPT 5.4
2. GPT 5.3 Codex
3. GLM 5
4. GLM 4.7
5. Minimax M2.5
6. Qwen(3.5 / Code Next)

### 핵심 결론

- Qwen을 제외한 다른 모델은 우리 프로젝트 작업에서 어느 정도 목표를 달성할 수 있었습니다.
- GLM 4.7 이상(GLM 4.7, GLM 5)은 전반적으로 우리의 요구를 비교적 순조롭게 해냅니다.
- GPT 5.3 Codex와 GPT 5.4는 요구를 달성할 뿐 아니라 대체로 더 나은 엔지니어링 실무와 구현 결과를 내놓습니다.
- Minimax M2.5의 주된 문제는 코드 닫기 오류(예: 괄호나 구조 블록의 닫힘이 불완전함)가 더 쉽게 생겨 추가 검토가 필요하다는 점입니다.

## 가성비 평가(경제적 비용 + 중국 내 이용 가능성)

"비용 대비 효과 + 중국 내에서 순조롭게 사용할 수 있는지"를 우선하여 정렬했습니다.

1. Minimax M2.5
2. GLM 4.7
3. GLM 5
4. Qwen 3.5 / Code Next
5. GPT 5.3 Codex
6. GPT 5.4

> 설명: 이 순서는 효율 완성도 순서와 다르며, 경제적 비용과 입수 가능성이라는 현실적 제약을 주로 반영합니다.

## 모델 선택 권장 사항

- **품질 우선**: GPT 5.4 / GPT 5.3 Codex를 우선합니다.
- **균형 우선**: GLM 5 / GLM 4.7을 우선합니다.
- **비용 우선**: Minimax M2.5를 우선합니다(다만 코드 닫기 검사를 강화해야 합니다).
- **도입 전략**: "고품질 모델은 핵심 작업을, 가성비 높은 모델은 일반 작업을 처리"하는 계층형 라우팅을 권장합니다.

## 테스트하지 않은 모델에 대한 안내

이 문서에 나열되지 않은 다른 모델은 현재 **테스트하지 않았고**, **실제 사용 경험도 없으므로** 평가하지 않습니다.

후원자가 해당 모델 리소스를 제공해 준다면 실제 워크플로와 결합하여 주관적 평가를 계속하고 이 문서를 갱신하겠습니다.
