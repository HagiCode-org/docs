## Обзор

### Что такое голосовой ввод Doubao

Голосовой ввод Doubao — это функция распознавания речи, интегрированная в HagiCode; в основе лежит сервис открытой платформы Doubao от ByteDance. Вы говорите, а система превращает речь в текст. Продукт также учитывает контекст текущего проекта, чтобы лучше распознавать предметную лексику и технические термины.

### Основные сценарии применения

В HagiCode голосовой ввод лучше всего подходит для следующих сценариев:

- **Быстрый ввод предложений**: не нужно печатать — достаточно продиктовать, чтобы быстро создать и отправить предложение, что заметно повышает эффективность
- **Комментарии**: при проверке кода или рецензировании документов быстро добавляйте комментарии и замечания голосом
- **Ответы на сообщения**: в беседах и обсуждениях быстро отвечайте на сообщения голосом — набор текста больше не в тягость
- **Создание объёмных текстов**: быстро создавайте проектную документацию, технические описания, протоколы встреч и другие объёмные тексты

### Какую практическую пользу это даёт

- **Глубокая интеграция и учёт контекста**: HagiCode глубоко интегрирован с распознаванием речи Doubao и автоматически использует контекст текущего проекта (например, структуру кода, стек технологий, предметные термины), чтобы точно распознавать предметную лексику; точность распознавания технических терминов заметно возрастает
- **Бесплатное пробное время**: платформа Doubao предоставляет 20 часов бесплатного распознавания, так что попробовать голосовой ввод можно без каких-либо барьеров
- **Очень высокая скорость**: распознавание в реальном времени — текст появляется прямо во время речи, ждать не нужно
- **Высокая точность**: на основе передовой модели распознавания речи Doubao и в сочетании с контекстом проекта результаты распознавания точны и надёжны
- **Бесшовная интеграция**: функция встроена прямо в поле ввода сообщений HagiCode, переключаться между приложениями не нужно
- **Удобство использования**: достаточно нажать на микрофон, чтобы начать, — просто и наглядно

## Быстрый старт

### Предварительные требования

Прежде чем использовать функцию голосового ввода Doubao, вам понадобится:

1. **Получить аккаунт открытой платформы Doubao**
   - Откройте [консоль распознавания речи Doubao](https://console.volcengine.com/speech/service/10038)
   - Зарегистрируйтесь или войдите в аккаунт

2. **Создать приложение и получить учётные данные**
   - Создайте на платформе приложение для распознавания речи
   - Получите `APP ID` и `Access Token`

3. **Убедиться в наличии сетевого подключения**
   - Сервису распознавания речи требуется подключение к сети
   - Убедитесь, что ваше устройство имеет доступ к API-сервису Doubao

### Основной порядок использования

Ниже приведены основные шаги по использованию голосового ввода Doubao:

1. Получите `APP ID` и `Access Token`
2. Настройте распознавание речи в продукте
3. Проверьте API Key
4. Найдите поле голосового ввода
5. Нажмите кнопку микрофона
6. Предоставьте разрешение на доступ к микрофону
7. Начните запись
8. Следите за результатами распознавания в реальном времени
9. Нажмите кнопку остановки записи
10. Дождитесь вставки текста

## Технические требования

### HTTP-среда

Функция голосового ввода Doubao должна работать в среде HTTP/HTTPS.

| Среда | Поддержка | Описание |
|------|----------|------|
| **localhost** | ✓ | Локальная среда разработки (http://localhost или http://127.0.0.1) |
| **Удалённый HTTPS-сервер** | ✓ | Веб-приложение, развёрнутое во внешней сети с использованием HTTPS |
| **Удалённый HTTP-сервер** | ✗ | Веб-приложение, развёрнутое во внешней сети с использованием HTTP |
| **Протокол file://** | ✗ | Прямое открытие HTML-файла не поддерживается |

:::caution
У функции голосового ввода Doubao есть следующие ограничения:
1. **При развёртывании во внешней сети необходим HTTPS**: из-за ограничений безопасности браузера при доступе из внешней сети для получения разрешения на микрофон нужно использовать протокол HTTPS
2. **Для локальных адресов ограничений нет**: при использовании `localhost` или `127.0.0.1` поддерживаются и HTTP, и HTTPS
3. **Протокол file:// не поддерживается**: в среде с протоколом `file://` микрофон и соединение WebSocket недоступны
:::

### Версия Desktop

В версию Desktop из HagiCode встроена HTTP-среда, и функция голосового ввода поддерживается полностью. Вы можете сразу пользоваться распознаванием речи без дополнительной настройки.

### Режим Host

Локальный режим Host поддерживает функцию голосового ввода:
- при использовании `localhost` или `127.0.0.1` поддерживаются и HTTP, и HTTPS
- при развёртывании во внешней сети необходимо использовать HTTPS

## Шаги настройки

### Получение APP ID

1. Откройте [консоль распознавания речи Doubao](https://console.volcengine.com/speech/service/10038)
2. Войдите в аккаунт или зарегистрируйтесь
3. Перейдите в консоль и создайте новое приложение для распознавания речи
4. На странице сведений о приложении найдите и скопируйте `APP ID`

### Получение Access Token

1. В консоли открытой платформы Doubao
2. Перейдите в своё приложение для распознавания речи
3. Найдите раздел управления API-ключами
4. Создайте или скопируйте `Access Token`

:::note
Храните свой `Access Token` в надёжном месте и никому его не передавайте. При необходимости его можно заменить: создайте новый на открытой платформе Doubao.
:::

### Настройка в продукте

1. Откройте приложение HagiCode
2. Перейдите в **Настройки** → **Настройки распознавания речи**
3. В форме настройки заполните следующие сведения:
   - **Provider**: выберите `doubao` (Doubao)
   - **APP ID**: вставьте APP ID, полученный на платформе Doubao
   - **Access Token**: вставьте Access Token, полученный на платформе Doubao
4. (Необязательно) при необходимости измените остальные параметры конфигурации
5. Нажмите кнопку **Проверить API Key**, чтобы проверить настройку
6. После успешной проверки конфигурация автоматически сохраняется локально в браузере

### Проверка API Key

После настройки рекомендуется проверить, действителен ли API Key:

1. Нажмите кнопку **Проверить API Key**
2. Система вызовет тестовый интерфейс, чтобы проверить вашу конфигурацию
3. Если конфигурация верна, появится сообщение об успехе
4. Если конфигурация неверна, появится сообщение об ошибке — проверьте следующее:
   - правильны ли APP ID и Access Token
   - в порядке ли сетевое подключение
   - не истёк ли срок действия Access Token

:::tip
Если проверка не удалась, сначала убедитесь, что сетевое подключение в порядке, а затем проверьте, что API-ключ на открытой платформе Doubao действителен и его срок не истёк.
:::

## Использование

### Где найти голосовой ввод

В HagiCode голосовой ввод поддерживают текстовые поля со значком микрофона. Эти компоненты обычно называются `VoiceTextArea`.

Типичные места голосового ввода:
- поле ввода сообщений
- области редактирования текста
- различные поля форм, в которые нужно вводить текст

### Запуск распознавания речи

1. Найдите поле ввода со значком микрофона
2. Нажмите кнопку микрофона
3. Браузер запросит разрешение на доступ к микрофону
4. Нажмите **Разрешить**, чтобы предоставить доступ к микрофону

:::note
Если вы уже предоставляли доступ к микрофону, браузер может не запрашивать разрешение повторно. Чтобы проверить или изменить настройки разрешений, нажмите на значок замка слева от адресной строки браузера.
:::

### Состояния записи

После успешной авторизации распознавание речи запускается автоматически, и вы увидите:

- **Анимация волны**: внутри кнопки микрофона отображается динамическая звуковая волна, показывающая, что идёт запись
- **Длительность**: под кнопкой отображается текущая длительность записи
- **Распознавание в реальном времени**: распознанный текст временно отображается в позиции курсора

### Отображение результатов распознавания в реальном времени

Во время записи движок распознавания речи в реальном времени преобразует вашу речь в текст:

- распознанный текст временно отображается в поле ввода серым цветом
- по мере речи результат распознавания постоянно обновляется
- поддерживается распознавание путунхуа с высокой точностью

:::tip
Чтобы добиться лучшего распознавания, рекомендуется:
- пользоваться функцией в тихой обстановке
- говорить чётко и в умеренном темпе
- избегать фонового шума
:::

### Остановка распознавания

Чтобы остановить распознавание речи, можно:

1. **Нажать кнопку микрофона**: повторное нажатие кнопки останавливает запись
2. **Нажать на поле ввода**: щелчок по любой другой области поля ввода тоже останавливает запись

После остановки итоговый распознанный текст окончательно вставляется в поле ввода, и вы можете продолжить редактирование или отправить его.
