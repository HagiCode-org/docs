# Style notes — ru-RU (docs, source zh-CN)

- 源文档(简体中文)的语气与人称保持一致;读者一律用正式的 «вы»(«ваш/ваши»),不用 «ты»。
- 标题用句首大写(只有第一个词和专有名词大写),与站点现有俄文页一致。
- 引号用 «ёлочки»;中文全角标点译为半角俄文标点;不使用全角标点;破折号用 «—»(两侧空格)。
- 列表与表格的句末标点跟随源文档(中文句号译为俄文句号)。
- 「」强调的界面元素名保持强调(粗体或原引号形式);界面术语先查 src/i18n/locales/ru-RU/*.yml,查不到再按术语表翻译。
- `Yes`/`No`、`Enabled`/`Disabled` 这类固定状态词在整个站点内统一译法(进术语表):是/否 → Да/Нет,启用/禁用 → Включено/Отключено。
- 产品名与概念词按术语表的 doNotTranslate 保持原写法(产品名写作 MonoSpecs,文件名保持 `monospecs.yaml`);模型名、供应商名保持拉丁字母。
- Starlight 提示块名保持英文(`:::tip`、`:::note`、`:::caution`、`:::danger`),只翻译方括号里的标题。
- 常见英语技术词(Agent, Skill, Provider, Prompt, Session)可保留原词或用通行俄译,整站统一;数字与单位之间用空格;不硬译专有名词。
