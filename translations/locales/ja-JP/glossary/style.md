# Style notes — ja-JP (docs, source zh-CN)

- 源文档(简体中文)的语气与人称保持一致;文体统一为「です・ます」調。
- 句读使用「、」「。」(全角);括号、冒号、感叹号等汉字紧邻处用全角;行内代码与其后日文之间的标点同样用全角。
- 读者称呼以省略为基本,必要时也不用「あなた」;不用「お客様」之类敬称。
- 日文与英文、数字之间不强制加空格,但产品名/代码与日文相邻时沿用现有日文页的写法(英文单词前后可不加空格,保持一篇内一致)。
- 列表与表格的句末标点跟随源文档(中文句号译为「。」)。
- 「」或粗体强调的界面元素名保持强调形式;界面术语以 src/i18n/locales/ja-JP/*.yml 现成译法为准。
- `Yes`/`No`、`Enabled`/`Disabled` 这类固定状态词在整个站点内统一译法(进术语表)。
- 产品名与概念词按术语表的 doNotTranslate 保持原写法(MonoSpecs 的文件名仍为 `monospecs.yaml`)。
- 小节标题固定译法见术语表(下一步=次のステップ、前置条件/先决条件=前提条件)。
