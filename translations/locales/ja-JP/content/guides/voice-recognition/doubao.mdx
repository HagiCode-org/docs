## 概要

### Doubao 音声入力とは

Doubao 音声入力は、HagiCode に統合された音声認識機能で、内部では ByteDance の Doubao オープンプラットフォームのサービスを利用しています。話しかけると、システムが音声をテキストに変換します。さらに、現在のプロジェクトのコンテキストも踏まえて、専門分野の語彙や技術用語の認識を助けます。

### 主な利用シーン

HagiCode では、次のような場面で音声入力を直接使うのが適しています。

- **提案をすばやく入力**：タイピングせずに、口述するだけで提案を作成して提出でき、効率が大きく向上します
- **コメントの入力**：コードレビューやドキュメントレビューの際に、音声でコメントやフィードバックをすばやく追加できます
- **メッセージへの返信**：会話や議論の中で、音声ですばやく返信でき、タイピングが負担になりません
- **長文コンテンツの作成**：プロジェクトのドキュメント、技術的な説明、議事録などの長文をすばやく作成できます

### 実際に得られるメリット

- **深い統合とコンテキスト認識**：HagiCode は Doubao の音声認識と深く統合されており、現在のプロジェクトのコンテキスト（コード構造、技術スタック、専門用語など）を自動的に活用して、分野特有の語彙を的確に認識します。技術用語の認識精度が大幅に向上します
- **無料トライアル時間**：Doubao プラットフォームは 20 時間分の無料認識時間を提供しており、ハードルなしで音声入力を体験できます
- **非常に高速**：リアルタイムで認識され、話しながら文字が表示されるため、待つ必要がありません
- **高い精度**：Doubao の先進的な音声認識モデルにプロジェクトのコンテキストを組み合わせることで、認識結果が正確で信頼できます
- **シームレスな統合**：HagiCode のメッセージ入力欄に直接統合されているため、アプリを切り替える必要がありません
- **使いやすさ**：マイクをクリックするだけで開始でき、シンプルで直感的です

## クイックスタート

### 前提条件

Doubao 音声入力を使う前に、次の準備が必要です。

1. **Doubao オープンプラットフォームのアカウントを取得する**
   - [Doubao 音声認識コンソール](https://console.volcengine.com/speech/service/10038)にアクセスします
   - アカウントを登録するか、ログインします

2. **アプリケーションを作成して認証情報を取得する**
   - プラットフォーム上で音声認識アプリケーションを作成します
   - `APP ID` と `Access Token` を取得します

3. **ネットワーク接続を確認する**
   - 音声認識サービスにはネットワーク接続が必要です
   - お使いのデバイスから Doubao の API サービスにアクセスできることを確認します

### 基本的な使い方の流れ

Doubao 音声入力を使う基本的な手順は次のとおりです。

1. `APP ID` と `Access Token` を取得する
2. 製品で音声認識を設定する
3. API Key をテストする
4. 音声入力欄を見つける
5. マイクボタンをクリックする
6. マイクの権限を許可する
7. 録音を開始する
8. 認識結果をリアルタイムで確認する
9. クリックして録音を停止する
10. テキストの挿入を完了する

## 技術要件

### HTTP 環境

Doubao 音声入力機能は、HTTP/HTTPS 環境で動作する必要があります。

| 環境 | 対応状況 | 説明 |
|------|----------|------|
| **localhost** | ✓ | ローカル開発環境（http://localhost または http://127.0.0.1） |
| **HTTPS リモートサーバー** | ✓ | 外部ネットワークにデプロイされ、HTTPS を使用している Web アプリケーション |
| **HTTP リモートサーバー** | ✗ | 外部ネットワークにデプロイされているが、HTTP を使用している Web アプリケーション |
| **file:// プロトコル** | ✗ | HTML ファイルを直接開く方法には対応していません |

:::caution
Doubao 音声入力機能には、次の制限があります。
1. **外部ネットワークへのデプロイでは HTTPS が必須**：ブラウザのセキュリティ制限により、外部ネットワークからアクセスする場合は、マイクの権限を取得するために HTTPS プロトコルを使用する必要があります
2. **ローカルアドレスには制限なし**：`localhost` または `127.0.0.1` を使う場合は、HTTP と HTTPS のどちらにも対応しています
3. **file:// プロトコルは非対応**：`file://` プロトコル環境では、マイクと WebSocket 接続を使用できません
:::

### Desktop 版

HagiCode の Desktop 版には HTTP 環境が組み込まれているため、音声入力機能に完全に対応しています。追加の設定なしで、そのまま音声認識を使えます。

### Host モード

ローカルの Host モードでは、音声入力機能に対応しています。
- `localhost` または `127.0.0.1` を使う場合は、HTTP と HTTPS のどちらにも対応しています
- 外部ネットワークにデプロイする場合は、HTTPS が必須です

## 設定手順

### APP ID を取得する

1. [Doubao 音声認識コンソール](https://console.volcengine.com/speech/service/10038)にアクセスします
2. ログインするか、アカウントを登録します
3. コンソールに入り、新しい音声認識アプリケーションを作成します
4. アプリケーションの詳細ページで `APP ID` を見つけてコピーします

### Access Token を取得する

1. Doubao オープンプラットフォームのコンソールで
2. 自分の音声認識アプリケーションを開きます
3. API キー管理の領域を見つけます
4. `Access Token` を生成するか、コピーします

:::note
`Access Token` は大切に保管し、他人に漏らさないでください。変更したい場合は、Doubao オープンプラットフォームで再生成できます。
:::

### 製品で設定する

1. HagiCode アプリを開きます
2. **設定** → **音声認識設定**を開きます
3. 設定フォームに次の情報を入力します。
   - **Provider**：`doubao`（豆包）を選択します
   - **APP ID**：Doubao プラットフォームで取得した APP ID を貼り付けます
   - **Access Token**：Doubao プラットフォームで取得した Access Token を貼り付けます
4. （任意）必要に応じて、その他の設定パラメーターを調整します
5. **API Key をテスト**ボタンをクリックして、設定を検証します
6. 設定の検証に成功すると、ブラウザのローカルに自動で保存されます

### API Key をテストする

設定が完了したら、API Key が有効かどうかをテストすることをおすすめします。

1. **API Key をテスト**ボタンをクリックします
2. システムがテスト用のインターフェースを呼び出して、設定を検証します
3. 設定が正しければ、成功のメッセージが表示されます
4. 設定が誤っている場合はエラーメッセージが表示されるので、次の点を確認してください。
   - APP ID と Access Token が正しいか
   - ネットワーク接続が正常か
   - Access Token の有効期限が切れていないか

:::tip
テストに失敗した場合は、まずネットワーク接続が正常かを確認し、そのうえで Doubao オープンプラットフォームの API キーが有効で、期限切れでないことを確認してください。
:::

## 使い方

### 音声入力できる場所を探す

HagiCode では、マイクアイコンのあるテキスト入力欄が音声入力に対応しています。これらのコンポーネントは通常、`VoiceTextArea` と呼ばれます。

音声入力できる主な場所は次のとおりです。
- メッセージ入力欄
- テキスト編集エリア
- テキストの入力が必要なさまざまなフォーム項目

### 音声認識を開始する

1. マイクアイコンのある入力欄を見つけます
2. マイクボタンをクリックします
3. ブラウザがマイクの権限を求めます
4. **許可**をクリックして、マイクへのアクセスを許可します

:::note
以前にマイクを許可している場合は、ブラウザが権限を再度求めないことがあります。権限の設定を確認または変更したいときは、ブラウザのアドレスバーの左側にある鍵アイコンから確認できます。
:::

### 録音状態の説明

許可が成功すると、音声認識が自動で開始され、次の表示が確認できます。

- **波形アニメーション**：マイクボタンの中に動的な音声波形が表示され、録音中であることを示します
- **時間表示**：ボタンの下に、現在の録音時間が表示されます
- **リアルタイム認識**：認識されたテキストが、カーソル位置に仮表示されます

### リアルタイムの認識結果の表示

録音中、音声認識エンジンはあなたの音声をリアルタイムで文字に変換します。

- 認識されたテキストは、入力欄に灰色で仮表示されます
- 話すにつれて、認識結果が更新され続けます
- 標準中国語（普通話）の認識に対応しており、精度は高めです

:::tip
より良い認識結果を得るために、次のことをおすすめします。
- 静かな環境で使う
- はっきりと、適度な速さで話す
- 背景ノイズの影響を避ける
:::

### 認識を停止する

音声認識を停止するには、次のいずれかの方法があります。

1. **マイクボタンをクリックする**：もう一度ボタンをクリックすると、録音が停止します
2. **入力欄をクリックする**：入力欄のほかの部分をクリックしても、録音が停止します

停止すると、認識された最終的なテキストが入力欄に正式に挿入されるので、そのまま編集や送信を続けられます。
