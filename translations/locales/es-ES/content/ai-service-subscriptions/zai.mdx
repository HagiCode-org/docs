## Posicionamiento del servicio

Zhipu AI es una de las vías de suscripción a Claude Code recomendadas en el preset actual de la documentación. El plan GLM Coding y su asignación a varios modelos son adecuados para desarrolladores que usan Claude Code como herramienta principal en su día a día.

## Para quién es adecuado

- Quienes desean un plan pensado específicamente para escenarios de programación
- Quienes necesitan una asignación de modelos bastante completa para los niveles de Claude
- Quienes quieren cubrir con un solo servicio varias herramientas, como Claude Code y Cline

## Aspectos que conviene tener en cuenta primero

- El preset actual marca Zhipu AI como proveedor recomendado.
- Ofrece una interfaz compatible con Anthropic, lo que facilita la conexión directa con Claude Code.
- El preset incluye asignaciones de modelos predeterminadas como `glm-4.7`, `glm-5` y `glm-4.5-air`.

## Datos clave de integración

| Elemento | Contenido |
|------|------|
| Acceso a la suscripción | [Ir a la página de suscripción](https://www.bigmodel.cn/claude-code?ic=14BY54APZA) |

| URL base compatible con Anthropic | `https://open.bigmodel.cn/api/anthropic` |
| Variable de entorno de autenticación recomendada | `ANTHROPIC_AUTH_TOKEN` |

## Asignación de modelos predeterminada

| Nivel de Claude | Modelo predeterminado |
|-------------|----------|
| Sonnet | `glm-4.7` |
| Opus | `glm-5` |
| Haiku | `glm-4.5-air` |

:::tip
Los planes, las promociones y los beneficios cambian con el tiempo; si le interesa más el precio en tiempo real, consulte directamente la página de suscripción del proveedor.
:::

## Recomendaciones de configuración

1. Confirme primero el plan que desea usar o la forma de activar la API Key.
2. A continuación, abra la entrada de Claude Code en la página unificada de AI Agent CLI y continúe hacia la documentación oficial de instalación y referencia de Anthropic.
3. Una vez terminado, puede ejecutar `claude --version` en local, revisar el archivo de configuración o hacer una solicitud real para comprobar que la integración funciona.
