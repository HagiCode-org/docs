## Posicionamiento del servicio

Alibaba Cloud DashScope es una de las vías de suscripción a Claude Code recomendadas en el preset actual de la documentación. Es adecuado para equipos que ya trabajan en el ecosistema de Alibaba Cloud y desean unificar la suscripción, la consola y la gestión de claves en la plataforma en la nube.

## Para quién es adecuado

- Equipos que ya usan la consola o los recursos en la nube de Alibaba Cloud
- Quienes desean gestionar los servicios y las API Key desde una plataforma en la nube unificada
- Quienes desean empezar a usar Claude Code con rapidez mediante una asignación de modelos fija

## Aspectos que conviene tener en cuenta primero

- El preset actual marca Alibaba Cloud DashScope como proveedor recomendado.
- Usa `glm-4.7` como modelo asignado por defecto, con una ruta de configuración clara.
- Si el equipo ya cuenta con un sistema de cuentas de Alibaba Cloud, la integración y la gestión de permisos resultarán más cómodas.

## Datos clave de integración

| Elemento | Contenido |

| Nivel de Claude | Modelo predeterminado |
|-------------|----------|

| Opus | `glm-4.7` |
| Haiku | `glm-4.7` |

:::tip
Los planes, las promociones y los beneficios cambian con el tiempo; si le interesa más el precio en tiempo real, consulte directamente la página de suscripción del proveedor.
:::

## Recomendaciones de configuración

1. Confirme primero el plan que desea usar o la forma de activar la API Key.
2. A continuación, abra la entrada de Claude Code en la página unificada de AI Agent CLI y continúe hacia la documentación oficial de instalación y referencia de Anthropic.
3. Una vez terminado, puede ejecutar `claude --version` en local, revisar el archivo de configuración o hacer una solicitud real para comprobar que la integración funciona.
