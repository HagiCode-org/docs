## Überblick

### Was ist die Doubao-Spracheingabe

Die Doubao-Spracheingabe ist eine in HagiCode integrierte Spracherkennungsfunktion, die im Hintergrund den Dienst der Doubao Open Platform von ByteDance nutzt. Sie sprechen, und das System wandelt die Sprache in Text um. Das Produkt berücksichtigt dabei zusätzlich den Kontext des aktuellen Projekts und hilft so, Fachvokabular und technische Begriffe zu erkennen.

### Wichtige Anwendungsszenarien

In HagiCode eignen sich die folgenden Szenarien besonders gut für die Spracheingabe:

- **Proposals schnell eingeben**: Ohne zu tippen können Sie Proposals einfach diktieren, schnell erstellen und einreichen, was die Effizienz erheblich steigert
- **Kommentare verfassen**: Fügen Sie bei Code-Reviews oder Dokumentenprüfungen per Sprache schnell Kommentare und Rückmeldungen hinzu
- **Nachrichten beantworten**: Antworten Sie in Unterhaltungen und Diskussionen schnell per Sprache auf Nachrichten, sodass Tippen keine Last mehr ist
- **Längere Inhalte erstellen**: Erstellen Sie schnell Projektdokumentation, technische Beschreibungen, Besprechungsprotokolle und andere längere Inhalte

### Der praktische Nutzen

- **Tiefe Integration und Kontextbewusstsein**: HagiCode ist tief in die Doubao-Spracherkennung integriert und nutzt automatisch den Kontext des aktuellen Projekts (etwa Codestruktur, Technologie-Stack und Fachterminologie), um Fachvokabular präzise zu erkennen; die Erkennungsgenauigkeit bei technischen Begriffen steigt dadurch deutlich
- **Kostenlose Testzeit**: Die Doubao-Plattform bietet 20 Stunden kostenlose Erkennungszeit, sodass Sie die Spracheingabe ohne Hürden ausprobieren können
- **Extrem schnell**: Echtzeiterkennung; Sie sehen den Text, während Sie sprechen, ohne zu warten
- **Hohe Genauigkeit**: Auf Grundlage der fortschrittlichen Spracherkennungsmodelle von Doubao und in Verbindung mit dem Projektkontext sind die Ergebnisse präzise und zuverlässig
- **Nahtlose Integration**: Direkt in das Nachrichteneingabefeld von HagiCode eingebunden, ohne die Anwendung wechseln zu müssen
- **Einfache Bedienung**: Ein Klick auf das Mikrofon genügt, einfach und intuitiv

## Schnellstart

### Voraussetzungen

Bevor Sie die Doubao-Spracheingabe verwenden, benötigen Sie Folgendes:

1. **Ein Konto bei der Doubao Open Platform erhalten**
   - Rufen Sie die [Doubao-Spracherkennungskonsole](https://console.volcengine.com/speech/service/10038) auf
   - Registrieren Sie ein Konto oder melden Sie sich an

2. **Eine Anwendung erstellen und Zugangsdaten abrufen**
   - Erstellen Sie auf der Plattform eine Spracherkennungsanwendung
   - Rufen Sie `APP ID` und `Access Token` ab

3. **Netzwerkverbindung sicherstellen**
   - Der Spracherkennungsdienst benötigt eine Netzwerkverbindung
   - Stellen Sie sicher, dass Ihr Gerät auf den Doubao-API-Dienst zugreifen kann

### Grundlegender Ablauf

Die grundlegenden Schritte zur Nutzung der Doubao-Spracheingabe:

1. `APP ID` und `Access Token` abrufen
2. Die Spracherkennung im Produkt konfigurieren
3. API Key testen
4. Das Spracheingabefeld finden
5. Auf die Mikrofonschaltfläche klicken
6. Die Mikrofonberechtigung erteilen
7. Die Aufnahme starten
8. Die Erkennungsergebnisse in Echtzeit ansehen
9. Zum Beenden der Aufnahme klicken
10. Das Einfügen des Textes abschließen

## Technische Anforderungen

### HTTP-Umgebung

Die Doubao-Spracheingabe muss in einer HTTP/HTTPS-Umgebung ausgeführt werden.

| Umgebung | Unterstützung | Beschreibung |
|------|----------|------|
| **localhost** | ✓ | Lokale Entwicklungsumgebung (http://localhost oder http://127.0.0.1) |
| **HTTPS-Remote-Server** | ✓ | Im Internet bereitgestellte Webanwendungen, die HTTPS verwenden |
| **HTTP-Remote-Server** | ✗ | Im Internet bereitgestellte Webanwendungen, die HTTP verwenden |
| **file://-Protokoll** | ✗ | Das direkte Öffnen von HTML-Dateien wird nicht unterstützt |

:::caution
Für die Doubao-Spracheingabe gelten die folgenden Einschränkungen:
1. **Bei Bereitstellung im Internet ist HTTPS erforderlich**: Aufgrund von Sicherheitsbeschränkungen des Browsers muss beim Zugriff aus dem Internet das HTTPS-Protokoll verwendet werden, um die Mikrofonberechtigung zu erhalten
2. **Lokale Adressen sind nicht eingeschränkt**: Bei `localhost` oder `127.0.0.1` werden sowohl HTTP als auch HTTPS unterstützt
3. **Das file://-Protokoll wird nicht unterstützt**: In einer Umgebung mit dem `file://`-Protokoll können Mikrofon und WebSocket-Verbindung nicht verwendet werden
:::

### Desktop-Version

Die Desktop-Version von HagiCode enthält eine eigene HTTP-Umgebung und unterstützt die Spracheingabe vollständig. Sie können die Spracherkennung direkt nutzen, ohne zusätzliche Konfiguration.

### Host-Modus

Der lokale Host-Modus unterstützt die Spracheingabe:
- Bei `localhost` oder `127.0.0.1` werden sowohl HTTP als auch HTTPS unterstützt
- Bei Bereitstellung im Internet muss HTTPS verwendet werden

## Konfigurationsschritte

### APP ID abrufen

1. Rufen Sie die [Doubao-Spracherkennungskonsole](https://console.volcengine.com/speech/service/10038) auf
2. Melden Sie sich an oder registrieren Sie ein Konto
3. Öffnen Sie die Konsole und erstellen Sie eine neue Spracherkennungsanwendung
4. Suchen Sie auf der Detailseite der Anwendung die `APP ID` und kopieren Sie sie

### Access Token abrufen

1. Rufen Sie die Konsole der Doubao Open Platform auf
2. Öffnen Sie Ihre Spracherkennungsanwendung
3. Suchen Sie den Bereich für die Verwaltung der API-Schlüssel
4. Erzeugen oder kopieren Sie den `Access Token`

:::note
Bewahren Sie Ihren `Access Token` sorgfältig auf und geben Sie ihn nicht an andere weiter. Wenn Sie ihn ersetzen möchten, können Sie ihn auf der Doubao Open Platform neu erzeugen.
:::

### Im Produkt konfigurieren

1. Öffnen Sie die HagiCode-Anwendung
2. Gehen Sie zu **Einstellungen** → **Spracherkennungseinstellungen**
3. Tragen Sie im Konfigurationsformular die folgenden Angaben ein:
   - **Provider**: Wählen Sie `doubao` (Doubao)
   - **APP ID**: Fügen Sie die APP ID ein, die Sie von der Doubao-Plattform erhalten haben
   - **Access Token**: Fügen Sie den Access Token ein, den Sie von der Doubao-Plattform erhalten haben
4. (Optional) Passen Sie bei Bedarf weitere Konfigurationsparameter an
5. Klicken Sie auf die Schaltfläche **API Key testen**, um die Konfiguration zu überprüfen
6. Nach erfolgreicher Überprüfung wird die Konfiguration automatisch lokal im Browser gespeichert

### API Key testen

Nach Abschluss der Konfiguration empfiehlt es sich, zu testen, ob der API Key gültig ist:

1. Klicken Sie auf die Schaltfläche **API Key testen**
2. Das System ruft eine Testschnittstelle auf, um Ihre Konfiguration zu überprüfen
3. Ist die Konfiguration korrekt, wird eine Erfolgsmeldung angezeigt
4. Ist die Konfiguration fehlerhaft, wird eine Fehlermeldung angezeigt; prüfen Sie dann Folgendes:
   - Ob APP ID und Access Token korrekt sind
   - Ob die Netzwerkverbindung in Ordnung ist
   - Ob der Access Token abgelaufen ist

:::tip
Wenn der Test fehlschlägt, prüfen Sie zuerst, ob die Netzwerkverbindung in Ordnung ist, und vergewissern Sie sich dann, dass der API-Schlüssel der Doubao Open Platform gültig und nicht abgelaufen ist.
:::

## Verwendung

### Den Ort der Spracheingabe finden

In HagiCode unterstützen alle Texteingabefelder mit einem Mikrofonsymbol die Spracheingabe. Diese Komponenten heißen in der Regel `VoiceTextArea`.

Häufige Orte für die Spracheingabe sind:
- Nachrichteneingabefelder
- Textbearbeitungsbereiche
- Verschiedene Formularfelder, in die Text eingegeben werden muss

### Spracherkennung starten

1. Suchen Sie ein Eingabefeld mit Mikrofonsymbol
2. Klicken Sie auf die Mikrofonschaltfläche
3. Der Browser fordert die Mikrofonberechtigung an
4. Klicken Sie auf **Zulassen**, um den Mikrofonzugriff zu erlauben

:::note
Wenn Sie dem Mikrofon zuvor bereits Zugriff erteilt haben, fordert der Browser die Berechtigung möglicherweise nicht erneut an. Um die Berechtigungseinstellungen zu prüfen oder zu ändern, klicken Sie in der Adressleiste des Browsers auf das Schlosssymbol links neben der Adresse.
:::

### Erläuterung der Aufnahmezustände

Nach erfolgreicher Autorisierung startet die Spracherkennung automatisch, und Sie sehen Folgendes:

- **Wellenformanimation**: Auf der Mikrofonschaltfläche wird eine bewegte Schallwellenform angezeigt, die signalisiert, dass aufgenommen wird
- **Dauer**: Unter der Schaltfläche wird die aktuelle Aufnahmedauer angezeigt
- **Echtzeiterkennung**: Der erkannte Text wird vorläufig an der Cursorposition angezeigt

### Anzeige der Erkennungsergebnisse in Echtzeit

Während der Aufnahme wandelt die Spracherkennungs-Engine Ihre Sprache in Echtzeit in Text um:

- Der erkannte Text wird im Eingabefeld vorläufig in Grau angezeigt
- Während Sie sprechen, werden die Erkennungsergebnisse laufend aktualisiert
- Mandarin wird mit hoher Genauigkeit erkannt

:::tip
Für bessere Erkennungsergebnisse empfehlen wir:
- Nutzung in einer ruhigen Umgebung
- Deutlich und in mäßigem Tempo sprechen
- Störgeräusche im Hintergrund vermeiden
:::

### Erkennung beenden

Um die Spracherkennung zu beenden, haben Sie folgende Möglichkeiten:

1. **Auf die Mikrofonschaltfläche klicken**: Ein erneuter Klick auf die Schaltfläche beendet die Aufnahme
2. **In das Eingabefeld klicken**: Auch ein Klick auf eine andere Stelle des Eingabefelds beendet die Aufnahme

Nach dem Beenden wird der endgültig erkannte Text in das Eingabefeld eingefügt, und Sie können ihn weiter bearbeiten oder absenden.
