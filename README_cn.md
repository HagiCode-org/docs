# HagiCode Docs

[![website](https://img.shields.io/website?url=https%3A%2F%2Fdocs.hagicode.com&label=website)](https://docs.hagicode.com)

[English](./README.md)

HagiCode Docs 是 HagiCode 的文档站，集中提供产品介绍、安装说明、上手教程、功能指南和版本更新说明，帮助你根据当前任务找到下一步。

**[开始阅读文档 →](https://docs.hagicode.com/)**

## 适合谁阅读

- **正在了解 HagiCode 的人**：了解它能做什么，以及如何用于自己的开发工作。
- **准备开始使用的新用户**：选择安装方式，完成初始化设置，开始第一次会话。
- **已经在使用的用户**：查阅功能用法、寻找常见问题的答案，了解版本变化。

## 你能找到什么

- [产品概览](https://docs.hagicode.com/product-overview/)：了解主要概念，以及 HagiCode 能帮你完成哪些工作。
- [安装指南](https://docs.hagicode.com/installation/)：选择安装方式，确认所需的前置条件。
- [快速上手](https://docs.hagicode.com/quick-start/wizard-setup/)：跟随初始化向导，准备好第一个项目。
- [使用手册](https://docs.hagicode.com/user-guide/)：查阅项目、会话、Agent 和设置等功能的操作说明。
- [常见问题](https://docs.hagicode.com/faq/)：查看常见疑问、使用技巧和排障指引。
- [更新说明](https://docs.hagicode.com/release-notes/)：了解不同版本之间的变化。
- [博客](https://docs.hagicode.com/blog/)：阅读专题文章与实践教程。

## 从这里开始

1. 阅读[安装指南](https://docs.hagicode.com/installation/)，选择安装方式并准备好前置条件。
2. 完成[初始化向导](https://docs.hagicode.com/quick-start/wizard-setup/)，设置 Agent 并创建第一个项目。
3. 创建[第一次普通会话](https://docs.hagicode.com/quick-start/conversation-session/)，开始使用 HagiCode。

你可以通过文档站的语言选择器，切换到自己偏好的阅读语言。
