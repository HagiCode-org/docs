# HagiCode Docs

[![website](https://img.shields.io/website?url=https%3A%2F%2Fdocs.hagicode.com&label=website)](https://docs.hagicode.com)

[简体中文](./README_cn.md)

HagiCode Docs is the documentation site for HagiCode. It brings product introductions, installation instructions, tutorials, feature guides, and release notes together so you can find the next step for your task.

**[Read the documentation →](https://docs.hagicode.com/en-US/)**

## Who it's for

- **Exploring HagiCode:** Understand what it does and how it fits your development work.
- **Getting started:** Choose an installation method, complete the initial setup, and begin your first session.
- **Already using HagiCode:** Look up feature behavior, find answers to common questions, and review release changes.

## What you'll find

- [Product overview](https://docs.hagicode.com/en-US/product-overview/) — Learn the main concepts and what HagiCode can help you do.
- [Installation](https://docs.hagicode.com/en-US/installation/) — Choose an installation method and check its prerequisites.
- [Quick start](https://docs.hagicode.com/en-US/quick-start/wizard-setup/) — Follow the setup wizard and prepare your first project.
- [User guide](https://docs.hagicode.com/en-US/user-guide/) — Find instructions for projects, sessions, Agents, and settings.
- [FAQ](https://docs.hagicode.com/en-US/faq/) — Browse common questions, usage tips, and troubleshooting guidance.
- [Release notes](https://docs.hagicode.com/en-US/release-notes/) — Read about changes between versions.
- [Blog](https://docs.hagicode.com/en-US/blog/) — Explore articles and practical tutorials.

## Start reading

1. Follow the [installation guide](https://docs.hagicode.com/en-US/installation/) to choose a method and prepare the prerequisites.
2. Complete the [initialization wizard](https://docs.hagicode.com/en-US/quick-start/wizard-setup/) to set up your Agent and first project.
3. Create your [first conversation session](https://docs.hagicode.com/en-US/quick-start/conversation-session/) to start working with HagiCode.

Use the documentation site's language selector to choose your preferred reading language.
