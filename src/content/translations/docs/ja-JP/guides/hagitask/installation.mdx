---
title: HagiTask のインストール
description: Community Gallery またはアーカイブから HagiTask のタスクパッケージをインストールし、結果を確認する方法を説明します。
---

**対象読者：** コミュニティタスクをインストールして HagiCode で使いたい方。

**前提条件：**

- 現在使用している HagiCode アプリとバックエンドサービスにアクセスできること。
- アプリのバージョンが HagiTask のコミュニティタスク管理と Community Gallery に対応していること。
- タスクに必要な agent、skills、CLI の依存関係を準備していること。要件はタスクの詳細で確認できます。

## Community Gallery からインストールする

現在サポートされている手順では、HagiTask Site の Community Gallery からタスクの詳細と ZIP アーカイブを取得し、アプリのコミュニティタスクのインストール機能に渡します。

1. Gallery でタスク名、カテゴリ、タグからタスクを探します。
2. タスクの詳細を開き、バージョン、公開者、互換性、インストールサイズを確認します。
3. インストールを選択します。アプリは `packageUrl` から ZIP を取得し、タスク ID、バージョン、SHA-256 を検証します。
4. 検証に通ると、アプリはパッケージをローカルの HagiTask データディレクトリに書き込み、タスク一覧を更新します。

Gallery のタスク検出、詳細、アーカイブの入口は、それぞれ `/index.json`、`/tasks/<taskId>.json`、`/packages/<taskId>.zip` です。インストールにはアーカイブを使用し、サイトのページ本文を解析する必要はありません。

### アーカイブファイルを使う

サポートされている Gallery の手順で ZIP をすでに取得している場合は、アプリのコミュニティタスク管理画面でローカルアーカイブからのインストールを選択できます。アーカイブには完全なタスクパッケージのディレクトリが含まれ、内部の ID、バージョン、コンテンツのダイジェストがインストール要求と一致している必要があります。

ブラウザ上のローカルフォルダーのアップロードは、現在の Community Gallery のインストール手順には含まれません。サーバー側のフォルダーをソースとして設定する操作には別の用途があります。詳しくは[HagiTask の使い方](/ja-JP/guides/hagitask/usage)を参照してください。

## インストール結果を確認する

インストール後、コミュニティタスク管理画面で次の点を確認してください。

- 正しい `taskId`、バージョン、公開者が表示されている。
- タスクが有効になっているか、手動で有効にできる。
- タスクの依存関係と互換性に関する表示に、満たされていない要件がない。
- 一覧を更新してもタスクが残り、タスクパネルを開ける。

インストール記録には、提供元、バージョン、アーカイブのダイジェスト、有効化状態が保存されます。組み込みタスクは読み取り専用で表示され、コミュニティパッケージとしてアンインストールすることはできません。

## よくある問題

### Gallery にアクセスできない

アプリに設定された Gallery のアドレスが利用可能で HTTPS を使用していることを確認し、ネットワーク、タイムアウト、サイトの状態を調べてください。初めて一覧を取得する際に失敗しても、アプリが空の一覧を偽って作ることはありません。有効なキャッシュがあれば、古い一覧が一時的に表示される場合があります。

### タスクが見つからない、または詳細が無効

表示用の別名ではなく、詳細に記載された正規の `taskId` を使ってください。`agentsmd` と `portytail` は、それぞれ `claude-md-update` と `ponytail` を指す人間向けの別名であり、インストール可能なタスク ID ではありません。

### 整合性またはバージョンの検証に失敗する

Gallery からアーカイブを再取得してください。ZIP や生成された一覧ファイルを手動で変更しないでください。それでも失敗する場合は、パッケージのメンテナーに連絡し、Community Packages のソースデータとバージョン番号を確認してもらってください。

### インストール後に利用できない

タスクの詳細にある agent、skills、CLI の要件を確認し、アプリでタスクを有効にして一覧を更新してください。パッケージの内容自体が無効な場合は、Schema と検証手順について[コミュニティ貢献ガイド](/ja-JP/guides/hagitask/community)を参照してください。
