**対象読者：** HagiTask のエコシステムを知りたい利用者、メンテナー、コントリビューター。

**前提条件：** ありません。タスクのインストールや実行には、HagiCode アプリとそのバックエンドサービスを準備してください。

## HagiTask とは

HagiTask は、HagiCode のタスクパッケージとプリセットタスクのモデルです。タスクパッケージは、タスクの識別情報、フロントエンドのパネル、バックエンドのプロンプト、テンプレート、UI の文言、ストアでの紹介文を、検証可能な一つのディレクトリにまとめます。アプリはこれを使ってタスクを検出、インストール、管理、実行できます。

タスクパッケージはアプリそのものではなく、アプリの実行時設定に代わるものでもありません。アプリがタスクを読み込み、タスクに宣言された機能を実行します。タスクパッケージが提供するのは、規定の形式で整理されたリソースだけです。

## エコシステムを構成する役割

| 役割 | 担当 |
| --- | --- |
| HagiTask | 共通 Schema と製品に同梱される組み込みプリセットパッケージを管理し、パッケージ形式の source of truth となります。 |
| 組み込みプリセット | アプリまたはランタイムに付属する利用可能なタスクです。例：`normal-session`、`research-investigation`。 |
| Community Packages | コミュニティタスクのソースデータを `data/<taskId>/` で管理します。 |
| HagiTask Site | コミュニティパッケージのソースから一覧、詳細 JSON、ZIP アーカイブを生成し、Community Gallery に公開します。 |
| HagiCode アプリ | タスクを表示し、パッケージをインストールして有効化状態を保存し、実行時にタスクを実行します。 |

組み込みプリセットとコミュニティタスクは同じパッケージ Schema を使用しますが、提供元とライフサイクルは異なります。組み込みプリセットは HagiTask リポジトリ、コミュニティタスクは Community Packages リポジトリで管理されます。サイトの `/index.json`、詳細ドキュメント、ZIP はいずれも生成物であり、コントリビューターが直接編集するソースファイルではありません。

## パッケージ管理とソース管理は別の操作

Gallery から ZIP をインストールすると、パッケージがアプリのデータディレクトリにコピーされ、バージョン、提供元、有効化状態が記録されます。一方、サーバーのソース管理では、ランタイムがタスクを検出できるよう、サーバーから参照可能なディレクトリを設定します。ブラウザ上のローカルフォルダーをインストール用パッケージとしてアップロードする操作ではありません。

操作上の区別とフォルダーをソースにする方法は、[HagiTask の使い方](/ja-JP/guides/hagitask/usage)を参照してください。インストールする場合は[HagiTask のインストール](/ja-JP/guides/hagitask/installation)、タスクを作成・公開する場合は[コミュニティへの貢献](/ja-JP/guides/hagitask/community)を参照してください。

## Source of truth の責任範囲

- docs は利用者とコントリビューター向けの説明と操作ガイドを管理します。
- HagiTask は共通 Schema と組み込みプリセットのソースを管理します。
- Community Packages はコミュニティパッケージのソースデータを管理します。
- HagiTask Site はパッケージのソースから生成された一覧、詳細、アーカイブを公開します。
