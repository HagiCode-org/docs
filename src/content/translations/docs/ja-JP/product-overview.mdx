HagiCode は、AI がコードを変更するときに文脈を見失わないようにします。**まずリポジトリを理解し、範囲を決め、追跡できる形で実行します。**HagiCode はプロジェクト開発向けの AI ワークスペースで、普段使っている Agent CLI とモデルを接続するため、エディターを乗り換える必要はありません。豊富で便利な UI インタラクションにより、計画・エージェント実行・プロジェクト作業を始めやすく、進めやすくします。

毎回提案を作る必要はありません。コードを調べるだけの場合や簡単な問題に対処する場合は、通常のセッションから始められます。より多くの文脈が必要なタスクには、HagiCode が追跡しやすい進行手順を提供します。

## 機能の詳細

### まず理解してから動く

HagiCode は「コードを読む」ことと「コードを変更する」ことを分けています。AI にすべて直接編集させるのではなく、タスクの規模に応じて選べます。

- **通常のセッション：** デフォルトは読み取り専用です。リポジトリを調べる、問題を調査する、ロジックの場所を尋ねるといった用途に使います。ファイルを変更する必要が出たときだけ編集モードに切り替えます。
- **提案セッション：** 複雑な変更向けです。プロジェクトとリポジトリの範囲を選び、目的、タスク、検証方法を整理します。計画に納得してから実行に進みます。
- **セッションボード：** Proposal & Review、Execution、Archived の各レーンで、すべてのセッションの状況をひと目で確認できます。Classic、Execution Flow Kanban、Dashboard Kanban のレイアウトを切り替えられます。

![待機中、進行中、アーカイブ済みの列を持つセッションボードと、リポジトリ状態を表示したプロジェクト詳細パネル](../img/screenshots/shared/screenshot-796f3c34/original.png)

詳しくは：[通常のセッションを作成](/ja-JP/quick-start/conversation-session) · [提案セッションを作成](/ja-JP/quick-start/proposal-session) · [セッションボード](/ja-JP/user-guide/sessions)

### リポジトリをまたぐ単一の範囲

1 つの要件がフロントエンド、バックエンド、ドキュメントに同時に関わる場合でも、MonoSpecs を使えば HagiCode はそれらを 1 つのプロジェクトとして理解できます。

- サブリポジトリの場所、Git URL、表示名を `.hagicode/monospecs.yaml` に登録します。
- 変更仕様（OpenSpec）はメインリポジトリに置くため、サブリポジトリのコードディレクトリは汚れません。
- 提案を作成するときに、関係するサブリポジトリを選びます。プロジェクトページには、各リポジトリのブランチと未コミットの変更が表示されます。

![11 個のリポジトリのブランチと変更状態、および VS Code、Git、AI Compose Commit の操作を表示した MonoSpec プロジェクトページ](../img/screenshots/monospecs/hover-project-show-repository-status/original.png)

詳しくは：[MonoSpecs ガイド](/ja-JP/guides/monospecs)

### Agent CLI をそのまま使う

HagiCode はお使いのツールチェーンを置き換えません。1 つのワークスペースにまとめます。

- **Agent は、CLI、モデル、任意の人格テキストで構成されます。** 複数の Agent を作成し、実行シナリオに割り当て、バックアップグループを設定できます。
- Claude Code、Codex、GitHub Copilot をはじめ、11 種類の Agent CLI に対応しています。ワークスペースには、各 CLI のバージョン、応答時間、状態が表示されます。
- [OmniRoute](/ja-JP/related-software-installation/omniroute/) を使うと、複数の OpenAI 互換ツールとモデルを 1 つのローカルゲートウェイに接続できます。CLI とモデルの接続は引き続き別々に管理されます。

![Claude Code、Codex、GitHub Copilot などの Agent CLI のバージョン、応答時間、状態を一覧表示した AI Monitoring ポップオーバー](../img/screenshots/shared/status-of-agent-clis/original.png)

詳しくは：[Agents ワークスペース](/ja-JP/user-guide/agents) · [AI Agent CLI のインストールと対応範囲](/ja-JP/related-software-installation/ai-agent-cli/)

### Skills

Skills パネルでは、すでにお使いのマシンにあるスキルと、ギャラリーからインストールできるスキルを 1 つの入口にまとめています。

- **Local Skills：** このマシンにインストール済みのスキルを確認し、更新を一括でチェックします。
- **Gallery：** キーワードやソースで検索し、スキルがすでにインストール済みかどうかを確認できます。
- **Trusted Providers：** インストールの前に、ソース、信頼状態、実際に実行されるコマンドを確認し、どのソースを信頼するかを決めます。

![検索欄、ソースフィルター、スキル・ソース・インストール数の表を表示した Skills ギャラリー](../img/screenshots/shared/skills-gallary/original.png)

詳しくは：[Skills ガイド](/ja-JP/guides/skills)

### Vault と Code Server

- **Vault** は、プロジェクトのリポジトリの外にあり、HagiCode が参照できるフォルダーです。参考資料、メモ、調査結果などに使います。Folder、CodeRef、Obsidian の 3 種類に対応しています。
- セッションを作成するときに、範囲に含める Vault を選びます。1 つを編集可能にすると AI が書き込めるようになり、それ以外は読み取り専用の参照になります。
- **Code Server** は、Vault やプロジェクトから直接開けるブラウザー上の編集入口です。

![登録済みの Vault カード、システム Vault、Open Code Server ボタンを表示した Vault ワークスペース](../img/screenshots/shared/vault-view/original.png)

詳しくは：[Vault ガイド](/ja-JP/user-guide/vault)

### AI Compose Commit

Git タブで「AI Compose Commit」をクリックすると、HagiCode が現在の変更を読み取り、Conventional Commits 形式でコミットメッセージを作成します。

- 関連する変更はまとめて、1 つの大きなコミットではなく複数のコミットに分けられます。
- MonoSpecs プロジェクトでは、変更が適切なサブリポジトリにコミットされます。
- Co-Authored-By タグが自動で付与され、名前とメールアドレスはプロジェクトごと、または全体で設定できます。

![Git タブの AI Compose Commit ボタン](../img/screenshots/ai-compose-commit/trigger-ai-compose-commit-button/original.png)

詳しくは：[AI Compose Commit ガイド](/ja-JP/guides/ai-compose-commit)

### 進捗の可視化

豊富で便利な UI インタラクションにより、計画・エージェント実行・プロジェクト作業を始めやすく、進めやすくします。ヒーロー、実績、日報、Token の指標は、長く続く作業を振り返るための補助的なフィードバックです。[冒険チームの紹介](/ja-JP/adventure-team-introduction)で Hero シナリオ の機能を確認できます。こうしたゲーム要素はワークスペース体験を補うもので、なくても通常の開発ツールとして HagiCode を利用できます。

![日次とグローバルの進捗、サイクルの状態、提案ライフサイクルの指標を表示した実績ダッシュボード](../img/screenshots/shared/achivement-view/original.png)

詳しくは：[ステータスバーと進捗](/ja-JP/user-guide/status-bar-and-progress)

## 対象となる人

- **向いている人：** 複数のリポジトリを保守していて、複雑な変更を実行前に計画したい開発者やチーム。すでに Claude Code や Codex などの Agent CLI を使っていて、それらを 1 つのワークスペースで扱いたい人。
- **必須ではない場合：** エディターで数行を補完できれば十分なら、現在のツールで足ります。

## エディションと価格

基本機能は無料です。Desktop、Microsoft Store は HagiCode の入手方法の違いであり、2 段階の有料プランではありません。Microsoft Store 版では Turbo Engine も提供しています。これは別途購入する買い切りライセンスで、提案の同時実行数の上限を引き上げ、ドキュメントテーマ、署名のカスタマイズ、ブランディング、カスタムアバターアップロードなどの追加機能を利用可能にします。具体的な対象は [Turbo Engine 追加パッケージ](/ja-JP/dlc/turbo-engine-dlc/)を参照してください。

| 利用環境 | 推奨する方法 |
| --- | --- |
| Microsoft Store を利用できる Windows | [Microsoft Store からインストール](/ja-JP/installation/windows-store) |
| Windows への手動インストール、または macOS・Linux でのローカル利用 | [Desktop をインストール](/ja-JP/installation/desktop) |

Steam のメインアプリは提供を終了しており、現在のインストール方法には含まれません。詳しくは [Steam での配布状況](/ja-JP/faq/steam-distribution-status/)を参照してください。

## なぜワークスペースなのか

私は HagiCode の制作者、俞坤（Kun Yu）です。ひとつの質問と回答で目の前の問題は解決できても、実際の開発にはプロジェクトの理解、作業範囲の設定、変更の実施、結果の振り返りも必要です。これまで分かれていた工程をつなげたいと考えました。ゲーム的なフィードバックは、長期的な作業の進捗を見やすくします。必要な機能だけを使って構いません。コードを書き始める前にすべての機能を覚える必要はありません。
