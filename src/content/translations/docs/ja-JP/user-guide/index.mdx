このセクションは HagiCode ワークスペースの操作マニュアルで、画面のモジュールごとに説明しています。現在使っている機能に対応するページを直接開いてください。

## ワークスペースの全体像

ワークスペースは既定で**セッションボード**を開きます。下の画像では、完了したセッションが 1 件ある `orbit-notes` という小さなデモプロジェクトを使っています。

![HagiCode ワークスペース。トップバー、プロジェクトレール、3 つのスイムレーンを持つセッションボード、プロジェクトパネル、ステータスバーが表示されている](../img/user-guide/workbench/01-workbench-overview.png)

画面は 5 つのエリアに分かれています。

| エリア | 位置 | 用途 | ガイド |
| --- | --- | --- | --- |
| **トップバー**（Header） | 画面上部 | Agents、Wizard、Skills、HagiTask、Vault、設定、言語、テーマ、プロフィールなど、ワークスペース全体のモジュールを開く | [トップバー](#トップバー) |
| **プロジェクトレール**（Project rail） | 左端 | すべてのプロジェクトと個別のプロジェクトを切り替え、新しいプロジェクトを作成する | [プロジェクト](/user-guide/projects) |
| **セッションボード**（Session board） | 中央 | セッションをスイムレーンで表示し、新しいセッションを作成するボタンを提供する | [セッション](/user-guide/sessions) |
| **プロジェクトパネル**（Project panel） | 右側 | 選択中のプロジェクトのクイックアクションとリポジトリの状態を表示する | [プロジェクト](/user-guide/projects) |
| **ステータスバー**（Status bar） | 下端 | ヒント、Agent CLI の正常性、実行中のセッション、休憩リマインダー、日給カウンター、ビルドバージョンを表示する | [ステータスバーと進捗](/user-guide/status-bar-and-progress) |

## トップバー

トップバーは常に表示されています。ここにあるボタンは現在のページの上にドロワーやダイアログを開くため、ボードでの位置を失うことはありません。

![HagiCode のトップバー。Agents、Wizard、Refresh、Skills、HagiTask、Vault、Get Support、言語、テーマ、設定、プロフィールのボタンが並んでいる](../img/user-guide/workbench/03-header-navigation.png)

| ボタン | 開く内容 |
| --- | --- |
| **Agents**（中国語 UI では Agents） | Agents ワークスペース。自分の Agent、実行シナリオ、AgentCLI の一覧、モデルカタログ、コピーのテーマ、アバターギャラリーを含みます。[Agents](/user-guide/agents) を参照してください。 |
| **Wizard**（ウィザード） | 4 ステップの初期化ウィザード。[初回起動](#初回起動初期化ウィザード)を参照してください。 |
| **Refresh**（更新） | 現在のページの内容を再読み込みします。 |
| **Skills**（スキル） | Local Skills、Gallery、Trusted Providers を含む統合スキルモジュール。[スキルと HagiTask](/user-guide/skills-and-hagitask) を参照してください。 |
| **HagiTask**（中国語 UI では HagiTask） | タスクプリセットを管理する HagiTask 管理画面。[スキルと HagiTask](/user-guide/skills-and-hagitask) を参照してください。 |
| **Vault**（中国語 UI では Vault） | HagiCode が閲覧・プレビューできるフォルダを管理する Vault マネージャー。[Vault](/user-guide/vault) を参照してください。 |
| **Get Support**（テクニカルサポートを受ける） | コミュニティとサポートのページをブラウザで開きます。 |
| **Language**（言語） | 画面の表示言語を切り替えます。HagiCode は簡体字中国語を含む 10 言語に対応しています。 |
| **Theme**（テーマ、葉のアイコン） | テーマセレクターを開きます。[外観、テーマ、言語](/user-guide/settings#外観テーマと言語)を参照してください。 |
| **Settings**（設定、歯車のアイコン。開くダイアログのタイトルは「設定」） | 設定ダイアログを開きます。[設定](/user-guide/settings)を参照してください。 |
| **Profile**（プロフィール、丸いアバター） | ポイント、履歴タイムライン、クイックリンクを含むプロフィールドロワーを開きます。[ステータスバーと進捗](/user-guide/status-bar-and-progress#プロフィール)を参照してください。 |

## 初回起動：初期化ウィザード

新規インストール後、**Initialization wizard**（初期化ウィザード）が自動的に開きます。トップバーの **Wizard** ボタンからいつでも再度開けます。ウィザードは 4 ステップで、必須の 3 ステップのうち準備が完了した数を表示します。

![初期化ウィザードのステップ 1。表示言語と配色テーマを選択する画面](../img/user-guide/wizard/01-language-theme.png)

1. **Language & theme**（言語とテーマ） – 表示言語と季節ごとの配色テーマを選びます。どちらもすぐに反映されます。
2. **Hagicoder** – ローカルの Agent CLI とモデルを選び、最初の Agent を作成して **Fallback Crew**（フォールバック班）に加えます。接続テストを行うことを推奨しますが、必須ではありません。
3. **Project**（プロジェクト） – 最初のプロジェクトのフォルダを登録します。
4. **Community**（コミュニティ）（任意） – 最初の会話を始めるか、「について」ページを開きます。

![初期化ウィザードのステップ 2。既定の Agent を設定し、Fallback Crew に加える画面](../img/user-guide/wizard/02-agent.png)

全体の流れと各項目の意味は、[初期化ウィザードの設定](/quick-start/wizard-setup)を参照してください。
