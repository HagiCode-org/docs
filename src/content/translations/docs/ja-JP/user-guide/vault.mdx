**Vault** は、HagiCode がプロジェクトリポジトリの外で閲覧およびプレビューすることを許可されたフォルダです。参考文書、ノート、調査結果、そしてセッションに読み取りや書き込みをさせたいその他のコンテンツを Vault に保存できます。

上部バーの **Vault**（画面上の表記：Vault）をクリックすると **Vault Workspace**（Vault ワークスペース）が開きます。

![Vault ワークスペース。登録済みの Orbit Notes Docs Vault と、折りたたまれた System vaults グループが表示されている](../img/user-guide/vault/01-vault.png)

## 登録済みの Vault とシステム Vault

ワークスペースには 2 つのグループがあります。

- **Registered vaults**（登録済み Vault）は、あなたが追加したフォルダです。各カードには Vault の種類、名前、短縮されたパス、そして **Open Code Server**（Code Server を開く）ボタンが表示されます。このボタンを使うと、ブラウザ上のエディタでそのフォルダを編集できます。
- **System vaults**（システム Vault）は HagiCode が作成・管理します。**Expand**（展開）をクリックすると表示されます。

![展開したシステム Vault。システムが管理する読み取り専用の Vault が 7 つ表示されている](../img/user-guide/vault/02-vault-system-expanded.png)

このドロワーでは、システム Vault は**読み取り専用**です。アプリケーションログ、データディレクトリ、プロンプトテンプレート、個人データ、プロジェクトデータ、現在のアーカイブ、システムプリセットが含まれます。セッションのスコープでは、参考資料としてのみ扱われます。

## Vault を追加する

**Add vault**（Vault を追加）をクリックし、**Vault name**（Vault 名）と絶対パスの **Physical path**（物理パス）を入力します。**Vault type**（Vault の種類）を選択してから、**Save vault**（Vault を保存）をクリックします。

![Add vault ドロワー。名前とパスを入力する欄があり、Folder の種類が選択されている](../img/user-guide/vault/03-add-vault.png)

| Vault の種類 | 役割 |
| --- | --- |
| **Folder**（フォルダ） | 既存のローカルディレクトリを、そのままの形で登録します。 |
| **CodeRef**（コード参照） | `docs/`、`repos/`、`AGENTS.md`、`index.yaml` を自動的に作成します。調査タスクの出力先 Vault として使えます。 |
| **Obsidian** | `.obsidian/`、`app.json`、プレビュー可能なノートファイルを自動的に作成し、そのフォルダを Obsidian Vault として使えるようにします。 |

:::caution[保存する前に種類を選択してください]
**Save vault** をクリックする前に、3 つの Vault の種類のいずれかを選択してください。このガイドを作成した時点のバージョンでは、種類を選ばずに保存すると、検証メッセージではなく分かりにくいエラーが表示されて保存に失敗します。
:::

## セッションで Vault を使う

Vault は、[提案の作成ドロワーと通常セッションの作成ドロワー](/user-guide/sessions)の **Scope**（スコープ。画面上では「作用域」または「タスクスコープ」と表示されることがあります）に表示されます。タスクで Vault 内のファイルを更新する必要がある場合は、その Vault を **editable**（編集可能）に設定してください。設定しない場合、AI はその Vault を読み取り専用の参考資料として扱います。システムが管理する Vault は、常に参考資料としてのみ使われます。
