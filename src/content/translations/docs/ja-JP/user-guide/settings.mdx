上部バーの**歯車アイコン**をクリックすると**設定**（**Settings**。上部バーのボタンは「設定」、ダイアログのタイトルも「設定」と表示されます）が開きます。左側にはグループとそのタブが一覧表示され、右側には選択したタブの内容が表示されます。タブによっては変更すると自動的に保存されるものもあれば、独自の **Save**（保存）ボタンを持つものもあります。

グループは折りたたむことができ、HagiCode はどのグループを展開したままにするかを記憶します。

## Common（共通）

### General Settings（一般設定）

![General Settings タブ。ブランドのカスタマイズと、トップに戻るボタンの位置が表示されている](../../img/user-guide/settings/01-general-settings.png)

- **Brand Customization**（ブランドのカスタマイズ）では、カスタムのトップバーロゴ、アプリタイトル、ブランドのリンク先、ブラウザのタイトルを設定し、効果をリアルタイムでプレビューできます。これらのコントロールはプレビューできますが、TurboEngine DLC を有効にするまではロックされています。
- **Back to Top Button Settings**（トップに戻るボタンの設定）では、セッション内で「トップに戻る」ボタンを表示する位置を選択します（例: *Bottom Right*（右下））。

## Project（プロジェクト）

### Project Icon（プロジェクトアイコン）

![Project Icon タブ。デフォルトのアイコンモードとアイコンコレクションが表示されている](../../img/user-guide/settings/02-project-icon.png)

- **Project Icon Mode**（プロジェクトアイコンモード）では、新しいプロジェクトのデフォルトの表示スタイルを設定します。*Game Icon*（ゲームアイコン。ランダムなカラーアイコンで、デフォルト値）または *Text Abbreviation*（テキストの略称。プロジェクト名の頭文字を使用）から選べます。個々のプロジェクトは[プロジェクトの詳細](/user-guide/projects#詳細)でこの設定を上書きできます。
- **Icon Collection**（アイコンコレクション）では、選択可能なアイコンを管理します。**Show All**（すべて表示）、**Enable All**（すべて有効化）、**Disable All**（すべて無効化）、**Random 50**（ランダムに 50 個）、**Refresh**（更新）を使用できるほか、個々のアイコンをクリックして切り替えることもできます。

## Process & Interaction（プロセスと操作）

このグループでは、セッション、提案、カンバンの動作を制御します。

### Comments（コメント）

![Comments タブ。行コメントとファイルコメントの 2 つのテンプレート一覧が表示されている](../../img/user-guide/settings/03-comments.png)

よく使うコメントのテンプレートを保存します。テンプレートは **Line Comments**（行コメント）と **File Comments**（ファイルコメント）の 2 つの一覧に分かれています。**Add Comment**（コメントを追加）でテンプレートを作成し、**Save** で変更を保存します。

### Notifications（通知）

![Notifications タブ。通知チャネルと状態ルールの表が表示されている](../../img/user-guide/settings/04-notifications.png)

まず通知をオンにし、次にチャネルを選択します。**Toast notifications**（トースト通知）、**Browser notifications**（ブラウザ通知。ブラウザで許可が必要）、**Speech synthesis**（音声合成）、**Sound Settings**（サウンド設定）から選べます。**Status rules**（状態ルール）の表では、セッションの状態ごと（例: *New*（新規）、*Drafted*（下書き済み）、*Executing*（実行中）、*Waiting for Reply*（返信待ち）、*Execution Complete*（実行完了）、*Archived*（アーカイブ済み））に、どのチャネルを使うか、どのサウンドを再生するかを選択します。再生ボタンでサウンドを試聴できます。

### Quick Actions（クイックアクション）

![Quick Actions タブ。コマンド一覧と実行履歴がどちらも空の状態で表示されている](../../img/user-guide/settings/05-quick-actions.png)

**Configured Commands**（設定済みコマンド）には、**Add Command**（コマンドを追加）で追加したカスタムコマンドが一覧表示されます。**Execution History**（実行履歴）には、それらの実行時刻が記録されます。

### Kanban Right Panel（カンバン右パネル）

![Kanban Right Panel タブ。表示モードのオプションとプレビューが表示されている](../../img/user-guide/settings/06-kanban-right-panel.png)

セッションカンバンの右側に何を表示するかを選択します。*Hidden*（非表示）、*GitHub Discussion*、またはクイック操作とリポジトリの状態を表示する *Quick Operations Panel*（クイック操作パネル。デフォルト値）から選べます。ライブの **Preview**（プレビュー）で、設定後の表示を確認できます。

### Proposal Creation（提案作成）

![Proposal Creation タブ。最近使ったリポジトリの表示数が表示されている](../../img/user-guide/settings/07-proposal-creation.png)

提案リポジトリのセレクターの上部に、最近使ったリポジトリのカードをいくつ表示するかを設定します。`0` を選ぶと、この行を非表示にできます。

### Planning Direction（計画の方向性）

![Planning Direction タブ。Agent CLI ごとに計画の方向性を並べたマトリクス](../../img/user-guide/settings/08-planning-direction.png)

提案フローが Agent CLI ごとに提示する、デフォルトの計画の方向性を並べたマトリクスです。探索モード、変更マップ、インタラクションフロー、プロトタイプ、アーキテクチャ、API シーケンス、そして編集可能な範囲と参照専用の範囲を設定できます。個々の Agent でこれらのデフォルトを上書きできます。

### Proposal Stage Diagram（提案ステージ図）

![Proposal Stage Diagram タブ。Full と Compact の 2 つの表示モードとライブプレビューが表示されている](../../img/user-guide/settings/09-proposal-stage-diagram.png)

提案のドロワーにあるステージ一覧の詳しさを設定します。*Full*（完全）ではステージのラベルと説明を表示し、*Compact*（コンパクト）ではラベルのみを表示します。この設定はドロワーのサイドバーにのみ影響し、メインのフロー図には影響しません。

### Mermaid Appearance（Mermaid の外観）

![Mermaid Appearance タブ。Default と Archify-inspired の 2 つのプリセットが表示されている](../../img/user-guide/settings/10-mermaid-appearance.png)

Mermaid 図の外観を選択します。*Default*（デフォルト）または *Archify-inspired*（Archify 風）から選べます。この選択は現在のブラウザにのみ保存され、見た目だけを変更します。

### Session List（セッション一覧）

![Session List タブ。プロジェクトの範囲、並び替えモード、表示オプションが表示されている](../../img/user-guide/settings/11-session-list.png)

- **Project Scope**（プロジェクトの範囲）では、*All Sessions*（すべてのセッション）カンバンに含めるプロジェクトを選択します。*All Projects*（すべてのプロジェクト）または *Custom Selection*（カスタム選択）から選べます。**Save** をクリックして適用します。
- **Session Sorting**（セッションの並び替え）では、*Smart Sorting*（スマート並び替え。実行状態と最近のアクティビティで並べる）または *Custom Sorting*（カスタム並び替え。独自の優先度ルールを使用）を選択します。
- **Session Display Settings**（セッション表示設定）には、アーカイブ済みのセッションを一覧に引き続き表示するかどうかの設定が含まれます。

### Confirm Prompts（確認プロンプト）

![Confirm Prompts タブ。各確認ダイアログに対応するスイッチが並んでいる](../../img/user-guide/settings/12-confirm-prompts.png)

すべてをまとめて切り替えるスイッチと、各確認ダイアログごとのスイッチがあります。対象は、AI によるクイックコミットの前、提案の生成・実行待ちへの移動・即時実行・アーカイブの前、そして選択したセッションのアーカイブまたは削除の前です。プロンプトをオフにするとクリック数は減りますが、誤操作の代償は大きくなります。**Reset to Default**（デフォルトに戻す）で既定値に戻せます。

### Common Requirements（共通要件）

![Common Requirements タブ。再利用可能な提案要件が表示されている](../../img/user-guide/settings/13-common-requirements.png)

提案の要件に 1 クリックで追加できる、再利用可能な要件の断片です。例: *No docs / tests*（ドキュメントとテストは不要）、*Self commit*（自分でコミット）、*Output English*（英語で出力。表示言語に応じて変化）、*Ask before edit*（編集前に確認）、*No backward compatibility*（後方互換性は不要）。表示されるのは現在の表示言語に対応する要件のみです。**Add Common Requirement**（共通要件を追加）で独自の要件を作成し、編集・削除ボタンで管理できます。

### Error Retry（エラー時の再試行）

![Error Retry タブ。デフォルトの再試行ポリシーと CLI ごとの上書き設定が表示されている](../../img/user-guide/settings/14-error-retry.png)

失敗した実行の自動再試行を設定します。**Default Policy**（デフォルトポリシー）では、最大再試行回数と各再試行前の待機時間を設定します。以降の試行では、末尾の待機時間が使われます。デフォルトの再試行間隔は、順に 30 秒、30 秒、30 秒、60 秒です。**CLI Overrides**（CLI の上書き設定）では、Agent CLI ごとにデフォルトポリシーをそのまま使うか、独自の間隔を設定するかを選べます。

### AgentCLI Interactive Control（AgentCLI の対話制御）

![AgentCLI Interactive Control タブ。Agent CLI ごとに 1 つずつスイッチが並んでいる](../../img/user-guide/settings/15-agentcli-interactive-control.png)

Agent CLI ごとにスイッチがあり、生成される OpenSpec と HagiTask のプロンプトに、今回の実行が非対話的であることを Agent に伝える文言を含めるかどうかを決めます。スイッチがオフの場合（デフォルト）は、この文言が含まれます。変わるのは生成されるプロンプトの言い回しだけです。

### Chat View（チャットビュー）

![Chat View タブ。チャットモード、デバッグメタデータ、長いメッセージのオプションが表示されている](../../img/user-guide/settings/16-chat-view.png)

- **Default to Edit Mode for Normal Chats**（通常のチャットのデフォルトを編集モードにする）では、新しく作成した通常のセッションを編集モード（Agent がファイルを変更できる）で開始するか、読み取り専用モードで開始するかを決めます。
- **Show debug metadata entry points**（デバッグメタデータの入口を表示）は、チャットメッセージにデバッグ用の入口を追加します。
- **Auto-collapse long messages**（長いメッセージを自動的に折りたたむ）では、長い過去のメッセージをプレビューとして表示し、展開コントロールを付けます。
- **Simplified historical tool calls**（過去のツール呼び出しを簡略化）では、古いツール呼び出しを短い要約にまとめ、次の表示されるメッセージに添えます。

### Standard Phrases（定型句）

![Standard Phrases タブ。カテゴリの表示設定、パスのソース、カスタムグループが表示されている](../../img/user-guide/settings/17-standard-phrases.png)

メッセージ入力欄で再利用できる `@` の定型句トークンを管理します。`@` セレクターに表示するカテゴリと、パスのソース（プロジェクト、Vault、提案セッション、最近使ったプロジェクト、カスタムパス）を選択します。**Add Group**（グループを追加）で、独自の定型句グループを作成できます。

### Haginput

![Haginput タブ。入力モードとリモートモードの設定が表示されている](../../img/user-guide/settings/18-haginput.png)

スマート入力です。**Disabled**（無効）、**Doubao Local Voice**（Doubao ローカル音声）、**Haginput Remote Mode**（Haginput リモートモード）から選べます。リモートモードでは、ローカルのマイクを開かずに、スマートフォンや 2 台目のデバイスからテキストを転送できます。このタブには、モードの状態、自動接続のオプション、テキストを受信したときの通知音、テスト用の入力欄が表示されます。

## Integration（連携）

### Break Reminder（休憩リマインダー）

![Break Reminder タブ。タイマーの状態と通知テーマが表示されている](../../img/user-guide/settings/19-break-reminder.png)

水分補給、ストレッチ、立ち上がって体を動かすよう知らせるタイマーです。前回と次回の通知、今日の周回数が表示され、*Basic*（ベーシック）などの通知テーマを選べます。通知は[ステータスバー](/user-guide/status-bar-and-progress#休憩リマインダー)に表示されます。

### Salary Tracker（給与カウンター）

![Salary Tracker タブ。日給、労働時間、単位の絵文字が表示されている](../../img/user-guide/settings/20-salary-tracker.png)

分単位で収入を計算する、楽しいカウンターです。**Daily salary**（日給）と **Work hours per day**（1 日の労働時間）を入力します。1 分あたりの収入は、日給を（労働時間 × 60）で割った値になります。日給を `0` にすると計算は停止します。20 種類の単位の絵文字から 1 つ選び、そのインジケーターをステータスバーに表示するかどうかを選択します。

### GitHub

![GitHub タブ。接続済みのローカル gh CLI セッションと設定手順が表示されている](../../img/user-guide/settings/21-github.png)

ローカルの GitHub CLI（`gh`）セッションを使って、セッションを同期し、GitHub のデータをインポートします。このタブには接続状態と付与されているスコープが表示され、**Refresh status**（状態を更新）と **Copy login command**（ログインコマンドをコピー）が使えます。トークンは現在のページセッション中だけメモリに保持され、ローカルストレージに保存されることはありません。`gh` にまだログインしていない場合は、タブに表示される *Local `gh` setup*（ローカルの `gh` セットアップ）の手順に従ってください。

### Git

![Git タブ。Git プロファイル、状態の監視、AI コミットのデフォルト値が表示されている](../../img/user-guide/settings/22-git.png)

- **Git Profiles**（Git プロファイル）は、AI コミットで使用できる作成者の情報を保存します。AI コミットを始める前に、少なくとも 1 つ作成しておくと、プロンプトに常に明確な作成者が記載されます。
- **Automatically refresh and monitor Git status**（Git の状態を自動的に更新して監視）では、アクティブなプロジェクトを定期的にチェックします。特に Windows やリポジトリが多い環境では、ディスクアクティビティが増える場合があります。**Maximum monitored Git repositories**（監視する Git リポジトリの最大数）で、同時に監視する数を制限できます（デフォルトは 15）。
- **AI commit default behavior**（AI コミットボタンのデフォルトの動作）では、メインの AI コミットボタンの動作を決めます。*Open confirmation panel*（確認パネルを開く）、または保存済みのプロファイルとデフォルト値を使って *Commit immediately*（すぐにコミット）から選べます。その他のオプションでは、コミット後にデフォルトでプッシュするか、rebase するかを設定します。

### OmniRoute

![OmniRoute タブ。連携のスイッチ、API エンドポイント、実行状態、モデルカタログが表示されている](../../img/user-guide/settings/23-omniroute.png)

共有の OmniRoute 連携を有効にします。**API endpoint**（API エンドポイント）と、任意の **API key**（API キー）を設定し、**Test connection**（接続をテスト）を使い、OmniRoute のモデルカタログをどの Agent CLI で使うかを選択します。右側には実行状態とキャッシュ済みのモデルカタログが表示されます。連携をオフにすると、モデル管理は最初のシステムデフォルトに戻ります。インストール方法は [OmniRoute](/related-software-installation/omniroute) を参照してください。

### TokenMonitor

![TokenMonitor タブ。ステータスバーのスイッチと HostHub の項目が表示されている](../../img/user-guide/settings/24-tokenmonitor.png)

TokenMonitor デスクトップアプリの当日のトークン使用量と料金を、ステータスバーに表示します。スイッチがオフの場合は、何も読み取られません。ほぼリアルタイムで更新するには、**HostHub address**（HostHub のアドレス）と **HostHub secret**（HostHub のシークレット）の両方を入力してください。どちらかが空欄の場合は、代わりに TokenMonitor のローカルデータファイルを読み取ります。

### Code Server

![Code Server タブ。解析済みの設定と実行状態が表示されている](../../img/user-guide/settings/25-code-server.png)

解析済みの Code Server の設定（ホスト、ポート、認証モード、ソース）と、最新のランタイムスナップショットを読み取り専用で表示します。ここでは Code Server の設定を編集できません。

### Status Bar Scroll（ステータスバーのスクロール）

![Status Bar Scroll タブ。表示スイッチと現在のプロモーション一覧が表示されている](../../img/user-guide/settings/26-status-bar-scroll.png)

ステータスバーをスクロールさせるかどうか、そして使用するソースを選択します。ソースは **Tips**（ヒント）と **Promotions**（プロモーション）です。スクロールやプロモーションをオフにするには、有効な TurboEngine サブスクリプションが必要です。このタブには現在のプロモーション内容が一覧表示されます。

## Game（ゲーム）

### Achievements（実績）

![Achievements タブ。毎日の進捗ポップアップのスイッチが表示されている](../../img/user-guide/settings/27-achievements.png)

ステータスバーに表示される毎日の実績の進捗ポップアップを、オンまたはオフにします。この設定に関係なく、グローバルなマイルストーン通知とデータ同期は有効なままです。詳しくは[ステータスバーと進捗](/user-guide/status-bar-and-progress#トロフィーと実績の殿堂)を参照してください。

## System（システム）

### Data Management（データ管理）

![Data Management タブ。データベースディレクトリ、アーカイブディレクトリ、データクリーンアップが表示されている](../../img/user-guide/settings/28-data-management.png)

現在のアーカイブと、そのデータフォルダー（アーカイブのルート、設定ディレクトリ、データディレクトリ）を表示します。**Save Catalog**（アーカイブの一覧）ではアーカイブを一覧表示し、準備ができているアーカイブを安全に有効化できます。**Workspace**（ワークスペース）の切り替えで、*Primary Database*（メインデータベース）、*Message Database*（メッセージデータベース）、*Image Storage*（画像ストレージ）のツールを切り替えられます。**Data Cleanup**（データクリーンアップ）ではデータベースの情報を表示し、アーカイブ済みセッションのメッセージデータを削除してストレージ容量を解放できます。

### Danger Zone（危険な操作）

![Danger Zone タブ。Reset system data ボタンが表示されている](../../img/user-guide/settings/29-danger-zone.png)

**Reset system data**（システムデータをリセット）は、永続化された状態をリセットし、現在のアーカイブのメインデータベースのレコードとメッセージのシャードを削除します。画像、プラグイン、リポジトリ、他のアーカイブには影響しません。アプリは引き続き動作し、その後はアプリの再起動をおすすめします。この操作は元に戻せません。

### About（バージョン情報）

![About タブ。HagiCode プラットフォームのバージョンとコミュニティリソースが表示されている](../../img/user-guide/settings/30-about.png)

バージョンとビルド日を表示し、コミュニティの一覧をすべて掲載している公式の「バージョン情報」ページへのリンクを表示します。

## Debug（デバッグ）

### Debug（デバッグ）

![Debug タブ。SignalR ログ、HagiPower の調整、DLC のオプションが表示されている](../../img/user-guide/settings/31-debug.png)

開発ビルド向けのツールです。

- **SignalR Log**（SignalR ログ）は、SignalR のイベントとメッセージをリアルタイムでコンソールに出力します。
- **HagiPower Adjustment**（HagiPower の調整）は、開発環境で共有の公開プールを直接編集します。通常の本番環境の計算は変更されません。
- **Enable DLC**（DLC を有効化）は、バックエンドの設定を通じて TurboEngine DLC を明示的に有効または無効にします。ローカルの開発環境には、内部の有効化スイッチがないためです。

通常の使用では、このタブは必要ありません。

## 外観、テーマ、言語

上部バーの 2 つのボタンを使うと、設定を開かなくても HagiCode の外観を変更できます。

![Choose theme ダイアログ。ライトとダークのバリエーションを持つテーマシリーズと、自動切り替えのパネルが表示されている](../../img/user-guide/status/07-theme-chooser.png)

**Theme**（テーマ）では、テーマセレクター（**Choose theme**、テーマを選択）を開きます。各テーマシリーズには **Light**（ライト）と **Dark**（ダーク）の 2 つのバリエーションがあり、すぐに適用されます。シリーズには Standard（標準）、Spring（春）、Summer（夏）、Vacation（バカンス）、Autumn（秋）、Winter（冬）、Lunar New Year（旧正月）、Soccer（サッカー）、Cyberpunk（サイバーパンク）、School（学校）、Space Travel（宇宙旅行）があります。**Auto-switch**（自動切り替え）を使うと、1 分から 240 分の固定間隔で、ライトテーマとダークテーマが交互に切り替わります。

![Select Language ダイアログ。English が選択され、他の 9 つの表示言語が一覧表示されている](../../img/user-guide/status/08-language.png)

**Language**（言語）では、言語ダイアログ（**Select Language**、言語を選択）を開きます。言語を選び、**Confirm**（確認）をクリックします。HagiCode は English、简体中文、繁體中文、日本語、한국어、Deutsch、Français、Español、Português (Brasil)、Русский に対応しています。
