ワークベンチの下端と上端にある小さなウィジェットが、邪魔にならない形で状況を知らせます。このページでは、ステータスバー、トロフィーと実績のホール、そしてプロフィールについて説明します。

## ステータスバー

![ステータスバー。Microsoft Store バッジ、スクロール表示、Agent CLI の正常性、実行中のセッション、休憩リマインダー、日給カウンター、バージョンが並んでいる](../img/user-guide/workbench/04-status-bar.png)

左から右へ、次の項目が並びます。

| 項目 | 表示内容 |
| --- | --- |
| **Microsoft Store badge** | HagiCode の Microsoft Store 掲載ページへのリンクです。 |
| **スクロールするヒントとプロモーション** | 一度に 1 件のヒントまたはプロモーションが流れます。ヒントは HagiCode の使い方を説明し、プロモーションは関連プロジェクトへのリンクです。**Settings → Integration → Status Bar Scroll**（設定 → 統合 → ステータスバーのスクロール）で、スクロールを無効にしたり、表示内容の供給元を選んだりできます。 |
| **Agent CLI の正常性** | `CC`、`CO`、`GC` などの小さなバッジです。それぞれ Claude Code、Codex、GitHub Copilot を表し、正常な場合は緑の点が付きます。`+N` は、ほかにいくつのツールがあるかを示します。バッジをクリックすると、正常性チェックを更新できます。 |
| **Running sessions**（実行中のセッション） | 現在実行中のセッション数です。クリックすると詳細を確認できます。 |
| **Break reminder**（休憩リマインダー） | 水滴のアイコンで、次のリマインダーまでの残り時間を示します。 |
| **Salary tracker**（時給カウンター） | 単位の絵文字と、今日の累計金額です。カウンターとそのステータスバーのインジケーターが有効なときに表示されます。 |
| **Version**（バージョン） | ビルドのバージョンです。開発ビルドでは `dev` と表示されます。 |

### 実行中のセッション

![実行中のセッションのポップオーバー。セッション上限、オーバークロックのオプションを表示しており、現在実行中のセッションはない](../img/user-guide/status/03-running-sessions.png)

HagiCode が同時に実行するセッション数には上限があり、既定値は 20 です。ポップオーバーには、現在の数と上限の比較と、実行中のセッションの一覧が表示されます。

- **Overclock**（オーバークロック）は上限を 3 増やします。現在の上限に達したときに使用できます。ポップオーバーには、使用済みの回数が表示されます。
- TurboEngine DLC を利用すると、同時実行の段階をさらに引き上げられます。

### 休憩リマインダー

![休憩リマインダーのポップオーバー。メッセージと、Remind me later と Take a break のボタンがある](../img/user-guide/status/04-break-reminder.png)

タイマーが作動すると、現在のリマインダーのテーマに沿ったメッセージのカードが表示されます。**Take a break**（休憩する）は確認したことを、**Remind me later**（後で通知）は通知を延期することを意味します。間隔とトーンは **Settings → Integration → Break Reminder**（設定 → 統合 → 休憩リマインダー）で設定します。

### 日給カウンター

![日給カウンターのポップオーバー。1 分あたりの収入、今日、経過した分数、昨日、履歴の合計を表示している](../img/user-guide/status/05-salary-tracker.png)

絵文字をクリックすると、1 分あたりの収入、今日の合計、経過した分数、昨日の合計、履歴の合計が表示されます。**Open settings**（設定を開く）を選ぶと **Settings → Integration → Salary Tracker**（設定 → 統合 → 時給カウンター）に移動し、そこで日給と勤務時間を設定できます。

## トロフィーと実績のホール

セッションボードの右上にある **Trophies**（トロフィー）のウィジェットは、星で進捗を示します。4 個の星（Star）で 1 か月（Month）、4 か月で 1 日（Day）、4 日で 1 冠（Crown）になります。見出しの横の数字は、次の昇格までに必要な星の数です。

クリックすると **Achievement Hall**（実績のホール）が開きます。

![実績のホール。日ごとのスコア、達成率、今日の概要、オンラインの成長を表示している](../img/user-guide/status/01-achievements.png)

- **Daily Achievements**（日次の実績）は毎日リセットされる目標です。たとえば、提案の開始と完了、Agent の成果物、ツールの活動などがあります。見出しには `0/17` のように日次のスコアが表示されます。
- **Global Achievements**（全体の実績）は、日をまたいで積み上がる長期的なマイルストーンです。
- **Mission Board**（ミッションボード）は、その日の状況をまとめます。達成率、進行中の目標、報酬のチャネルが表示されます。
- **Online growth**（オンラインの成長）は、HagiCode の実行中に蓄積された進捗を記録します。

ここで、または日常の作業で獲得したポイントは、プロフィールに表示されます。日次の進捗ポップアップは、**Settings → Game → Achievements**（設定 → ゲーム → 実績）で無効にできます。

## プロフィール

上部バーの右端にある丸いアバターをクリックすると、プロフィールのドロワーが開きます。

![プロフィールのドロワー。アバター、ポイント、履歴のタイムライン、クイックリンクを表示している](../img/user-guide/status/02-profile.png)

- **Avatar**（アバター）– 10 MB 以下の JPEG、PNG、WEBP、GIF 画像をアップロードできます。
- **Points**（ポイント）– 実績と日常の作業から確定した、現在の残高です。
- **History timeline**（履歴のタイムライン）– 作成や削除したセッションなど、最近のシステム履歴です。ドロワーを開いたときにだけ読み込まれます。
- **Quick links**（クイックリンク）– たとえば **View Yesterday's Report**（昨日のレポートを見る）は、昨日の全画面のヒーローレポートを開きます。
