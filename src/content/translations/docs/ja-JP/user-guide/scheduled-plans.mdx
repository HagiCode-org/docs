**プラン**（スケジュールプラン、スケジュールタスクとも呼びます）を使うと、指定した時刻に HagiCode がセッションを自動で開始します。送信ボタンをその場でクリックする必要はありません。たとえば、平日の 2:00 にコードレビューを実行する、毎朝依存関係の更新を確認する、明日の 10:00 にリリースノートの下書きを作成する、といった使い方ができます。

プランには 2 つの情報が保存されます。**セッションの作成に必要な内容すべて**（通常は作成ダイアログで入力する内容そのもの）と、**スケジュール**です。時刻になると、HagiCode は手動で送信した場合と同じ流れでセッションを作成します。そのため、プランが開始したセッションは、自分で作成したセッションと何も変わりません。

## 概念

| 概念 | 意味 |
| --- | --- |
| **Type**（種類） | プランには 2 種類あります。**Proposal**（提案）は実行時に提案セッションを作成し、**HagiTask** は実行時に HagiTask からセッションを作成します。種類は、どの作成ダイアログからプランを保存したかで決まります。 |
| **Run once / Recurring**（1 回のみ / 繰り返し） | 1 回限りのプランは、ある 1 つの時点で 1 度だけ実行されます。繰り返しプランは、開始日から終了日までの間、毎日または毎週繰り返し実行されます。 |
| **Next run**（次回の実行） | プランが次に自動で開始される時刻です。選択したタイムゾーンで表示されます。 |
| **Scheduled / Completed**（予定済み / 完了） | プランの状態です。1 回限りのプランは実行後に Completed になり、繰り返しプランは終了日を過ぎると Completed になります。 |
| **Enabled / Disabled**（有効 / 無効） | すべてのプランに有効化スイッチがあります。無効のプランは一覧に残りますが、自動では実行されません。 |

## プランマネージャーを開く

トップバーの **Plans**（プラン）ボタンでプランマネージャーを開きます。ウィンドウ幅が狭いときはカレンダーのアイコンだけが表示されます。マウスを重ねると **Scheduled plans**（スケジュールプラン）のツールチップが表示されます。

![HagiCode のトップバー。Vault と Get Support の間に新しい Plans ボタンがある](../../img/user-guide/workbench/03-header-navigation.png)

初めて開いたときは一覧が空です。プランマネージャーは既存のプランの**閲覧と管理**専用で、ここから新しいプランを作成することはできません。プランは、提案または HagiTask を作成するダイアログから保存します。

![空の状態のプランマネージャードロワー。「No scheduled plans yet」と、作成方法のヒントが表示されている](../../img/user-guide/plans/01-empty-manager.png)

## プランを作成する

提案と HagiTask の作成ダイアログは、どちらも「今すぐ開始」から「スケジュールで開始」に切り替えられます。**Create Normal Session**（通常セッションを作成）には Plan スイッチはありません。

1. いつもどおり作成ダイアログを開きます（たとえば **New Idea**）。アイデア名、プロジェクト、リクエストを入力します。各項目については、[セッション](/user-guide/sessions#アイデアを作成提案)を参照してください。
2. ダイアログの右下を見てください。送信ボタンの横に、既定でオフの **Plan**（プラン）スイッチがあります。

   ![Create Proposal ドロワーのフッター。左に Cancel、右に Plan スイッチと Submit idea ボタンがある](../../img/user-guide/plans/02-plan-switch.png)

3. **Plan** スイッチをオンにします。ダイアログがプランモードに切り替わります。
   - 左上のラベルが **Create Proposal** から **Proposal plan**（提案プラン）に変わります。
   - 上部に必須の **Plan name**（プラン名）欄が表示されます。たとえば「Nightly code review」のように、200 文字まで入力できます。
   - 下部に **Schedule**（スケジュール）セクションが表示されます。
   - 送信ボタンが **Save plan**（プランを保存）になります。

   ![プランモードの Create Proposal ドロワー。上部に Plan name、その下に元のフォーム、下部に Schedule セクションと Save plan ボタンがある](../../img/user-guide/plans/03-plan-mode-once.png)

4. **Schedule** で、プランをいつ実行するかを設定します。[スケジュールを設定する](#スケジュールを設定する)を参照してください。HagiTask プランでは Agent も必要です。[HagiTask プランの Agent を選ぶ](#hagitask-プランの-agent-を選ぶ)を参照してください。
5. **Save plan** をクリックします。HagiCode に **Plan saved**（プランを保存しました）の通知が表示されます。**View plans**（プランを表示）をクリックすると、すぐにプランマネージャーを開けます。

   ![画面左下の通知。Plan saved と、View plans ボタンが表示されている](../../img/user-guide/plans/07-plan-saved-toast.png)

:::note
プランには画像を含められません。フォームにすでに画像が添付されている場合、**Plan** スイッチは無効になり、タスクをプランとして保存する前に画像を削除するよう案内が表示されます。
:::

## スケジュールを設定する

**Schedule** の上部にある 2 つのボタンで、プランの実行方法を選びます。**Run once**（1 回のみ）または **Recurring**（繰り返し）です。どちらのモードでも、セクション下部の **Next run** には、現在の設定から求められる次回の実行時刻がリアルタイムで表示されます。**Not scheduled**（予定なし）と表示される場合は、現在の設定では実行時刻を確定できないため、日付または時刻を調整してください。

### 1 回のみ実行

1 度だけ実行します。

| 項目 | 説明 |
| --- | --- |
| **Date**（日付）と **Time**（時刻） | 実行する日と時刻です。既定は明日の 09:00 です。現在より後の時刻でなければなりません。 |
| **Run in**（何分後に実行） | クイックボタンです。`+5 min`、`+10 min`、`+30 min`、`+1 hour` があり、現在時刻から数えます。 |
| **Next at**（次にその時刻） | クイックボタンです。`02:00`、`09:00`、`12:00`、`18:00`、`22:00` があります。その時刻の次の機会を選びます。今日まだ先ならば今日、そうでなければ明日になります。 |
| **Time zone**（タイムゾーン） | 日付と時刻を解釈するタイムゾーンです。既定はブラウザーの現在のタイムゾーンです。 |

### 繰り返し

開始日から終了日までの間、毎日または毎週繰り返します。

![Schedule セクションの繰り返しモード。開始日と終了日、時刻、Every week、月曜から金曜、タイムゾーン Asia/Shanghai、次回の実行時刻が表示されている](../../img/user-guide/plans/04-recurring-schedule.png)

| 項目 | 説明 |
| --- | --- |
| **From**（開始）と **To**（終了） | 期間の最初の日と最後の日です。どちらも含まれます。既定は今日から 1 か月間です。**Start**（開始日）の下にある `Today`、`Tomorrow`、`In 1 week`、`In 1 month`、`In 3 months` で開始日をすばやく設定でき、**Length**（期間）の下にある `+1 week`、`+1 month`、`+3 months` で期間の長さを設定できます。 |
| **Time**（時刻） | 毎回の実行時刻です。`HH:mm` 形式で指定します。**Quick time**（クイック時刻）には `02:00`、`09:00`、`12:00`、`18:00`、`22:00` があります。 |
| **Repeat**（繰り返し） | **Every day**（毎日）または **Every week**（毎週）です。 |
| **On**（曜日） | **Every week** を選ぶと表示されます。プランを実行する曜日（`Mon` から `Sun`）を選びます。少なくとも 1 つは選択してください。 |
| **Time zone**（タイムゾーン） | 時刻を解釈するタイムゾーンです。毎回の実行はこのタイムゾーンの現地時刻に従うため、毎日 02:00 のプランは夏時間の切り替えをまたいでも 02:00 のままです。 |

:::tip
プランを「長期間有効」にするには、**To** を先の日付にします。たとえば **+3 months** をクリックします。終了日を過ぎると、プランは **Completed** になり、実行されなくなります。
:::

## HagiTask プランの Agent を選ぶ

提案プランでは Agent は不要です。**HagiTask プランでは Agent を 1 つ選択する必要があります**。自動で開始されるときには、Agent を選ぶ人がいないためです。

- プランモードのダイアログには **Available Agents**（利用可能な Agent）セクションが表示されます。これはプランの実行に使う Agent であり、プランが開始するときもこの選択が保持される、という説明が付いています。Agent をクリックして選択します。
- 下部のバーに `Agent: name` と表示されます。選択するまでは `No agent selected yet.` と表示され、プランを保存できません。
- 現在、プランに指定できる Agent は 1 つだけです。Agent の作成方法は [Agents](/user-guide/agents) を参照してください。

## 既存のプランを管理する

**Plans** を開くと、すべてのプランが表示されます。各行が 1 つのプランです。

![5 件のプランを表示しているプランマネージャー。平日の提案プラン、毎日の HagiTask プラン、1 回限りの提案プラン、無効にした毎週のプラン、完了したプラン](../../img/user-guide/plans/05-plan-manager.png)

各行には次の内容が含まれます。

- **名前**、**Proposal** または **HagiTask** の種類バッジ、**Scheduled** または **Completed** の状態バッジ。
- **スケジュールの要約**。たとえば `Weekly on Mon, Tue, Wed, Thu, Fri 02:00 AM, Oct 18, 2026 - Jan 18, 2027 (Asia/Shanghai)` のように表示されます。
- **Next run**。完了したプランには `–` が表示されます。

各行の右側には 4 つの操作があります。

| 操作 | 内容 |
| --- | --- |
| **Enabled / Disabled** スイッチ | プランを有効または無効にします。無効のプランは自動では実行されませんが、一覧には残ります。再び有効にすると、HagiCode は現在時刻から次回の実行を再計算します。無効にしていた間に過ぎた時刻の分は実行されません。 |
| **Run now**（今すぐ実行） | 保存済みの入力内容から、すぐにセッションを作成します。成功すると、その行に **Session started.**（セッションを開始しました）と表示されます。プランのスケジュールや **Next run** は変わりません。無効のプランや完了したプランも手動で実行できます。 |
| **Edit**（編集） | プランの作成に使ったのと同じダイアログを、プランモードで開きます。名前、内容、Agent、スケジュールを変更して **Save plan** をクリックします。保存済みのプランは常にプランのままです。**Plan** スイッチは固定されており、通常のタスクに戻すことはできません。 |
| **Delete**（削除） | 先に確認が表示されます。削除すると、プランが実行されなくなるだけです。**すでに開始されたセッションは残ります**。 |

![削除の確認ダイアログ。「Delete this scheduled plan?」と表示され、「Weekly docs cleanup」は実行されなくなるが、すでに開始されたセッションは残ることが説明されている](../../img/user-guide/plans/06-delete-confirm.png)

## プランが実行されるタイミング

- **プランは HagiCode が起動している間だけ実行されます。** HagiCode は 30 秒ごとに実行時刻になったプランがないかを確認します。そのため、予定時刻から最大で約 30 秒遅れて開始されることがあります。
- **実行できなかった分は 1 回だけ補われます。** プランの実行時刻に HagiCode が起動していなかった場合（たとえばコンピューターの電源が切れていた場合）、HagiCode が起動した直後にプランが 1 回実行され、その後は通常どおり次回の実行が予定されます。何回分が過ぎていても、まとめて実行されることはなく、実行は 1 回だけです。
- **失敗した実行は再試行されません。** 実行時にセッションを作成できなかった場合（たとえばプロジェクトが削除された、選択した Agent が利用できないなど）、その回の実行はスキップされ、プランは次の予定時刻まで待ちます。復旧するには、問題を解決してから **Run now** をクリックします。手動の実行に失敗した場合は、その行に **Run now failed:** と理由が表示されます。
- **1 回限りのプランは実行後に Completed になります。** もう一度使うには、**Edit** をクリックして、未来の新しい時刻を設定します。期限切れの 1 回限りのプランのスイッチをオンにしようとしても、実行時刻がすでに過去なので拒否されます。
- **実行のたびに新しいセッションが作成されます。** 提案プランは提案セッションを、HagiTask プランは HagiTask セッションを作成します。これらは、手動で作成したセッションと同じようにセッションボードに表示されます。

## FAQ

**プランを保存しようとすると、実行時刻は現在より後でなければならない、または曜日を 1 つ以上選択するよう表示されます。**
これはフォームの入力チェックで、理由は該当する欄の下に表示されます。1 回限りのプランは現在より後の時刻でなければなりません。繰り返しプランでは、終了日が開始日より前であってはならず、毎週のプランでは曜日を少なくとも 1 つ選ぶ必要があり、期間内に実行可能な時刻が少なくとも 1 つ含まれている必要があります。

**Plan スイッチがグレーアウトしています。**
フォームに画像が添付されています。プランは画像に対応していません。画像を削除すると、スイッチが再び使えるようになります。

**予定の時刻にプランが実行されませんでした。**
次の順に確認してください。プランが **Enabled** であること、**Next run** が想定した時刻であること（特にタイムゾーン）、その時刻に HagiCode が起動していたこと、プランが使うプロジェクトと Agent がまだ存在すること。

**プランはどこに保存されますか。**
すべてのプランは、HagiCode のシステム管理の設定ディレクトリにある `scheduled-plans.json` に保存されます。ブラウザーには依存しないため、別のブラウザーから同じ HagiCode を開いても、同じプランが表示されます。
