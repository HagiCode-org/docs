会話セッションは、HagiCode で最も手軽に始められる入口です。プロジェクトを選んで質問すると、Agent がリポジトリを読み取って回答します。Agent にファイルの変更を許可するかどうかは、セッションごとに決められます。

## 前提条件

会話セッションを始める前に、次の項目を確認してください。

- [インストールガイド](/ja-JP/installation)に従い、いずれかのインストール方法（Microsoft Store、Desktop、Docker Compose）を完了している
- [ウィザードセットアップ](/ja-JP/quick-start/wizard-setup)を完了している（最初の Agent と少なくとも 1 つのプロジェクトが作成されます）
- そのプロジェクトをセッションボードで選択している

## 会話セッションの用途

会話セッションは、まず理解してから編集したい場合に最適です。主な用途は次のとおりです。

- 見慣れないリポジトリをすばやく分析する
- 特定のファイル、モジュール、エラーについて的を絞った質問をする
- 提案（proposal）として計画するまでもない小さな変更を行う
- 送信前に画像、定型フレーズ、過去のメッセージを添付する

タスクが「問題を理解する」段階から「構造化された変更を計画し、レビューし、アーカイブする」段階に進んだ場合は、[提案セッションを作成する](/ja-JP/quick-start/proposal-session)に進んでください。このページでは会話セッションのみを扱います。

## ワークフローの概要

| 段階 | 操作 | 動作 |
| --- | --- | --- |
| 作成 | **Create Normal Session**（通常セッションを作成）をクリックし、やりたいことを入力する | ドロワーでプロジェクト、任意のタイトル、スコープ、最初のメッセージを入力します |
| 開始 | **Available Agents** から Agent を選ぶ | セッションがすぐに開始され、**Execution** レーンに表示されます |
| 確認 | セッションカードを開く | Agent がリポジトリを読み取って回答し、**Session Complete** カードが実行内容を要約します |
| 判断 | メッセージ欄の横のモード切り替えを使う | 読み取り専用モードのままにするか、編集モードをオンにして Agent にファイルの変更を許可します |
| コンテキスト追加 | 画像、定型フレーズ、履歴のボタンを使う | 次のメッセージにより豊富なコンテキストを付けられます |

## ステップ 1: セッションを作成する

プロジェクトを選択し、ボード上部のツールバーにある **Create Normal Session**（吹き出しアイコン）をクリックします。

![プロジェクト、セッションタイトル、タスクスコープ、リクエスト、Available Agents の選択欄を含む Create Normal Session ドロワー](../../img/quick-start/conversation-session/01-create-normal-session.png)

ドロワーに次の内容を入力します。

- **Project**（必須）– 選択中のプロジェクトが初期値になります。
- **Session title** – 任意。ボード上のカードのタイトルになります。
- **Task scope** – 任意。**Repos** は MonoSpecs プロジェクトのリポジトリにセッションを絞り込み、**Vault** と **Projects** は追加の参照資料を添付します。
- **What do you want to do?**（必須）– 最初のメッセージです。**Upload Image** で画像を添付できます。

ドロワーの隣に **Available Agents** パネルが開きます。Agent をクリックすると、セッションが**すぐに開始**されます。最初のカードはランタイムの既定値で、2 番目の一覧では、この 1 回の実行に限って別の Agent を選べます。キーボードの `Ctrl/⌘ + Enter` でも送信できます。

:::tip[変更ではなく質問から始める]
「このプロジェクトが何をするものか 2 文で説明してください。ファイルは変更しないでください。」のような最初のメッセージは、Agent とプロジェクトが正しく連携しているかを安全に確認する方法です。
:::

## ステップ 2: 結果を読む

新しいセッションは、ステータスバッジ付きのカードとして **Execution** レーンに表示されます。クリックしてセッションを開きます。

![Agent の回答、Session Complete の要約、メッセージ欄、Agent ステータスカードを表示したセッションドロワー](../../img/quick-start/conversation-session/02-session-detail.png)

- **ヘッダー**には、タイトルと Agent に加え、**Archive**、**Delete Session**、**Open Code Server**、**…** メニューが表示されます。
- **会話**には、あなたのメッセージ、Agent のツール呼び出し（カード形式）、そして回答が一覧表示されます。
- **Session Complete** カードは、各実行の最後にターン数、経過時間、コストを表示します。クリックすると詳細が展開されます。
- メッセージ欄の右にある **Agent ステータスカード**には、Agent CLI、モデル、状態（例: *Idle*）、経過時間が表示されます。

メッセージ欄にフォローアップを入力します。`Enter` で送信、`Shift + Enter` で改行します。

## ステップ 3: 読み取り専用モードか編集モードかを選ぶ

メッセージ欄の左にあるスイッチには 2 つの位置があります。目のアイコンは**読み取り専用**で、Agent は調査と説明のみを行い、ファイルは変更しません。鉛筆のアイコンは**編集モード**で、新しいメッセージでファイルが変更されたり、現在の実装が調整されたりする可能性が高くなります。

![鉛筆（編集モード）を選択したメッセージ欄](../../img/quick-start/conversation-session/03-composer-edit.png)

![目（読み取り専用モード）を選択したメッセージ欄](../../img/quick-start/conversation-session/04-composer-readonly.png)

モードは現在のセッションに適用され、メッセージの合間に切り替えられます。**新しい**通常セッションを編集モードで開始するかどうかは、**Settings → Process & Interaction → Chat View → Default to Edit Mode for Normal Chats** で設定します。[設定](/ja-JP/user-guide/settings)を参照してください。

安全な進め方はシンプルです。まず読み取り専用モードで方向性を確認し、実際に変更が必要になったら編集モードに切り替えます。

## ステップ 4: 送信前にコンテキストを追加する

モード切り替えの横にある 3 つのボタンで、次のメッセージにコンテキストを追加できます。

- **Insert an image attachment** – スクリーンショット、エラーのキャプチャ、デザインの参考資料を添付します。画像はファイル名とサイズとともにメッセージ欄の上に表示され、送信前に **×** で削除できます。
- **Standard Phrases** – `@` 参照を挿入します。選択画面には、**Projects**（プロジェクトルートの正規パス）、**Vaults**（登録済み vault のパス）、**Proposal Sessions**（OpenSpec の変更フォルダー）、**Recent Items** があります。
- **Import Recent History** – このセッションの最近のメッセージを再利用できるため、同じ内容を入力し直す必要がありません。

![添付した画像が上に表示されているメッセージ欄](../../img/quick-start/conversation-session/05-composer-image.png)

![メッセージ欄から開いた定型フレーズの選択画面（Projects、Vaults、Proposal Sessions、Recent Items）](../../img/quick-start/conversation-session/06-standard-phrases.png)

画像は、次のような場合に役立ちます。

- Agent にインターフェースのスクリーンショットを説明してもらう
- エラーのスクリーンショットやデザインのモックアップを添付し、追加の指示を加える
- 編集モードに切り替える前に、視覚的なコンテキストを伝える

## 典型的な進め方

1. ツールバーからセッションを**作成**し、Agent を選びます。
2. プロジェクトに関する質問から**読み取り専用で開始**します。
3. **回答を読み**、フォローアップを質問します。
4. ファイルを直接変更する必要がある場合にのみ、**編集モードをオン**にします。
5. **画像、定型フレーズ、履歴を追加**して、次のメッセージにより多くのコンテキストを与えます。
6. 作業が終わったらセッションを**アーカイブ**します。セッションは **Archived** レーンに移動します。

タスクに計画、レビュー、アーカイブといった規律が必要になった場合は、提案セッションのガイドに進んでください。
