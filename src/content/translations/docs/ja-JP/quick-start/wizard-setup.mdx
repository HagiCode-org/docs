[Microsoft Store](/ja-JP/installation/windows-store)、[Desktop](/ja-JP/installation/desktop)、[Docker Compose](/ja-JP/installation/docker-compose) のいずれでインストールした場合でも、HagiCode の Web インターフェースを初めて開くと **初期化ウィザード** が表示されます。ウィザードを完了すると、使用可能なデフォルトの Hagicoder と少なくとも 1 つのプロジェクトが用意され、そのまま最初のセッションを始められます。

:::note[Desktop の初回セットアップとは別のものです]
Desktop の初回起動時に表示される「初回セットアップ」(言語の選択、法的文書の確認、Hagicode Server のダウンロード) は、Web インターフェースが表示される前に行われます。詳しくは [Desktop インストール](/ja-JP/installation/desktop#初回起動ガイド) を参照してください。このページで説明するのは、その後に Web インターフェース内で表示される初期化ウィザードです。
:::

## 始める前に

次の点を確認してください。

- **Agent CLI を 1 つ以上インストールし、ログインしていること**。ウィザードには、Hagicode Server が動作しているこのマシンで検出された CLI だけが一覧表示されます。1 つも検出されない場合は、Hagicoder を作成できません。サポートされている CLI とインストール方法は [AI Agent CLI のインストール](/ja-JP/related-software-installation/ai-agent-cli/) を参照してください。
- **Desktop / Store をお使いの場合**: [インストールガイド](/ja-JP/installation/#インストール前の準備) に従って、Node.js 24+ と Git をインストール済みであること。
- **Docker をお使いの場合**: Docker Compose Builder で API プロバイダーと Token を設定済みであること。
- 接続したいローカルのリポジトリまたは作業ディレクトリを用意していること。ステップ 3 でそれを登録します。

## ウィザードの概要

ウィザードは 4 つのステップで構成され、左側のナビゲーションに現在の進行状況が表示されます。

| ステップ | 目的 | 完了の目安 |
| --- | --- | --- |
| 1. 初期設定 | 画面の言語とテーマを選ぶ | 「次へ: プロジェクトを作成」をクリックする |
| 2. Hagicoder をセットアップ | CLI とモデルを選び、デフォルトの Hagicoder を作成する | 「確認して Hagicoder を作成」をクリックする、または使用可能なエージェントがすでにある |
| 3. プロジェクトを作成 | 少なくとも 1 つのプロジェクトを作成する | プロジェクトのステップに「プロジェクトのステップが完了しました」と表示される |
| 4. コミュニティ案内 | コミュニティの入口を確認する | 「HagiCode の使用を開始する」をクリックする |

## ステップ 1: 初期設定

**目的**: 画面の言語とテーマを決めます。

1. 「インターフェース言語を選択」で言語を 1 つ選びます。切り替わるのは画面のテキストだけで、Hagicoder の言語スタイルは変わりません。
2. 「テーマを選択」でテーマを 1 つ選びます。現在は「スプリングライト」と「スプリングダーク」が用意されています。
3. 「次へ: プロジェクトを作成」をクリックします。

## ステップ 2: Hagicoder をセットアップ

**目的**: デフォルトのエージェントを作成します。名前は **Hagicoder** で固定です。

すでにエージェントが存在する場合、このステップには「既存の エージェント が見つかりました」と表示されるので、既存のラインナップをそのまま使用してください。存在しない場合は、次の手順で作成します。

1. **「主に使用する AgentCLI を選択」**: ドロップダウンには、このマシンで検出された CLI だけが表示されます。使用できる CLI が検出されないと表示された場合は、先に [AI Agent CLI のインストール](/ja-JP/related-software-installation/ai-agent-cli/) に従ってインストールとログインを済ませ、ウィザードに戻って更新してください。
2. **「主に使用する モデル を選択」**:
   - **「既存のテンプレートを選択」**: その CLI にすでにあるモデルテンプレートを再利用します。名前またはモデル ID で検索できます。
   - **「カスタムモデルを入力」**: モデル名を直接入力します (例: `gpt-5.5`、`glm-5.1`、`claude-opus-4-7`)。作成時に、対応するテンプレートが自動的に再利用または新規作成されます。
3. **(任意) 「可用性をテスト」をクリック**: 選択した CLI とモデルに対して ping-pong 検証を 1 回送信し、モデルが `pong` を返せることを確認します。テスト結果は、現在の CLI とモデルの組み合わせにのみ有効です。変更した場合は、再度テストが必要です。Hagicoder の作成に、テストの合格は必須ではありません。
4. **(任意) 「シャッフル」をクリック** して、デフォルトの外見を変更します。アバターは画像ギャラリーからランダムに選ばれます。
5. 「確認して Hagicoder を作成」をクリックします。作成に成功すると、Hagicoder は緊急チームに追加され、選択した CLI とモデルがそのデフォルト設定として保存されます。

:::tip[サポートされている CLI]
ウィザードで選択できる CLI は、このマシンにインストールされて検出された Agent CLI によって決まり、特定の 1 種類に限られません。サポート範囲とインストール方法の全体は [AI Agent CLI のインストール](/ja-JP/related-software-installation/ai-agent-cli/) を正としてください。このうち Hermes、Gemini、DeepAgents は、先に手動でのインストールまたは認証を済ませる必要があります。
:::

**よくある問題**

- **一覧に使いたい CLI が表示されない**: その CLI がインストールされ、Hagicode Server が動作している環境で使用できることを確認してください。Desktop をお使いの場合は、`PATH` を更新するために Desktop を再起動してください。
- **可用性テストが失敗する**: よくある原因は、CLI にまだログインしていない、トークンが無効である、モデル名がその CLI でサポートされていない、などです。まずターミナルでその CLI を使って最小限の対話を実行し、CLI 自体が動作することを確認してください。
- **緊急チームへの追加に失敗する**: 画面に「緊急チームへの追加を再試行」が表示されるので、再試行してください。

## ステップ 3: プロジェクトを作成

**目的**: 少なくとも 1 つのプロジェクトを登録し、以降のセッションが読み取れる作業ディレクトリを用意します。ウィザードはまず、ローカルプロジェクトがすでに存在するかを確認します。存在する場合は現在のプロジェクトの概要が表示され、存在しない場合は先に 1 つ登録する必要があります。

1. 「ローカルプロジェクトを1つ登録する」で、プロジェクト名、フォルダーのパス、および任意のプロジェクトの説明を入力します。各フィールドとパスの検証は、メイン画面の「新しいプロジェクト」ダイアログとまったく同じです。
2. 「作成して続行する」をクリックして次のステップに進みます。このステップに留まって続けて追加したい場合は、「プロジェクトの作成」をクリックします。
3. すでにプロジェクトがある場合は、そのまま「コミュニティを続ける」をクリックするか、「別のプロジェクトを作成する」ことができます。また、「セットアップに戻る」で初期設定に戻ることもできます。

:::tip[先にサンプルプロジェクトで試したい場合]
ウィザードで提供されるのは、ローカルプロジェクトの登録だけです。「デモプロジェクト」は、メイン画面の「新しいプロジェクト」ダイアログにある「デモプロジェクト」タブにあります。公式の MonoSpecs Demo リポジトリを自動的にクローンして登録し、既定のパスは `data/repos/monospecs-demo` です。実際のディレクトリは実行時のデータディレクトリ (DataDir) の設定に従います。この方法には Git が必要で、GitHub にアクセスできる必要があります。
:::

**よくある問題**

- **パスの検証に失敗する**: フォルダーのパスが正しく、実際に存在することを確認してください。Docker でデプロイしている場合は、ホストマシン上のパスではなく、コンテナ内からアクセスできるマウント先のディレクトリを入力する必要があります。

## ステップ 4: コミュニティ案内

**目的**: コミュニティの入口を手元に置いておきます。

公式サイトの「About」ページに、すべてのコミュニティの入口がまとめられています。リンクは新しいタブで開きます。確認したらウィザードに戻り、「HagiCode の使用を開始する」をクリックすると、ワークスペースに入れます。このステップのあとも、ウィザードはいつでも開き直せます。
