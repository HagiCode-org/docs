このページでは、Windows、macOS、Linux での Node.js のインストール方法を説明します。Desktop と Microsoft Store 版は Node.js を同梱しなくなり、システムにインストールされた `node` と `npm` をそのまま使用します。OpenSpec とほとんどの Agent CLI も Node.js に依存しています。

:::tip[必要なバージョン]
**Node.js 24 以上** が必要です。最低要件も 24 です。通常は最新の LTS バージョンをインストールすれば問題ありません。`npm` は Node.js と一緒にインストールされるため、別途インストールする必要はありません。
:::

:::note[Node.js が必要なインストール方法]
- **Microsoft Store / Desktop**: 必要です。システムの `PATH` から `node` と `npm` を見つけられる必要があります。
:::

## Node.js のインストール

<Tabs>
  <TabItem value="windows" label="Windows" default>

### 方法 1: 公式インストーラー (推奨)

1. [Node.js 公式サイト](https://nodejs.org/) にアクセスします
2. **LTS (長期サポート)** 版の Windows インストーラー (`.msi` ファイル) をダウンロードし、バージョン番号が 24 以上であることを確認します
3. ダブルクリックしてインストーラーを実行します
4. インストールウィザードの案内に従ってインストールを完了します。
   - ライセンス契約に同意する
   - インストール先のパスを選択する (既定のままで問題ありません)
   - 「Add to PATH」のチェックを入れたままにする
   - 「Install」をクリックしてインストールを開始する
5. インストールが完了したら、「Finish」をクリックします

### 方法 2: winget を使用する

PowerShell またはコマンドプロンプトを開き、次のコマンドを実行します。

```powershell
winget install OpenJS.NodeJS.LTS
```

インストール後は、変更を反映させるためにターミナルを開き直してください。

  </TabItem>
  <TabItem value="macos" label="macOS">

### 方法 1: 公式インストーラー (推奨)

1. [Node.js 公式サイト](https://nodejs.org/) にアクセスします
2. **LTS (長期サポート)** 版の macOS インストーラー (`.pkg` ファイル) をダウンロードし、バージョン番号が 24 以上であることを確認します
3. ダブルクリックしてインストーラーを実行します
4. インストールウィザードの案内に従ってインストールを完了します。
   - 「続ける」をクリックする
   - ライセンス契約に同意する
   - インストール先のディスクを選択する
   - 「インストール」をクリックし、管理者パスワードを入力する
5. インストールが完了したら、「閉じる」をクリックします

### 方法 2: Homebrew を使用する

[Homebrew](https://brew.sh/) がすでにインストールされている場合は、ターミナルから Node.js をインストールできます。

```bash
brew install node
```

:::tip
Homebrew は Node.js を自動的に PATH に追加します。コマンドが使えない場合は、ターミナルを再起動するか、次のコマンドを実行してください。
```bash
eval "$(/opt/homebrew/bin/brew shellenv)"
```
:::

### NodeSource リポジトリを使用する (推奨)

ディストリビューション標準のリポジトリにある Node.js は、通常 24 より古いバージョンです。NodeSource が提供する 24.x のリポジトリを使用してください。

```bash
# curl でインストールスクリプトをダウンロード
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt-get install -y nodejs
```

:::caution
`sudo apt-get install nodejs npm` でディストリビューション標準のバージョンを直接インストールしないでください。24 という最低要件を満たさない可能性が高いです。
:::

サードパーティのソフトウェアリポジトリを追加したくない場合は、後述の [nvm または fnm](#バージョン管理ツールの使用) を使用することもできます。

  </TabItem>
  <TabItem value="centos" label="CentOS/RHEL">

### NodeSource リポジトリを使用する (推奨)

```bash
# curl でインストールスクリプトをダウンロード
curl -fsSL https://rpm.nodesource.com/setup_24.x | sudo bash -
sudo yum install -y nodejs
```

ディストリビューション標準のリポジトリにある Node.js は通常 24 より古いため、直接の使用はおすすめしません。後述の [nvm または fnm](#バージョン管理ツールの使用) に切り替えることもできます。

  </TabItem>
  <TabItem value="fedora" label="Fedora">

### dnf パッケージマネージャーを使用する

```bash
sudo dnf install -y nodejs npm
```

インストール後は `node --version` を実行して、バージョンが 24 以上であることを確認してください。リポジトリのバージョンが古い場合は、NodeSource の 24.x リポジトリを使用するか、後述の [nvm または fnm](#バージョン管理ツールの使用) を使用してください。

  </TabItem>
</Tabs>

## バージョン管理ツールの使用

複数の Node.js バージョンを切り替える必要がある場合は、バージョン管理ツールを使用できます。

:::caution[Desktop をお使いの方へ]
macOS と Linux では、nvm や fnm などのツールは、通常シェルの設定ファイル (`.bashrc`、`.zshrc` など) の中でのみ `PATH` を設定します。Dock、アプリケーションメニュー、デスクトップのアイコンから起動した Desktop はこれらの設定を読み込まないため、`node` を見つけられないことがあります。バージョン管理ツールを使用している場合は、すでに `node` を実行できるターミナルから Desktop を起動するか、前述のシステム全体へのインストール方法に切り替えてください。
:::

### nvm (Node Version Manager)

<Tabs>
  <TabItem value="nvm-install" label="nvm のインストール" default>

#### Linux/macOS

[nvm 公式リポジトリの README](https://github.com/nvm-sh/nvm#installing-and-updating) に記載されている最新のインストールコマンドをそのままコピーして使用してください。古いバージョンのインストールスクリプトのアドレスは使用しないでください。

インストール後、シェルの設定を再読み込みします。

```bash
source ~/.bashrc
# Zsh を使用している場合
source ~/.zshrc
```

#### Windows

Windows では、[nvm-windows](https://github.com/coreybutler/nvm-windows) の使用をおすすめします。

1. [nvm-windows のリリースページ](https://github.com/coreybutler/nvm-windows/releases) から最新の `nvm-setup.exe` をダウンロードします
2. インストーラーを実行します
3. コマンドプロンプトまたは PowerShell を開き直します

  </TabItem>
  <TabItem value="nvm-use" label="nvm の使用">

nvm をインストールしたら、それを使って Node.js のバージョンをインストール・管理できます。

```bash
# Node.js 24 をインストール
nvm install 24

# Node.js 24 に切り替え
nvm use 24

# 既定のバージョンを設定
nvm alias default 24

# インストール済みのバージョンを一覧表示
nvm list
```

nvm-windows では `alias` コマンドは使用できません。`nvm install 24` と `nvm use 24` を使用してください。

  </TabItem>
</Tabs>

### fnm (Fast Node Manager)

fnm は、Rust で構築された、より高速でシンプルな Node.js バージョン管理ツールです。

<Tabs>
  <TabItem value="fnm-install" label="fnm のインストール" default>

#### Linux/macOS

```bash
# curl を使用してインストール
curl -fsSL https://fnm.vercel.app/install | bash

# インストール後、シェルの設定を再読み込み
source ~/.bashrc
# Zsh を使用している場合
source ~/.zshrc
```

#### Windows

[scoop](https://scoop.sh/) または [winget](https://learn.microsoft.com/en-us/windows/package-manager/winget/) を使用します。

```powershell
# scoop を使用
scoop install fnm

# または winget を使用
winget install Schniz.fnm
```

  </TabItem>
  <TabItem value="fnm-use" label="fnm の使用">

```bash
# Node.js 24 をインストール
fnm install 24

# Node.js 24 に切り替え
fnm use 24

# 既定のバージョンを設定
fnm default 24

# インストール済みのバージョンを一覧表示
fnm list
```

  </TabItem>
</Tabs>

## 中国本土のユーザー向けの高速化

中国本土にお住まいの場合、Node.js や npm パッケージのダウンロードが遅くなることがあります。その場合は、国内のミラーを使用できます。

### npm ミラー

```bash
# 一時的にミラーを使用してインストール
npm install --registry=https://registry.npmmirror.com

# ミラーを恒久的に設定
npm config set registry https://registry.npmmirror.com

# ミラーが正しく設定されたか確認
npm config get registry
```

### Node.js インストーラーのミラー

Node.js のインストーラーにも、ミラーのダウンロードアドレスがあります: [https://npmmirror.com/mirrors/node/](https://npmmirror.com/mirrors/node/)。アクセスしたら、24 以上のバージョンを選択してダウンロードしてください。

### Homebrew ミラー

中国本土で Homebrew を使用している場合は、bottle に中国科学技術大学 (USTC) のミラーを設定できます。

```bash
export HOMEBREW_BOTTLE_DOMAIN=https://mirrors.ustc.edu.cn/homebrew-bottles
```

## インストールの確認

インストールが完了したら、**新しく開いたターミナル** で Node.js と npm が使用できることを確認します。

```bash
# Node.js のバージョンを確認 (v24.0.0 以上が必要)
node --version

# npm のバージョンを確認
npm --version
```

成功した場合の出力は、次のようになります。

```
$ node --version
v24.3.0

$ npm --version
11.4.2
```

:::note
`node --version` に表示されるバージョンが 24 より低い場合は、上記の方法で再インストールするか、バージョン管理ツールで 24 以上に切り替えてください。
:::

## npm グローバルディレクトリの設定

Desktop は、Agent CLI などの管理対象パッケージを、お使いのマシンの npm のグローバルディレクトリにインストールします。グローバルディレクトリが管理者権限を必要とする場所にあると、インストール時に `EACCES` の権限エラーが発生することがあります。システムのディレクトリの権限を変更するのではなく、グローバルディレクトリをユーザーのディレクトリに変更することをおすすめします。

```bash
mkdir -p ~/.npm-global
npm config set prefix ~/.npm-global
```

そのうえで、`~/.npm-global/bin` (Windows では npm のグローバルディレクトリそのもの) をシステムの `PATH` に追加し、ターミナルと Desktop を再起動します。nvm や fnm を使用している場合は、グローバルディレクトリがすでにユーザーのディレクトリ内にあるため、この手順は不要です。

## トラブルシューティング

### Windows の問題

<Tabs>
  <TabItem value="win-path" label="コマンドが使えない">

インストール後に `node` や `npm` コマンドが使えない場合は、次を試してください。

1. コマンドプロンプトまたは PowerShell を再起動する
2. それでも使えない場合は、Node.js を PATH に手動で追加する
   - 「環境変数」を検索して、「システム環境変数の編集」を開く
   - 「環境変数」をクリックする
   - 「システム環境変数」の中から「Path」を探し、「編集」をクリックする
   - Node.js のインストールパスを追加する (既定: `C:\Program Files\nodejs\`)
   - 「OK」をクリックして変更を保存する
3. Desktop を完全に終了してから、起動し直す

  </TabItem>
  <TabItem value="win-policy" label="PowerShell の実行ポリシー">

nvm や npm のスクリプトを使用する際に実行ポリシーのエラーが発生した場合は、次を実行してください。

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

  </TabItem>
</Tabs>

### macOS の問題

<Tabs>
  <TabItem value="mac-perm" label="権限エラー">

グローバルの npm パッケージをインストールする際に権限エラーが発生した場合は、前述の [npm グローバルディレクトリの設定](#npm-グローバルディレクトリの設定) を参照するか、nvm / fnm に切り替えてください。

  </TabItem>
  <TabItem value="mac-path" label="コマンドが使えない">

インストール後にコマンドが使えない場合は、ターミナルを再起動し、Node.js があるディレクトリ (通常は `/usr/local/bin` または `/opt/homebrew/bin`) が `PATH` に含まれていることを確認してください。

  </TabItem>
</Tabs>

### Linux の問題

<Tabs>
  <TabItem value="linux-perm" label="権限エラー">

グローバルの npm パッケージをインストールする際に権限エラーが発生した場合は、前述の [npm グローバルディレクトリの設定](#npm-グローバルディレクトリの設定) を参照するか、nvm / fnm を使用してください。`sudo` でグローバルパッケージをインストールするのは避けてください。

  </TabItem>
  <TabItem value="linux-old" label="バージョンが古すぎる">

システムのパッケージマネージャー経由でインストールした Node.js のバージョンが 24 より低い場合は、次のいずれかを行ってください。

1. NodeSource の 24.x リポジトリを使用する (前述)
2. バージョン管理ツール (nvm / fnm) を使用する

  </TabItem>
</Tabs>

### 環境の確認

確認に失敗する場合は、次の内容を確認してください。

<Tabs>
  <TabItem value="win-check" label="Windows">

```powershell
# Node.js が PATH にあるか確認
where node

# インストールパスを確認
Get-Command node
```

  </TabItem>
  <TabItem value="mac-check" label="macOS">

```bash
# Node.js が PATH にあるか確認
which node

# インストールパスを確認
ls -l $(which node)
```

  </TabItem>
  <TabItem value="linux-check" label="Linux">

```bash
# Node.js が PATH にあるか確認
which node

# インストールパスを確認
ls -l $(which node)
```

  </TabItem>
</Tabs>
