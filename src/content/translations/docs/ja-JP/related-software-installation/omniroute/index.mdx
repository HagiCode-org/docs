HagiCode の OmniRoute 組み込みサポートは削除されました。製品内に OmniRoute のインストール手順、設定画面、接続テスト、モデルカタログの同期はありません。

現在モデルに接続するには：

- Magpie で接続したモデルを使う、または
- Agent CLI がネイティブに対応しているプロバイダーとモデルを設定する。

HagiCode は古い OmniRoute のエンドポイントやキーを移行しません。設定で対応済みのプロバイダーとモデルを選択してください。Agent CLI の設定は [AI Agent CLI のインストール](/ja-JP/related-software-installation/ai-agent-cli/) を参照してください。

## 独立した OmniRoute ドキュメント

OmniRoute は独立したプロジェクトで、ドキュメントは自身のサイトで管理されています。HagiCode はこれをサポートしていません。
