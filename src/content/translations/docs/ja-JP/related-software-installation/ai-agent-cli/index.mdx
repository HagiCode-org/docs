このページは、HagiCode 共通の AI Agent CLI ローカルインストールの入口です。HagiCode は現在、次の 11 個の Agent CLI を有効にサポートしています: Claude Code、Codex、GitHub Copilot、OpenCode、Hermes、QoderCLI、Kiro、Kimi、Gemini、DeepAgents、Codebuddy。

:::tip[このページの使い方]
まず現在のサポート状態とセットアップ モードの表を確認してから、ベンダーが管理するインストール、認証、ACP、権限、およびトラブルシューティングに関するドキュメントに進みます。サポート範囲とセットアップ モードは別の問題です。
:::

:::note[インストール前に Node.js 24+ を準備してください]
ワンクリックインストールに対応しているほとんどの CLI は Node.js と npm に依存しており、Desktop もお使いのシステムの `node` と `npm` を使用します (Desktop は Node.js を同梱しなくなりました)。先に [Node.js のインストール](/ja-JP/related-software-installation/nodejs/installation) に従って 24 以上のバージョンを用意し、インストールが完了したら**ログインまたは認証を済ませてください**。初期化ウィザードには、このマシンで検出された CLI だけが表示されます。
:::

## 州の用語集

- **現在サポートされている** は、CLI が現在アクティブなHagiCode サポート範囲に属していることを意味します。
- **ワンクリック インストール** は、HagiCode がガイド付きインストール エントリ ポイントを提供することを意味します。一部の CLI では、インストール後もベンダー ログインまたは認証手順が必要です。
- **手動インストール/認証** は、CLI が現在サポートされていることを意味しますが、HagiCode が CLI を検出して使用できるようにするには、ローカル インストールまたは認証フローを完了する必要があります。
- **レガシー互換性のみ** は、iFlow CLI が旧データとの互換性のためだけに残されており、現在の有効なサポート対象には含まれず、現行の推奨項目としても扱わないことを意味します。

## 推奨される次のステップ

- 基本環境を先に整えたい場合は、[Node.js のインストール](/ja-JP/related-software-installation/nodejs/installation) に進み、必要に応じて [OpenSpec の紹介](/ja-JP/related-software-installation/openspec/intro-openspec) も参照してください。
- 複数の OpenAI 互換ツールに 1 つのローカル ゲートウェイが必要な場合は、次の手順に進みます。 [OmniRoute のインストールと使用法](/ja-JP/related-software-installation/omniroute/).
- インストール全体の流れや、Node.js、Git などの前提条件を知りたい場合は、[インストールガイド](/ja-JP/installation) に戻ってください。
- 歴史的なブログ投稿からここにたどり着いた場合は、このページとインストールの概要を最新の信頼できる情報源として扱ってください。
