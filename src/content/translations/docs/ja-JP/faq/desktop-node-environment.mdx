HagiCode Desktop は、**お使いのシステムにインストールされた外部の `node` と `npm`** を使用します。Desktop を初めて起動する前に Node.js をインストールし、両方のコマンドがシステムの `PATH` から見つかることを確認してください。

この FAQ では、Desktop が外部の Node 環境を見つける方法、Agent CLI のインストール先、Node または npm が見つからない場合の対処方法を説明します。

## バージョン要件

**Node.js 24 以上** が必要です (最低要件も 24 です)。`npm` は Node.js と一緒にインストールされます。インストール方法は [Node.js のインストール](/ja-JP/related-software-installation/nodejs/installation) を参照してください。

Git も同様にご自身でインストールする必要があります。[インストールガイド](/ja-JP/installation/#git-のインストール) を参照してください。

## Desktop が node と npm を見つける方法

Desktop は起動時にシステムの `PATH` を読み取り、その中から `node`、`npm`、`git` を探します。つまり、次のようになります。

- ターミナルで `node --version` を実行して表示されるバージョンが、通常は Desktop が使用するバージョンです。
- Desktop はお使いの Node 環境を**使用する**だけで、置き換えたり変更したりすることはありません。
- Desktop をすでに開いた状態で Node.js をインストールまたはアップグレードした場合は、Desktop を完全に終了してから起動し直し、新しい `PATH` を読み取らせてください。

:::caution[バージョン管理ツールと PATH]
macOS と Linux では、nvm や fnm などのバージョン管理ツールは、通常シェルの設定ファイルの中でのみ `PATH` を設定します。Dock、アプリケーションメニュー、デスクトップのアイコンから起動した Desktop はこれらの設定を読み込まないため、`node` を見つけられないことがあります。すでに `node` を実行できるターミナルから Desktop を起動するか、システム全体へのインストールに切り替えてください。
:::

## Agent CLI などの管理対象パッケージのインストール先

Desktop の依存関係管理ページは、`PATH` にある `node` と `npm` を検出し、解決された npm のグローバルプレフィックスを表示して、カタログに載っている CLI パッケージをこの**外部の**グローバルディレクトリにインストールします。

管理対象の各 CLI について、Desktop は次の順序で実行ファイルを探します。

1. すでに存在する管理対象のパス
2. npm のグローバル `bin` ディレクトリ (Windows では `.cmd` と `.ps1` の起動スクリプトを含む)
3. `PATH`

npm のミラー設定は、インストールと同期の操作に適用されます。アンインストールも同様に外部のグローバルディレクトリが対象で、画面での確認が必要です。現在のグローバルディレクトリは、次のコマンドで確認できます。

```bash
npm prefix -g
```

グローバルディレクトリが管理者権限を必要とする場所にある場合、インストール時に権限エラーが発生することがあります。その場合は [npm グローバルディレクトリの設定](/ja-JP/related-software-installation/nodejs/installation#npm-グローバルディレクトリの設定) を参照してください。

## Node または npm が見つからないと表示された場合

1. ターミナルで `node --version` を実行し、Node.js がバージョン 24 以上であることを確認します。続けて `npm --version` を実行し、npm が利用できることを確認します。
2. インストールされていない、またはバージョンが古すぎる場合は、先に Desktop の外で Node.js をインストールします。
3. Desktop を完全に終了してから起動し直し、依存関係のページに戻って更新をクリックします。

Desktop が特定の CLI パッケージの手動インストールを求めたときは、Desktop の外のターミナルで、表示されたコマンドを実行してください。完了したら Desktop に戻って一度更新し、再検出させます。
