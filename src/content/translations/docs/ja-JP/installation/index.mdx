HagiCode には 2 つのインストール方法があります。まず利用シーンに合った方法を 1 つ選び、その方法に必要な前提条件を確認してから、対応するインストールページに進んでください。

## インストール方法の選択

| 利用シーン | 推奨される方法 |
| --- | --- |
| Windows で個人のローカル環境として使う | [Microsoft Store インストール](/ja-JP/installation/windows-store) |
| macOS / Linux で個人のローカル環境として使う、または Windows でストアを利用できない | [Desktop インストール](/ja-JP/installation/desktop) |

## インストール前の準備

必要な前提条件はインストール方法によって異なります。

| インストール方法 | Node.js | Git |
| --- | --- | --- |
| Microsoft Store / Desktop | **24 以上** を自分でインストールする必要があります | 自分でインストールする必要があります |

:::caution[Desktop は Node.js を同梱しなくなりました]
Desktop に同梱されているのは Hagicode Server の実行に必要な .NET ランタイムだけで、**Node.js は提供されなくなりました**。Desktop はシステムの `PATH` から `node` と `npm` を探し、Agent CLI などの管理対象パッケージをお使いのマシンの npm のグローバルディレクトリにインストールします。Desktop を初めて起動する前に、Node.js 24 以上をインストールしておいてください。詳しくは [Node.js のインストール](/ja-JP/related-software-installation/nodejs/installation) を参照してください。
:::

### Git のインストール

Desktop は起動時に `node`、`npm`、`git` を検出します。また、メイン画面の「新しいプロジェクト」ダイアログにある「デモプロジェクト」でも、Git を使って公式のサンプルリポジトリをクローンします。お使いのシステムに合わせて、次のいずれかの方法でインストールしてください。

- **Windows**: `winget install --id Git.Git -e` を実行するか、[git-scm.com](https://git-scm.com/downloads) からインストーラーをダウンロードします。
- **macOS**: `xcode-select --install` を実行するか、Homebrew で `brew install git` を実行します。
- **Debian / Ubuntu**: `sudo apt-get install -y git` を実行します。
- **Fedora**: `sudo dnf install -y git` を実行します。

インストールが完了したらターミナルを開き直し、コマンドが使えることを確認します。

```bash
node --version
npm --version
git --version
```

:::tip[インストールしてから Desktop を起動してください]
Desktop は起動時にシステムの `PATH` を読み取ります。Desktop をすでに開いた状態で Node.js や Git をインストールした場合は、Desktop を完全に終了してから起動し直してください。
:::

### Agent CLI

HagiCode は、お使いのマシンにインストールされ、ログイン済みの Agent CLI を通じて動作します。初期化ウィザードにはこのマシンで検出された CLI だけが表示されるため、ウィザードに進む前に少なくとも 1 つをインストールしてログインしておいてください。現在サポートしている CLI、インストール方法、公式の入口は [AI Agent CLI のインストール](/ja-JP/related-software-installation/ai-agent-cli/) にまとめて掲載しています。

## 次のステップ

1. 上の表からインストール方法を選び、先に前提条件を済ませます。
2. インストールを完了して初回起動したら、[初期化ウィザードのセットアップ](/ja-JP/quick-start/wizard-setup) に従って、デフォルトの Hagicoder と最初のプロジェクトを作成します。
