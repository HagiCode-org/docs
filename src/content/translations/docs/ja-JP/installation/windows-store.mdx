Windows ユーザー向けには、Microsoft Store が現在の公開デスクトップ導入口です。このページでは Store 経由の導入だけを扱います。通常の Desktop の配布、バージョン管理、トラブルシューティングについては [Desktop インストール](/ja-JP/installation/desktop) を参照してください。

Steam のメインアプリ登録はすでに退役しているため、現在の主要な Windows 配布チャネルは Microsoft Store です。背景は [HagiCode が Steam で提供されていない理由](/ja-JP/faq/steam-distribution-status/) を参照してください。

:::tip[この方法が向いているケース]
- Windows 10 または Windows 11 を利用していて、システムストアから直接導入したい
- インストーラーファイルを手動で扱うより、Store 経由でアプリ本体を受け取りたい
- 個人向けのローカル環境だけが必要で、Docker Compose のデプロイは予定していない
:::

## 事前確認

始める前に、次の条件を確認してください。

- 端末で [HagiCode for Windows の Microsoft Store ページ](https://apps.microsoft.com/detail/9N3PM0N3SVDW) を開けること
- 初回起動時に Hagicode Server に必要なコンポーネントをダウンロードまたは準備する場合があるため、ネットワークを利用できること
- デバイス、地域、組織ポリシーによっては Microsoft アカウントのサインインを求められることがある
- 会社の端末でストアが無効になっている場合は、[Desktop インストール](/ja-JP/installation/desktop) に切り替える

## インストール前の準備

Store 版も Desktop と同じ動作方式です。**Node.js は同梱されない** ため、ご自身でインストールし、システムの `PATH` から見つかるようにしておく必要があります。初回起動の前に、次のものを準備してください。

- **Node.js 24 以上** (`npm` も同時に提供されます)。[Node.js のインストール](/ja-JP/related-software-installation/nodejs/installation) を参照してください
- **Git**。[Git のインストール](/ja-JP/installation/#git-のインストール) を参照してください
- インストール済みでログイン済みの **Agent CLI** を 1 つ以上。[AI Agent CLI のインストール](/ja-JP/related-software-installation/ai-agent-cli/) を参照してください

HagiCode をすでに開いた状態でこれらをインストールした場合は、HagiCode を完全に終了してから起動し直し、新しい `PATH` を読み取らせてください。

## Microsoft Store からインストールする

1. [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW) のページを開きます。
2. 「入手」、「インストール」、またはストアページ上の同等のボタンをクリックします。
3. Microsoft Store によるダウンロードとインストールが完了するまで待ちます。
4. 完了後、スタートメニューまたはストアページから HagiCode を起動します。

## 初回起動時の挙動

インストール後も、HagiCode は標準の Desktop 初期化フローに進みます。

- 初回起動ではまず Desktop の初回セットアップが表示されます。言語の選択、法的文書の確認を行い、必要に応じて Hagicode Server をダウンロードするため、一般的なアプリより遅く感じられることがあります
- Microsoft Store / MSIX チャネルでは「ランタイムデータの保存パス」の設定がロックされます。これはこの配布方式で想定されている挙動です
- アプリ本体は独立した自己更新を行わず、アプリパッケージの更新は導入チャネルに依存します。Store 版の場合、配信は Microsoft Store チャネルに結び付いています

初期化ウィザードを続ける場合は、[初期化ウィザードのセットアップ](/ja-JP/quick-start/wizard-setup) を参照してください。

## 別の導入方法を選ぶべき場合

次のような場合は、別のチャネルのほうが適しています。

- Microsoft Store にアクセスできない、または会社の端末で Store からのインストールが明確に禁止されている
- `.exe` や `.msix` のパッケージを手動で取得し、インストーラーの取得元を自分で管理したい
- サーバー、NAS、チーム共有環境に展開する場合は、[Docker Compose のデプロイメント](/ja-JP/installation/docker-compose) を参照してください

## よくある問題

### Microsoft Store ページが開かない

まずネットワーク、地域設定、Microsoft Store のサインイン状態を確認してください。ブラウザではリンクが開くのに Store クライアントが使えない場合は、通常、ローカルのシステムポリシーによって Store の機能が制限されています。その場合は [Desktop インストール](/ja-JP/installation/desktop) を利用してください。

### 一部の設定がグレーアウトされている

Store / MSIX インストールでは「ランタイムデータの保存パス」オプションがロックされ、「Microsoft Store によりロックされています」と表示されます。これはインストールの異常ではなく、現在の配布チャネルの仕様です。

### 初回起動でさらにダウンロードや準備が行われる

Store パッケージが配布するのはデスクトップアプリ本体だけです。初回起動時には、HagiCode が Hagicode Server に必要なコンポーネントをダウンロードまたは準備し、既定の初期化を行うことがあります。ネットワークを維持したまま、現在のステップが終わるまで待ってください。
