**Vault** 是 HagiCode 被允許在專案倉庫之外瀏覽和預覽的資料夾。可以用 Vault 存放參考文件、筆記、調研輸出，以及其他希望工作階段讀取或寫入的內容。

點擊頂欄中的 **Vault**（中文介面：Vault）開啟 **Vault Workspace**（Vault 工作區）。

![Vault 工作區，列出已登記的 Orbit Notes Docs Vault 和一個折疊的 System vaults 分組](../../img/user-guide/vault/01-vault.png)

## 已登記的 Vault 和系統 Vault

工作區有兩個分組：

- **Registered vaults**（已註冊 Vault）是你新增的資料夾。每張卡片顯示 Vault 類型、名稱、縮短後的路徑，以及一個 **Open Code Server**（開啟 Code Server）按鈕，用於在瀏覽器編輯器中編輯該資料夾。
- **System vaults**（系統 Vault）由 HagiCode 建立和維護。點擊 **Expand**（展開）查看它們。

![展開後的系統 Vault，顯示七個由系統管理的唯讀 Vault](../../img/user-guide/vault/02-vault-system-expanded.png)

在這個抽屜中，系統 Vault 是**唯讀**的。它們包括應用程式日誌、資料目錄、prompt 範本、個人資料、專案資料、目前存檔和系統預設。在工作階段範圍中，它們只算作參考資料。

## 新增 Vault

點擊 **Add vault**（新增 Vault），填寫 **Vault name**（Vault 名稱）和絕對路徑 **Physical path**（實體路徑），選擇 **Vault type**（Vault 類型），然後點擊 **Save vault**（儲存 Vault）。

![Add vault 抽屜，包含名稱、路徑，並選中了 Folder 類型](../../img/user-guide/vault/03-add-vault.png)

| Vault 類型 | 作用 |
| --- | --- |
| **Folder**（資料夾） | 按原樣登記任意已有的本機目錄。 |
| **CodeRef**（程式碼參考） | 自動建立 `docs/`、`repos/`、`AGENTS.md` 和 `index.yaml`。可用作調研任務的輸出 Vault。 |
| **Obsidian** | 自動建立 `.obsidian/`、`app.json` 和可預覽的筆記產物，使該資料夾可作為 Obsidian Vault 使用。 |

:::caution[儲存前先選擇類型]
點擊 **Save vault** 之前，請先選擇三種 Vault 類型之一。在撰寫本指南所用的版本中，未選擇類型就儲存會失敗，並顯示一條難以理解的錯誤，而不是校驗提示。
:::

## 在工作階段中使用 Vault

Vault 會出現在[建立提案抽屜和建立一般工作階段抽屜](/user-guide/sessions)的**範圍**（Scope，即介面中的「作用域」或「任務範圍」）裡。如果任務應該更新 Vault 中的檔案，就把它標記為**可編輯**（editable）；否則 AI 會把它當作唯讀的參考資料。由系統管理的 Vault 始終只作參考。
