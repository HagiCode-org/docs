**計畫**（Plan，也叫 Scheduled plan，即「排程計畫」）讓 HagiCode 在你設定的時間自動開始一個會話，不需要你在場點擊提交。典型用法：每個工作日凌晨 2 點跑一次程式碼審查、每天早上檢查相依套件更新，或者明天上午 10 點起草發布說明。

計畫儲存的是兩樣東西：一份**建立會話所需的全部輸入**（與你平時在建立對話框裡填寫的完全一樣），以及一份**時間表**。時間一到，HagiCode 用與手動提交相同的流程建立會話，所以自動啟動的會話和你親手建立的沒有區別。

## 基本概念

| 概念 | 含義 |
| --- | --- |
| **Type**（類型） | 計畫分兩種：**Proposal**（提案計畫，時間一到建立一個提案會話）和 **HagiTask**（時間一到用某個 HagiTask 建立會話）。類型由你從哪個建立對話框儲存計畫決定。 |
| **Scope**（範圍） | 計畫儲存時選擇 **Team**（團隊，進入版本控制）或 **Personal**（個人，檔名帶 `.user.yaml`，可被版本控制忽略）。儲存後範圍不能再改。 |
| **Run once / Recurring**（單次 / 週期） | 單次計畫只在一個時間點執行；週期計畫在起訖日期之間按天或按週重複執行。 |
| **Occurrence**（某一次） | 計畫在日曆上的一個具體時間點。單次計畫只有一次；週期計畫每到一個時間點就是一次，可以單獨修改或刪除，不影響其他次。 |
| **Next run**（下次執行） | 計畫下一次自動啟動的時間，按計畫自己的時區顯示。 |
| **Scheduled / Completed**（已排程 / 已完成） | 計畫的狀態。單次計畫執行後、或週期計畫走完結束日期後變為 Completed。 |
| **Enabled / Disabled**（已啟用 / 已停用） | 每個計畫都有一個啟用開關。停用的計畫保留在清單和日曆裡，但不會自動執行。 |

## 找到計畫

計畫有兩個入口：頂欄的計畫議程，適合快速看「最近和接下來有什麼」；專案詳情裡的 **Plans** 分頁，用來完整地檢視和管理一個專案的計畫。

### 頂欄的計畫議程

從今天到之後三天（共四個本地日）內，只要有至少一個**已啟用**計畫的執行時間，頂欄就會出現一個日曆圖示按鈕，右上角的數字是這段時間裡的執行次數（超過 99 顯示 `99+`）。視窗範圍內沒有任何計畫時，按鈕不會出現，也不佔位置。

![頂欄計畫議程彈出層：Plans, today to 3 days ahead，按日期分組列出每個計畫的執行時間](../../img/user-guide/plans/01-header-plans-button.png)

把滑鼠停在按鈕上、用鍵盤聚焦或點擊它，都會彈出 **Plans, today to 3 days ahead**（今天起三天內的計畫）議程：

- 按日期升序分組，只列出有執行時間的日期。每個日期標題帶有 **Today** 或 **Upcoming**（晚於今天）標籤，今天之前的日期不會列出。
- 每一列包含時間、計畫圖示和名稱、專案名、類型（**Proposal** 或 **HagiTask**）和重複方式（**Once**、**Daily**、**Weekly**）。被單獨改過時間的一次帶有 **Modified**，已完成的單次計畫帶有 **Completed**；今天已經過去的列顏色更淡。
- 它涵蓋你能讀取的所有專案，但**只統計已啟用的計畫**，停用的計畫不會出現在議程裡，也不計入角標。
- 議程只列出**排定的時間**，底部的 **Scheduled times, not run records.**（這是排定時間，不是執行記錄）就是這個意思。

點擊議程裡的某一列，會開啟該計畫所屬專案的專案詳情抽屜，停在 **Plans** 分頁，並直接開啟這個計畫的編輯器。如果是週期計畫，編輯器會停在 **Current event**（只改這一列顯示的那一次），你可以隨時切換為 **Overall plan**，見[編輯計畫](#編輯計畫)。

### 專案詳情裡的 Plans 分頁

在專案面板點擊 **View Project Details**（檢視專案詳情），頂部分頁依次是 **Details**、**MonoSpecs**、**Standard Words**、**Prompts**、**Plans** 和 **Git**。**Plans** 只管理目前這個專案的計畫，頂部有兩個檢視：

- **Calendar**（日曆）：按月、週或議程檢視計畫在什麼時間點會執行。
- **All plans**（全部計畫）：列出這個專案的每一個計畫，可以啟用、停用、立即執行、編輯和刪除。

**Plans** 分頁只負責**檢視和管理**已有計畫，不能在這裡新建：計畫總是在建立提案或 HagiTask 的對話框裡儲存的。還沒有任何計畫時，**All plans** 會提示用建立對話框裡的 **Plan** 開關來建立；手機寬度下則提示在更寬的螢幕上建立。切換到別的分頁再回來，檢視和日期範圍會保持不變；切換到另一個專案則會從頭開始。

## 在日曆中檢視計畫

**Calendar** 預設顯示目前月份，每個計畫的每一個執行時間點都是日曆上的一個項目，項目前面是計畫自己的圖示和顏色（見[圖示與顏色](#圖示與顏色)）。

![Calendar 的月檢視：October 2026，週期計畫的項目帶有重複圖示，今天的日期醒目標示](../../img/user-guide/plans/02-calendar-month.png)

頂部的控制項如下：

| 控制項 | 作用 |
| --- | --- |
| **Today**（今天） | 回到包含今天的月、週或議程。 |
| **‹ / ›** | 切換到上一個或下一個週期：月檢視按月，週檢視和議程檢視按週。 |
| **Month / Week / Agenda**（月 / 週 / 議程） | 切換檢視。版面按分頁自身的寬度調整：太窄放不下格線時，月和週檢視會在日曆內部橫向捲動，頁面本身不會捲動。 |
| **Display time zone**（顯示時區） | 日曆使用哪個時區來排列和顯示時間，預設是瀏覽器目前所在的時區。它只改變顯示，不會改變計畫本身的時區和實際執行時間。 |

三種檢視顯示的是同一批資料（只包含目前專案的計畫）：

- **Month**：每個日期格最多顯示 3 個項目，再多會出現 **+N more**（還有 N 個），點擊會彈出當天的全部執行時間。
- **Week**：七欄並排，每個項目可以顯示完整的計畫名稱。
- **Agenda**：按日期分組的清單，只列出有執行時間的日期，項目右側用文字標出狀態。

![Calendar 的週檢視：October 25 到 October 31，其中週二的一個項目帶有「已修改」的鉛筆圖示](../../img/user-guide/plans/03-calendar-week.png)

![Calendar 的議程檢視：按日期列出每個執行時間，右側標出 Repeats、Completed 和 Disabled](../../img/user-guide/plans/04-calendar-agenda.png)

每個項目由**時間**和**計畫名稱**組成。月檢視和週檢視用圖示標記狀態，懸停可以看到文字說明；議程檢視直接寫出文字：

| 標記 | 含義 |
| --- | --- |
| 重複圖示 / **Repeats** | 這是週期計畫中的一次。 |
| 勾號 / **Completed** | 計畫已經完成（例如單次計畫已經執行過）。 |
| 暫停圖示 / **Disabled** | 計畫已停用，這個時間點不會自動執行。 |
| 鉛筆圖示 / **Changed** | 這一次被單獨修改過，時間或內容和週期計畫不同。 |

:::note
日曆顯示的是**按目前計畫設定排出來的執行時間，不是執行歷史**。頁面上的 **Scheduled times from current plan settings. They are not run history.** 就是這個意思：計畫被編輯過，或已經停用、完成後，日曆仍然按它現在的設定排布，而不會記錄以前執行過什麼。已啟動的會話請到會話看板檢視。
:::

### 檢視某一次的詳情

點擊任意項目，右側會滑出這一次的詳情抽屜。檢視詳情不需要開啟編輯器。

![某一次執行的詳情抽屜：This time、Original time、Schedule、Next run 和 Project / repositories，底部是 Delete、Edit single 與 Edit all 按鈕](../../img/user-guide/plans/05-event-details.png)

| 欄位 | 說明 |
| --- | --- |
| 標題與徽章 | 計畫名稱、類型（**Proposal** 或 **HagiTask**）、狀態（**Scheduled** 或 **Completed**）和 **Enabled** / **Disabled**。 |
| **This time**（這一次） | 這一次的執行時間，按顯示時區排列。 |
| **Original time**（原定時間） | 只在這一次被改期時出現，顯示週期計畫原本安排的時間。 |
| **Schedule**（時間表） | 計畫的完整時間表。 |
| **Schedule time zone**（計畫時區） | 計畫自己使用的時區。 |
| **Next run**（下次執行） | 整個計畫真正的下一次執行時間，已完成的計畫顯示 `–`。注意它不一定等於「這一次」。 |
| **Project / repositories**（專案 / 儲存庫） | 計畫儲存的目標專案和儲存庫。 |
| **Agent** | 只在計畫指定了 Agent 時出現，顯示 **Random agent from the plan pool**。 |

抽屜底部的按鈕取決於計畫類型：

- **週期計畫**：**Edit single** 只修改這一次，**Edit all** 修改整個計畫，**Delete** 刪除這一次或整個系列。抽屜裡的說明寫著 **Edit single changes only this time. Edit all changes every time of the plan.**
- **單次計畫**：只有一個 **Edit** 和 **Delete**，**Edit** 直接開啟整個計畫的編輯器。

詳見[編輯計畫](#編輯計畫)和[刪除計畫](#刪除計畫)。

## 建立計畫

在建立提案和 HagiTask 的對話框裡，都可以把「立即開始」換成「按計畫開始」。一般會話（**Create Normal Session**）沒有計畫開關。

1. 像平時一樣開啟建立對話框，例如 **New Idea**（新建主意），填寫主意名稱、專案和需求。詳細欄位參見[會話](/zh-Hant/user-guide/sessions#新建主意提案)。
2. 看對話框右下角，提交按鈕旁邊有一個 **Plan**（計畫）開關，預設關閉。

   ![Create Proposal 抽屜的底部列：左側是 Cancel，右側依次是 Plan 開關和 Submit idea 按鈕](../../img/user-guide/plans/10-plan-switch.png)

3. 開啟 **Plan** 開關，對話框會切換為計畫模式：
   - 左上角的標籤從 **Create Proposal** 變為 **Proposal plan**（提案計畫）。
   - **Basic Setup** 頂部出現必填的 **Plan name**（計畫名稱），例如「Weekly release check」，最多 200 個字元。
   - 出現 **Schedule**（時間安排）區域。
   - 提交按鈕變為 **Save plan**（儲存計畫）。

   ![計畫模式下的 Create Proposal 抽屜：左側是 Plan name 和原有表單，右側是 Required content 清單和 Schedule 區域，底部是 Save plan](../../img/user-guide/plans/11-plan-mode-once.png)

4. 在 **Schedule** 裡設定執行時間，詳見[設定時間表](#設定時間表)。HagiTask 計畫還需要選擇一個 Agent，詳見[為 HagiTask 計畫選擇 Agent](#為-hagitask-計畫選擇-agent)。
5. 點擊 **Save plan**。HagiCode 會顯示 **Plan saved**（計畫已儲存）提示，點擊 **View plans**（檢視計畫）可直接開啟這個專案的 **Plans** 分頁。

   ![螢幕上的提示：Plan saved，右側有 View plans 按鈕](../../img/user-guide/plans/13-plan-saved-toast.png)

**Schedule** 區域最上方還有 **Team / Personal** 兩個按鈕，選擇這個計畫儲存為團隊計畫還是個人計畫，預設 **Team**。**Personal** 計畫儲存為 `.hagicode/plans/*.user.yaml`，可以用 `.gitignore` 把這類檔案排除在版本控制之外；儲存之後範圍唯讀，不能再改。

**Required content**（必填內容）清單會即時告訴你還缺什麼：提案計畫檢查 **Project**、**Requirement description**、**Plan name** 和 **Schedule**；HagiTask 計畫檢查 **Project**、該 HagiTask 自己的必填輸入、**Plan name**、**Schedule** 和 **Agent**。全部完成時顯示 **All required content is ready**。

:::note[視窗寬度與版面]
視窗足夠寬（約 1464 像素以上）時，**Required content** 和 **Schedule** 作為兩張卡片顯示在抽屜右側。視窗較窄時，**Schedule** 區域移到抽屜底部、提交按鈕上方，**Required content** 摺疊成一個可展開的列。兩種版面裡的內容和規則完全相同。
:::

:::note
計畫不能包含圖片。如果表單裡已經附加了圖片，**Plan** 開關會被停用，並提示先移除圖片再儲存為計畫。
:::

## 設定時間表

**Schedule** 區域的兩個按鈕決定執行方式：**Run once**（單次執行）和 **Recurring**（週期執行）。無論哪種方式，區域最下方的 **Next run** 都會即時顯示按目前設定計算出的下次執行時間；如果顯示 **Not scheduled**（未排程），說明目前設定下沒有可執行的時間，需要調整日期或時間。

### 單次執行

只在一個時間點執行一次。

| 欄位 | 說明 |
| --- | --- |
| **Date**（日期）和 **Time**（時間） | 執行的日期與時刻，預設是明天 09:00。必須晚於目前時間。 |
| **Run in**（多久後） | 快捷按鈕：`+5 min`、`+10 min`、`+30 min`、`+1 hour`，從現在起算。 |
| **Next at**（下一次） | 快捷按鈕：`02:00`、`09:00`、`12:00`、`18:00`、`22:00`，選當天或次日最近的這個時刻。 |
| **Time zone**（時區） | 日期和時間所使用的時區，預設是瀏覽器目前所在的時區。 |

### 週期執行

在起訖日期之間，按天或按週重複執行。

![Schedule 區域的週期模式：起訖日期、時間、Every week、週五，以及下次執行時間](../../img/user-guide/plans/12-recurring-schedule.png)

| 欄位 | 說明 |
| --- | --- |
| **From**（開始）和 **To**（結束） | 週期的起訖日期，兩端的日期都包含在內。預設從今天開始，持續一個月。**Start** 下的 `Today`、`Tomorrow`、`In 1 week`、`In 1 month`、`In 3 months` 用來快速設定開始日期，**Length** 下的 `+1 week`、`+1 month`、`+3 months` 用來快速設定時長。 |
| **Time**（時間） | 每次執行的時刻，格式 `HH:mm`。**Quick time** 提供 `02:00`、`09:00`、`12:00`、`18:00`、`22:00` 快捷選擇。 |
| **Repeat**（重複） | **Every day**（每天）或 **Every week**（每週）。 |
| **On**（星期） | 選擇 **Every week** 時出現，用 `Mon` 到 `Sun` 選擇在星期幾執行，至少選一天。 |
| **Time zone**（時區） | 時間所使用的時區。每次執行都以這個時區的本地時間為準，所以每天 02:00 的計畫在夏令時間切換前後仍然是 02:00。 |

:::tip
想讓計畫「長期有效」，把 **To** 設得遠一些即可，例如點 **+3 months**。到了結束日期之後，計畫會變為 **Completed**，不再執行。
:::

## 為 HagiTask 計畫選擇 Agent

提案計畫不需要選 Agent。**HagiTask 計畫必須選擇一個 Agent**，因為時間一到自動啟動時沒有人可以臨時挑選：

- 在計畫模式的對話框裡，會出現 Agent 選擇區，說明是「選擇本計畫執行時使用的 Agent，計畫啟動時會沿用這一選擇」。點擊一個 Agent 即可選取。
- 底部列會顯示 `Agent: 名稱`；還沒選時顯示 `No agent selected yet.`（尚未選擇智慧體），此時無法儲存計畫。
- 目前每個計畫只能選擇一個 Agent。建立 Agent 參見 [Agents](/zh-Hant/user-guide/agents)。

## 圖示與顏色

每個計畫都可以有自己的**圖示**和**顏色**，方便在日曆、清單和頂欄議程裡一眼區分。**Plan name** 旁邊有一個外觀欄位：

![計畫編輯器中 Plan name 旁的外觀欄位：圖示按鈕、Reset to default icon 和 Automatic 顏色](../../img/user-guide/plans/16-plan-appearance.png)

- 點圖示按鈕開啟 Lucide 圖示選擇器，選一個圖示並確認；點 **Reset to default icon** 恢復預設的日曆圖示。
- 顏色可以選 **Automatic**（自動，按計畫編號穩定地挑一個顏色，每個檢視裡都一樣），也可以從色盤裡選一個固定顏色。
- 外觀屬於**整個計畫**。只改某一次（**Current event**）時不顯示這個欄位，也不會改動它。

## 編輯計畫

編輯有三個入口：頂欄議程裡點某一列；**Calendar** 裡某一次的詳情抽屜中點 **Edit single** / **Edit all**（單次計畫只有 **Edit**）；或 **All plans** 裡計畫那一列的 **Edit**。無論哪個入口，HagiCode 都會先讀取這個計畫最新儲存的內容，再開啟與建立時相同的對話框（計畫模式）。已儲存的計畫始終是計畫，**Plan** 開關處於鎖定狀態，不能改回一般任務。

### 單次計畫

直接開啟編輯器，修改名稱、內容、Agent 或時間後點擊 **Save plan**。單次計畫只有一個範圍，編輯器裡沒有 **Edit scope** 開關。

### 週期計畫：Current event 與 Overall plan

編輯已有的週期計畫時，底部列的 **Plan** 開關旁邊有一個 **Edit scope**（編輯範圍）開關，兩個選項同一時間只選中一個，目前選中的帶有勾號：

![編輯器底部列：Edit scope 的 Current event 與 Overall plan 兩個選項，選中 Overall plan，右側是 Plan 開關和 Save plan](../../img/user-guide/plans/06-edit-scope-control.png)

| 選項 | 作用範圍 |
| --- | --- |
| **Current event**（目前這一次） | 只改你正在編輯的這個時間點，計畫的其他次保持不變。會寫明是哪一次。 |
| **Overall plan**（整個計畫） | 改整個週期計畫的每一次。之前被單獨修改過、但不再符合新時間表的那些次，會被重設。 |

不同入口預設停在不同的範圍：

| 入口 | 預設範圍 |
| --- | --- |
| 頂欄議程裡的某一列 | **Current event**，對應這一列顯示的那一次 |
| 日曆詳情裡的 **Edit single** | **Current event** |
| 日曆詳情裡的 **Edit all** | **Overall plan** |
| **All plans** 裡的 **Edit** | **Overall plan** |

無論從哪裡進入，都可以在編輯器裡隨時切換：

- **切換不會關閉編輯器，也不會丟掉你填的內容。** 你改過的欄位在兩個範圍之間保持你輸入的值；沒改過的欄位顯示新範圍自己的值。
- 從 **All plans** 進入並選擇 **Current event** 時，指的是計畫的下一次執行；如果計畫已經沒有未來的執行時間，**Current event** 會變灰並顯示原因，只能編輯 **Overall plan**。
- **儲存只寫入儲存那一刻選中的範圍。**

選中 **Overall plan** 時，抽屜頂部會提示 **This is a recurring plan. Saving changes the entire series, not a single time.**，提醒你儲存會影響所有次。

選中 **Current event** 時，抽屜頂部會寫明「Saving changes only this time, …」，時間表區域只剩下這一次的**日期、時間和時區**，不能再改成週期。你可以修改這一次的執行時間、名稱、需求內容和 Agent；沒有改動的欄位仍然跟隨整個計畫。

![編輯某一次：抽屜頂部寫明只修改這一次，右側的 Schedule 只有日期、時間和時區](../../img/user-guide/plans/14-edit-occurrence.png)

儲存後回到日曆，被改動的那一次會帶上鉛筆圖示（**Changed**），日曆頂部顯示 **Saved.**。

![儲存後的日曆：頂部是 Saved.，10 月 27 日的項目變成 03:00 並帶有鉛筆圖示](../../img/user-guide/plans/15-calendar-saved.png)

:::note
儲存後，如果這個計畫在目前顯示的月、週或議程裡沒有任何執行時間，日曆會提示 `"…" has no scheduled time in this period`，並給出 **All plans** 按鈕，計畫的詳情仍然可以從那裡檢視。
:::

## 刪除計畫

刪除同樣有兩個入口，並且都會先確認。

- **從日曆刪除**：在某一次的詳情抽屜裡點 **Delete**。週期計畫會先彈出 **Delete this time or the series** 範圍選擇：

  ![Delete this time or the series 對話框：This occurrence 和 Entire series 兩個選項，以及 Cancel 與 Continue 按鈕](../../img/user-guide/plans/07-delete-scope.png)

  選 **This occurrence** 並點 **Continue**，會出現 **Delete this time?** 確認；選 **Entire series** 則確認刪除整個計畫。單次計畫只有一個範圍，直接進入刪除確認。

  ![Delete this time? 確認：只刪除指定的這一次，計畫的其他次保持排程](../../img/user-guide/plans/07-delete-time-confirm.png)

- **從 All plans 刪除**：點計畫那一列的 **Delete**，確認後刪除整個計畫。

  ![刪除確認對話框：Delete this scheduled plan? 說明「Weekly docs cleanup」將停止執行，已啟動的會話會保留](../../img/user-guide/plans/09-delete-plan-confirm.png)

刪除某一次，只會讓這一個時間點不再執行；刪除整個計畫，計畫就停止執行。**無論哪種刪除，已經啟動的會話都會保留。**

## 在 All plans 中管理計畫

切換到 **All plans** 會看到所有計畫，每一列是一個計畫。

![All plans 清單：頂部是 All / Team / Personal 篩選，每列有計畫圖示、名稱、類型、範圍和狀態徽章、時間表、下次執行和定義檔路徑，右側是啟用開關與操作按鈕](../../img/user-guide/plans/08-all-plans.png)

清單上方的 **All / Team / Personal** 按鈕按範圍篩選，括號裡是各自的數量。每一列包含：

- **名稱**，以及 **Proposal** 或 **HagiTask** 類型徽章、**Team** 或 **Personal** 範圍徽章和 **Scheduled** 或 **Completed** 狀態徽章。
- **時間表摘要**，例如 `Weekly on Mon, Tue, Wed, Thu, Fri 02:00 AM, Oct 19, 2026 - Jan 18, 2027 (America/New_York)`。
- **Next run**（下次執行）。已完成的計畫顯示 `–`。
- **Definition file**（定義檔）：計畫定義檔的完整路徑，位於專案的 `.hagicode/plans/` 下，團隊計畫是 `<名稱>.yaml`，個人計畫是 `<名稱>.user.yaml`。右側的按鈕用來複製這個路徑，複製成功會提示 **File path copied**。

列右側的控制項：

| 控制項 | 作用 |
| --- | --- |
| **Enabled / Disabled** 開關 | 啟用或停用計畫。停用後計畫不會自動執行，但會保留在清單和日曆裡。再次啟用時，HagiCode 會從目前時間重新計算下次執行，停用期間錯過的時間點不會補跑。 |
| **Run now**（立即執行） | 馬上用儲存的輸入建立一次會話，成功後該列顯示 **Session started.**（會話已啟動）。它不會改變計畫的時間表和 **Next run**，已停用或已完成的計畫也可以手動執行。 |
| **Edit**（編輯） | 編輯整個計畫，見[編輯計畫](#編輯計畫)。 |
| **Delete**（刪除） | 刪除整個計畫，見[刪除計畫](#刪除計畫)。 |

## 計畫檔案

除了上面的**定義檔**（計畫本身的儲存位置），儲存計畫時 HagiCode 還會把計畫的內容同步成 Markdown 檔案，放進由 HagiCode 自動管理的 **Scheduled Plans** 保險庫（Vault），不需要你自己建立。每個計畫一個以編號命名的資料夾：

- `series.md`：整個計畫的設定和需求文字。
- `occurrence-<時間>.md`：每個帶有自己內容的「被修改的某一次」各有一份。

這些檔案是根據計畫產生的**副本**，方便你檢視、檢索或在別處引用；HagiCode 會按計畫的最新內容重寫它們，並在計畫被刪除時清理。要修改計畫，請在 **Plans** 分頁裡編輯：直接改這些副本不會改變計畫，改動也會被覆蓋。保險庫本身參見 [Vault](/zh-Hant/user-guide/vault)。

## 計畫何時執行

- **只在 HagiCode 執行時運作。** HagiCode 每 30 秒檢查一次是否有到時間的計畫，所以實際啟動時間可能比設定時間晚最多約 30 秒。
- **錯過的時間點只補跑一次。** 如果計畫到時間時 HagiCode 沒有執行（比如電腦關機），下次啟動 HagiCode 後會立即執行一次，然後按時間表安排下一次。錯過了多少個時間點都只補一次，不會批次補跑。
- **失敗不會重試。** 如果自動執行時無法建立會話（例如專案已被移除，或所選 Agent 不可用），這次執行會被跳過，計畫仍按時間表等待下一次。需要補救時，修復問題後點擊 **Run now** 手動執行；手動執行失敗時，該列會顯示 **Run now failed:** 和原因。
- **單次計畫執行後變為 Completed。** 如果想再次使用，點擊 **Edit** 設定一個新的未來時間。直接用開關啟用已過期的單次計畫會被拒絕，因為執行時間已在過去。
- **每個計畫都會建立新會話。** 提案計畫建立提案會話，HagiTask 計畫建立 HagiTask 會話，它們會像手動建立的會話一樣出現在會話看板上。

## 常見問題

**儲存計畫時提示「執行時間必須晚於目前時間」或「請至少選擇一個星期」。**
這是表單驗證。表單會在對應欄位下方顯示原因：單次計畫的時間要晚於現在；週期計畫的結束日期不能早於開始日期，按週重複時至少要選一個星期，並且起訖範圍內至少有一次可執行的時間。

**Plan 開關是灰色的。**
表單裡已經附加了圖片，而計畫不支援圖片。移除圖片後開關即可使用。

**日曆上沒有我剛儲存的計畫。**
日曆只顯示目前月、週或議程範圍內的時間點。切換到包含這些日期的月份，或到 **All plans** 檢視這個計畫。

**日曆上的時間和我設定的不一樣。**
日曆用 **Display time zone** 排列時間，預設是瀏覽器時區。計畫自己的時區顯示在詳情的 **Schedule time zone** 裡，實際執行始終按計畫的時區計算。

**計畫到時間了卻沒有執行。**
依次檢查：計畫是否為 **Enabled**；**Next run** 是否是你預期的時間（尤其是時區）；HagiCode 在那個時間點是否在執行；計畫使用的專案或 Agent 是否仍然存在；這一次是否被單獨刪除了。日曆顯示的是計畫設定，不是執行記錄，不能用來確認「有沒有跑過」。

**計畫儲存在哪裡？**
每個計畫儲存為所屬專案 `.hagicode/plans/` 資料夾中的一個檔案：團隊計畫是 `<名稱>.yaml`，個人計畫是 `<名稱>.user.yaml`。檔案格式和手動建立的方法見專案文件的 `.hagicode` 資料檔案一節。執行狀態（例如下次執行時間）儲存在本機，不寫入計畫檔案。舊版全域 `scheduled-plans.json` 不再讀取，其中的計畫不會自動遷移。
