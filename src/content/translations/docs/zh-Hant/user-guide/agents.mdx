HagiCode 中的 **Agent** 是一個開箱即用的工作者：由一個 Agent CLI（例如 Claude Code）、一個模型和可選的性格文字組成。會話由 Agent 執行，因此開始工作前至少需要一個 Agent。

點擊頂欄中的 **Agents**（中文介面：Agents）開啟 **Agents Workspace**（Agents 工作台）。它有六個分頁。

| 分頁 | 用途 |
| --- | --- |
| [Agents](#agents-分頁) | 建立和管理你的 Agent。 |
| [Execution Scenarios（執行場景）](#執行場景) | 決定由哪些 Agent 執行哪類工作。 |
| [AgentCLI](#agentcli) | 查看哪些 Agent CLI 已安裝、是否健康、是否啟用。 |
| [Model（模型）](#模型) | 瀏覽並擴充每個 Agent CLI 的模型目錄。 |
| [Document Theme（文案主題）](#文案主題) | 選擇介面的文案主題。 |
| [Avatar Gallery（頭像畫廊）](#頭像畫廊) | 瀏覽頭像包。 |

:::note
AgentCLI 和模型目錄屬於系統級。Agents 分頁只儲存你目前的 Agent 及其編組。
:::

## Agents 分頁

![Agents 分頁，My Agents 清單依 Agent CLI 分組，顯示 Hagicoder 這個 Agent](../img/user-guide/agents/01-agents.png)

**My Agents**（我的Agents）列出你的 Agent，並依它們使用的 Agent CLI 分組。每張卡片顯示頭像、名稱、模型，以及表示 CLI 的小徽標。

- **New Agent**（新建Agent）開啟建立抽屜。
- **Batch create Agents**（批次建立Agents）一次建立多個。
- **Search**（搜尋）依 Agent 名稱、AgentCLI 或簡介篩選。
- **Select all visible**（全選目前可見）、**Clear visible**（清除目前可見）和 **Delete N selected**（刪除已選 N 項）用於批次刪除。

### 建立 Agent

![New Agent 抽屜，包含 Agent 裝備欄、特質和靈魂部分](../img/user-guide/agents/02-new-agent.png)

此抽屜一次建立一個 Agent。建立成功之前，Agents 視圖保持原樣。

- **Name and avatar**（名稱與頭像）– 會從名稱池中建議一個隨機名稱。上傳自訂頭像需要 TurboEngine DLC。
- **Agent loadout**（Agent 裝備欄）– 兩個必填槽位。點擊候選圖示即可裝備：
  - **AgentCLI** – 由哪個命令列工具執行 Agent。
  - **Model**（模型）– 該 CLI 使用的模型。清單只顯示與所選 CLI 相容的模型。
- **Trait · knowledge and behavior**（特質 · 知識與行為）– 自由文字，或來自特質平台（Trait platform）的特質，用來塑造 Agent 的工作方式。
- **Soul · language style**（靈魂 · 語言風格）– 自由文字，或來自靈魂平台（Soul platform）的靈魂，用來塑造 Agent 的說話風格。
- **Battle ready**（出戰狀態）開關 – 啟用或停用該 Agent。

## 執行場景

對應 **Execution Scenarios** 分頁。

![Execution Scenarios 分頁，包含提案、HagiTask 和聊天場景以及編組編輯器](../img/user-guide/agents/03-execution-scenarios.png)

場景決定每類工作選用哪個 Agent。它們依出現的位置分組：

| 分組 | 場景 |
| --- | --- |
| **Proposal**（提案階段執行場景） | Optimize Proposal（優化提案）、Generate Proposal（生成提案）、Execute Proposal（執行提案）、Archive Proposal（歸檔提案） |
| **HagiTask**（Hagitask 執行場景） | AI commit（AI 提交）、Create Normal Session（建立普通會話）、Create Research Investigation Task（建立程式碼調研任務） |
| **Chat**（聊天執行場景） | Conversation Title Optimization（會話標題優化） |

**Fallback Crew**（備援班組）是安全網。當某個場景自己的編組裡沒有合適的 Agent 時，HagiCode 會從備援班組中隨機嘗試符合條件的成員。它是必需的：**在備援班組至少有一個已啟用的 Agent 之前，其他所有場景都保持鎖定。**初始化精靈會自動把你的第一個 Agent 加進去。

點擊某個場景即可編輯。**Assigned Agents**（已編組Agents）顯示編組裡有誰，**Available Agents**（可加入Agents）顯示可以加入的成員，篩選標籤可依 Agent CLI 縮小清單。執行時會隨機嘗試符合條件的成員，因此介面上的顯示順序並不代表優先順序。

## AgentCLI

![AgentCLI 管理表格，列出每個 CLI 的啟用狀態、可用性、版本和監控狀態](../img/user-guide/agents/04-agentcli.png)

此分頁列出 HagiCode 能驅動的所有命令列工具：Claude Code、Codebuddy、Codex、DeepAgents、DSH、Gemini、GitHub Copilot、Hermes、Junie、Kimi、Kiro、OMP、OpenCode、Pi、QoderCLI 和 Reasonix。

對於每個 CLI，你可以看到：

- **Enabled**（已啟用）和 **Availability**（可用狀態）– CLI 必須安裝在執行 HagiCode 的機器上才可用。
- **CLI version**（CLI 版本）– 偵測到的版本；找不到可執行檔時顯示 *Not detected*（未偵測）。
- **Monitoring**（監測）– 最近一次健康檢查，例如 *Healthy*（健康）。
- **Show diagnostics**（展開診斷資訊）– 檢查結果背後的詳細資訊，在 CLI 未被偵測到時很有用。
- 一個用於啟用或停用該 CLI 的**開關**。使用核取方塊配合 **Enable selected**（啟用所選項）和 **Disable selected**（停用所選項）可一次修改多個；篩選器可以只顯示 *Available*（可用）或 *Unavailable*（不可用）的 CLI。

如果已安裝的 CLI 沒有被偵測到，請確認它的可執行檔位於執行 HagiCode 的處理程序的 `PATH` 中，然後重新載入。參見 [AI Agent CLI 安裝](/related-software-installation/ai-agent-cli)。

## 模型

對應 **Model** 分頁。

![Model 分頁，顯示 Claude Code 模型目錄和 Create Model 表單](../img/user-guide/agents/05-model.png)

在頂部選擇一個 **AgentCLI** 即可查看它的模型。表格顯示每個模型的名稱、模型 ID、來源，以及是否支援圖片。

- **System defaults**（系統預設）條目是唯讀的，由 HagiCode 維護。
- **Custom**（自訂）條目屬於你自己。用 **Create Model**（新增模型）表單建立：*Display name*（顯示名稱）、*Summary*（摘要）、*Icon*（圖示）、CLI 所需的 *Model value*（模型值），以及是否 *Supports images*（支援圖片）。**Create blank entry**（建立空白條目）從一個空白列開始。
- 可以依名稱或模型 ID 篩選，依來源（*All sources*（所有來源）、*Custom*、*System default*）篩選，或只看 *Support images only*（僅支援圖片）的模型。

## 文案主題

對應 **Document Theme** 分頁。

![Document Theme 分頁，AgentCLI Baseline 主題為目前主題，其他主題處於鎖定狀態](../img/user-guide/agents/06-document-theme.png)

文案主題會改變介面的用詞。**AgentCLI Baseline**（AgentCLI 基線）使用中性措辭，例如 *Agents*、*Jobs*（作業）和 *Workspace*（工作台），是預設主題。其他主題（例如 *Fantasy Adventure*（奇幻冒險）措辭）需要 TurboEngine DLC；它們的預覽仍然可見，但處於鎖定狀態。**Restore default theme**（還原預設主題）會回到基線主題。

## 頭像畫廊

對應 **Avatar Gallery** 分頁。

![Avatar Gallery，左側是頭像包，右側是所選頭像的大圖預覽](../img/user-guide/agents/07-avatar-gallery.png)

瀏覽可用於 Agent 的頭像包。選擇一個頭像包和一個頭像，即可查看它的預覽、外掛來源、版本和穩定 ID。
