## General（一般）

### General Settings（一般設定）

![General Settings 分頁，包含品牌自訂與回到頂部按鈕的位置](../../img/user-guide/settings/01-general-settings.png)

- **Brand Customization**（品牌自訂）用於設定自訂的頂欄 Logo、應用程式標題、品牌跳轉連結和瀏覽器標題，並即時預覽效果。這些控制項可以預覽，但在 TurboEngine DLC 啟用之前處於鎖定狀態。
- **Back to Top Button Settings**（回到頂部按鈕設定）選擇「回到頂部」按鈕在工作階段中的位置，例如 *Bottom Right*（右下角）。

### Notifications（通知）

![Notifications 分頁，包含通知管道與狀態規則表格](../../img/user-guide/settings/04-notifications.png)

先開啟通知，再選擇管道：**Toast notifications**（Toast 通知）、**Browser notifications**（瀏覽器通知，瀏覽器必須允許）、**Speech synthesis**（語音合成）和 **Sound Settings**（音效設定）。**Status rules**（狀態規則）表格讓你為每種工作階段狀態（例如 *New*（新建）、*Drafted*（已起草）、*Executing*（執行中）、*Waiting for Reply*（等待回覆）、*Execution Complete*（執行完成）或 *Archived*（已封存））選擇觸發哪些管道以及播放哪個聲音。播放按鈕可以試聽聲音。

### Confirm Prompts（確認提示）

![Confirm Prompts 分頁，每個確認對話框對應一個開關](../../img/user-guide/settings/12-confirm-prompts.png)

一個總開關，加上每個確認對話框各一個開關：超級提交全部之前；產生提案、將其移到待執行、立即執行或封存之前；以及封存或刪除所選工作階段之前。關閉提示可以少點幾次，但出錯的代價會更高。**Reset to Default**（恢復預設設定）會恢復預設值。

### About（關於）

![About 分頁，顯示 HagiCode 平台版本與社群資源](../../img/user-guide/settings/30-about.png)

顯示版本和建置日期，並連結到包含完整社群清單的官方「關於」頁面。

## Appearance and interface（外觀與介面）

### Startup Splash（啟動畫面）

![Startup Splash 分頁，包含啟動畫面開關、圖片選擇方式與固定圖片選擇器](../../img/user-guide/settings/32-startup-splash.png)

決定 HagiCode 啟動時顯示哪張畫面。**Changes apply the next time HagiCode starts.**（修改在下次啟動時生效）

- **Show startup splash image**（顯示啟動畫面圖片）關閉後，啟動時只顯示品牌名稱、版本和載入指示。
- **Image selection**（圖片選擇方式）有三種：**Random on every startup**（每次啟動隨機）、**Random once per day**（每天隨機一張，當天首次啟動時選定，之後保持不變）和 **Fixed image**（固定圖片）。
- 選擇 **Fixed image** 後，下方的選擇器會列出可用的啟動畫面，點一張就會在每次啟動時顯示它。

這些控制項可以預覽，但在 TurboEngine DLC 啟用之前處於鎖定狀態，就像截圖裡顯示的那樣。

### Status Bar Scroll（狀態列捲動）

![Status Bar Scroll 分頁，包含顯示開關與目前推廣清單](../../img/user-guide/settings/26-status-bar-scroll.png)

選擇狀態列是否捲動，以及使用哪些來源：**Tips**（提示）和 **Promotions**（推廣）。關閉捲動或推廣需要有效的 TurboEngine 訂閱。此分頁會列出目前的推廣內容。

### TokenMonitor

![TokenMonitor 分頁，包含狀態列開關與 HostHub 欄位](../../img/user-guide/settings/24-tokenmonitor.png)

在狀態列中顯示來自 TokenMonitor 桌面應用程式的今日 token 用量和費用。開關關閉時不會讀取任何內容。要獲得近即時更新，請同時填寫 **HostHub address**（HostHub 位址）和 **HostHub secret**（HostHub 金鑰）；任一留空，則改為讀取 TokenMonitor 的本地資料檔案。

### Mermaid Appearance（Mermaid 圖表外觀）

![Mermaid Appearance 分頁，包含 Default 和 Archify-inspired 兩種預設](../../img/user-guide/settings/10-mermaid-appearance.png)

選擇 Mermaid 圖表的外觀：*Default*（預設）或 *Archify-inspired*（Archify 風格）。此選擇只儲存在目前的瀏覽器中，只改變視覺效果。

### Kanban Right Panel（看板右側面板）

![Kanban Right Panel 分頁，包含顯示模式選項與預覽](../../img/user-guide/settings/06-kanban-right-panel.png)

選擇工作階段看板右側顯示什麼：*Hidden*（隱藏）、*GitHub Discussion*，或帶有快捷操作和儲存庫狀態的 *Quick Operations Panel*（快速操作面板，預設值）。即時的 **Preview**（預覽效果）會顯示設定後的樣子。

## Sessions and conversation（工作階段與對話）

### Session List（工作階段清單）

![Session List 分頁，包含專案範圍、排序模式與顯示選項](../../img/user-guide/settings/11-session-list.png)

- **Project Scope**（專案範圍）選擇哪些專案進入 *All Sessions* 看板：*All Projects*（全部專案）或 *Custom Selection*（自訂選擇）。點擊 **Save** 套用。
- **Session Sorting**（工作階段排序）可選 *Smart Sorting*（智慧排序，依執行狀態和最近活動排序）或 *Custom Sorting*（自訂排序，使用你自己的優先順序規則）。
- **Session Display Settings**（工作階段顯示設定）包括已封存的工作階段是否繼續顯示在清單中。

### Chat View（聊天檢視）

![Chat View 分頁，包含聊天模式、除錯中繼資料和長訊息選項](../../img/user-guide/settings/16-chat-view.png)

- **Default to Edit Mode for Normal Chats**（一般工作階段預設為編輯模式）決定新建的一般工作階段是以編輯模式（Agent 可以修改檔案）開始，還是以唯讀模式開始。
- **Show debug metadata entry points**（顯示除錯中繼資料入口）會在聊天訊息中增加除錯入口。
- **Auto-collapse long messages**（自動摺疊超長訊息）會把較長的歷史訊息顯示為預覽，並帶有展開控制項。
- **Simplified historical tool calls**（簡化歷史工具呼叫）會把較早的工具呼叫摺疊為一段簡短摘要，附在下一則可見訊息上。

### AgentCLI Interactive Control（AgentCLI 互動控制）

![AgentCLI Interactive Control 分頁，每個 Agent CLI 對應一個開關](../../img/user-guide/settings/15-agentcli-interactive-control.png)

每個 Agent CLI 一個開關，決定產生的 OpenSpec 和 HagiTask 提示詞是否仍然告知 Agent 本次執行是非互動的。開關關閉時（預設）會包含這條提示。這只會改變產生提示詞的措辭。

### Agent resource limits（Agent 資源上限）

![Agent resource limits 分頁，分為 Memory 和 CPU 兩組，各有一個開關和一個上限下拉選單](../../img/user-guide/settings/33-agent-resource-limits.png)

限制每個 Agent CLI 以及它執行的指令最多能用多少記憶體和 CPU。**修改後的上限只對之後啟動的 Agent 生效。**分頁分為 **Memory** 和 **CPU** 兩組。

- **Limit memory per agent**（限制每個 Agent 的記憶體）：開啟後，每次新的 Agent 執行連同它啟動的所有處理程序，都受下面的上限約束。
- **Limit per agent**（每個 Agent 的上限）：從下拉選單裡選擇上限，預設 4 GB。說明文字會列出對應的軟限制、Node.js 堆積大小、交換分割區和工作數上限。Hagicode 會在 systemd 使用者範圍（user scope）裡啟動 Agent 來實現這個限制。
- **Limit CPU per agent**（限制每個 Agent 的 CPU）：開啟後，每次新的 Agent 執行連同它啟動的所有處理程序，共用下面設定的 CPU 時間。
- **Virtual CPU cores per agent**（每個 Agent 的虛擬 CPU 核心數）：以虛擬核心數（本機回報的邏輯處理器）計，預設 1。說明文字會顯示所選核心數佔本機總核心數的比例。

如果目前系統不支援其中某項能力（例如不是 Linux、沒有 `systemd-run`、沒有 systemd 使用者範圍，或沒有委派 cpu 控制器），分頁會顯示原因，對應的開關無法使用，Agent 會在沒有該限制的情況下啟動。

### Error Retry（錯誤重試）

![Error Retry 分頁，包含預設重試策略與依 CLI 的覆寫項](../../img/user-guide/settings/14-error-retry.png)

失敗執行的自動重試。**Default Policy**（預設策略）設定最大重試次數和每次重試前的延遲，後續嘗試使用末尾延遲。預設的重試間隔依序為 30、30、30、60 秒。**CLI Overrides**（CLI 覆寫項）讓每個 Agent CLI 可以沿用預設策略，或使用自己的間隔。

### Post-state actions（工作階段狀態後動作）

![Post-state actions 分頁，Super Commit 工作階段在 Execution completed 後自動 Archive session](../../img/user-guide/settings/34-post-state-actions.png)

決定某類工作階段進入某個狀態之後，HagiCode 自動做什麼。規則按列出的順序執行。目前內建的規則針對 **Super Commit sessions**（由超級提交訊息產生啟動的工作階段）：

- **Enabled**（啟用）：開啟後，規則生效。
- **When the session reaches**（當工作階段達到）：觸發規則的狀態，例如 **Execution completed**（執行完成）。
- **Then**（然後）：要執行的動作，例如 **Archive session**（封存工作階段）。

預設的規則會在超級提交工作階段執行完成後自動封存它們，讓它們離開工作階段清單。

## Proposals and planning（提案與規劃）

### Proposal Creation（提案建立）

![Proposal Creation 分頁，包含最近儲存庫位數量](../../img/user-guide/settings/07-proposal-creation.png)

設定提案儲存庫選擇器頂部顯示多少張最近儲存庫卡片。選擇 `0` 可隱藏這一列。

### Planning Direction（規劃方向）

![Planning Direction 分頁，依 Agent CLI 列出規劃方向的矩陣](../../img/user-guide/settings/08-planning-direction.png)

這是一個矩陣，列出提案流程預設為每個 Agent CLI 提出的規劃方向：探索模式、變更地圖、互動流程、原型、架構、API 時序，以及可編輯和僅參考的儲存庫範圍。單一 Agent 可以覆寫這些預設值。

### Proposal Stage Diagram（提案階段圖）

![Proposal Stage Diagram 分頁，包含 Full 和 Compact 兩種顯示模式及即時預覽](../../img/user-guide/settings/09-proposal-stage-diagram.png)

設定提案抽屜中階段清單的詳細程度：*Full*（完整）顯示階段標籤和說明，*Compact*（精簡）只顯示標籤。這只影響抽屜的側邊欄，不影響主流程圖。

## Input and efficiency（輸入與效率）

### Haginput

![Haginput 分頁，包含輸入模式與遠端模式設定](../../img/user-guide/settings/18-haginput.png)

智慧輸入。可選擇 **Disabled**（已關閉）、**Doubao Local Voice**（豆包本地語音）或 **Haginput Remote Mode**（Haginput 遠端模式），後者可以在不開啟本地麥克風的情況下，從手機或第二台裝置轉送文字。此分頁顯示模式狀態、自動連線選項、收到文字時的提示音和一個測試框。

### Common Phrases（常用片語）

![Common Phrases 分頁，包含分類可見性、路徑來源與自訂分組](../../img/user-guide/settings/17-standard-phrases.png)

這個分頁合併了原來的 **Standard Phrases**（標準用詞）和 **Common Requirements**（常用需求），分為兩部分。

**片語**：管理訊息框中可重複使用的 `@` 片語標記。選擇哪些分類和路徑來源（專案、Vault、提案工作階段、最近專案、自訂路徑）出現在 `@` 選擇器中，並用 **Add Group**（新增分組）建立自訂片語分組。

**常用需求**：

![Common Phrases 分頁下半部分的常用需求清單](../../img/user-guide/settings/13-common-requirements.png)

可重複使用的需求片段，可一鍵加入提案需求中，例如 *No docs / tests*（不含文件測試）、*Self commit*（自行提交）、*Output English*（輸出中文，隨介面語言變化）、*Ask before edit*（編輯前詢問）和 *No backward compatibility*（不相容舊版）。只會列出目前介面語言對應的需求。用 **Add Common Requirement**（新增常用需求）建立你自己的需求，並用編輯和刪除按鈕管理它們；內建的系統預設可以用 **Restore missing system presets**（恢復缺失的系統預設）找回。

### Quick Actions（快速操作）

![Quick Actions 分頁，指令清單和執行歷史均為空](../../img/user-guide/settings/05-quick-actions.png)

**Configured Commands**（已設定指令）列出你用 **Add Command**（新增指令）加入的自訂指令。**Execution History**（執行歷史）記錄它們的執行時間。

### Comments（註解）

![Comments 分頁，包含行註解和檔案註解兩個範本清單](../../img/user-guide/settings/03-comments.png)

儲存你常用的註解範本，分為兩個清單：**Line Comments**（行註解）和 **File Comments**（檔案註解）。用 **Add Comment**（新增註解）建立範本，用 **Save** 儲存修改。

## Projects and integrations（專案與整合）

### Project Icon（專案圖示）

![Project Icon 分頁，包含預設圖示模式與圖示集合](../../img/user-guide/settings/02-project-icon.png)

- **Project Icon Mode**（專案圖示模式）設定新專案的預設樣式：*Game Icon*（遊戲圖示，隨機的彩色圖示，為預設值）或 *Text Abbreviation*（文字縮寫，取專案名稱的首字母）。單一專案可以在[專案詳情](/user-guide/projects#詳情)中覆寫它。
- **Icon Collection**（圖示集合）控制哪些圖示可以被選取。可以使用 **Show All**（顯示全部）、**Enable All**（全部啟用）、**Disable All**（全部停用）、**Random 50**（隨機 50 個）和 **Refresh**（重新整理），也可以點擊某個圖示來切換它。

### GitHub

![GitHub 分頁，顯示已連線的本地 gh CLI 工作階段與設定說明](../../img/user-guide/settings/21-github.png)

使用你本地的 GitHub CLI（`gh`）工作階段來同步工作階段並匯入 GitHub 資料。此分頁顯示連線狀態和已授予的權限範圍，並提供 **Refresh status**（重新整理狀態）和 **Copy login command**（複製登入指令）。權杖只在目前頁面工作階段期間保留在記憶體中，從不寫入本地儲存。如果 `gh` 尚未登入，請依照分頁上顯示的 *Local `gh` setup*（本地 `gh` 設定步驟）操作。

### Git

![Git 分頁，包含 Git Profile、狀態監控與超級提交預設值](../../img/user-guide/settings/22-git.png)

- **Git Profiles**（Git Profile）儲存超級提交可以使用的作者身分。開始超級提交之前請至少建立一個，這樣提示詞總能寫明明確的作者。
- **Automatically refresh and monitor Git status**（自動重新整理並監控 Git 狀態）會定期檢查活躍專案。這可能增加磁碟活動，尤其是在 Windows 上或儲存庫很多時。**Maximum monitored Git repositories**（最大監控 Git 儲存庫數）限制同時監視的數量（預設 15）。
- **Super Commit default behavior**（超級提交按鈕預設行為）決定主超級提交按鈕的動作：先 *Open confirmation panel*（開啟確認面板），或使用已儲存的 Profile 和預設值 *Commit immediately*（立即提交）。其他選項設定提交後預設是否推送或 rebase。

### Code Server

![Code Server 分頁，顯示解析後的設定與執行狀態](../../img/user-guide/settings/25-code-server.png)

唯讀展示解析後的 Code Server 設定（主機、連接埠、認證模式、來源）和最新的執行時快照。這裡不支援編輯 Code Server 設定。

### OmniRoute

![OmniRoute 分頁，包含整合開關、API 端點、執行狀態與模型目錄](../../img/user-guide/settings/23-omniroute.png)

啟用共享的 OmniRoute 整合。設定 **API endpoint**（API 端點）和可選的 **API key**（API 金鑰），使用 **Test connection**（測試連線），並選擇哪些 Agent CLI 使用 OmniRoute 的模型目錄。右側顯示執行狀態和已快取的模型目錄。整合關閉時，模型管理會回退到最初的系統預設值。安裝方法參見 [OmniRoute](/related-software-installation/omniroute)。

## Lifestyle and wellbeing（生活與健康）

### Achievements（成就）

![Achievements 分頁，包含每日進度彈出提示的開關](../../img/user-guide/settings/27-achievements.png)

用於開關狀態列中每日成就進度的彈出提示。無論是否開啟，全域里程碑通知和資料同步都保持啟用。參見[狀態列與進度](/user-guide/status-bar-and-progress#獎盃與成就殿堂)。

### Break Reminder（休息提醒）

![Break Reminder 分頁，包含計時器狀態與提醒主題](../../img/user-guide/settings/19-break-reminder.png)

一個提醒你喝水、伸展或站起來活動的計時器。它顯示上一次和下一次提醒以及今天的循環次數，並可選擇提醒主題，例如 *Basic*（基礎樣式）。提醒會顯示在[狀態列](/user-guide/status-bar-and-progress#休息提醒)中。

### Salary Tracker（時薪掛機）

![Salary Tracker 分頁，包含日薪、工時與單位 emoji](../../img/user-guide/settings/20-salary-tracker.png)

一個有趣的按分鐘計算收入的計數器。填寫 **Daily salary**（日薪）和 **Work hours per day**（每日工時）；每分鐘收益等於日薪除以（工時 × 60），日薪為 `0` 時關閉計算。從 20 個單位 emoji 中選一個，並選擇狀態列是否顯示該指示器。

## System（系統）

### Data Management（資料管理）

![Data Management 分頁，包含資料庫目錄、存檔目錄與資料清理](../../img/user-guide/settings/28-data-management.png)

顯示目前的存檔及其資料資料夾（存檔根目錄、設定目錄、資料目錄）。**Save Catalog**（存檔目錄）列出存檔，並讓你安全地啟用一個就緒的存檔。**Workspace**（工作區）切換器可在 *Primary Database*（主資料庫）、*Message Database*（Message 資料庫）和 *Image Storage*（圖片儲存）工具之間切換。**Data Cleanup**（資料清理）顯示資料庫資訊，並清理已封存的工作階段訊息資料以釋放儲存空間。

### Debug（除錯）

![Debug 分頁，包含 SignalR 日誌、HagiPower 調整與 DLC 選項](../../img/user-guide/settings/31-debug.png)

面向開發建置的工具：

- **SignalR Log**（SignalR 日誌）會把 SignalR 事件和訊息即時列印到主控台。
- **HagiPower Adjustment**（HagiPower 調整）在開發環境中直接編輯共享的公共池。它不會改變正常的生產環境計算。
- **Enable DLC**（啟用 DLC）透過後端設定明確地讓 TurboEngine DLC 啟用或停用，因為本地開發環境沒有內部的啟用開關。

正常使用時不需要這個分頁。

### Danger Zone（危險區域）

![Danger Zone 分頁，包含 Reset system data 按鈕](../../img/user-guide/settings/29-danger-zone.png)

**Reset system data**（重設系統資料）會重設持久化狀態，並刪除目前存檔的主資料庫記錄和訊息分片。圖片、外掛、儲存庫和其他存檔不受影響。應用程式會繼續執行，之後建議重新啟動。此操作無法復原。

## 外觀、主題與語言

頂欄中的兩個按鈕無需開啟設定就能改變 HagiCode 的外觀。

![Choose theme 對話框，包含淺色和深色變體的主題系列以及自動切換面板](../../img/user-guide/status/07-theme-chooser.png)

**Theme**（主題）開啟主題選擇器（**Choose theme**，選擇主題）。每個主題系列都有 **Light**（亮色）和 **Dark**（暗色）兩種變體，並立即生效。系列包括 Standard（標準）、Spring（春季）、Summer（夏季）、Vacation（暑假）、Autumn（秋季）、Winter（冬季）、Lunar New Year（新年）、Soccer（足球）、Cyberpunk（賽博）、School（學校）和 Space Travel（星際）。**Auto-switch**（自動切換）會依 1 到 240 分鐘的固定間隔在淺色或深色主題之間輪換。

![Select Language 對話框，選取了 English，並列出其他九種介面語言](../../img/user-guide/status/08-language.png)

**Language**（語言）開啟語言對話框（**Select Language**，選擇語言）。選擇一種語言並點擊 **Confirm**（確認）。HagiCode 支援 English、簡體中文、繁體中文、日本語、한국어、Deutsch、Français、Español、Português (Brasil) 和 Русский。
