本節是 HagiCode 工作台的操作手冊，依介面模組逐一說明。你可以直接開啟與目前所用功能對應的頁面。

## 工作台一覽

工作台預設開啟**工作階段看板**。下圖使用一個名為 `orbit-notes` 的小型示範專案，其中有一個已完成的工作階段。

![HagiCode 工作台，顯示頂欄、專案欄、含三條泳道的工作階段看板、專案面板和狀態列](../../img/user-guide/workbench/01-workbench-overview.png)

介面分為五個區域：

| 區域 | 位置 | 用途 | 指南 |
| --- | --- | --- | --- |
| **頂欄**（Header） | 頂部邊緣 | 開啟工作區層級模組：Agents、Wizard、Skills、HagiTask、Vault、Plans、設定、語言、主題和個人資料 | [頂欄](#頂欄) |
| **專案欄**（Project rail） | 左側邊緣 | 在全部專案與單一專案之間切換，並新建專案 | [專案](/user-guide/projects) |
| **工作階段看板**（Session board） | 中間 | 以泳道呈現工作階段，並提供新建工作階段的按鈕；可在五種檢視之間切換 | [工作階段](/user-guide/sessions)、[檢視](/user-guide/views) |
| **專案面板**（Project panel） | 右側 | 所選專案的快捷操作和儲存庫狀態 | [專案](/user-guide/projects) |
| **狀態列**（Status bar） | 底部邊緣 | 提示、Agent CLI 健康狀態、執行中工作階段、休息提醒、日薪計數器和建置版本 | [狀態列與進度](/user-guide/status-bar-and-progress) |

## 頂欄

頂欄始終可見。其中的按鈕會在目前頁面之上開啟抽屜或對話框，因此不會失去看板上的位置。

![HagiCode 頂欄，包含 Agents、Wizard、Refresh、Skills、HagiTask、Vault、Plans、Get Support、語言、主題、設定和個人資料按鈕](../../img/user-guide/workbench/03-header-navigation.png)

| 按鈕 | 開啟的內容 |
| --- | --- |
| **Agents**（中文介面：Agents） | Agents 工作台：你的 Agent、執行場景、AgentCLI 清單、模型目錄、文案主題和頭像圖庫。參見 [Agents](/user-guide/agents)。 |
| **Wizard**（精靈） | 四步驟初始化精靈。參見[首次啟動](#首次啟動初始化精靈)。 |
| **Refresh**（重新整理） | 重新載入目前頁面的內容。 |
| **Skills**（技能） | 統一的技能模組，包含 Local Skills、Gallery 和 Trusted Providers。參見[技能與 HagiTask](/user-guide/skills-and-hagitask)。 |
| **HagiTask**（中文介面：HagiTask） | HagiTask 管理，用於管理任務預設集。參見[技能與 HagiTask](/user-guide/skills-and-hagitask)。 |
| **Vault**（中文介面：Vault） | Vault 管理器，用於管理 HagiCode 可以瀏覽和預覽的資料夾。參見 [Vault](/user-guide/vault)。 |
| **Plans**（計畫，日曆圖示；視窗較窄時只顯示圖示，懸停提示 Scheduled plans） | 計畫管理器，用於管理按時間表自動啟動會話的計畫。參見[計畫任務](/zh-Hant/user-guide/scheduled-plans)。 |
| **Get Support**（取得技術支援） | 在瀏覽器中開啟社群與支援頁面。 |
| **Language**（語言） | 切換介面語言。HagiCode 提供十種介面語言，包括簡體中文。 |
| **Theme**（主題，葉子圖示） | 開啟主題選擇器。參見[外觀、主題與語言](/user-guide/settings#外觀主題與語言)。 |
| **Settings**（設定，齒輪圖示；開啟的對話框標題為「設定」） | 開啟設定對話框。參見[設定](/user-guide/settings)。 |
| **Profile**（個人資料，圓形頭像） | 開啟個人資料抽屜，包含積分、歷史時間軸和快捷入口。參見[狀態列與進度](/user-guide/status-bar-and-progress#個人資料)。 |

## 首次啟動：初始化精靈

全新安裝後，**Initialization wizard**（初始化精靈）會自動開啟。你也可以隨時透過頂欄的 **Wizard** 按鈕重新開啟。精靈共四步，並會顯示三個必要步驟中已就緒的數量。

![初始化精靈第 1 步：選擇介面語言和配色主題](../../img/user-guide/wizard/01-language-theme.png)

1. **Language & theme**（語言與主題） – 選擇介面語言和季節配色主題，兩者都會立即生效。
2. **Hagicoder** – 選擇本地 Agent CLI 和模型，建立你的第一個 Agent，並將其加入 **Fallback Crew**（備援班組）。建議進行一次連線測試，但不是必要的。
3. **Project**（專案） – 登記第一個專案的資料夾。
4. **Community**（社群）（選用） – 開始第一次對話，或開啟「關於」頁面。

![初始化精靈第 2 步：設定預設 Agent 並將其加入 Fallback Crew](../../img/user-guide/wizard/02-agent.png)

完整流程以及各欄位的意義，參見[初始化精靈設定](/quick-start/wizard-setup)。
