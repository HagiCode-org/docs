技能和 HagiTask 都能擴展 Agent 的能力，兩者都從頂欄開啟。

- **技能**是 Agent CLI 會載入的可重用指令包，例如設計規範或框架最佳實踐。
- **HagiTask** 是 HagiCode 透過會話流程執行的任務預設，例如 *Normal Session*（普通會話）或 *Research Investigation*（程式碼調研）。

## 技能

點擊頂欄中的 **Skills**（技能）。抽屜有三個標籤頁。更詳細的操作說明參見 [Skills 使用指南](/guides/skills)。

### Local Skills（本地技能）

![Local Skills 標籤頁，包含搜尋、Refresh inventory、Update all 和已安裝技能表格](../../img/user-guide/skills/01-local-skills.png)

後端是這台機器上已安裝全域技能的唯一可信來源。

- **Refresh inventory**（重新整理庫存）會重新掃描機器。**Update all**（全部更新）會更新所有可更新的技能。
- 表格顯示每個 **Skill**（技能）、它綁定到哪些 **Agents**（代理）、它的 **Path**（路徑），以及可用的 **Actions**（操作）：**Update**（更新）和 **Uninstall**（解除安裝）。
- 帶警告的列缺少一鍵更新所需的安裝中繼資料檔案，所以它的更新操作會顯示 *Unavailable*（不可更新）。

### Gallery（畫廊）

![Gallery 標籤頁，包含搜尋框、來源篩選，以及帶安裝次數的技能排行清單](../../img/user-guide/skills/02-gallery.png)

可以依名稱、ID、來源搜尋技能庫，也可以貼上 GitHub 儲存庫 URL。**Trusted only**（僅授信）會把清單限制為你信任的提供者的技能。每一列顯示技能、它的來源和被安裝的次數。安裝前，開啟某一列即可查看確切的安裝指令。

### Trusted Providers（授信提供者）

![Trusted Providers 標籤頁，包含規則格式說明和預設提供者表格](../../img/user-guide/skills/03-trusted-providers.png)

授信提供者決定哪些來源會獲得 *Trusted* 標籤。此目錄只保存已驗證的來源，從不保存憑證。每行寫一條規則：

- `prefix:owner/` 信任某個擁有者的全部儲存庫。
- `exact:owner/repo` 信任單一儲存庫。

預設包含 Vercel、Azure、anthropics 和 Microsoft 等預設提供者。使用 **Add provider**（新增提供者）、**Edit**（編輯）、**Delete**（刪除）或 **Reset defaults**（重設為預設清單）來修改它們。

## HagiTask

點擊頂欄中的 **HagiTask**，或點擊會話看板上的 **More HagiTasks**（更多 HagiTask），開啟 **HagiTask workspace**。它同樣有三個標籤頁。

### Package management（套件管理）

![Package management 標籤頁，列出 Create proposal、Normal Session 和 Research Investigation 預設](../../img/user-guide/skills/04-hagitask-packages.png)

清單顯示每個已安裝的預設及其 **Order**（順序）、**Name**（名稱）、**Version**（版本）、**Source**（來源）和 **Enabled**（已啟用）開關。用開關開啟或關閉某個預設。

- **Create proposal**（建立提案）是內建的特殊操作。它一律存在，無法安裝或解除安裝。
- **Normal Session**（普通會話）和 **Research Investigation**（程式碼調研）是工作區預設。
- **Change order**（變更排序）可調整清單順序。**Install community HagiTask**（安裝社群 HagiTask）會跳轉到畫廊。**Reload list**（重新載入清單）會重新讀取各來源。

點擊某一列，可在右側查看它的詳細資料。

### Community Gallery（社群市集）

![Community Gallery 標籤頁，列出社群 HagiTask 預設，帶有 Install 按鈕和詳細資料面板](../../img/user-guide/skills/06-hagitask-gallery.png)

瀏覽由 HagiCode 團隊和社群發布的預設，例如 *CodeGraph Tasks*、*GitHub Tasks* 和 *AGENTS.md Update*。每個項目顯示它的分類、版本、標籤和所需的 CLI 工具。點擊 **Install**（安裝）即可新增。**Create or contribute a task**（建立或貢獻 Task）會開啟貢獻指南，而 *Add Community Task* 預設會帶你一步步撰寫任務。

### Source management（來源管理）

**Source management** 標籤頁顯示預設的載入來源：內建預設和社群資料夾。**Add folder source**（新增資料夾來源）可登記另一個資料夾，**Reload sources**（重新載入來源）會重新掃描它們。不再支援從本機資料夾安裝單一任務；請從社群畫廊安裝。
