工作台底部邊緣和頂部的幾個小元件會在不打擾你的前提下隨時告知資訊。本頁介紹狀態列、獎盃與成就殿堂，以及你的個人資料。

## 狀態列

![狀態列，包含 Microsoft Store 徽標、捲動提示、Agent CLI 健康狀態、執行中會話、休息提醒、日薪計數器和版本](../img/user-guide/workbench/04-status-bar.png)

從左到右依序是：

| 項目 | 顯示什麼 |
| --- | --- |
| **Microsoft Store badge** | 指向 HagiCode 在 Microsoft Store 上架頁面的連結。 |
| **捲動的提示和推廣** | 一次捲動顯示一則提示或推廣。提示說明如何使用 HagiCode；推廣連結到相關專案。你可以在 **Settings → Integration → Status Bar Scroll**（設定 → 整合 → 狀態列捲動）中關閉捲動或選擇內容來源。 |
| **Agent CLI 健康狀態** | 小徽標，例如 `CC`、`CO` 和 `GC`，分別代表 Claude Code、Codex 和 GitHub Copilot，健康時帶有綠點。`+N` 表示另外還有多少個工具。點擊這些徽標可重新整理健康檢查。 |
| **Running sessions**（執行中會話） | 目前正在執行的會話數量。點擊可查看詳情。 |
| **Break reminder**（休息提醒） | 一個水滴圖示，顯示目前提醒間隔還剩多少。 |
| **Salary tracker**（時薪掛機） | 單位 emoji 和今天累計的金額。計數器及其狀態列指示器開啟時顯示。 |
| **Version**（版本） | 建置版本，例如開發建置中顯示 `dev`。 |

### 執行中會話

![執行中會話彈出層，顯示會話上限、超頻選項，目前沒有執行中的會話](../img/user-guide/status/03-running-sessions.png)

HagiCode 會限制同時執行的會話數量，預設是 20。彈出層顯示目前數量與上限的對比，並列出執行中的會話。

- **Overclock**（超頻）會把上限提高 3。達到目前上限後才可使用；彈出層會顯示已使用的次數。
- TurboEngine DLC 可以進一步提高並行檔位。

### 休息提醒

![休息提醒彈出層，包含一則訊息以及 Remind me later 和 Take a break 按鈕](../img/user-guide/status/04-break-reminder.png)

計時器觸發時，會出現一張卡片，顯示目前提醒主題的訊息。**Take a break**（休息一下）表示已確認，**Remind me later**（稍後提醒）表示延後提醒。在 **Settings → Integration → Break Reminder**（設定 → 整合 → 休息提醒）中設定間隔和語氣。

### 日薪計數器

![日薪計數器彈出層，顯示每分鐘收益、今天、已用分鐘、昨天和歷史總計](../img/user-guide/status/05-salary-tracker.png)

點擊 emoji 可以查看每分鐘收益、今日總額、已用分鐘、昨日總額和歷史總額。**Open settings**（開啟設定）會跳轉到 **Settings → Integration → Salary Tracker**（設定 → 整合 → 時薪掛機），在那裡設定日薪和工時。

## 獎盃與成就殿堂

會話看板右上角的 **Trophies**（獎盃）小元件會用星星顯示你的進度。四顆星（星）組成一個月（月），四個月組成一個日（日），四個日組成一個冠（冠）。標題旁的數字表示距離下一次晉升還差多少顆星。

點擊它即可開啟 **Achievement Hall**（成就殿堂）。

![成就殿堂，顯示每日得分、完成率、今日戰況概覽和線上成長](../img/user-guide/status/01-achievements.png)

- **Daily Achievements**（每日成就）是每天重置的目標，例如開始並完成提案、Agent 產出和工具活動。標題處顯示每日得分，例如 `0/17`。
- **Global Achievements**（全域成就）是跨天累積的終身里程碑。
- **Mission Board**（任務大廳）彙總當天的情況：完成率、進行中的目標和獎勵通道。
- **Online growth**（線上成長）記錄 HagiCode 執行期間累積的進度。

你在這裡以及日常工作中獲得的積分會顯示在個人資料中。每日進度彈出提示可以在 **Settings → Game → Achievements**（設定 → 遊戲 → 成就）中關閉。

## 個人資料

點擊頂欄最右側的圓形頭像，開啟你的個人資料抽屜。

![個人資料抽屜，包含頭像、積分、歷史時間線和快捷入口](../img/user-guide/status/02-profile.png)

- **Avatar**（頭像）– 上傳不超過 10 MB 的 JPEG、PNG、WEBP 或 GIF 圖片。
- **Points**（積分）– 你目前已結算的餘額，來自成就和日常工作。
- **History timeline**（歷史時間線）– 最近的系統歷史，例如建立或刪除的會話。僅在開啟抽屜時才會載入。
- **Quick links**（快捷入口）– 例如 **View Yesterday's Report**（查看昨日報告），會開啟昨天的全螢幕英雄戰報。
