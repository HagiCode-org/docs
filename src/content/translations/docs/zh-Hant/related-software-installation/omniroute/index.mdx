HagiCode 已移除內建的 OmniRoute 支援。產品內不再提供 OmniRoute 的安裝步驟、設定頁面、連線測試或模型目錄同步。

現在接入模型的方式：

- 使用透過 Magpie 連線的模型，或
- 在 Agent CLI 中設定它原生支援的提供商與模型。

HagiCode 不會遷移舊的 OmniRoute 位址或金鑰。請在設定中重新選擇受支援的提供商與模型。Agent CLI 的安裝說明見 [AI Agent CLI 安裝](/zh-Hant/related-software-installation/ai-agent-cli/)。

## 獨立的 OmniRoute 文件

OmniRoute 是獨立專案，文件由其自身網站維護。HagiCode 不提供對它的支援。
