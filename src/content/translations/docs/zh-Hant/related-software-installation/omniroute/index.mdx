官方 Desktop 應用程式現在是建議路徑：請從 [OmniRoute GitHub Releases](https://github.com/diegosouzapw/OmniRoute/releases) 下載適用於 Windows、macOS 或 Linux 的安裝包。下方仍保留 npm，供無桌面環境使用。

此頁面介紹 OmniRoute 建議的本機路徑：執行 `npm install -g omniroute`，接著執行 `omniroute start`；儀表板位於 `http://localhost:20128`，OpenAI 相容的基本 URL 位於 `http://localhost:20128/v1`。

:::提示[建議路徑]
儀表板位於 `http://localhost:20128`，OpenAI 相容的基本 URL 位於 `http://localhost:20128/v1`。Docker 和進階部署模式為選用方式。
:::

## 先決條件

- Node.js 必須是 `>=22.0.0 <23` 或 `>=24.0.0 <27`。不支援 Node.js 21 和 23。完成 [安裝 Node.js](/zh-Hant/related-software-installation/nodejs/installation) 如果需要的話首先。
- 本地埠 `20128` 和 `20129` 可用且尚未被佔用。
- 您至少有一個計劃透過 OmniRoute 進行路由的上游模型提供者帳戶。
- 在整合 HagiCode、CLI 或 SDK 之前，請將這兩個位址分開：
  - 儀表板： `http://localhost:20128`
  - OpenAI 相容的基本 URL： `http://localhost:  20128/v1`

## 本地安裝並運行

從建議的全域 npm 路徑開始：

```bash
npm install -g omniroute
omniroute start
```

服務啟動後，按以下順序驗證：

1. 打開 `http://localhost:20128` 在瀏覽器中並確認儀表板已載入。
2. 前往 `Endpoints` 儀表板中的頁面並建立或複製 API 金鑰。
3. 請記下稍後將傳遞給工具的基本 URL： `http://localhost:20128/v1`.

:::注意[為什麼從儀表板開始]
對於首次設置，儀表板是確認 OmniRoute 正在運行、您的提供者已連接並且存在 API 金鑰的最快方法。如果稍後的客戶端呼叫失敗，首先檢查儀表板通常比立即偵錯 SDK 程式碼更快。
:::

## 驗證正在運行的服務

### 驗證1：確認模型目錄可讀

將鑰匙從 `Endpoints` 頁面到環境變數：

```bash
export OMNIROUTE_API_KEY="replace-with-the-key-you-copied-from-the-Endpoints-page"
```

然後請求 `/v1/models`:

```bash
curl http://localhost:20128/v1/models \
  -H "Authorization: Bearer ${OMNIROUTE_API_KEY}"
```

如果您返回模型列表，则说明兼容 OpenAI 的端点和身份验证流程正在运行。

### 驗證 2：發送最少的聊天請求

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer ${OMNIROUTE_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "replace-with-a-model-id-from-v1-models",
    "messages": [
      { "role": "user", "content": "Reply with ok." }
    ]
  }'
```

这里的目标不是即时质量。是为了证明你选择的模型已经可以通过OmniRoute成功路由。
