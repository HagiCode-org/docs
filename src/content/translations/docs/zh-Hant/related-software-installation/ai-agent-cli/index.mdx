本頁是 HagiCode 統一的 AI Agent CLI 本機安裝入口。HagiCode 目前活躍支援 11 個 Agent CLI：Claude Code、Codex、GitHub Copilot、OpenCode、Hermes、QoderCLI、Kiro、Kimi、Gemini、DeepAgents、Codebuddy。

:::tip[使用方式]
先看下表確認某個 CLI 的**目前狀態**與**安裝方式**，再跳到對應官方文件完成安裝、登入、ACP、權限與疑難排解。重點是：**是否支援**，與**是否支援一鍵安裝**，是兩件事。
:::

:::note[安裝前先準備 Node.js 24+]
多數支援一鍵安裝的 CLI 依賴 Node.js 與 npm，Desktop 也會使用你系統裡的 `node` 與 `npm`（Desktop 不再內建 Node.js）。請先依 [安裝 Node.js](/zh-Hant/related-software-installation/nodejs/installation) 準備 24 或更高版本，並在安裝完成後**完成登入或驗證**：初始化嚮導只會列出本機已偵測到的 CLI。
:::

## 狀態說明

- **目前支援**：屬於 HagiCode 目前活躍支援範圍，可在系統中作為現行 Agent CLI 使用。
- **一鍵安裝**：HagiCode 提供引導式安裝入口；部分 CLI 安裝後仍要依廠商流程繼續登入或驗證。
- **手動安裝 / 驗證**：該 CLI 已在目前支援範圍內，但需要你先完成本機安裝、登入或驗證，再回到 HagiCode 重新整理可用狀態。
- **歷史相容保留**：iFlow CLI 僅為相容舊資料而保留，不屬於目前活躍支援清單，也不應視為現行建議項目。
