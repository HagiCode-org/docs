對於 Windows 使用者來說，Microsoft Store 是目前公開的桌面入口。本文只說明商店安裝這條路徑；如果你想看通用的 Desktop 下載安裝、版本管理與疑難排解說明，請繼續閱讀 [Desktop 安裝](/zh-Hant/installation/desktop)。

Steam 主應用程式條目已經退役，目前 Windows 管道以 Microsoft Store 為主。相關背景可見 [為什麼 HagiCode 沒有上架 Steam](/zh-Hant/faq/steam-distribution-status/)。

:::tip[適合這條路徑的情況]
- 你正在使用 Windows 10 或 Windows 11，並希望直接從系統商店安裝
- 你更希望由商店管道發行應用程式套件，而不是手動處理安裝檔案
- 你只需要個人本機安裝，不打算進行 Docker Compose 部署
:::

## 安裝前確認

開始前請確認這些條件：

- 裝置可以正常開啟 [HagiCode for Windows 的 Microsoft Store 頁面](https://apps.microsoft.com/detail/9N3PM0N3SVDW)
- 首次啟動時網路可用，因為程式可能還需要下載或準備 Hagicode Server 所需元件
- 某些裝置、組織原則或地區設定可能會要求你先登入 Microsoft 帳戶
- 如果你的公司裝置停用了商店，請改用 [Desktop 安裝](/zh-Hant/installation/desktop)

## 安裝前準備

Store 版與 Desktop 使用同一套執行方式：**不內建 Node.js**，需要您自行安裝並讓它出現在系統 `PATH` 中。請在首次啟動前準備好：

- **Node.js 24 或更高版本**（同時提供 `npm`），見 [安裝 Node.js](/zh-Hant/related-software-installation/nodejs/installation)
- **Git**，見 [安裝 Git](/zh-Hant/installation/#安裝-git)
- 至少一個已安裝並登入的 **Agent CLI**，見 [AI Agent CLI 安裝](/zh-Hant/related-software-installation/ai-agent-cli/)

如果在 HagiCode 已經開啟之後才安裝它們，請完全結束並重新啟動 HagiCode，讓它讀取新的 `PATH`。

## 從 Microsoft Store 安裝

1. 開啟 [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW) 頁面。
2. 點擊 `取得`、`安裝`，或商店頁面中的對應按鈕。
3. 等待 Microsoft Store 完成下載與安裝。
4. 安裝完成後，從開始功能表或商店頁面直接啟動 HagiCode。

## 首次啟動時會發生什麼

安裝完成後，HagiCode 仍會進入標準 Desktop 初始化流程。

- 首次啟動會先進入 Desktop 的首次使用引導：選擇語言、確認法律文件，並視需要下載 Hagicode Server，因此可能比一般應用程式更慢
- Microsoft Store / MSIX 管道會鎖定「執行時資料儲存路徑」設定，這是此發行方式的預期行為
- 軟體本體不會獨立自行更新，應用程式套件更新由安裝管道決定；對於 Store 安裝，交付方式取決於 Microsoft Store 管道

如果你需要繼續完成初始化嚮導，請直接閱讀 [初始化嚮導設定](/zh-Hant/quick-start/wizard-setup)。

## 什麼時候改用其他安裝方式

以下情況更適合改用別的管道：

- 你無法存取 Microsoft Store，或公司裝置明確禁止商店安裝
- 你需要手動下載 `.exe` 或 `.msix` 套件，並自行控制安裝檔案來源
- 你要部署到伺服器、NAS 或團隊共用環境，這時應改看 [Docker Compose 部署](/zh-Hant/installation/docker-compose)

## 常見問題

### 無法開啟 Microsoft Store 頁面

請優先確認系統網路、地區設定和 Microsoft Store 登入狀態。如果瀏覽器能開啟頁面但商店用戶端仍不可用，通常代表目前系統原則限制了商店功能，這時請改用 [Desktop 安裝](/zh-Hant/installation/desktop)。

### 為什麼某些設定是灰色的

Store / MSIX 安裝會鎖定「執行時資料儲存路徑」選項，並顯示「已由 Microsoft Store 鎖定」。這不是安裝異常，而是目前發行管道的限制。

### 為什麼第一次啟動還要繼續下載或準備內容

商店安裝只負責交付桌面應用程式套件。首次啟動時，HagiCode 仍可能下載或準備 Hagicode Server 所需元件，並完成預設初始化。請保持網路可用並等待目前步驟結束。
