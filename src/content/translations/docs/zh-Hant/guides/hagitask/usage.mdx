---
title: 使用 HagiTask
description: 探索、安裝、啟用、重新整理和執行 HagiTask，並了解來源管理的界線。
---

**適用對象：** 已安裝 HagiCode 並需要管理或執行任務的使用者。

**前置條件：** 已完成[安裝 HagiTask](/zh-Hant/guides/hagitask/installation)，或應用程式已提供內建預設。

## 探索任務

開啟應用程式的 HagiTask／社群任務管理介面。應用程式會合併顯示內建任務、已安裝的社群套件、工作區套件和受管理來源，並標示每個任務的來源以及是否可移除。社群 Gallery 的目錄用於探索和取得社群套件；伺服器可存取的目錄則用於執行階段的來源探索。

## 安裝任務

從 Gallery 選擇任務並安裝，或使用本機封存檔安裝功能，安裝已取得且受支援的 ZIP。安裝成功後，應用程式會記錄正式 ID、版本、發布者、來源、封存檔摘要和安裝目錄。相同 ID 的已安裝任務不會被悄悄覆蓋；必須先處理現有安裝。

## 啟用和停用

- **啟用：** 將已安裝任務放入作用中的任務目錄，使其可被探索和執行。
- **停用：** 保留安裝紀錄和套件檔案，但將任務移出作用中目錄，因此任務不會執行。
- **解除安裝：** 僅適用於有安裝紀錄的社群任務；內建任務只是資訊項目，無法解除安裝。

狀態變更完成後，應用程式會重新整理目錄。若重新整理失敗，生命週期操作應維持原有的可用狀態，而不是留下只完成一部分的目錄。

## 重新整理和執行

使用重新整理功能重新讀取目前的任務目錄。強制重新整理 Gallery 目錄時，應用程式會重新取得並驗證目錄；若上游暫時發生故障，現有的有效快取仍可能繼續提供資料。重新整理不會自動變更任務的啟用狀態或版本。

執行前確認任務已啟用且相依條件已滿足，再從任務面板或對應的執行入口執行。若任務未顯示，請先重新整理並檢查安裝狀態、任務 ID 和相容性提示；若 Schema 或套件資源無效，請參閱[社群貢獻指南](/zh-Hant/guides/hagitask/community)。

## 套件管理與伺服器來源管理

這兩種操作經常被混淆：

| 功能 | 作用 | 路徑含義 |
| --- | --- | --- |
| 套件管理 | 安裝、啟用、停用和解除安裝本機 HagiTask 套件。 | 應用程式管理的資料目錄。 |
| 伺服器來源管理 | 設定執行階段用於目錄探索的任務來源。 | 必須是伺服器可存取的目錄。 |

伺服器來源中的路徑由後端讀取，用於探索目錄中的任務套件；它不是瀏覽器路徑，也不是上傳控制項。目前的安裝流程不會將瀏覽器本機資料夾直接上傳為 Community Gallery 套件。若要安裝套件，請使用 Gallery 或受支援的本機 ZIP 流程。

## 任務無法使用時

1. 確認任務 ID、版本和安裝紀錄仍然存在。
2. 確認任務已啟用，且所需的 agent、skills 和 CLI 已準備就緒。
3. 重新整理任務目錄並重新開啟管理介面。
4. 如果來源是伺服器目錄，確認後端程序有權讀取該路徑。
5. 如果封存檔驗證或套件資源發生錯誤，請回到[安裝疑難排解](/zh-Hant/guides/hagitask/installation)；如果你是套件維護者，請閱讀[參與社群貢獻](/zh-Hant/guides/hagitask/community)。
