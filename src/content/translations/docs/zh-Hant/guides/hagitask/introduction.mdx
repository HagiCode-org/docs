**適用對象：** 想了解 HagiTask 生態系的使用者、維護者和貢獻者。

**前置條件：** 無。若要安裝或執行任務，請先準備好 HagiCode 應用程式及其後端服務。

## HagiTask 是什麼

HagiTask 是 HagiCode 的任務套件和預設任務模型。一個任務套件將任務識別資訊、前端面板、後端提示詞、範本、介面文字和商店介紹放在同一個可驗證的目錄中，應用程式可以據此探索、安裝、管理並執行任務。

任務套件不是應用程式本身，也不會取代應用程式的執行階段設定。應用程式負責載入任務並執行任務宣告的能力；任務套件只提供依照約定格式組織的資源。

## 生態系中的幾個角色

| 角色 | 職責 |
| --- | --- |
| HagiTask | 維護共用 Schema 和隨產品發布的內建預設套件，是套件格式的權威來源（source of truth）。 |
| 內建預設 | 隨應用程式或執行階段提供的可用任務，例如 `normal-session` 和 `research-investigation`。 |
| Community Packages | 維護社群任務的來源資料，目錄位於 `data/<taskId>/`。 |
| HagiTask Site | 從社群套件來源產生目錄、詳細資料 JSON 和 ZIP 封存檔，發布到 Community Gallery。 |
| HagiCode 應用程式 | 顯示任務、安裝套件、儲存啟用狀態，並在執行階段執行任務。 |

內建預設與社群任務使用相同的套件 Schema，但來源和生命週期不同：內建預設由 HagiTask 儲存庫維護，社群任務由 Community Packages 儲存庫維護。網站上的 `/index.json`、詳細資料文件和 ZIP 都是產生的成果，不是貢獻者直接編輯的來源檔案。

## 套件管理和來源管理不是一回事

從 Gallery 安裝 ZIP，是將套件複製到應用程式的資料目錄，並記錄版本、來源和啟用狀態。伺服器來源管理則是設定伺服器可存取的目錄，讓執行階段從該目錄探索任務；它不會將瀏覽器本機資料夾上傳為安裝套件。

有關操作界線和資料夾來源，請閱讀[使用 HagiTask](/zh-Hant/guides/hagitask/usage)。準備安裝時，繼續閱讀[安裝 HagiTask](/zh-Hant/guides/hagitask/installation)；若要建立或發布任務，請閱讀[參與社群貢獻](/zh-Hant/guides/hagitask/community)。

## Source of truth 職責界線

- docs 維護面向使用者和貢獻者的說明與操作指南。
- HagiTask 維護共用 Schema 和內建預設來源。
- Community Packages 維護社群套件來源資料。
- HagiTask Site 發布由套件來源產生的目錄、詳細資料和封存檔。
