title: 安裝 HagiTask

**適用對象：** 想安裝社群任務並在 HagiCode 中使用的使用者。

**前置條件：**

- 已能存取目前使用的 HagiCode 應用程式和後端服務。
- 應用程式版本支援 HagiTask 社群任務管理和 Community Gallery。
- 任務所需的 agent、skills 或 CLI 相依項目已準備就緒；這些需求可在任務詳細資料中查看。

## 從 Community Gallery 安裝

目前支援的流程是透過 HagiTask Site 的 Community Gallery 取得任務詳細資料和 ZIP 封存檔，再交由應用程式的社群任務安裝功能處理：

1. 在 Gallery 中依任務名稱、分類或標籤尋找任務。
2. 開啟任務詳細資料，確認版本、發布者、相容性和安裝大小。
3. 選擇安裝。應用程式會從 `packageUrl` 取得 ZIP，並驗證任務 ID、版本和 SHA-256。
4. 驗證通過後，應用程式會將套件寫入本機 HagiTask 資料目錄並重新整理任務目錄。

Gallery 的探索、詳細資料和封存檔入口分別是 `/index.json`、`/tasks/<taskId>.json` 和 `/packages/<taskId>.zip`。安裝使用封存檔，無須解析網站頁面內容。

### 使用封存檔

如果你已透過受支援的 Gallery 流程取得 ZIP，可以在應用程式的社群任務管理介面選擇安裝本機封存檔。封存檔必須包含完整的任務套件目錄，且其中的 ID、版本和內容摘要必須與安裝請求一致。

上傳瀏覽器本機資料夾並非目前的 Community Gallery 安裝途徑。伺服器端的資料夾來源設定另有用途，詳見[使用 HagiTask](/zh-Hant/guides/hagitask/usage)。

## 驗證是否成功

安裝後，在社群任務管理介面確認：

- 任務顯示正確的 `taskId`、版本和發布者。
- 任務狀態為已啟用，或可以手動啟用。
- 任務的相依項目和相容性提示沒有未滿足的條件。
- 重新整理目錄後任務仍然存在，並且可以開啟任務面板。

安裝紀錄會儲存來源、版本、封存檔摘要和啟用狀態。內建任務僅供唯讀顯示，不能當作社群套件解除安裝。

## 常見問題

### 無法存取 Gallery

確認應用程式設定的 Gallery 位址可用且使用 HTTPS，並檢查網路、逾時和網站狀態。首次取得目錄失敗時，應用程式不會憑空產生空目錄；若已有有效快取，可能暫時顯示舊目錄。

### 找不到任務或詳細資料無效

使用詳細資料中的正式 `taskId`，不要使用顯示別名。`agentsmd` 和 `portytail` 只是 `claude-md-update` 與 `ponytail` 的人類可讀別名，不是可安裝的任務 ID。

### 完整性或版本驗證失敗

重新從 Gallery 取得封存檔，不要手動修改 ZIP 或產生的目錄檔案。若仍失敗，應聯絡套件維護者檢查 Community Packages 的來源資料和版本號。

### 安裝後無法使用

檢查任務詳細資料中的 agent、skills、CLI 需求，確認應用程式已啟用任務並重新整理目錄。若套件內容本身無效，請參閱[社群貢獻指南](/zh-Hant/guides/hagitask/community)，了解 Schema 和驗證流程。
