HagiCode 讓 AI 修改程式碼時不遺失脈絡：**先讀懂儲存庫，再界定範圍，最後可追蹤地執行。** 它是面向專案開發的 AI 工作台，串接你既有的 Agent CLI 與模型，不需要更換編輯器。

**[開始安裝](/zh-Hant/installation/)** · [觀看示範影片](#product-video-showcase-en)

支援 11 個 Agent CLI（Claude Code、Codex、GitHub Copilot 等）· Windows、macOS、Linux 皆可使用 · 基本功能免費

## 一項開發任務如何進行

以「修改一項涉及多個儲存庫的功能」為例：

1. **先理解**：在[一般會話](/zh-Hant/quick-start/conversation-session)中分析現有程式碼。一般會話預設為唯讀，需要修改檔案時再切換至編輯模式。
2. **再界定範圍**：面對複雜變更，在[提案會話](/zh-Hant/quick-start/proposal-session)中選擇專案與儲存庫，先整理目標、任務與驗證方式，再推進執行。

   ![新建提案抽屜，顯示儲存庫選擇與提案預覽](../img/screenshots/shared/create-proposal-drawser/original.png)

3. **追蹤結果**：在工作台回顧會話與執行狀態；需要整理提交紀錄時，可以使用 [AI Compose Commit](/zh-Hant/guides/ai-compose-commit)。

   ![提案工作流程執行完成後的會話詳情](../img/screenshots/shared/classic-proposal-view/original.png)

4. **保留脈絡**：提案與提交紀錄可供日後回顧；需要跨儲存庫協作時，使用 [MonoSpecs](/zh-Hant/guides/monospecs) 管理儲存庫關係與變更範圍。

你不必每次都走提案流程：只想了解程式碼或處理簡單問題，可以從一般會話開始。HagiCode 的重點是讓任務需要更多脈絡時，仍有一條可追蹤的推進路徑。

## 適合誰

- **適合**：同時維護多個儲存庫、希望複雜改動先規劃再執行的開發者與團隊；已經在使用 Claude Code、Codex 等 Agent CLI，想把它們放進同一個工作台的人。
- **不是必需品**：如果你只需要在編輯器裡補全幾行程式碼，現有工具已經足夠。

## 讓長期進度看得見

HagiCode 把英雄、成就、日報和 Token 做成回饋，讓長期使用中的狀態與進度更容易被看見，這也是它和一般 AI 程式設計工具不同的地方。你可以在[冒險團介紹](/zh-Hant/adventure-team-introduction)裡看看英雄如何編組、副本如何推進；設計思路見[遊戲化設計文章](/zh-Hant/blog/2026-03-16-gamifying-ai-coding/)。這部分是工作台體驗的一部分，不想使用時，也可以只把它當作一般開發工具。

## 取得方式與定價

基本功能免費。Desktop、Container 與 Microsoft Store 是三種不同的取得或部署方式，不是三檔付費版本。Microsoft Store 通路另有一次性購買的 Turbo Engine 增強包，用於解鎖更高的提案並行上限，以及文件主題、自訂署名、品牌與頭像等功能。具體解鎖項目以 [Turbo Engine 增強包](/zh-Hant/dlc/turbo-engine-dlc/)為準。

| 你的環境 | 建議入口 |
| --- | --- |
| Windows，且可以使用 Microsoft Store | [Microsoft Store 安裝](/zh-Hant/installation/windows-store) |
| Windows 手動安裝，或 macOS、Linux 本機使用 | [Desktop 安裝](/zh-Hant/installation/desktop) |
| 伺服器、NAS 或團隊部署 | [Docker Compose 安裝](/zh-Hant/installation/docker-compose) |

Steam 主應用程式已退役，不是目前的安裝管道；詳情見 [Steam 發行狀態](/zh-Hant/faq/steam-distribution-status/)。

## 為什麼還要做成工作台

我是 HagiCode 的製作人俞坤。單次問答能解決眼前的問題，但實際開發還需要理解專案、界定邊界、推進變更、回顧結果。我希望把這些原本分散的環節串在一起；遊戲化回饋則讓長期工作中的進度更容易被看見。你可以只使用其中一部分功能，不需要為了開始寫程式而先學會所有模組。
