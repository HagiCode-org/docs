HagiCode 是面向專案開發的 AI 工作台。你可以先透過會話理解儲存庫，再釐清需求與影響範圍、讓 AI 執行修改，並在同一處查看進度、整理提交紀錄和重複運用專案知識。它串接你使用的 Agent CLI 與模型，不要求你改用特定的程式碼編輯器。

**第一次使用？**先[選擇安裝方式](/zh-Hant/installation/)，完成[初始化精靈](/zh-Hant/quick-start/wizard-setup)，建立專案後從[一般會話](/zh-Hant/quick-start/conversation-session)開始；如果任務需要先規劃、再實作，則使用[提案會話](/zh-Hant/quick-start/proposal-session)。

## 一項開發任務如何進行

以「修改一項涉及多個儲存庫的功能」為例：

1. **先理解：**在[一般會話](/zh-Hant/quick-start/conversation-session)中分析現有程式碼。一般會話預設為唯讀；需要修改檔案時再切換至編輯模式。
2. **再界定範圍：**面對複雜變更，在[提案會話](/zh-Hant/quick-start/proposal-session)中選擇專案與儲存庫，先整理目標、任務和驗證方式，再推進執行。
3. **追蹤結果：**在工作台回顧會話與執行狀態；需要整理提交紀錄時，可以使用 [AI Compose Commit](/zh-Hant/guides/ai-compose-commit)。
4. **保留脈絡：**提案和提交紀錄可供日後回顧；需要跨儲存庫協作時，使用 [MonoSpecs](/zh-Hant/guides/monospecs) 管理儲存庫關係與變更範圍。

不必每次都走提案流程：如果只是想了解程式碼或處理簡單問題，可以從一般會話開始。當任務需要更多脈絡時，HagiCode 仍提供一條可追蹤的推進路徑。

## 依需求了解功能

| 如果你想…… | 可以從這裡開始 |
| --- | --- |
| 先弄清楚程式碼，再決定是否修改 | [建立一般會話](/zh-Hant/quick-start/conversation-session) |
| 在複雜需求中先規劃、再執行 | [建立提案會話](/zh-Hant/quick-start/proposal-session) |

| 搜尋、安裝及管理擴充功能 | [Skills 使用指南](/zh-Hant/guides/skills) |

| 分開管理 CLI 與模型連線 | [OmniRoute 安裝與啟動驗證](/zh-Hant/related-software-installation/omniroute/) |

Vault 可以彙整參考儲存庫、資料夾和筆記，供後續工作重複運用；Code Server 則提供瀏覽器中的編輯入口。開始使用 HagiCode 並不需要先設定這些功能。若想了解設計背景，可閱讀 [Vault 知識庫實踐](/zh-Hant/blog/2026-04-10-vault-system-ai-knowledge-base/)及[瀏覽器編輯整合](/zh-Hant/blog/2026-04-13-vscode-web-integration-browser-editing/)。

HagiCode 也提供英雄、成就、日報和 Token 等回饋，讓長期使用中的狀態與進度更容易看見。這些是工作台體驗的一部分，不影響你把它當作一般開發工具使用；設計思路可參閱[遊戲化設計文章](/zh-Hant/blog/2026-03-16-gamifying-ai-coding/)。

## 版本和定價

**Desktop、Container 與 Microsoft Store 是不同的取得或部署方式，不是三種付費方案。**基本功能可免費使用；Microsoft Store 通路的 Turbo Engine 是另外購買的一次性授權，用於解鎖更高的提案並行上限，以及文件主題、自訂署名、品牌與頭像等進階功能。實際解鎖項目請參閱 [Turbo Engine 擴充套件](/zh-Hant/dlc/turbo-engine-dlc/)。

| 你的環境 | 建議入口 |
| --- | --- |
| Windows，且可以使用 Microsoft Store | [從 Microsoft Store 安裝](/zh-Hant/installation/windows-store) |
| 手動安裝 Windows 版，或在 macOS、Linux 本機使用 | [安裝 Desktop](/zh-Hant/installation/desktop) |
| 伺服器、NAS 或團隊部署 | [使用 Docker Compose 安裝](/zh-Hant/installation/docker-compose) |

Steam 主應用程式已退役，不再是目前的安裝管道；詳見 [Steam 發行狀態](/zh-Hant/faq/steam-distribution-status/)。

## 為什麼要做成工作台

我是 HagiCode 的製作人俞坤。單次問答能解決眼前的問題，但實際開發還需要理解專案、界定邊界、推進變更並回顧結果。我希望把這些原本分散的環節串在一起；遊戲化回饋則讓長期工作中的進度更容易被看見。你可以只使用其中部分功能，不需要為了開始寫程式而先學會所有模組。
