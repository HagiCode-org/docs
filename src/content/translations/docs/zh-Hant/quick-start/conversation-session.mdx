對話工作階段是 HagiCode 中最輕量的入口。選擇一個專案、提出問題，讓 Agent 閱讀儲存庫並回答。是否允許 Agent 修改檔案，由你針對每個工作階段自行決定。

## 前置條件

開始對話工作階段之前，請確認你已經：

- 依照[安裝指南](/zh-Hant/installation)完成任一種安裝方式（Microsoft Store 或 Desktop）
- 完成[精靈設定](/zh-Hant/quick-start/wizard-setup)，這會建立你的第一個 Agent 以及至少一個專案
- 在工作階段看板上選取該專案

## 對話工作階段適合做什麼？

當你想先理解、之後再修改時，對話工作階段最合適。常見用途包括：

- 快速分析不熟悉的儲存庫
- 針對某個檔案、模組或錯誤提出聚焦的問題
- 不需要規劃成提案的小幅修改
- 在傳送前附上圖片、標準片語或先前的訊息

如果你的任務已經從「理解問題」進展到「規劃、審查並封存一項結構化的變更」，請繼續閱讀[建立提案工作階段](/zh-Hant/quick-start/proposal-session)。本頁僅介紹對話工作階段。

## 流程總覽

| 階段 | 你要做的事 | 會發生什麼 |
| --- | --- | --- |
| 建立 | 按一下 **Create Normal Session**（建立一般工作階段）並描述你的需求 | 抽屜面板會收集專案、選填的標題、範圍以及你的第一則訊息 |
| 啟動 | 從 **Available Agents**（可用的 Agent）中挑選一個 Agent | 工作階段立即啟動，並出現在 **Execution** 欄 |
| 閱讀 | 開啟工作階段卡片 | Agent 閱讀儲存庫並回答；**Session Complete** 卡片會摘要本次執行 |
| 決定 | 使用訊息輸入框旁的模式開關 | 維持唯讀模式，或開啟編輯模式讓 Agent 可以修改檔案 |
| 補充上下文 | 使用圖片、標準片語與歷史記錄按鈕 | 你的下一則訊息會帶有更豐富的上下文 |

## 步驟 1：建立工作階段

選取你的專案，然後按一下看板上方工具列中的 **Create Normal Session**（對話框圖示）。

![Create Normal Session 抽屜面板，包含專案、工作階段標題、任務範圍、需求內容，以及 Available Agents 選擇器](../../img/quick-start/conversation-session/01-create-normal-session.png)

填寫抽屜面板：

- **Project**（必填）– 預設為目前選取的專案。
- **Session title** – 選填；會成為看板上卡片的標題。
- **Task scope** – 選填。**Repos** 會將工作階段限縮到 MonoSpecs 專案的儲存庫，而 **Vault** 與 **Projects** 則會附加額外的參考資料。
- **What do you want to do?**（必填）– 你的第一則訊息。**Upload Image** 可附上圖片。

**Available Agents** 面板會在抽屜面板旁邊展開。按一下某個 Agent，工作階段就會**立即啟動**。第一張卡片是執行階段的預設 Agent；第二個清單則讓你僅為這一次執行挑選不同的 Agent。你也可以按 `Ctrl/⌘ + Enter` 以鍵盤送出。

:::tip[從提問開始，而不是從修改開始]
第一則訊息可以像這樣：「用兩句話說明這個專案是做什麼的，不要修改任何檔案。」這是確認 Agent 與專案已正確串接的安全做法。
:::

## 步驟 2：閱讀結果

新的工作階段會以卡片形式出現在 **Execution** 欄，並帶有狀態徽章。按一下卡片即可開啟工作階段。

![工作階段抽屜面板，顯示 Agent 的回答、Session Complete 摘要、訊息輸入框與 Agent 狀態卡片](../../img/quick-start/conversation-session/02-session-detail.png)

- **標題列**顯示標題與 Agent，並提供 **Archive**、**Delete Session**、**Open Code Server** 以及 **…** 選單。
- **對話內容**依序列出你的訊息、以卡片呈現的 Agent 工具呼叫，以及它的回答。
- 每次執行結束時，**Session Complete** 卡片會列出回合數、經過時間與費用。按一下即可展開詳細資訊。
- 訊息輸入框右側的 **Agent 狀態卡片**會顯示 Agent CLI、模型、目前狀態（例如 *Idle*）以及經過時間。

在訊息輸入框中輸入後續問題。按 `Enter` 傳送，按 `Shift + Enter` 換行。

## 步驟 3：選擇唯讀或編輯模式

訊息輸入框左側的開關有兩個位置。眼睛代表**唯讀**：Agent 可以檢視與說明，但不會修改檔案。鉛筆代表**編輯模式**：新的訊息更有可能修改檔案或調整目前的實作。

![已選取鉛筆（編輯模式）的訊息輸入框](../../img/quick-start/conversation-session/03-composer-edit.png)

![已選取眼睛（唯讀模式）的訊息輸入框](../../img/quick-start/conversation-session/04-composer-readonly.png)

模式僅套用於你目前所在的工作階段，且可以在訊息之間切換。**新建**的一般工作階段是否預設為編輯模式，則由 **Settings → Process & Interaction → Chat View → Default to Edit Mode for Normal Chats** 控制。請參閱[設定](/zh-Hant/user-guide/settings)。

較安全的做法很簡單：先以唯讀模式確認方向，等到真正需要修改時再切換到編輯模式。

## 步驟 4：傳送前補充上下文

模式開關旁的三個按鈕可為你的下一則訊息補充上下文：

- **Insert an image attachment** – 附上螢幕截圖、錯誤畫面擷取或設計參考圖。圖片會連同檔名與大小顯示在訊息輸入框上方，傳送前可按 **×** 移除。
- **Standard Phrases** – 插入 `@` 參照。選擇器提供 **Projects**（標準的專案根目錄路徑）、**Vaults**（已註冊的 vault 路徑）、**Proposal Sessions**（OpenSpec 變更資料夾）以及 **Recent Items**。
- **Import Recent History** – 重複使用此工作階段中最近的某則訊息，免去重新輸入。

![上方顯示已附加圖片的訊息輸入框](../../img/quick-start/conversation-session/05-composer-image.png)

![從訊息輸入框開啟的標準片語選擇器，包含 Projects、Vaults、Proposal Sessions 與 Recent Items](../../img/quick-start/conversation-session/06-standard-phrases.png)

在以下情況中，圖片特別有用：

- 請 Agent 說明某個介面截圖
- 附上錯誤截圖或設計稿，並加上後續指示
- 在切換到編輯模式之前提供視覺上下文

## 典型流程

1. 從工具列**建立**工作階段並挑選 Agent。
2. 以唯讀模式**開始**，先針對專案提出問題。
3. **閱讀回答**，然後繼續追問。
4. 只有在需要直接修改檔案時，才**開啟編輯模式**。
5. **加入圖片、標準片語或歷史訊息**，讓下一則訊息帶有更多上下文。
6. 完成後將工作階段**封存**，它會移到 **Archived** 欄。

如果任務現在需要規劃、審查與封存的嚴謹流程，請繼續閱讀提案工作階段指南。
