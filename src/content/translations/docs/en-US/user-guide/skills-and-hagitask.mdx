Skills and HagiTasks both extend what your Agents can do, and both open from the header.

- **Skills** are reusable instruction packages that Agent CLIs load, such as design guidelines or framework best practices.
- **HagiTasks** are task presets that HagiCode runs through its session flow, such as *Normal Session* or *Research Investigation*.

## Skills

Click **Skills** in the header. The drawer has three tabs. For a longer walkthrough, see the [Skills Guide](/en-US/guides/skills).

### Local Skills

![Local Skills tab with Installed, Built-in, and Skill bases categories, search, Refresh inventory, Update all, and a table of installed skills](../../img/user-guide/skills/01-local-skills.png)

The top of the tab has three categories: **Installed**, **Built-in**, and **Skill bases**, each with a count. The backend is the source of truth for the global skills installed on this machine.

- **Refresh inventory** re-scans the machine. **Update all** updates every skill that can be updated.
- The table shows each **Skill**, which **Agents** it is bound to, its **Path**, and the available **Actions**: update and **Uninstall**.
- A row with a warning is missing the install metadata file that one-click updates need, so its update action shows *Unavailable*.

#### Skill bases

![Skill bases category with a folder path box and a list of skills with switches under one base](../../img/user-guide/skills/05-skill-bases.png)

A **skill base** is a folder on the machine that runs HagiCode; each subfolder with a `SKILL.md` file is one skill. Enter the path in **Folder path on the server** and click **Add base** to load its skills. The path is read on the machine that runs HagiCode, not on this device.

- Each base shows its path, its **Status** (Available or Unavailable), and its skill count, with **Rescan** and **Remove** actions.
- Each skill shows its status (for example *Ready*) and a switch. The switch is the skill's global state; each Agent can override it in its own configuration.

### Gallery

![Gallery tab with a search box, source filter, and a ranked list of skills with install counts](../../img/user-guide/skills/02-gallery.png)

Search the skill library by name, ID, source, or paste a GitHub repository URL. **Trusted only** limits the list to skills from providers you trust. Each row shows the skill, its source, and how often it was installed. Open a row to review the exact install command before you install.

### Trusted Providers

![Trusted Providers tab with rule format help and a table of preset providers](../../img/user-guide/skills/03-trusted-providers.png)

Trusted providers decide which sources get the *Trusted* label. The directory only stores verified sources, never credentials. Write one rule per line:

- `prefix:owner/` trusts every repository of an owner.
- `exact:owner/repo` trusts one repository.

Presets such as Vercel, Azure, anthropics, and Microsoft are included. Use **Add provider**, **Edit**, **Delete**, or **Reset defaults** to change them.

## HagiTask

Click **HagiTask** in the header, or **More HagiTasks** on the session board, to open the **HagiTask workspace**. It also has three tabs.

### Package management

![Package management tab listing the Create proposal, Normal Session, and Research Investigation presets](../../img/user-guide/skills/04-hagitask-packages.png)

The list shows every installed preset with its **Order**, **Name**, **Version**, **Source**, and an **Enabled** switch. Use the switch to turn a preset on or off.

- **Create proposal** is a built-in special action. It is always present and cannot be installed or uninstalled.
- **Normal Session** and **Research Investigation** are workspace presets.
- **Change order** reorders the list. **Install community HagiTask** jumps to the gallery. **Reload list** re-reads the sources.

Click a row to see its details on the right.

### Community Gallery

![Community Gallery tab listing community HagiTask presets with Install buttons and a details panel](../../img/user-guide/skills/06-hagitask-gallery.png)

Browse presets published by the HagiCode team and the community, such as *CodeGraph Tasks*, *GitHub Tasks*, and *AGENTS.md Update*. Each entry shows its category, version, tags, and the CLI tools it requires. Click **Install** to add it. **Create or contribute a task** opens the contribution guide, and the *Add Community Task* preset walks you through authoring one.

### Source management

The **Source management** tab shows where presets are loaded from: the built-in presets and the community folder. **Add folder source** registers another folder, and **Reload sources** rescans them. Local folder installation of single tasks is no longer supported; install from the community gallery instead.
