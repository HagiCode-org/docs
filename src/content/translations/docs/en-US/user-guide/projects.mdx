A **project** is a folder that HagiCode works in. Sessions, Git state, standard words, and MonoSpecs settings all belong to a project, so the project rail on the left edge of the workbench is where most work starts.

## The project rail

By default the rail is collapsed to one round icon per project. Click the small arrow at the top of the rail to expand it.

![Expanded project rail listing All Sessions and the orbit-notes project, with a plus button to add a project](../../img/user-guide/workbench/02-project-rail.png)

- **All Sessions** shows sessions from every project on one board.
- Click a project to filter the board to that project and show it in the project panel.
- The green **+** button creates a project. The arrow next to it collapses the rail again.

:::tip[Which projects feed the "All Sessions" board?]
In **Settings → Process & Interaction → Session List** you can switch the scope from *All Projects* to a *Custom Selection* of projects. See [Settings](/en-US/user-guide/settings).
:::

## Create a project

Click **+** in the project rail. The **New Project** dialog offers three ways to add projects.

### Single Project

Use this when you already have a folder on disk.

![New Project dialog on the Single Project tab with a name, folder path, and description filled in](../../img/user-guide/projects/01-create-project.png)

| Field | Notes |
| --- | --- |
| **Project Name** | Required, up to 200 characters. |
| **Folder Path** | Required, up to 1000 characters. Enter the absolute path of the folder, for example `/home/user/projects/orbit-notes`. |
| **Project Description** | Optional, up to 1000 characters. |

When the path contains `.hagicode/monospecs.yaml`, the dialog detects it and shows MonoSpecs guidance for that project. See [MonoSpecs](/en-US/guides/monospecs).

### Batch Create

Use this when you keep many repositories under one parent folder.

![New Project dialog on the Batch Create tab asking for a folder to scan](../../img/user-guide/projects/02-create-project-batch.png)

Enter the full path of the parent folder. HagiCode scans up to three directory levels for Git repositories and registers each one it finds as a project.

### Demo Project

Use this to explore HagiCode before you connect your own code.

![New Project dialog on the Demo Project tab showing the MonoSpecs Demo repository and its target path](../../img/user-guide/projects/03-create-project-demo.png)

HagiCode clones the official MonoSpecs Demo repository (`https://github.com/HagiCode-org/monospecs-demo`) and registers it. This needs Git on your machine. The path shown is the default; the real folder follows your runtime data directory.

## The project panel

Select a project and the right side of the board shows its project panel.

![Project panel with Quick actions and Repository status for the orbit-notes project](../../img/user-guide/workbench/06-project-panel.png)

**Quick actions**

| Button | What it does |
| --- | --- |
| **Auto Super Commit** | Starts an AI-assisted commit for the project. See [Super Commit](/en-US/guides/ai-compose-commit). |
| **Open Code Server** | Opens the project in the browser-based code editor. |
| **Open Git Management** | Opens the Git tab of the project details drawer. |
| **View Project Details** | Opens the project details drawer. |

**Repository status** lists each repository of the project with its current branch. The colored dot shows the working tree state; in the screenshot the dot is red because `src/server.js` has an uncommitted change. Use the refresh button to re-read the state.

The **Recent changes** menu in the board toolbar lists recently changed repositories. It shows "No recent changes yet" until a repository changes.

## Project Details

Click **View Project Details** to open the drawer. It has four tabs.

### Details

![Project Details drawer on the Details tab showing name, path, description, and icon settings](../../img/user-guide/projects/04-project-details.png)

- **Name**, **Path**, and **Description** of the project.
- **Icon Settings** choose between a *Game Icon* and a *Text Abbreviation* for the project avatar. **Change Icon** opens the icon picker.
- **Manage DESIGN.md** manages the project's `DESIGN.md` file.
- **Delete Project** removes the project after you type its name to confirm. The confirmation dialog lists what is permanently deleted: all sessions in the project and all messages in those sessions. This cannot be undone.

### MonoSpecs

![MonoSpecs tab offering to initialize MonoSpecs for the project](../../img/user-guide/projects/05-project-monospecs.png)

MonoSpecs turns a project into a workspace that coordinates specs and several repositories. On a project that is not yet a MonoSpecs workspace, **Initialize MonoSpecs** creates only what is needed. No repositories are cloned automatically:

- `.hagicode/monospecs.yaml`
- a `repos/` folder for child repositories
- `openspec/changes/archive/` and `openspec/specs/`
- a `.gitignore` update so the `repos/` folder stays untracked

Read the [MonoSpecs guide](/en-US/guides/monospecs) before you initialize.

### Standard Words

![Standard Words tab with an empty list of groups and an Add group button](../../img/user-guide/projects/06-project-standard-words.png)

Standard words are shared terminology for the project, stored in `.hagicode/standard_words.yaml`. The tab shows group, phrase, and tag counts, lets you search, **Add group**, **Refresh** from disk, and **Save changes**.

### Git

![Git tab showing the repository list on the left and a repository brief with Push, Pull, and Super Commit actions on the right](../../img/user-guide/projects/07-git-management.png)

The Git tab is the project's Git cockpit.

- **Repository list** (left) shows the monitored repositories; the counter (for example `1 / 15`) compares them with the monitoring limit from **Settings → Integration → Git**. Use **Select Changed**, **Select All**, and **Clear Selection** for batch work, or search by name. **Manage Super Commit All exclusions** controls which files the quick commit skips.
- **Repository brief** (right) shows the branch, sync status, whether there are uncommitted changes, the remote, and the repository path.
- Actions for the focused repository: **Super Commit**, **Push**, **Pull**, **Rebase Upstream**, **Open Remote Repository**, **Open Code Server**, and **Manage DESIGN.md**.

The brief replaces a diff preview on purpose. For deeper Git work, use **Open Code Server**.

Git behavior such as profiles, status monitoring, and the default Super Commit action is configured in **Settings → Integration → Git**.
