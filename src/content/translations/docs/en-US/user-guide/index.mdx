This section is the hands-on manual for the HagiCode workbench. It follows the interface module by module, so you can open the page for the part of the product you are using right now.

## The workbench at a glance

The workbench opens on the **session board**. The screenshot below uses a small demo project called `orbit-notes` with one finished session.

![HagiCode workbench showing the header, project rail, session board with three lanes, project panel, and status bar](../../img/user-guide/workbench/01-workbench-overview.png)

The screen is divided into five regions:

| Region | Where | What it is for | Guide |
| --- | --- | --- | --- |
| **Header** | Top edge | Opens the workspace-level modules: Agents, Wizard, Skills, HagiTask, Vault, settings, language, theme, and your profile | [Header](#header) |
| **Project rail** | Left edge | Switches between all projects or a single project and creates new projects | [Projects](/en-US/user-guide/projects) |
| **Session board** | Center | Shows sessions in lanes and holds the buttons that create new sessions | [Sessions](/en-US/user-guide/sessions) |
| **Project panel** | Right | Quick actions and repository status for the selected project | [Projects](/en-US/user-guide/projects) |
| **Status bar** | Bottom edge | Tips, Agent CLI health, running sessions, break reminder, salary tracker, and the build version | [Status bar and progress](/en-US/user-guide/status-bar-and-progress) |

## Header

The header is always visible. Its buttons open drawers and dialogs on top of the current page, so you never lose your place on the board.

![HagiCode header with Agents, Wizard, Refresh, Skills, HagiTask, Vault, Get Support, language, theme, settings, and profile buttons](../../img/user-guide/workbench/03-header-navigation.png)

| Button | What it opens |
| --- | --- |
| **Agents** | The Agents workspace: your Agents, execution scenarios, AgentCLI list, model catalog, document theme, and avatar gallery. See [Agents](/en-US/user-guide/agents). |
| **Wizard** | The four-step initialization wizard. See [First launch](#first-launch-the-initialization-wizard). |
| **Refresh** | Reloads the content of the current page. |
| **Skills** | The unified skills module with Local Skills, Gallery, and Trusted Providers. See [Skills and HagiTask](/en-US/user-guide/skills-and-hagitask). |
| **HagiTask** | HagiTask management for task presets. See [Skills and HagiTask](/en-US/user-guide/skills-and-hagitask). |
| **Vault** | The vault manager for folders HagiCode can browse and preview. See [Vault](/en-US/user-guide/vault). |
| **Get Support** | Opens the community and support page in your browser. |
| **Language** | Switches the interface language. HagiCode ships ten interface languages, including English. |
| **Theme** (leaf icon) | Opens the theme chooser. See [Appearance](/en-US/user-guide/settings#appearance-theme-and-language). |
| **Settings** (gear icon) | Opens the settings dialog. See [Settings](/en-US/user-guide/settings). |
| **Profile** (round avatar) | Opens your profile drawer with points, history timeline, and quick links. See [Status bar and progress](/en-US/user-guide/status-bar-and-progress#profile). |

## First launch: the initialization wizard

On a fresh installation the **Initialization wizard** opens by itself. You can reopen it any time with the **Wizard** button in the header. It has four steps and tracks how many of the three required steps are ready.

![Initialization wizard, step 1: choose the interface language and a color theme](../../img/user-guide/wizard/01-language-theme.png)

1. **Language & theme** – pick the interface language and a seasonal color theme. Both apply immediately.
2. **Hagicoder** – choose a local Agent CLI and a model, create your first Agent, and add it to the **Fallback Crew**. A connection test is recommended but optional.
3. **Project** – register the folder of your first project.
4. **Community** *(optional)* – start your first conversation or open the About page.

![Initialization wizard, step 2: set up the default Agent and add it to the Fallback Crew](../../img/user-guide/wizard/02-agent.png)

For the full walkthrough, including what each field means, see [Wizard Setup](/en-US/quick-start/wizard-setup).
