A **session** is one unit of work with an Agent. The session board is the center of the workbench: it shows where every session stands and holds the buttons that start new ones.

## The session board

![Session board with Proposal & Review, Execution, and Archived lanes and one finished session card in Execution](../../img/user-guide/workbench/01-workbench-overview.png)

The board has three lanes:

| Lane | What lands here |
| --- | --- |
| **Proposal & Review** | Ideas that are being drafted, generated, and reviewed as proposals. |
| **Execution** | Sessions that are running or finished, including normal sessions. |
| **Archived** | Sessions you archived. They stay available for review. |

Each card shows the session number, its project, an icon for its type, the title, when it last changed, and a status badge such as **Executing** or **Execution Complete**. Click a card to open the session. The counter beside each lane title shows how many sessions it holds, and the arrow on a lane header collapses that lane.

### Toolbar

The toolbar above the lanes has four controls:

- **Layout mode switcher** (the small icon next to *Session List*) switches between the five views. See [Views](/en-US/user-guide/views).
- **New Idea** (sprout icon) starts a proposal.
- **Create Normal Session** (speech-bubble icon) starts a conversation.
- **More HagiTasks** (list icon) opens the HagiTask workspace for other task presets. See [Skills and HagiTask](/en-US/user-guide/skills-and-hagitask).

The **Recent changes** menu and the **Trophies** widget sit at the right end of the toolbar. See [Projects](/en-US/user-guide/projects) and [Status bar and progress](/en-US/user-guide/status-bar-and-progress).

### Layout modes

![Choose a view drawer listing the five views](../../img/user-guide/views/01-layout-switcher.png)

| Mode | Badge | Best for |
| --- | --- | --- |
| **Classic** | Focused | A compact session list beside the project and detail columns. |
| **Execution Flow Kanban** | Flow | Swimlanes plus the full operations surface on the right. This is the layout used in this guide. |
| **Dashboard Kanban** | Compact | A lighter board that groups sessions by status and leaves more room for the overview. |
| **Project × Status Matrix** | Matrix | One grid of every project against its status lanes, with counts of what needs attention. |
| **Command View** | Command | A wall of live tiles for watching several running sessions and answering their questions in place. |

See [Views](/en-US/user-guide/views) for how to switch and what each view shows.

## Create an idea (proposal)

Click **New Idea** to open the **Create Proposal** drawer. Use it for changes that deserve a plan: you describe what you want, HagiCode drafts a proposal, and you review it before execution. The [Create a Proposal Session](/en-US/quick-start/proposal-session) walkthrough follows a whole proposal from start to archive.

![Create Proposal drawer with idea name, project, scope, quick requests, and a request about adding a POST endpoint](../../img/user-guide/sessions/01-new-idea.png)

**Left column: Basic Setup**

- **Idea Name** and **Project Name** (required).
- **Scope** has two tabs. **Vault** lets you *Specify Target Vaults (Optional)*: mark the vaults the AI may edit. System-managed vaults are reference-only. **Projects** lets you add other projects as context.
- **Quick Requests** are one-click additions to your request: *No docs / tests*, *Self commit*, *Output English*, *Ask before edit*, and *No backward compatibility*.

**Right column: Requirement Drafting & Preview**

- **You Request** is where you describe the change, up to 14,000 characters. **Upload Image** attaches a picture.
- **Combined preview** shows the full text that will be sent to the AI, so you can review it before you submit.
- **Submit idea** creates the proposal session. **Load Favorite** and **Save as Favorite** reuse a saved setup.
- The **Plan** switch at the bottom right of the drawer swaps "submit now" for "submit on a schedule": once saved, HagiCode creates this proposal session automatically at the time you set. See [Scheduled plans](/en-US/user-guide/scheduled-plans).

## Create a normal session

Click **Create Normal Session** for a plain conversation with an Agent. Use it to understand a repository, ask a question, or make a small change without a proposal.

![Create Normal Session drawer with project, session title, task scope, a request, and the Available Agents picker](../../img/user-guide/sessions/02-create-normal-session.png)

| Field | Notes |
| --- | --- |
| **Project** | Required. Defaults to the selected project. |
| **Session title** | Optional label shown on the card. |
| **Task scope** | **Repos** narrows the session to repositories of a MonoSpecs project. **Vault** and **Projects** attach extra reference material. |
| **What do you want to do?** | Required. The first message of the session. **Upload Image** attaches a picture. |

The **Available Agents** panel lists your Agents. Pick one and the session **starts immediately**; the first entry is the runtime default. A second list lets you pick a different Agent only for this run. If no Agent is listed, set one up first in [Agents](/en-US/user-guide/agents). Press `Ctrl/⌘ + Enter` to submit from the keyboard.

:::note[Start with a read-only question]
The sample session in this guide asked a read-only question about the demo project. It finished in about 23 seconds and changed no files. Edit mode is controlled per session, see below.
:::

## Work inside a session

Click a card to open the session drawer.

![Session drawer showing the final answer, a Session Complete summary, the message box, and the Agent status card](../../img/user-guide/sessions/03-session-detail.png)

**Header** – the title, the Agent's avatar, and the buttons **Archive** (moves the session to the Archived lane), **Delete Session**, **Open Code Server**, and a **…** menu with more actions.

**Conversation** – messages from you and the Agent in order. While the Agent works you can follow what it does: tool calls are folded into a thin ledger with one line per call, showing the tool name, what it acted on (a path, command, or search pattern), and a short digest such as line count and duration. A running or failed call carries a mark, and clicking a row opens the full details.

![Top of a session showing the run mode block and a Bash tool call row](../../img/user-guide/sessions/04-session-detail-top.png)

When the run ends, a **Session Complete** card summarizes the number of turns, the elapsed time, and the cost of the run. Click it to expand the details.

**Message box** – at the bottom:

- The **Edit / Readonly** switch turns edit mode on or off. With edit mode on, new messages are more likely to modify files. Whether new normal sessions start in edit mode is set in **Settings → Sessions and conversation → Chat View**.
- Buttons for **images**, **Standard Phrases** (the `@` picker), and **Import Recent History**.
- **Send** submits the message. Press `Enter` to send and `Shift + Enter` for a new line.

**Agent status card** – on the right of the message box: the Agent CLI and model (for example `claude-sonnet-5-5`), its current state such as *Idle*, and the elapsed time.
