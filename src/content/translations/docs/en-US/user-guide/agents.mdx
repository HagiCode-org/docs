An **Agent** in HagiCode is a ready-to-use worker: an Agent CLI (such as Claude Code), a model, and optional personality text. Sessions are run by Agents, so you need at least one before you can start work.

Click **Agents** in the header to open the **Agents Workspace**. It has six tabs.

| Tab | Purpose |
| --- | --- |
| [Agents](#agents-tab) | Create and manage your Agents. |
| [Execution Scenarios](#execution-scenarios) | Decide which Agents run which kind of work. |
| [AgentCLI](#agentcli) | See which Agent CLIs are installed, healthy, and enabled. |
| [Model](#model) | Browse and extend the model catalog for each Agent CLI. |
| [Document Theme](#document-theme) | Choose the wording theme of the interface. |
| [Avatar Gallery](#avatar-gallery) | Browse the avatar packs. |

:::note
The AgentCLI and Model catalogs are system-level. The Agents tab only stores your current Agents and their lineup.
:::

## Agents tab

![Agents tab with the My Agents list grouped by Agent CLI, showing the Hagicoder Agent](../../img/user-guide/agents/01-agents.png)

**My Agents** lists your Agents, grouped by the Agent CLI they use. Each card shows the avatar, the name, the model, and a small badge for the CLI.

- **New Agent** opens the creation drawer.
- **Batch create Agents** creates several at once.
- **Search** filters by Agent name, AgentCLI, or summary.
- **Select all visible**, **Clear visible**, and **Delete N selected** handle bulk removal.

### Create an Agent

![New Agent drawer with the Agent loadout, trait, and soul sections](../../img/user-guide/agents/02-new-agent.png)

The drawer creates one Agent. The Agents view stays where it is until creation succeeds.

- **Name and avatar** – a random name is suggested from the name pool. Uploading a custom avatar requires the TurboEngine DLC.
- **Agent loadout** – two required slots. Click one of the candidate icons to equip it:
  - **AgentCLI** – which command-line tool runs the Agent.
  - **Model** – the model that CLI uses. The list only shows models compatible with the selected CLI.
- **Trait · knowledge and behavior** – free text, or traits from the Trait platform, that shape how the Agent works.
- **Soul · language style** – free text, or a soul from the Soul platform, that shapes the Agent's voice.
- **Battle ready** toggle – enables or disables the Agent.

## Execution Scenarios

![Execution Scenarios tab with proposal, HagiTask, and chat scenarios and the lineup editor](../../img/user-guide/agents/03-execution-scenarios.png)

Scenarios decide which Agent is picked for each kind of work. They are grouped by where they occur:

| Group | Scenarios |
| --- | --- |
| **Proposal** | Optimize Proposal, Generate Proposal, Execute Proposal, Archive Proposal |
| **HagiTask** | Super Commit, Create Normal Session, Create Research Investigation Task |
| **Chat** | Conversation Title Optimization |

The **Fallback Crew** is the safety net. When a scenario's own lineup has no suitable Agent, HagiCode randomly tries eligible members of the Fallback Crew. It is required: **until the Fallback Crew has at least one enabled Agent, every other scenario stays locked.** The initialization wizard adds your first Agent to it for you.

Click a scenario to edit it. **Assigned Agents** shows who is in the lineup, **Available Agents** shows who can be added, and the filter chips narrow the list by Agent CLI. The runtime tries eligible members at random, so the visible order does not set priority.

## AgentCLI

![AgentCLI management table listing each CLI with its enabled state, availability, version, and monitoring status](../../img/user-guide/agents/04-agentcli.png)

This tab lists every command-line tool HagiCode can drive: Claude Code, Codebuddy, Codex, DeepAgents, DSH, Gemini, GitHub Copilot, Hermes, Junie, Kimi, Kiro, OMP, OpenCode, Pi, QoderCLI, and Reasonix.

For each CLI you see:

- **Enabled** and **Availability** – a CLI must be installed on the machine that runs HagiCode to be available.
- **CLI version** – the detected version, or *Not detected* when the executable cannot be found.
- **Monitoring** – the latest health check, such as *Healthy*.
- **Show diagnostics** – the details behind a result, useful when a CLI is not detected.
- A **switch** to enable or disable the CLI. Use the checkboxes with **Enable selected** and **Disable selected** to change several at once, and the filter to show *Available* or *Unavailable* CLIs only.

If a CLI you installed is not detected, make sure its executable is on the `PATH` of the process that runs HagiCode, then reload. See [AI Agent CLI installation](/en-US/related-software-installation/ai-agent-cli).

## Model

![Model tab with the Claude Code model catalog and the Create Model form](../../img/user-guide/agents/05-model.png)

Pick an **AgentCLI** at the top to see its models. The table shows each model's name, model ID, source, and whether it supports images.

- **System defaults** are read-only and maintained by HagiCode.
- **Custom** entries are yours. Create one with the **Create Model** form: *Display name*, *Summary*, an *Icon*, the *Model value* the CLI expects, and whether it *Supports images*. **Create blank entry** starts from an empty row.
- Filter by name or model ID, by source (*All sources*, *Custom*, *System default*), or to models that *Support images only*.

## Document Theme

![Document Theme tab showing the AgentCLI Baseline theme as current and other themes locked](../../img/user-guide/agents/06-document-theme.png)

The document theme changes the vocabulary of the interface. **AgentCLI Baseline** uses neutral wording such as *Agents*, *Jobs*, and *Workspace* and is the default. Other themes, such as the *Fantasy Adventure* wording, need the TurboEngine DLC; their previews stay visible but locked. **Restore default theme** goes back to the baseline.

## Avatar Gallery

![Avatar Gallery with avatar packs on the left and a large preview of the selected avatar on the right](../../img/user-guide/agents/07-avatar-gallery.png)

Browse the avatar packs that can be used for Agents. Pick a pack and an avatar to see its preview, plugin source, version, and stable ID.
