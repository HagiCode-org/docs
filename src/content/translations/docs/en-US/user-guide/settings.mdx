Click the **gear icon** in the header to open **Settings**. The left side lists the groups and their tabs; the right side shows the selected tab. Some tabs save changes as you make them; others have their own **Save** button.

Groups can be collapsed. HagiCode remembers which ones you left open.

## General

### General Settings

![General Settings tab with Brand Customization and the back-to-top button position](../../img/user-guide/settings/01-general-settings.png)

- **Brand Customization** sets a custom header logo, application title, brand link, and browser title. A live preview shows the result. These controls are visible for preview but locked until the TurboEngine DLC is active.
- **Back to Top Button Settings** chooses where the back-to-top button appears in a session, for example *Bottom Right*.

### Notifications

![Notifications tab with channels and a table of status rules](../../img/user-guide/settings/04-notifications.png)

Turn notifications on, then choose the channels: **Toast notifications**, **Browser notifications** (the browser must allow them), **Speech synthesis**, and **Sound Settings**. The **Status rules** table lets you pick, for each session status such as *New*, *Drafted*, *Executing*, *Waiting for Reply*, *Execution Complete*, or *Archived*, which channels fire and which sound plays. The play button tests a sound.

### Confirm Prompts

![Confirm Prompts tab with switches for each confirmation dialog](../../img/user-guide/settings/12-confirm-prompts.png)

A master switch plus one switch per confirmation dialog: before a Super Commit All commit, before generating a proposal, moving it to pending execution, executing immediately, or archiving it, and before archiving or deleting selected conversations. Turning prompts off saves clicks but makes mistakes more costly. **Reset to Default** restores the defaults.

### About

![About tab with the HagiCode platform version and community resources](../../img/user-guide/settings/30-about.png)

Shows the version and build date and links to the official About page with the full community list.

## Appearance and interface

### Startup Splash

![Startup Splash tab with the startup splash switch, the image selection mode, and the fixed image picker](../../img/user-guide/settings/32-startup-splash.png)

Decides which splash image HagiCode shows when it starts. **Changes apply the next time HagiCode starts.**

- **Show startup splash image**: when turned off, startup shows only the brand name, the version, and a loading indicator.
- **Image selection** has three modes: **Random on every startup**, **Random once per day** (chosen on the first start of the day and kept for the rest of it), and **Fixed image**.
- With **Fixed image** selected, the picker below lists the available splash images; click one and it is shown on every startup.

These controls are visible for preview but locked until the TurboEngine DLC is active, as shown in the screenshot.

### Status Bar Scroll

![Status Bar Scroll tab with display switches and the list of current promotions](../../img/user-guide/settings/26-status-bar-scroll.png)

Chooses whether the status bar scrolls and which sources it uses: **Tips** and **Promotions**. Turning scrolling or promotions off needs an active TurboEngine subscription. The tab lists the current promotions.

### TokenMonitor

![TokenMonitor tab with the status bar switch and HostHub fields](../../img/user-guide/settings/24-tokenmonitor.png)

Shows today's token usage and cost from the TokenMonitor desktop app in the status bar. Nothing is read while the switch is off. For near-real-time updates, enter both the **HostHub address** and **HostHub secret**; leave either empty to read TokenMonitor's local data file instead.

### Mermaid Appearance

![Mermaid Appearance tab with the Default and Archify-inspired presets](../../img/user-guide/settings/10-mermaid-appearance.png)

Chooses the look of Mermaid diagrams: *Default* or *Archify-inspired*. The choice is saved only in this browser and changes visuals only.

### Kanban Right Panel

![Kanban Right Panel tab with display mode options and a preview](../../img/user-guide/settings/06-kanban-right-panel.png)

Choose what the right side of the session board shows: *Hidden*, *GitHub Discussion*, or the *Quick Operations Panel* with quick actions and repository status (the default). A live **Preview** shows the effect.

## Sessions and conversation

### Session List

![Session List tab with project scope, sort mode, and display options](../../img/user-guide/settings/11-session-list.png)

- **Project Scope** chooses which projects feed the *All Sessions* board: *All Projects* or a *Custom Selection*. Click **Save** to apply it.
- **Session Sorting** is either *Smart Sorting* (by runtime status and recent activity) or *Custom Sorting* with your own prioritized rules.
- **Session Display Settings** includes whether archived sessions stay visible in the list.

### Chat View

![Chat View tab with chat mode, debug metadata, and long message options](../../img/user-guide/settings/16-chat-view.png)

- **Default to Edit Mode for Normal Chats** decides whether new normal sessions start in edit mode, where the Agent may modify files, or read-only.
- **Show debug metadata entry points** adds debugging entries to chat messages.
- **Auto-collapse long messages** shows long history messages as a preview with an expand control.
- **Simplified historical tool calls** collapses older tool calls into a short summary attached to the next visible message.

### AgentCLI Interactive Control

![AgentCLI Interactive Control tab with one switch per Agent CLI](../../img/user-guide/settings/15-agentcli-interactive-control.png)

One switch per Agent CLI decides whether generated OpenSpec and HagiTask prompts still tell the Agent that the run is non-interactive. With a switch off (the default) the hint is included. This only changes the wording of generated prompts.

### Agent Memory Limit

![Agent Memory Limit tab with a memory limit switch and a limit dropdown for each Agent](../../img/user-guide/settings/33-agent-memory-limit.png)

Limits how much memory each Agent CLI, and the commands it runs, may use. **A changed limit applies only to Agents started afterwards.**

- **Limit memory per agent**: when turned on, every new Agent run, together with all the processes it starts, is held to the limit below.
- **Limit per agent**: choose the limit from the dropdown; the default is 4 GB. The description lists the corresponding soft limit, Node.js heap size, swap, and task count cap. Hagicode enforces the limit by starting the Agent in a systemd user scope.

If the current system does not support this capability, the tab shows the reason and the switch is unavailable.

### Error Retry

![Error Retry tab with the default retry policy and per-CLI overrides](../../img/user-guide/settings/14-error-retry.png)

Automatic retry for failed runs. The **Default Policy** sets the maximum number of retries and the delay before each retry, with a tail delay for later attempts. The default schedule waits 30, 30, 30, then 60 seconds. **CLI Overrides** let each Agent CLI follow the default or use its own schedule.

### Post-state actions

![Post-state actions tab: a Super Commit session is archived automatically after Execution completed](../../img/user-guide/settings/34-post-state-actions.png)

Decides what HagiCode does automatically after a type of session enters a certain state. Rules run in the order listed. The built-in rule currently targets **Super Commit sessions** (sessions started from a Super Commit message):

- **Enabled**: when turned on, the rule takes effect.
- **When the session reaches**: the state that triggers the rule, for example **Execution completed**.
- **Then**: the action to take, for example **Archive session**.

The default rule archives Super Commit sessions automatically once they finish executing, so they leave the session list.

## Proposals and planning

### Proposal Creation

![Proposal Creation tab with the recent repository slot count](../../img/user-guide/settings/07-proposal-creation.png)

Sets how many recent repository cards the proposal repository selector shows at the top. Choose `0` to hide the row.

### Planning Direction

![Planning Direction tab with a matrix of planning directions per Agent CLI](../../img/user-guide/settings/08-planning-direction.png)

A matrix of the planning directions the proposal flow proposes by default for each Agent CLI: explore mode, change map, interaction flow, prototype, architecture, API sequence, and the editable and reference repository scope. Individual Agents can override the defaults.

### Proposal Stage Diagram

![Proposal Stage Diagram tab with Full and Compact display modes and a live preview](../../img/user-guide/settings/09-proposal-stage-diagram.png)

Sets how detailed the stage list in the proposal drawer is: *Full* shows stage labels and descriptions, *Compact* shows labels only. This affects only the drawer's side rail, not the main flow diagram.

## Input and efficiency

### Haginput

![Haginput tab with the input mode and remote mode settings](../../img/user-guide/settings/18-haginput.png)

Intelligent input. Choose **Disabled**, **Doubao Local Voice**, or **Haginput Remote Mode** to relay text from a phone or second device without opening the local microphone. The tab shows the mode status, an auto-connect option, a sound for received text, and a test box.

### Common Phrases

![Common Phrases tab with category visibility, path sources, and custom groups](../../img/user-guide/settings/17-standard-phrases.png)

This tab combines the former **Standard Phrases** and **Common Requirements** into two parts.

**Phrases**: manages the reusable `@` phrase tokens in the message box. Choose which categories and path sources (projects, vaults, proposal sessions, recent projects, custom paths) appear in the `@` picker, and create custom phrase groups with **Add Group**.

**Common requirements**:

![The list of common requirements in the lower half of the Common Phrases tab](../../img/user-guide/settings/13-common-requirements.png)

Reusable requirement snippets that you can add to a proposal request with one click, for example *No docs / tests*, *Self commit*, *Output English* (it follows the interface language), *Ask before edit*, and *No backward compatibility*. Only requirements for the current interface language are listed. Use **Add Common Requirement** to create your own, and the edit and delete buttons to manage them; built-in system presets can be brought back with **Restore missing system presets**.

### Quick Actions

![Quick Actions tab with an empty command list and execution history](../../img/user-guide/settings/05-quick-actions.png)

**Configured Commands** lists the custom commands you add with **Add Command**. **Execution History** records when they ran.

### Comments

![Comments tab with line comment and file comment template lists](../../img/user-guide/settings/03-comments.png)

Save the comment templates you use often, in two lists: **Line Comments** and **File Comments**. Use **Add Comment** to create one and **Save** to keep your changes.

## Projects and integrations

### Project Icon

![Project Icon tab with the default icon mode and the icon collection](../../img/user-guide/settings/02-project-icon.png)

- **Project Icon Mode** sets the default style for new projects: *Game Icon* (a random colorful icon, the default) or *Text Abbreviation* (initials from the project name). A single project can override it in its [project details](/en-US/user-guide/projects#details).
- **Icon Collection** controls which icons can be picked. Use **Show All**, **Enable All**, **Disable All**, **Random 50**, and **Refresh**, or click an icon to toggle it.

### GitHub

![GitHub tab showing the connected local gh CLI session and setup instructions](../../img/user-guide/settings/21-github.png)

Uses your local GitHub CLI (`gh`) session to sync sessions and import GitHub data. The tab shows the connection status and granted scopes, **Refresh status**, and **Copy login command**. Tokens stay in memory for the current page session and are never written to local storage. If `gh` is not signed in, follow the *Local `gh` setup* steps shown on the tab.

### Git

![Git tab with Git profiles, status monitoring, and Super Commit defaults](../../img/user-guide/settings/22-git.png)

- **Git Profiles** hold the author identities that Super Commit can use. Create at least one before you start a Super Commit so the prompt always names a clear author.
- **Automatically refresh and monitor Git status** checks active projects regularly. This can raise disk activity, especially on Windows or with many repositories. **Maximum monitored Git repositories** limits concurrent watchers (default 15).
- **Super Commit default behavior** chooses what the primary Super Commit button does: *Open confirmation panel* first, or *Commit immediately* with your saved profile and defaults. Further options set whether to push or rebase after a commit by default.

### Code Server

![Code Server tab with the resolved configuration and runtime status](../../img/user-guide/settings/25-code-server.png)

A display-only view of the resolved Code Server configuration (host, port, authentication mode, source) and the latest runtime snapshot. Editing Code Server settings is not supported here.

### OmniRoute

![OmniRoute tab with the integration switch, API endpoint, runtime status, and model catalog](../../img/user-guide/settings/23-omniroute.png)

Enables the shared OmniRoute integration. Set the **API endpoint** and optional **API key**, use **Test connection**, and choose which Agent CLIs consume OmniRoute's model catalog. The right side shows the runtime status and the cached model catalog. When the integration is off, model management falls back to the original system defaults. See [OmniRoute](/en-US/related-software-installation/omniroute) for installation.

## Lifestyle and wellbeing

### Achievements

![Achievements tab with the daily progress popover switch](../../img/user-guide/settings/27-achievements.png)

Toggles the daily achievement progress popovers in the status bar. Global milestone notifications and data sync stay active either way. See [Status bar and progress](/en-US/user-guide/status-bar-and-progress#trophies-and-the-achievement-hall).

### Break Reminder

![Break Reminder tab with timer status and reminder themes](../../img/user-guide/settings/19-break-reminder.png)

A timer that nudges you to drink water, stretch, or stand up. It shows the last and next reminder and today's cycles, and lets you pick a reminder theme such as *Basic*. The reminder appears in the [status bar](/en-US/user-guide/status-bar-and-progress#break-reminder).

### Salary Tracker

![Salary Tracker tab with daily salary, work hours, and unit emoji](../../img/user-guide/settings/20-salary-tracker.png)

A playful per-minute earnings counter. Enter a **Daily salary** and **Work hours per day**; the per-minute rate is the salary divided by work hours times 60, and a salary of `0` turns it off. Pick one of 20 unit emojis and choose whether the status bar shows the indicator.

## System

### Data Management

![Data Management tab with the database catalog, save catalog, and data cleanup](../../img/user-guide/settings/28-data-management.png)

Shows the active save and its data folders (save root, config root, data root). The **Save Catalog** lists saves and lets you activate a ready save safely. The **Workspace** switcher moves between the *Primary Database*, *Message Database*, and *Image Storage* tools. **Data Cleanup** shows database information and cleans up archived session message data to free storage.

### Debug

![Debug tab with SignalR logging, HagiPower adjustment, and DLC options](../../img/user-guide/settings/31-debug.png)

Tools for development builds:

- **SignalR Log** prints SignalR events and messages to the console in real time.
- **HagiPower Adjustment** edits the shared public pool directly in development. It does not change normal production accounting.
- **Enable DLC** explicitly opts the TurboEngine DLC in or out through backend configuration, because local development has no internal enable flag.

You do not need this tab for normal use.

### Danger Zone

![Danger Zone tab with the Reset system data button](../../img/user-guide/settings/29-danger-zone.png)

**Reset system data** resets persisted state and deletes the primary database records and message shards of the active save. Images, plugins, repositories, and other saves are not affected. The application keeps running, and a restart is recommended afterwards. This cannot be undone.

## Appearance, theme, and language

Two buttons in the header change how HagiCode looks without opening Settings.

![Choose theme dialog with theme families in light and dark variants and an auto-switch panel](../../img/user-guide/status/07-theme-chooser.png)

**Theme** opens the theme chooser. Each family comes in a **Light** and a **Dark** variant and applies immediately. Families include Standard, Spring, Summer, Vacation, Autumn, Winter, Lunar New Year, Soccer, Cyberpunk, School, and Space Travel. **Auto-switch** rotates between light or dark themes on a fixed interval from 1 to 240 minutes.

![Select Language dialog with English selected and the other nine interface languages](../../img/user-guide/status/08-language.png)

**Language** opens the language dialog. Choose a language and click **Confirm**. HagiCode supports English, 简体中文, 繁體中文, 日本語, 한국어, Deutsch, Français, Español, Português (Brasil), and Русский.
