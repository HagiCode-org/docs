HagiCode has removed built-in OmniRoute support. The product no longer includes OmniRoute installation steps, settings, connection tests, or model catalog sync.

To connect models now:

- use a model connected through Magpie, or
- configure a provider and model that your Agent CLI supports natively.

HagiCode does not migrate old OmniRoute endpoints or keys. Select a supported provider and model in your configuration. For Agent CLI setup, see [AI Agent CLI Installation](/en-US/related-software-installation/ai-agent-cli/).

## Standalone OmniRoute Documentation

OmniRoute is a separate project with its own documentation site. HagiCode does not support it.
