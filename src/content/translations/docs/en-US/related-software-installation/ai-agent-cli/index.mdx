This page is HagiCode's unified local AI Agent CLI installation entry. HagiCode currently supports 16 active Agent CLIs: Claude Code, Codex, GitHub Copilot, OpenCode, Hermes, QoderCLI, Kiro, Kimi, Gemini, DeepAgents, Codebuddy, Reasonix, Pi, OMP, Junie, and DSH.

:::tip[How to use this page]
Check the table for the current support state and setup mode first, then continue with the vendor-maintained installation, authentication, ACP, permission, and troubleshooting docs. Support scope and setup mode are separate concerns.
:::

:::note[Prepare Node.js 24+ First]
Most CLIs that support one-click installation depend on Node.js and npm, and Desktop also uses the `node` and `npm` on your system (Desktop no longer bundles Node.js). Please prepare version 24 or higher by following [Installing Node.js](/en-US/related-software-installation/nodejs/installation) first, and **finish signing in or authenticating** after installation: the Initialization Wizard only lists CLIs it has detected locally.
:::

## State glossary

- **Currently supported** means the CLI belongs to the current active HagiCode support range.
- **One-click install** means HagiCode provides a guided installation entry point; some CLIs still require a vendor login or auth step after installation.
- **Manual installation / authentication** means the CLI is supported now, but you must finish the local install or auth flow before HagiCode can detect and use it.
- **Legacy compatibility only** means iFlow CLI is kept only for compatibility with old data. It is not part of the current active support range and should not be treated as a currently recommended option.
