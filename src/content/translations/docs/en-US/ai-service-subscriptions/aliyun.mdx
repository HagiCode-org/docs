## Positioning

Alibaba Cloud DashScope is one of the providers currently recommended by the docs preset for Claude Code. It suits teams already working in the Alibaba Cloud ecosystem that want subscriptions, the console, and key management all in one cloud platform.

## Good fit for

- You already use the Alibaba Cloud console or cloud resources
- You want to manage services and API keys from one cloud platform
- You want to get started with Claude Code quickly through a fixed model mapping

## Key things to notice

- The current preset marks Alibaba Cloud DashScope as a recommended provider.
- It uses `glm-4.7` as the default mapped model, which keeps the setup path clear.
- If your team already has an Alibaba Cloud account system, setup and permission management will feel more natural.

## Suggested next steps

1. Confirm which plan or API key activation path you want to use.
2. Open the Claude Code entry in the unified AI Agent CLI page and continue to Anthropic's official install and reference docs.
3. When you are done, verify the connection by running `claude --version` locally, checking your configuration files, or sending a real request.
