## Positioning

ZAI is one of the providers currently recommended by the docs preset for Claude Code. Its GLM Coding plans and multi-model mapping suit developers who want to use Claude Code as their main daily tool.

## Good fit for

- You want a plan built specifically for coding scenarios
- You need fairly complete mappings for the Claude tiers
- You want one service that covers Claude Code, Cline, and other tools

## Key things to notice

- The current preset marks ZAI as a recommended provider.
- It offers an Anthropic-compatible endpoint that Claude Code can use directly.
- The preset includes default model mappings such as `glm-4.7`, `glm-5`, and `glm-4.5-air`.

| Claude tier | Default model |

:::tip
Plans, promotions, and benefits change over time. If you mostly care about current pricing, check the provider's subscription page directly.
:::

## Suggested next steps

1. Confirm which plan or API key activation path you want to use.
2. Open the Claude Code entry in the unified AI Agent CLI page and continue to Anthropic's official install and reference docs.
3. When you are done, verify the connection by running `claude --version` locally, checking your configuration files, or sending a real request.
