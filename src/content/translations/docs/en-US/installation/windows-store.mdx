For Windows users, Microsoft Store is the current public desktop entry point. This page covers the Store path only. If you need the broader Desktop download, version-management, and troubleshooting guide, continue with [Desktop Installation](/en-US/installation/desktop).

The main Steam app entry has already been retired, so Microsoft Store is now the primary Windows channel. For background, see [Why HagiCode is not available on Steam](/en-US/faq/steam-distribution-status/).

:::tip[Good fit for this path]
- you are on Windows 10 or Windows 11 and want to install directly from the system store
- you prefer store-delivered app packages instead of handling installer files manually
:::

## Before you start

Confirm these conditions first:

- your device can open the [Microsoft Store page for HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW)
- network access is available on first launch because the app may still need to download or prepare the components Hagicode Server requires
- some devices, organization policies, or region settings may ask you to sign in with a Microsoft account first
- if Store access is disabled on your company device, switch to [Desktop Installation](/en-US/installation/desktop)

## Prerequisites

The Store edition runs the same way as Desktop: it **does not bundle Node.js**, so you need to install it yourself and make it available on the system `PATH`. Prepare the following before the first launch:

- **Node.js 24 or higher** (which also provides `npm`); see [Installing Node.js](/en-US/related-software-installation/nodejs/installation)
- **Git**; see [Install Git](/en-US/installation/#install-git)
- At least one installed and signed-in **Agent CLI**; see [AI Agent CLI Installation](/en-US/related-software-installation/ai-agent-cli/)

If you install them after HagiCode is already open, fully quit and restart HagiCode so it reads the new `PATH`.

## Install from Microsoft Store

1. Open [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW).
2. Click `Get`, `Install`, or the equivalent action shown by the Store page.
3. Wait for Microsoft Store to finish downloading and installing the app.
4. Launch HagiCode from the Start menu or directly from the Store page.

## What happens on first launch

After installation, HagiCode still continues through the standard Desktop initialization flow.

- the first launch starts with Desktop's First-Time Setup: choose a language, confirm the legal documents, and download Hagicode Server as needed, so it may be slower than a typical app
- the Microsoft Store / MSIX channel locks the "Runtime data storage path" setting, which is expected behavior for this distribution method
- the app does not update itself independently; package updates are determined by the installation channel, and for Store installs, delivery depends on the Microsoft Store channel

If you want to continue with the Initialization Wizard, read [Wizard Setup](/en-US/quick-start/wizard-setup).

## When to use another installation path

Another channel is a better fit when:

- you cannot access Microsoft Store, or your company device explicitly blocks Store installation
- you need to download `.exe` or `.msix` files manually and control the installer source yourself

## Troubleshooting

### The Microsoft Store page does not open

Check system network access, region settings, and Microsoft Store sign-in status first. If the browser link opens but the Store client remains unavailable, the usual cause is that local system policy restricts Store capabilities. In that case, switch to [Desktop Installation](/en-US/installation/desktop).

### Why some settings are greyed out

Store / MSIX installs lock the "Runtime data storage path" option and show "Locked by Microsoft Store". This is not an installation failure; it is a constraint of the current distribution channel.

### Why the first launch still downloads or prepares content

The Store package only delivers the desktop application package. On first launch, HagiCode may still download or prepare the components Hagicode Server requires, and complete the default initialization. Keep the network available and wait for the current step to finish.
