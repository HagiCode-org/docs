## Before You Install

Each path has different prerequisites:

| Installation method | Node.js | Git |
| --- | --- | --- |
| Microsoft Store / Desktop | Install it yourself, **version 24 or higher** | Install it yourself |

:::caution[Desktop No Longer Bundles Node.js]
Desktop only bundles the .NET runtime needed to run HagiCode Server and **no longer provides Node.js**. It looks for `node` and `npm` on the system `PATH`, and installs managed packages such as Agent CLIs into your local npm global directory. Install Node.js 24 or higher before you launch Desktop for the first time. See [Installing Node.js](/en-US/related-software-installation/nodejs/installation) for details.
:::

### Install Git

Desktop checks for `node`, `npm`, and `git` at startup, and the "Demo Project" in the "New Project" dialog of the main interface also needs Git to clone the official sample repository. Pick one of these ways to install it for your system:

- **Windows**: run `winget install --id Git.Git -e`, or download the installer from [git-scm.com](https://git-scm.com/downloads).
- **macOS**: run `xcode-select --install`, or use Homebrew and run `brew install git`.
- **Debian / Ubuntu**: run `sudo apt-get install -y git`.
- **Fedora**: run `sudo dnf install -y git`.

After installation, reopen your terminal and confirm the commands are available:

```bash
node --version
npm --version
git --version
```

:::tip[Install First, Then Launch Desktop]
Desktop reads the system `PATH` at startup. If you install Node.js or Git while Desktop is already open, fully quit and restart Desktop.
:::

### Agent CLI

HagiCode works through Agent CLIs that are installed and signed in on your machine. The initialization wizard only lists CLIs it has detected locally, so install and sign in to at least one before you enter the wizard. The currently supported CLIs, their installation methods, and official entry points are maintained in one place at [AI Agent CLI Installation](/en-US/related-software-installation/ai-agent-cli/).

## Next Steps

1. Choose an installation method from the table above and complete its prerequisites first.
2. Finish installing and launch HagiCode for the first time, then follow [Wizard Setup](/en-US/quick-start/wizard-setup) to create your default Hagicoder and your first project.
3. To learn about the OpenSpec proposal workflow, read the [Introduction to OpenSpec](/en-US/related-software-installation/openspec/intro-openspec) and [Create a Proposal Session](/en-US/quick-start/proposal-session).
