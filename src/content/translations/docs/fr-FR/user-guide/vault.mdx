Un **Vault** est un dossier que HagiCode est autorisé à parcourir et à prévisualiser en dehors du dépôt du projet. Vous pouvez utiliser un Vault pour stocker des documents de référence, des notes, des résultats de recherche et tout autre contenu que vous souhaitez que les sessions puissent lire ou écrire.

Cliquez sur **Vault** dans la barre supérieure (interface chinoise : Vault) pour ouvrir le **Vault Workspace** (espace de travail Vault).

![Espace de travail Vault, listant les Vault enregistrés Orbit Notes et Docs, ainsi qu'un groupe System vaults replié](../img/user-guide/vault/01-vault.png)

## Vault enregistrés et Vault système

L'espace de travail comporte deux groupes :

- **Registered vaults** (Vault enregistrés) regroupe les dossiers que vous avez ajoutés. Chaque carte affiche le type de Vault, son nom, un chemin raccourci et un bouton **Open Code Server** (Ouvrir Code Server) qui permet de modifier le dossier dans l'éditeur du navigateur.
- **System vaults** (Vault système) sont créés et gérés par HagiCode. Cliquez sur **Expand** (Développer) pour les afficher.

![Vault système développés, affichant sept Vault en lecture seule gérés par le système](../img/user-guide/vault/02-vault-system-expanded.png)

Dans ce tiroir, les Vault système sont **en lecture seule**. Ils comprennent les journaux de l'application, le répertoire de données, les modèles de prompts, les données personnelles, les données de projet, l'archive courante et les préréglages système. Dans le périmètre d'une session, ils sont considérés uniquement comme des références.

## Ajouter un Vault

Cliquez sur **Add vault** (Ajouter un Vault), renseignez **Vault name** (nom du Vault) et **Physical path** (chemin physique absolu), choisissez le **Vault type** (type de Vault), puis cliquez sur **Save vault** (Enregistrer le Vault).

![Tiroir Add vault, avec le nom, le chemin et le type Folder sélectionné](../img/user-guide/vault/03-add-vault.png)

| Type de Vault | Rôle |
| --- | --- |
| **Folder** (dossier) | Enregistre tel quel n'importe quel répertoire local existant. |
| **CodeRef** (référence de code) | Crée automatiquement `docs/`, `repos/`, `AGENTS.md` et `index.yaml`. Peut servir de Vault de sortie pour les tâches de recherche. |
| **Obsidian** | Crée automatiquement `.obsidian/`, `app.json` et des artefacts de notes prévisualisables, afin que le dossier puisse être utilisé comme Vault Obsidian. |

:::caution[Choisissez le type avant d'enregistrer]
Avant de cliquer sur **Save vault**, sélectionnez l'un des trois types de Vault. Dans la version utilisée pour rédiger ce guide, l'enregistrement sans type échoue avec un message d'erreur incompréhensible au lieu d'un message de validation.
:::

## Utiliser les Vault dans une session

Les Vault apparaissent dans le **Scope** (intitulé « Périmètre » dans l'interface, ou périmètre de la tâche) des [tiroirs de création de proposition et de création de session classique](/user-guide/sessions). Si la tâche doit mettre à jour des fichiers du Vault, marquez-le comme **editable** (modifiable). Sinon, l'IA le traitera comme une référence en lecture seule. Les Vault gérés par le système restent toujours en référence uniquement.
