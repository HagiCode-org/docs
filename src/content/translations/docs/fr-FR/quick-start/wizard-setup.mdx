Quelle que soit la méthode d'installation ([Microsoft Store](/fr-FR/installation/windows-store), [Desktop](/fr-FR/installation/desktop) ou [Docker Compose](/fr-FR/installation/docker-compose)), l'**assistant d'initialisation** s'affiche automatiquement à la première ouverture de l'interface Web de HagiCode. Une fois terminé, vous disposez d'un Hagicoder par défaut opérationnel et d'au moins un projet, et vous pouvez démarrer directement votre première session.

:::note[Différence avec le guide de premier lancement de Desktop]
Le guide « Configuration initiale » de Desktop (choisir la langue, confirmer les documents juridiques, télécharger Hagicode Server) se déroule avant l'apparition de l'interface Web, voir [Installation de bureau](/fr-FR/installation/desktop#guide-du-premier-lancement). Cette page décrit l'assistant d'initialisation qui apparaît ensuite dans l'interface Web.
:::

## Avant de commencer

Vérifiez d'abord les points suivants :

- **Au moins un Agent CLI installé et connecté.** L'assistant ne liste que les CLI détectés sur la machine qui exécute Hagicode Server ; tant qu'aucun n'est détecté, vous ne pouvez pas créer de Hagicoder. Les CLI pris en charge et leur mode d'installation figurent dans [Installation de la CLI de l'agent IA](/fr-FR/related-software-installation/ai-agent-cli/).
- **Utilisateurs Desktop / Store** : Node.js 24+ et Git sont déjà installés, conformément au [Guide d'installation](/fr-FR/installation/#préparation-avant-linstallation).
- **Utilisateurs Docker** : le fournisseur d'API et le jeton sont déjà configurés dans Docker Compose Builder.
- Préparez un dépôt local ou un répertoire de travail à connecter : l'étape 3 vous demandera de l'enregistrer, et le chemin doit exister réellement.

## Aperçu de l'assistant

L'assistant comporte 4 étapes. La navigation de gauche affiche la progression, et le badge en haut indique « N sur 3 étapes prêtes ». Les 3 premières étapes sont **requises** ; la 4e étape, « Communauté », est marquée **Facultatif** :

| Étape | Objectif | Critère d'achèvement |
| --- | --- | --- |
| 1. Langue et thème | Choisir la langue de l'interface et un thème de couleurs saisonnier | Cliquer sur « Continuer » pour confirmer la langue |
| 2. Hagicoder | Choisir un CLI et un modèle, puis créer le Hagicoder par défaut | L'Agent affiche « Le Agent fait partie de Équipage de secours » |
| 3. Projet | Enregistrer au moins un projet local | L'étape du projet affiche « Étape projet terminée » |
| 4. Communauté (facultatif) | Démarrer la première conversation ou consulter les points d'entrée de la communauté | Cliquer sur « Terminé » |

« Me rappeler plus tard », en bas à gauche, réduit d'abord l'assistant et vous le rappelle ensuite ; « Ne plus afficher » désactive l'affichage automatique. Dans les deux cas, vous pouvez rouvrir l'assistant à tout moment depuis l'entrée « Assistant » en haut de la page, et les étapes non terminées restent en attente.

## Étape 1 : Langue et thème

**Objectif** : définir la langue de l'interface et le thème de couleurs.

![Étape 1 de l'assistant d'initialisation : liste des langues, thèmes des quatre saisons et bouton « Continuer »](../../img/screenshots/quick-start/wizard-setup/step1-language-theme/original.png)

1. Dans « Choisir la langue de l'interface », sélectionnez une langue (10 sont prises en charge). Cela ne modifie que la langue de l'interface de l'application ; les héros et les projets ne sont pas affectés.
2. Dans « Choisir un thème de couleurs », choisissez pour l'une des saisons (printemps, été, automne ou hiver) la variante « Lumière » ou « Sombre ». Le choix s'applique immédiatement et peut être modifié plus tard depuis l'entrée de thème en haut de la page.
3. Cliquez sur « Continuer ». La langue est confirmée et vous passez à l'étape suivante, Hagicoder.

## Étape 2 : Configurer Hagicoder

**Objectif** : créer l'Agent par défaut, dont le nom est toujours **Hagicoder**, et l'ajouter à l'équipe de secours.

Si le système contient déjà un Agent, cette étape affiche « Agents trouvés » ou directement « Le Agent fait partie de Équipage de secours » :

- Si un Agent existe mais ne fait pas partie de l'équipe de secours, vous pouvez cliquer sur « Ajouter à Équipage de secours » ou choisir à la place « Créer plutôt un nouveau Agent ». L'assistant ne l'ajoute pas automatiquement.
- S'il en fait déjà partie, cliquez simplement sur « Suivant : créer un projet ».

Sinon, procédez ainsi :

1. **Choisissez votre AgentCLI principal** : seuls les CLI détectés sur la machine sont affichés ; la carte sélectionnée porte une coche à droite.
2. **Choisissez votre Modèle principal** :
   - Sélectionnez un modèle existant dans la liste ; vous pouvez la filtrer par nom ou par ID de modèle avec le champ de recherche situé au-dessus (« Rechercher des modèles »).
   - Ou saisissez manuellement un nom de modèle dans « Saisir un modèle personnalisé », par exemple `gpt-5.5`, `glm-5.1` ou `claude-opus-4-7` ; lors de la création, le backend réutilise ou crée le modèle correspondant.

   ![Étape 2 : sélection de Claude Code et de Sonnet 5.5](../../img/screenshots/quick-start/wizard-setup/step2-cli-model/original.png)

3. **(Recommandé) Cliquez sur « Lancer le test de connexion »** : il vérifie que le CLI choisi est disponible. Il n'envoie **aucune** invite au modèle ; il confirme donc seulement que le CLI peut être appelé, pas les réponses du modèle. Le résultat « La CLI est disponible » signifie que le test est réussi. Un test échoué ou expiré n'empêche pas la création, mais l'Agent risque de ne pas fonctionner tant que le CLI n'est pas corrigé.
4. **(Facultatif) Choisissez le portrait par défaut** : sélectionnez l'un des portraits proposés, ou cliquez sur « Mélanger » pour voir d'autres options.
5. Cliquez sur « Créer le Agent ». Une fois la création réussie, la page affiche « Le Agent fait partie de Équipage de secours », et le CLI et le modèle choisis sont inscrits dans la configuration par défaut du Hagicoder.

   ![Étape 2 : test de connexion réussi, portrait par défaut et bouton « Créer le Agent »](../../img/screenshots/quick-start/wizard-setup/step2-connection-test/original.png)

6. Cliquez sur « Suivant : créer un projet ».

:::tip[Quels CLI sont pris en charge]
Les CLI proposés dans l'assistant dépendent des Agent CLI installés et détectés sur la machine ; ils ne se limitent pas à un seul. La liste complète des CLI pris en charge et leurs modes d'installation font foi dans [Installation de la CLI de l'agent IA](/fr-FR/related-software-installation/ai-agent-cli/) ; Hermes, Gemini et DeepAgents nécessitent d'abord une installation ou une authentification manuelle.
:::

**Problèmes fréquents**

- **Le message « Aucune CLI locale disponible » s'affiche** : installez d'abord un CLI sur cet ordinateur et connectez-vous en suivant [Installation de la CLI de l'agent IA](/fr-FR/related-software-installation/ai-agent-cli/), puis cliquez sur « Relancer la détection ». Vous pouvez aussi cliquer sur « Passer pour l'instant » : cette étape reste alors en attente, et l'assistant vous le rappellera plus tard.
- **Mon CLI n'apparaît pas dans la liste** : vérifiez qu'il est installé et utilisable dans l'environnement qui exécute Hagicode Server ; les utilisateurs de Desktop doivent redémarrer Desktop pour actualiser le `PATH`.
- **Le test de connexion échoue** : la page affiche la raison de l'échec. Les causes courantes sont un CLI non connecté ou un jeton invalide. Lancez d'abord une conversation minimale avec ce CLI dans un terminal pour vérifier qu'il fonctionne par lui-même, puis cliquez sur « Relancer ».
- **L'Agent a été créé, mais son ajout à l'équipe de secours a échoué** : la page propose « Réessayer l'ajout à Équipage de secours ». Réessayer n'ajoute que le même Agent, sans le créer une seconde fois.

## Étape 3 : Créer un projet

**Objectif** : enregistrer au moins un projet, pour que les sessions suivantes disposent d'un répertoire de travail lisible. L'assistant vérifie d'abord s'il existe déjà un projet : s'il n'y en a pas, il affiche le formulaire d'enregistrement ; sinon, il affiche le résumé du projet actuel.

![Étape 3 : formulaire d'enregistrement d'un projet local](../../img/screenshots/quick-start/wizard-setup/step3-project-form/original.png)

1. Dans « Enregistrer un projet local », renseignez le **nom du projet** (obligatoire), le **chemin du dossier** (obligatoire) et, facultativement, une **description du projet**. Les champs et la validation du chemin sont exactement les mêmes que dans la boîte de dialogue « Nouveau projet » de l'interface principale.
2. Cliquez sur « Créer le projet et continuer ». Le chemin est validé à l'enregistrement ; une fois la validation réussie, le projet est créé et l'assistant passe automatiquement à l'étape suivante.
3. Si vous revenez à cette étape après avoir créé un projet, vous voyez « Résumé des projets actuels » et le repère « Étape projet terminée ». Vous pouvez alors cliquer sur « Continuer » pour passer à la communauté, ou sur « Ajouter un autre projet » pour en enregistrer d'autres (enregistrez ensuite avec « Ajouter le projet », ou revenez au résumé avec « Annuler »).

![Étape 3 : résumé des projets actuels lorsqu'un projet existe déjà](../../img/screenshots/quick-start/wizard-setup/step3-project-done/original.png)

:::tip[Envie d'essayer d'abord avec un projet d'exemple ?]
L'assistant ne propose que l'enregistrement d'un projet local. Le « Projet de démonstration » se trouve dans l'onglet « Projet de démonstration » de la boîte de dialogue « Nouveau projet » de l'interface principale : il clone et enregistre automatiquement le dépôt officiel MonoSpecs Demo, dans le chemin par défaut `data/repos/monospecs-demo` ; le répertoire réel suit la configuration du répertoire de données d'exécution (DataDir). Cette méthode nécessite Git et un accès à GitHub.
:::

**Problèmes fréquents**

- **Le message « Échec de la création du projet » s'affiche** : vérifiez que le chemin du dossier est correct et existe réellement ; avec un déploiement Docker, vous devez saisir un répertoire monté accessible dans le conteneur, et non un chemin de la machine hôte.

## Étape 4 : Communauté

**Objectif** : confirmer que tout est prêt et choisir la suite. Cette étape est facultative.

![Étape 4 : HagiCode est prêt à être utilisé ; vous pouvez démarrer la première conversation ou ouvrir la page À propos](../../img/screenshots/quick-start/wizard-setup/step4-community/original.png)

Une fois les trois étapes requises terminées, la page affiche « HagiCode est prêt à être utilisé » ainsi que l'état d'achèvement des trois étapes requises :

- **Démarrer la première conversation** : après le clic, l'assistant se ferme et la boîte de dialogue de nouvelle conversation s'ouvre dans l'espace de travail. Une conversation nécessite un projet ; s'il n'y en a pas encore, la page affiche « Créez d'abord un projet » et propose le bouton « Aller à l'étape Projet ».
- **À propos de HagiCode** : cliquer sur « Ouvrir la page À propos » ouvre dans le navigateur la page « À propos » du site officiel, qui regroupe tous les points d'entrée de la communauté ; l'assistant reste ouvert.
- **Terminé** : cliquer sur « Terminé » en bas à droite ferme l'assistant. Si des étapes requises ne sont pas terminées, elles restent en attente, et vous pouvez rouvrir l'assistant depuis l'entrée « Assistant » en haut de la page.
