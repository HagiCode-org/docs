Les sessions de conversation sont le point d'entrée le plus léger de HagiCode. Choisissez un projet, posez une question et laissez un Agent lire le dépôt pour y répondre. Vous décidez, session par session, si l'Agent peut modifier des fichiers.

## Prérequis

Avant de démarrer une session de conversation, assurez-vous d'avoir :

- terminé l'une des méthodes d'installation (Microsoft Store ou Desktop) en suivant le [Guide d'installation](/fr-FR/installation)
- terminé la [configuration avec l'assistant](/fr-FR/quick-start/wizard-setup), qui crée votre premier Agent et au moins un projet
- sélectionné ce projet sur le tableau des sessions

## À quoi sert une session de conversation ?

Une session de conversation convient surtout lorsque vous voulez d'abord comprendre, puis modifier. Cas d'usage typiques :

- analyser rapidement un dépôt que vous ne connaissez pas
- poser une question ciblée sur un fichier, un module ou une erreur
- effectuer une petite modification sans la planifier sous forme de proposition
- joindre des images, des phrases standard ou des messages précédents avant l'envoi

Si votre tâche est passée de « comprendre le problème » à « planifier, relire et archiver une modification structurée », poursuivez avec [Créer une session de proposition](/fr-FR/quick-start/proposal-session). Cette page ne traite que des sessions de conversation.

## Vue d'ensemble du flux de travail

| Étape | Ce que vous faites | Ce qui se passe |
| --- | --- | --- |
| Créer | Cliquez sur **Create Normal Session** et décrivez votre demande | Le panneau recueille le projet, un titre facultatif, le périmètre et votre premier message |
| Démarrer | Choisissez un Agent dans **Available Agents** | La session démarre immédiatement et apparaît dans la colonne **Execution** |
| Lire | Ouvrez la carte de la session | L'Agent lit le dépôt et répond ; une carte **Session Complete** résume l'exécution |
| Décider | Utilisez le commutateur de mode à côté de la zone de message | Restez en lecture seule, ou activez le mode édition pour que l'Agent puisse modifier des fichiers |
| Ajouter du contexte | Utilisez les boutons d'image, de phrases standard et d'historique | Votre prochain message embarque un contexte plus riche |

## Étape 1 : créer la session

Sélectionnez votre projet, puis cliquez sur **Create Normal Session** (l'icône de bulle de dialogue) dans la barre d'outils au-dessus du tableau.

![Panneau Create Normal Session avec un projet, un titre de session, un périmètre de tâche, une demande et le sélecteur Available Agents](../../img/quick-start/conversation-session/01-create-normal-session.png)

Renseignez le panneau :

- **Project** (obligatoire) – le projet sélectionné par défaut.
- **Session title** – facultatif ; il devient le titre de la carte sur le tableau.
- **Task scope** – facultatif. **Repos** limite la session aux dépôts d'un projet MonoSpecs, tandis que **Vault** et **Projects** joignent des documents de référence supplémentaires.
- **What do you want to do?** (obligatoire) – votre premier message. **Upload Image** joint une image.

Le panneau **Available Agents** s'ouvre à côté du tiroir. Cliquez sur un Agent et la session **démarre immédiatement**. La première carte correspond à l'Agent par défaut du runtime ; la seconde liste vous permet de choisir un autre Agent pour cette seule exécution. Vous pouvez aussi appuyer sur `Ctrl/⌘ + Enter` pour valider au clavier.

:::tip[Commencez par une question, pas par une modification]
Un premier message tel que « En deux phrases, que fait ce projet ? Ne modifie aucun fichier. » est un moyen sûr de vérifier que votre Agent et votre projet sont correctement reliés.
:::

## Étape 2 : lire le résultat

La nouvelle session apparaît sous forme de carte dans la colonne **Execution**, avec un badge d'état. Cliquez dessus pour l'ouvrir.

![Panneau de session affichant la réponse de l'Agent, le résumé Session Complete, la zone de message et la carte d'état de l'Agent](../../img/quick-start/conversation-session/02-session-detail.png)

- L'**en-tête** affiche le titre et l'Agent, avec **Archive**, **Delete Session**, **Open Code Server** et un menu **…**.
- La **conversation** liste votre message, les appels d'outils de l'Agent sous forme de lignes compactes d'un registre, puis sa réponse.
- Une carte **Session Complete** clôt chaque exécution en indiquant le nombre de tours, la durée écoulée et le coût. Cliquez dessus pour afficher les détails.
- La **carte d'état de l'Agent**, à droite de la zone de message, indique l'Agent CLI, le modèle, son état (par exemple *Idle*) et la durée écoulée.

Saisissez une question de suivi dans la zone de message. Appuyez sur `Enter` pour envoyer et sur `Shift + Enter` pour un retour à la ligne.

## Étape 3 : choisir le mode lecture seule ou édition

Le commutateur à gauche de la zone de message a deux positions. L'œil correspond au mode **lecture seule** : l'Agent peut examiner et expliquer, mais il ne modifie pas les fichiers. Le crayon correspond au **mode édition** : les nouveaux messages sont plus susceptibles de modifier des fichiers ou d'ajuster l'implémentation en cours.

![Zone de message avec le crayon (mode édition) sélectionné](../../img/quick-start/conversation-session/03-composer-edit.png)

![Zone de message avec l'œil (mode lecture seule) sélectionné](../../img/quick-start/conversation-session/04-composer-readonly.png)

Le mode s'applique à la session en cours, et vous pouvez le changer entre deux messages. Le fait que les **nouvelles** sessions normales démarrent en mode édition se règle dans **Settings → Sessions and conversation → Chat View → Default to Edit Mode for Normal Chats**. Voir [Paramètres](/fr-FR/user-guide/settings).

Le schéma le plus sûr est simple : confirmez d'abord la direction en mode lecture seule, puis passez en mode édition lorsque vous voulez réellement des modifications.

## Étape 4 : ajouter du contexte avant l'envoi

Trois boutons placés à côté du commutateur de mode ajoutent du contexte à votre prochain message :

- **Insert an image attachment** – joignez une capture d'écran, une capture d'erreur ou une référence de design. L'image apparaît au-dessus de la zone de message avec son nom de fichier et sa taille, et vous pouvez la retirer avec le **×** avant l'envoi.
- **Standard Phrases** – insère une référence `@`. Le sélecteur propose **Projects** (le chemin racine canonique d'un projet), **Vaults** (le chemin d'un vault enregistré), **Proposal Sessions** (un dossier de modification OpenSpec) et **Recent Items**.
- **Import Recent History** – réutilise l'un des messages récents de cette session pour éviter de le retaper.

![Zone de message avec une image jointe affichée au-dessus](../../img/quick-start/conversation-session/05-composer-image.png)

![Sélecteur de phrases standard ouvert depuis la zone de message, avec Projects, Vaults, Proposal Sessions et Recent Items](../../img/quick-start/conversation-session/06-standard-phrases.png)

Les images sont utiles lorsque vous voulez :

- demander à l'Agent d'expliquer une capture d'écran d'interface
- joindre une capture d'erreur ou une maquette de design et ajouter des instructions complémentaires
- donner un contexte visuel avant de passer en mode édition

## Progression typique

1. **Créez** la session depuis la barre d'outils et choisissez un Agent.
2. **Commencez en lecture seule** avec une question sur le projet.
3. **Lisez la réponse**, puis posez des questions de suivi.
4. **Activez le mode édition** uniquement lorsque des modifications directes de fichiers sont nécessaires.
5. **Ajoutez des images, des phrases standard ou de l'historique** pour donner plus de contexte au message suivant.
6. **Archivez** la session lorsque vous avez terminé ; elle est alors déplacée dans la colonne **Archived**.

Si la tâche demande désormais de la planification, de la relecture et une discipline d'archivage, poursuivez avec le guide des sessions de proposition.
