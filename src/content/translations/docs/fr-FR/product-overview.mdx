HagiCode est un espace de travail IA pour le développement de projets. Une session permet d'abord de comprendre un dépôt, puis de préciser les besoins et leur portée, de confier les modifications à l'IA et, au même endroit, de suivre l'avancement, préparer les commits et réutiliser les connaissances du projet. HagiCode relie les Agent CLI et les modèles que vous utilisez, sans vous imposer un éditeur de code particulier.

**Vous débutez ?** [Choisissez un mode d'installation](/fr-FR/installation/), terminez l'[assistant de configuration](/fr-FR/quick-start/wizard-setup), créez un projet et commencez par une [session de conversation](/fr-FR/quick-start/conversation-session). Si la tâche nécessite une planification avant sa réalisation, utilisez une [session de proposition](/fr-FR/quick-start/proposal-session).

## Le déroulement d'une tâche de développement

Prenons l'exemple d'une modification de fonctionnalité touchant plusieurs dépôts :

1. **Comprendre d'abord :** Analysez le code existant dans une [session de conversation](/fr-FR/quick-start/conversation-session). Ces sessions sont en lecture seule par défaut ; passez en mode édition lorsque vous devez modifier des fichiers.
2. **Définir la portée :** Pour un changement complexe, sélectionnez le projet et les dépôts dans une [session de proposition](/fr-FR/quick-start/proposal-session). Définissez les objectifs, les tâches et les vérifications avant de passer à l'exécution.
3. **Suivre le résultat :** Consultez les sessions et l'état d'exécution dans l'espace de travail. Pour préparer un commit, utilisez [AI Compose Commit](/fr-FR/guides/ai-compose-commit).
4. **Conserver le contexte :** Revenez sur les propositions et l'historique des commits. Pour travailler sur plusieurs dépôts, utilisez [MonoSpecs](/fr-FR/guides/monospecs) afin de gérer leurs relations et la portée des changements.

Une proposition n'est pas nécessaire pour chaque tâche : pour explorer le code ou résoudre un problème simple, commencez par une session de conversation. HagiCode offre un cheminement traçable lorsque la tâche demande davantage de contexte.

Vault regroupe des dépôts de référence, des dossiers et des notes à réutiliser plus tard ; Code Server donne accès à l'édition dans le navigateur. Aucun des deux n'est nécessaire pour commencer avec HagiCode. Pour comprendre leur conception, consultez [la base de connaissances Vault](/fr-FR/blog/2026-04-10-vault-system-ai-knowledge-base/) et [l'intégration de l'édition dans le navigateur](/fr-FR/blog/2026-04-13-vscode-web-integration-browser-editing/).

HagiCode propose également des retours sous forme de héros, de succès, de rapports quotidiens et de métriques Token, pour mieux voir l'état et la progression du travail au fil du temps. Ils font partie de l'expérience de l'espace de travail, mais ne sont pas nécessaires pour l'utiliser comme un outil de développement classique. Consultez [l'article sur la conception de la ludification](/fr-FR/blog/2026-03-16-gamifying-ai-coding/).

## Éditions et tarifs

**Desktop, Container et Microsoft Store sont des modes d'obtention ou de déploiement distincts, pas trois offres payantes.** Les fonctions de base sont gratuites. Dans le canal Microsoft Store, Turbo Engine est une licence distincte, achetée une seule fois, qui débloque une limite plus élevée de propositions simultanées ainsi que des améliorations telles que les thèmes de documentation, l'attribution personnalisée, l'identité visuelle et les avatars. Consultez le [module complémentaire Turbo Engine](/fr-FR/dlc/turbo-engine-dlc/) pour connaître les fonctions débloquées.

| Votre environnement | Option conseillée |
| --- | --- |
| Windows avec accès au Microsoft Store | [Installer depuis le Microsoft Store](/fr-FR/installation/windows-store) |
| Installation manuelle sous Windows ou utilisation locale sur macOS ou Linux | [Installer Desktop](/fr-FR/installation/desktop) |
| Serveur, NAS ou déploiement en équipe | [Installer avec Docker Compose](/fr-FR/installation/docker-compose) |

L'application principale sur Steam a été retirée et ne constitue plus un canal d'installation. Voir [l'état de la distribution sur Steam](/fr-FR/faq/steam-distribution-status/).

## Pourquoi en faire un espace de travail ?

Je suis Kun Yu, le créateur de HagiCode. Une question et sa réponse peuvent résoudre un problème immédiat, mais le développement exige aussi de comprendre le projet, de définir des limites, de mener les changements à bien et d'en examiner le résultat. J'ai voulu réunir ces étapes auparavant dispersées ; les retours ludiques aident à voir la progression du travail de longue durée. Vous pouvez n'utiliser qu'une partie des fonctionnalités, sans devoir apprendre tous les modules avant de coder.
