HagiCode évite que l'IA perde le contexte lorsqu'elle modifie votre code : **comprendre d'abord le dépôt, définir la portée, puis exécuter en laissant une trace vérifiable.** C'est un espace de travail IA pour le développement de projets, qui relie les Agent CLI et les modèles que vous utilisez déjà, sans que vous ayez à changer d'éditeur. Des interactions d’interface riches et pratiques rendent la planification, l’exécution des agents et le travail sur les projets accessibles et faciles à suivre, pour une expérience de développement engageante.

Une proposition n'est pas nécessaire pour chaque tâche. Commencez par une session de conversation lorsque vous voulez seulement explorer le code ou résoudre un problème simple. HagiCode offre un cheminement traçable lorsque la tâche demande davantage de contexte.

## Les fonctionnalités en détail

### Comprendre avant d’agir

HagiCode sépare « lire le code » de « modifier le code », afin que vous choisissiez selon l'ampleur de la tâche plutôt que de laisser l'IA tout modifier directement.

- **Session de conversation :** en lecture seule par défaut. Utilisez-la pour explorer un dépôt, examiner un problème ou demander où se trouve une logique donnée. Passez en mode édition uniquement lorsque vous devez modifier des fichiers.
- **Session de proposition :** pour les changements complexes. Choisissez le projet et la portée des dépôts, définissez les objectifs, les tâches et les vérifications, puis passez à l'exécution une fois le plan validé.
- **Tableau des sessions :** les colonnes Proposal & Review, Execution et Archived (proposition et revue, exécution, archivées) montrent d'un coup d'œil où en est chaque session. Vous pouvez alterner entre les dispositions Classic, Execution Flow Kanban et Dashboard Kanban.

Pour en savoir plus : [Créer une session de conversation](/fr-FR/quick-start/conversation-session) · [Créer une session de proposition](/fr-FR/quick-start/proposal-session) · [Le tableau des sessions](/fr-FR/user-guide/sessions)

### Une portée unique pour plusieurs dépôts

Lorsqu'une demande touche à la fois le frontend, le backend et la documentation, MonoSpecs permet à HagiCode de les comprendre comme un seul projet.

- Déclarez les emplacements des sous-dépôts, leurs URL Git et leurs noms d'affichage dans `.hagicode/monospecs.yaml`.
- Les spécifications de changement (OpenSpec) résident dans le dépôt principal, de sorte que les répertoires de code des sous-dépôts restent propres.
- Lorsque vous créez une proposition, choisissez les sous-dépôts concernés. La page du projet affiche la branche et les modifications non validées de chaque dépôt.

![Page de projet MonoSpecs affichant la branche et l'état des changements de 11 dépôts, avec les actions VS Code, Git et AI Compose Commit](../img/screenshots/monospecs/hover-project-show-repository-status/original.png)

Pour en savoir plus : [Guide MonoSpecs](/fr-FR/guides/monospecs)

### Conserver votre Agent CLI

HagiCode ne remplace pas votre chaîne d'outils. Il la réunit dans un seul espace de travail.

- **Un Agent se compose d'un CLI, d'un modèle et d'un texte de personnalité facultatif.** Créez plusieurs Agents, affectez-les à des scénarios d'exécution et configurez des groupes de secours.
- Prend en charge 11 Agent CLI, dont Claude Code, Codex et GitHub Copilot. L'espace de travail affiche la version, le temps de réponse et l'état de santé de chaque CLI.
- Avec [OmniRoute](/fr-FR/related-software-installation/omniroute/), vous pouvez relier plusieurs outils et modèles compatibles OpenAI à une passerelle locale unique, tandis que les connexions des CLI et celles des modèles restent gérées séparément.

Pour en savoir plus : [Espace de travail des Agents](/fr-FR/user-guide/agents) · [Installation et prise en charge des AI Agent CLI](/fr-FR/related-software-installation/ai-agent-cli/)

### Skills

Le panneau Skills regroupe derrière une seule entrée les Skills déjà présents sur votre machine et ceux que vous pouvez installer depuis la galerie.

- **Local Skills :** consultez ce qui est installé sur cette machine et recherchez les mises à jour par lot.
- **Gallery :** recherchez par mot-clé et par source, et voyez si un Skill est déjà installé.
- **Trusted Providers :** avant d'installer, confirmez la source, son statut de confiance et la commande qui sera réellement exécutée, puis décidez quelles sources sont considérées comme de confiance.

![Galerie de Skills avec un champ de recherche, des filtres de source et un tableau des Skills, de leurs sources et de leur nombre d'installations](../img/screenshots/shared/skills-gallary/original.png)

Pour en savoir plus : [Guide Skills](/fr-FR/guides/skills)

### Vault et Code Server

- Un **Vault** est un dossier situé en dehors de vos dépôts de projet que HagiCode peut parcourir. Utilisez-le pour des documents de référence, des notes et des résultats de recherche. Trois types sont pris en charge : Folder, CodeRef et Obsidian.
- Lorsque vous créez une session, choisissez les Vaults à inclure dans sa portée. Marquez-en un comme modifiable pour que l'IA puisse y écrire ; sinon il reste une référence en lecture seule.
- **Code Server** offre un point d'entrée d'édition dans le navigateur, que vous pouvez ouvrir directement depuis un Vault ou un projet.

![Espace de travail Vault avec les cartes des Vaults enregistrés, les Vaults système et les boutons Open Code Server](../img/screenshots/shared/vault-view/original.png)

Pour en savoir plus : [Guide Vault](/fr-FR/user-guide/vault)

### AI Compose Commit

Cliquez sur « AI Compose Commit » dans l'onglet Git : HagiCode lit vos changements en cours et rédige des messages de commit au format Conventional Commits.

- Les changements liés sont regroupés en plusieurs commits plutôt qu'en un seul commit fourre-tout.
- Dans les projets MonoSpecs, les changements sont validés dans le bon sous-dépôt.
- Une mention Co-Authored-By est ajoutée automatiquement ; son nom et son adresse e-mail peuvent être définis par projet ou globalement.

![Le bouton AI Compose Commit dans l'onglet Git](../img/screenshots/ai-compose-commit/trigger-ai-compose-commit-button/original.png)

Pour en savoir plus : [Guide AI Compose Commit](/fr-FR/guides/ai-compose-commit)

## À qui il s'adresse

- **Un bon choix :** les développeurs et les équipes qui maintiennent plusieurs dépôts et veulent planifier les changements complexes avant de les exécuter, ainsi que les personnes qui utilisent déjà des Agent CLI comme Claude Code ou Codex et souhaitent les réunir dans un seul espace de travail.
- **Pas indispensable :** si vous avez seulement besoin de compléter quelques lignes dans votre éditeur, vos outils actuels suffisent.

## Éditions et tarifs

Les fonctions de base sont gratuites. Desktop et Microsoft Store sont deux modes distincts d'obtention de HagiCode, pas deux offres payantes. Le canal Microsoft Store propose aussi Turbo Engine, un achat unique distinct qui débloque une limite plus élevée de propositions simultanées ainsi que des améliorations telles que les thèmes de documentation, l'attribution personnalisée, l'identité visuelle et le téléchargement d'avatars personnalisés. Consultez le [module complémentaire Turbo Engine](/fr-FR/dlc/turbo-engine-dlc/) pour connaître les fonctions précises qu'il débloque.

| Votre environnement | Option conseillée |
| --- | --- |
| Windows avec accès au Microsoft Store | [Installer depuis le Microsoft Store](/fr-FR/installation/windows-store) |
| Installation manuelle sous Windows ou utilisation locale sur macOS ou Linux | [Installer Desktop](/fr-FR/installation/desktop) |

L'application principale sur Steam a été retirée et ne constitue plus un canal d'installation. Voir [l'état de la distribution sur Steam](/fr-FR/faq/steam-distribution-status/).

## Pourquoi en faire un espace de travail ?

Je suis Kun Yu, le créateur de HagiCode. Une question et sa réponse peuvent résoudre un problème immédiat, mais le développement réel exige aussi de comprendre le projet, de définir des limites, de mener les changements à bien et d'en examiner le résultat. J'ai voulu réunir ces étapes dispersées ; les retours ludiques rendent la progression plus visible dans un travail de longue durée. Vous pouvez n'utiliser qu'une partie de ces fonctionnalités. Vous n'avez pas à apprendre tous les modules avant de commencer à coder.
