HagiCode évite que l'IA perde le contexte lorsqu'elle modifie votre code : **comprendre d'abord le dépôt, définir la portée, puis exécuter en laissant une trace vérifiable.** C'est un espace de travail IA pour le développement de projets, qui relie les Agent CLI et les modèles que vous utilisez déjà, sans que vous ayez à changer d'éditeur.

**[Installer HagiCode](/fr-FR/installation/)** · [Regarder la vidéo de démonstration](#product-video-showcase-en)

Prend en charge 11 Agent CLI (Claude Code, Codex, GitHub Copilot, et d'autres) · Fonctionne sous Windows, macOS et Linux · Les fonctions de base sont gratuites

## Le déroulement d'une tâche de développement

Prenons l'exemple d'une modification de fonctionnalité touchant plusieurs dépôts :

1. **Comprendre d'abord :** Analysez le code existant dans une [session de conversation](/fr-FR/quick-start/conversation-session). Ces sessions sont en lecture seule par défaut ; passez en mode édition lorsque vous devez modifier des fichiers.
2. **Définir la portée :** Pour un changement complexe, sélectionnez le projet et les dépôts dans une [session de proposition](/fr-FR/quick-start/proposal-session). Définissez les objectifs, les tâches et les vérifications avant de passer à l'exécution.

   ![Tiroir de nouvelle proposition affichant la sélection des dépôts et un aperçu de la proposition](../img/screenshots/shared/create-proposal-drawser/original.png)

3. **Suivre le résultat :** Consultez les sessions et l'état d'exécution dans l'espace de travail. Pour préparer un commit, utilisez [AI Compose Commit](/fr-FR/guides/ai-compose-commit).

   ![Détail d'une session après l'exécution complète d'un flux de proposition](../img/screenshots/shared/classic-proposal-view/original.png)

4. **Conserver le contexte :** Revenez sur les propositions et l'historique des commits. Pour travailler sur plusieurs dépôts, utilisez [MonoSpecs](/fr-FR/guides/monospecs) afin de gérer leurs relations et la portée des changements.

Une proposition n'est pas nécessaire pour chaque tâche. Commencez par une session de conversation lorsque vous voulez seulement explorer le code ou résoudre un problème simple. HagiCode offre un cheminement traçable lorsque la tâche demande davantage de contexte.

## À qui il s'adresse

- **Un bon choix :** les développeurs et les équipes qui maintiennent plusieurs dépôts et veulent planifier les changements complexes avant de les exécuter, ainsi que les personnes qui utilisent déjà des Agent CLI comme Claude Code ou Codex et souhaitent les réunir dans un seul espace de travail.
- **Pas indispensable :** si vous avez seulement besoin de compléter quelques lignes dans votre éditeur, vos outils actuels suffisent.

## Rendre visible la progression à long terme

HagiCode transforme les héros, les succès, les rapports quotidiens et les métriques Token en retours visuels, afin que l'état et la progression soient plus faciles à suivre dans la durée, ce qui le distingue des outils de programmation IA ordinaires. Dans la [présentation de l'Adventure Team](/fr-FR/adventure-team-introduction), vous voyez comment les héros sont regroupés et comment les donjons avancent ; pour la réflexion de conception, consultez [l'article sur la conception de la ludification](/fr-FR/blog/2026-03-16-gamifying-ai-coding/). Cela fait partie de l'expérience de l'espace de travail, et vous pouvez tout à fait utiliser HagiCode comme un outil de développement classique sans cela.

## Éditions et tarifs

Les fonctions de base sont gratuites. Desktop, Container et Microsoft Store sont trois modes distincts d'obtention ou de déploiement de HagiCode, pas trois offres payantes. Le canal Microsoft Store propose aussi Turbo Engine, un achat unique distinct qui débloque une limite plus élevée de propositions simultanées ainsi que des améliorations telles que les thèmes de documentation, l'attribution personnalisée, l'identité visuelle et les avatars. Consultez le [module complémentaire Turbo Engine](/fr-FR/dlc/turbo-engine-dlc/) pour connaître les fonctions précises qu'il débloque.

| Votre environnement | Option conseillée |
| --- | --- |
| Windows avec accès au Microsoft Store | [Installer depuis le Microsoft Store](/fr-FR/installation/windows-store) |
| Installation manuelle sous Windows ou utilisation locale sur macOS ou Linux | [Installer Desktop](/fr-FR/installation/desktop) |
| Serveur, NAS ou déploiement en équipe | [Installer avec Docker Compose](/fr-FR/installation/docker-compose) |

L'application principale sur Steam a été retirée et ne constitue plus un canal d'installation. Voir [l'état de la distribution sur Steam](/fr-FR/faq/steam-distribution-status/).

## Pourquoi en faire un espace de travail ?

Je suis Kun Yu, le créateur de HagiCode. Une question et sa réponse peuvent résoudre un problème immédiat, mais le développement réel exige aussi de comprendre le projet, de définir des limites, de mener les changements à bien et d'en examiner le résultat. J'ai voulu réunir ces étapes dispersées ; les retours ludiques rendent la progression plus visible dans un travail de longue durée. Vous pouvez n'utiliser qu'une partie de ces fonctionnalités. Vous n'avez pas à apprendre tous les modules avant de commencer à coder.
