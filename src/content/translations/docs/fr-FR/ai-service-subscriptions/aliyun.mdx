## Positionnement du service

Alibaba Cloud DashScope est l'un des points d'abonnement Claude Code recommandés dans le preset actuel de la documentation. Il convient aux équipes qui travaillent déjà dans l'écosystème Alibaba Cloud et souhaitent regrouper l'abonnement, la console et la gestion des clés au sein de la plateforme cloud.

## Pour qui

- Ceux qui utilisent déjà la console ou les ressources d'Alibaba Cloud
- Ceux qui souhaitent gérer les services et les clés API depuis une plateforme cloud unifiée
- Ceux qui veulent intégrer rapidement Claude Code grâce à un mappage de modèle fixe

## Points à examiner en premier

- Le preset actuel marque Alibaba Cloud DashScope comme fournisseur recommandé.
- Il utilise `glm-4.7` comme modèle de mappage par défaut, avec un chemin de configuration clair.
- Si l'équipe dispose déjà d'un système de comptes Alibaba Cloud, le raccordement et la gestion des autorisations seront plus fluides.

## Conseils de configuration

1. Confirmez d'abord le forfait ou le mode d'activation de clé API que vous souhaitez utiliser.
2. Ouvrez ensuite l'entrée Claude Code de la page unifiée AI Agent CLI, puis poursuivez vers la documentation officielle d'installation et de référence d'Anthropic.
3. Une fois cela fait, vous pouvez exécuter `claude --version` en local, vérifier le fichier de configuration ou envoyer une vraie requête pour confirmer que le raccordement fonctionne.
