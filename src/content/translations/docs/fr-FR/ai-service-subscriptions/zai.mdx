## Positionnement du service

Zhipu AI est l'un des points d'abonnement Claude Code recommandés dans le preset actuel de la documentation. Le forfait GLM Coding et le mappage multi-modèles conviennent aux développeurs qui font de Claude Code leur outil principal au quotidien.

## Pour qui

- Ceux qui souhaitent un forfait conçu spécifiquement pour la programmation
- Ceux qui ont besoin d'un mappage assez complet des niveaux de modèles Claude
- Ceux qui veulent couvrir plusieurs outils, comme Claude Code et Cline, avec un seul service

## Points à examiner en premier

- Le preset actuel marque Zhipu AI comme fournisseur recommandé.
- Il propose une interface compatible Anthropic, ce qui facilite le raccordement direct à Claude Code.
- Le preset inclut des mappages de modèles par défaut tels que `glm-4.7`, `glm-5` et `glm-4.5-air`.

## Informations de raccordement essentielles

| Élément | Contenu |
|------|------|
| Point d'abonnement | [Accéder à la page d'abonnement](https://www.bigmodel.cn/claude-code?ic=14BY54APZA) |

| URL de base compatible Anthropic | `https://open.bigmodel.cn/api/anthropic` |
| Variable d'environnement d'authentification recommandée | `ANTHROPIC_AUTH_TOKEN` |

## Mappage de modèles par défaut

| Niveau Claude | Modèle par défaut |
|-------------|----------|
| Sonnet | `glm-4.7` |
| Opus | `glm-5` |
| Haiku | `glm-4.5-air` |

:::tip
Les forfaits, les promotions et les avantages évoluent avec le temps ; si vous êtes surtout attentif aux prix en temps réel, consultez directement la page d'abonnement du fournisseur.
:::

## Conseils de configuration

1. Confirmez d'abord le forfait ou le mode d'activation de clé API que vous souhaitez utiliser.
2. Ouvrez ensuite l'entrée Claude Code de la page unifiée AI Agent CLI, puis poursuivez vers la documentation officielle d'installation et de référence d'Anthropic.
3. Une fois cela fait, vous pouvez exécuter `claude --version` en local, vérifier le fichier de configuration ou envoyer une vraie requête pour confirmer que le raccordement fonctionne.
