## Présentation

### Qu'est-ce que la saisie vocale Doubao

La saisie vocale Doubao est la fonction de reconnaissance vocale intégrée à HagiCode ; elle repose sur un service de la plateforme ouverte Doubao de ByteDance. Vous parlez, et le système convertit la voix en texte. Le produit s'appuie aussi sur le contexte du projet en cours pour aider à reconnaître le vocabulaire du domaine et les termes techniques.

### Principaux scénarios d'utilisation

Dans HagiCode, les scénarios suivants se prêtent particulièrement bien à la saisie vocale :

- **Saisie rapide de propositions** : sans taper au clavier, dictez simplement pour créer et soumettre rapidement des propositions, ce qui améliore considérablement l'efficacité
- **Rédaction d'annotations** : lors d'une revue de code ou de documentation, ajoutez rapidement des annotations et des retours à la voix
- **Réponse aux messages** : dans les conversations et les discussions, répondez rapidement aux messages à la voix : la saisie au clavier n'est plus une contrainte
- **Rédaction de contenus longs** : générez rapidement de longs contenus, comme de la documentation de projet, des explications techniques ou des comptes rendus de réunion

### Les avantages concrets

- **Intégration approfondie et prise en compte du contexte** : HagiCode intègre en profondeur la reconnaissance vocale Doubao et exploite automatiquement le contexte du projet en cours (structure du code, pile technique, terminologie du domaine) pour reconnaître avec précision le vocabulaire du domaine, ce qui améliore nettement la précision de reconnaissance des termes techniques
- **Durée d'essai gratuite** : la plateforme Doubao offre 20 heures de reconnaissance gratuite, pour découvrir la saisie vocale sans aucun obstacle
- **Très grande rapidité** : la reconnaissance se fait en temps réel, et le texte s'affiche pendant que vous parlez, sans attente
- **Précision élevée** : grâce aux modèles avancés de reconnaissance vocale de Doubao, associés au contexte du projet, les résultats sont précis et fiables
- **Intégration transparente** : la fonction est directement intégrée à la zone de saisie des messages de HagiCode, sans changer d'application
- **Simplicité d'utilisation** : il suffit de cliquer sur le microphone pour commencer, de façon simple et intuitive

## Démarrage rapide

### Prérequis

Avant d'utiliser la saisie vocale Doubao, vous devez :

1. **Obtenir un compte sur la plateforme ouverte Doubao**
   - Accédez à la [console de reconnaissance vocale Doubao](https://console.volcengine.com/speech/service/10038)
   - Créez un compte ou connectez-vous

2. **Créer une application et obtenir les identifiants**
   - Créez une application de reconnaissance vocale sur la plateforme
   - Obtenez l'`APP ID` et l'`Access Token`

3. **Vérifier la connexion réseau**
   - Le service de reconnaissance vocale nécessite une connexion réseau
   - Assurez-vous que votre appareil peut accéder au service API de Doubao

### Déroulement de base

Voici les étapes de base pour utiliser la saisie vocale Doubao :

1. Obtenir l'`APP ID` et l'`Access Token`
2. Configurer la reconnaissance vocale dans le produit
3. Tester la clé API
4. Trouver la zone de saisie vocale
5. Cliquer sur le bouton du microphone
6. Autoriser l'accès au microphone
7. Commencer l'enregistrement
8. Consulter les résultats de reconnaissance en temps réel
9. Cliquer pour arrêter l'enregistrement
10. Terminer l'insertion du texte

## Exigences techniques

### Environnement HTTP

La saisie vocale Doubao doit fonctionner dans un environnement HTTP/HTTPS.

| Environnement | Prise en charge | Description |
|------|----------|------|
| **localhost** | ✓ | Environnement de développement local (http://localhost ou http://127.0.0.1) |
| **Serveur distant en HTTPS** | ✓ | Application web déployée sur Internet et utilisant HTTPS |
| **Serveur distant en HTTP** | ✗ | Application web déployée sur Internet mais utilisant HTTP |
| **Protocole file://** | ✗ | L'ouverture directe d'un fichier HTML n'est pas prise en charge |

:::caution
La saisie vocale Doubao présente les limites suivantes :
1. **Le HTTPS est obligatoire pour un déploiement sur Internet** : en raison des restrictions de sécurité des navigateurs, l'accès depuis Internet doit passer par le protocole HTTPS pour obtenir l'autorisation d'utiliser le microphone
2. **Aucune limite pour les adresses locales** : avec `localhost` ou `127.0.0.1`, HTTP comme HTTPS sont pris en charge
3. **Le protocole file:// n'est pas pris en charge** : dans un environnement `file://`, le microphone et la connexion WebSocket sont inutilisables
:::

### Version Desktop

La version Desktop de HagiCode intègre un environnement HTTP et prend entièrement en charge la saisie vocale. Vous pouvez utiliser directement la reconnaissance vocale, sans configuration supplémentaire.

### Mode Host

Le mode Host local prend en charge la saisie vocale :
- Avec `localhost` ou `127.0.0.1`, HTTP comme HTTPS sont pris en charge
- Pour un déploiement sur Internet, le HTTPS est obligatoire

## Étapes de configuration

### Obtenir l'APP ID

1. Accédez à la [console de reconnaissance vocale Doubao](https://console.volcengine.com/speech/service/10038)
2. Connectez-vous ou créez un compte
3. Accédez à la console et créez une nouvelle application de reconnaissance vocale
4. Sur la page de détails de l'application, repérez et copiez l'`APP ID`

### Obtenir l'Access Token

1. Dans la console de la plateforme ouverte Doubao
2. Accédez à votre application de reconnaissance vocale
3. Repérez la zone de gestion des clés API
4. Générez ou copiez l'`Access Token`

:::note
Conservez soigneusement votre `Access Token` et ne le divulguez à personne. Pour le remplacer, vous pouvez le régénérer sur la plateforme ouverte Doubao.
:::

### Configurer dans le produit

1. Ouvrez l'application HagiCode
2. Accédez à **Paramètres** → **Paramètres de reconnaissance vocale**
3. Dans le formulaire de configuration, renseignez les informations suivantes :
   - **Provider** : choisissez `doubao` (Doubao)
   - **APP ID** : collez l'APP ID obtenu sur la plateforme Doubao
   - **Access Token** : collez l'Access Token obtenu sur la plateforme Doubao
4. (Facultatif) Ajustez les autres paramètres de configuration selon vos besoins
5. Cliquez sur le bouton **Tester la clé API** pour valider la configuration
6. Une fois la configuration validée, elle est automatiquement enregistrée localement dans le navigateur

### Tester la clé API

Une fois la configuration terminée, il est recommandé de tester la validité de la clé API :

1. Cliquez sur le bouton **Tester la clé API**
2. Le système appelle une interface de test pour valider votre configuration
3. Si la configuration est correcte, un message de réussite s'affiche
4. Si la configuration est erronée, un message d'erreur s'affiche ; vérifiez les points suivants :
   - L'APP ID et l'Access Token sont-ils corrects
   - La connexion réseau est-elle normale
   - L'Access Token est-il expiré

:::tip
Si le test échoue, vérifiez d'abord que la connexion réseau est normale, puis assurez-vous que la clé API de la plateforme ouverte Doubao est valide et n'a pas expiré.
:::

## Utilisation

### Trouver l'emplacement de la saisie vocale

Dans HagiCode, tous les champs de saisie de texte accompagnés d'une icône de microphone prennent en charge la saisie vocale. Ces composants sont généralement appelés `VoiceTextArea`.

Parmi les emplacements courants de saisie vocale :
- La zone de saisie des messages
- Les zones d'édition de texte
- Les différents champs de formulaire qui nécessitent une saisie de texte

### Démarrer la reconnaissance vocale

1. Repérez le champ de saisie accompagné d'une icône de microphone
2. Cliquez sur le bouton du microphone
3. Le navigateur demande l'autorisation d'utiliser le microphone
4. Cliquez sur **Autoriser** pour accorder l'accès au microphone

:::note
Si vous avez déjà accordé l'autorisation d'accès au microphone, le navigateur peut ne pas la redemander. Pour vérifier ou modifier les autorisations, utilisez l'icône en forme de cadenas à gauche de la barre d'adresse du navigateur.
:::

### État de l'enregistrement

Une fois l'autorisation accordée, la reconnaissance vocale démarre automatiquement, et vous voyez :

- **Animation de forme d'onde** : une onde sonore animée s'affiche dans le bouton du microphone pour indiquer que l'enregistrement est en cours
- **Affichage de la durée** : la durée d'enregistrement en cours s'affiche sous le bouton
- **Reconnaissance en temps réel** : le texte reconnu s'affiche provisoirement à l'emplacement du curseur

### Affichage des résultats de reconnaissance en temps réel

Pendant l'enregistrement, le moteur de reconnaissance vocale convertit votre voix en texte en temps réel :

- Le texte reconnu s'affiche provisoirement en gris dans le champ de saisie
- Les résultats de reconnaissance sont mis à jour en continu au fil de votre parole
- Le mandarin est pris en charge, avec une précision de reconnaissance élevée

:::tip
Pour obtenir un meilleur résultat de reconnaissance, nous vous recommandons de :
- Utiliser la saisie vocale dans un environnement calme
- Parler distinctement, à un débit modéré
- Éviter les perturbations dues au bruit de fond
:::

### Arrêter la reconnaissance

Pour arrêter la reconnaissance vocale, vous pouvez :

1. **Cliquer sur le bouton du microphone** : un nouveau clic sur le bouton arrête l'enregistrement
2. **Cliquer dans le champ de saisie** : cliquer sur une autre zone du champ de saisie arrête aussi l'enregistrement

Après l'arrêt, le texte final reconnu est officiellement inséré dans le champ de saisie, et vous pouvez continuer à le modifier ou l'envoyer.
