## Ce que contiendra cette section

La section FAQ rassemble les contenus suivants :

- Les précisions particulières sur le démarrage et l'exécution
- Les conseils d'utilisation issus d'Index qui méritent de devenir des articles durables
- Les avertissements de compatibilité liés à la plateforme, au canal de distribution, au mode de paquetage ou au runtime intégré
- Les points d'entrée de dépannage courants qui méritent une page d'explication autonome

Si vous souhaitez parcourir de façon systématique les recommandations d'utilisation quotidienne de HagiCode, lisez [Conseils d'utilisation de HagiCode](/fr-FR/faq/tips). Si vous voulez savoir quel Node externe Desktop utilise, où sont installés les Agent CLI, ou que faire lorsque Node est introuvable, lisez [Comment Desktop utilise votre environnement Node](/fr-FR/faq/desktop-node-environment). Si vous voulez comprendre la relation entre chaque Agent CLI et HagiCode, et pourquoi nous recommandons de les associer, lisez [Claude Vs HagiCode](/fr-FR/faq/claude-vs-hagicode), [Copilot Vs HagiCode](/fr-FR/faq/copilot-vs-hagicode), [Codex Vs HagiCode](/fr-FR/faq/codex-vs-hagicode), [Gemini Vs HagiCode](/fr-FR/faq/gemini-vs-hagicode), [OpenCode Vs HagiCode](/fr-FR/faq/opencode-vs-hagicode), [Hermes Vs HagiCode](/fr-FR/faq/hermes-vs-hagicode), [DeepAgents Vs HagiCode](/fr-FR/faq/deepagents-vs-hagicode), [Kimi Vs HagiCode](/fr-FR/faq/kimi-vs-hagicode), [CodeBuddy Vs HagiCode](/fr-FR/faq/codebuddy-vs-hagicode), [QoderCLI Vs HagiCode](/fr-FR/faq/qoder-vs-hagicode) ainsi que [Kiro Vs HagiCode](/fr-FR/faq/kiro-vs-hagicode). Si vous voulez savoir pourquoi HagiCode n'est pas disponible sur Steam, lisez [Pourquoi HagiCode n'est pas disponible sur Steam](/fr-FR/faq/steam-distribution-status).
