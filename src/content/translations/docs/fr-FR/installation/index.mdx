HagiCode propose trois méthodes d'installation. Choisissez d'abord un chemin selon votre cas d'usage, vérifiez ensuite les prérequis de ce chemin, puis ouvrez la page d'installation correspondante.

## Choisir une méthode d'installation

| Votre situation | Méthode recommandée |
| --- | --- |
| Utilisation personnelle en local sous Windows | [Installation via Microsoft Store](/fr-FR/installation/windows-store) |
| Utilisation personnelle en local sous macOS / Linux, ou Windows sans accès au Store | [Installation de bureau](/fr-FR/installation/desktop) |
| Serveur, NAS, partage en équipe, ou besoin d'isolation de l'environnement | [Installation avec Docker Compose](/fr-FR/installation/docker-compose) |

## Préparation avant l'installation

Les prérequis diffèrent selon le chemin choisi :

| Méthode d'installation | Node.js | Git |
| --- | --- | --- |
| Microsoft Store / Desktop | À installer vous-même, **version 24 ou supérieure** | À installer vous-même |
| Docker Compose | Inutile sur l'hôte | Inutile sur l'hôte |

:::caution[Desktop n'embarque plus Node.js]
Desktop n'embarque que le runtime .NET nécessaire à l'exécution de HagiCode Server et **ne fournit plus Node.js**. Il recherche `node` et `npm` dans le `PATH` du système et installe les paquets gérés, tels que les Agent CLI, dans le répertoire global de votre npm local. Installez Node.js 24 ou supérieur avant le premier lancement de Desktop ; voir [Installer Node.js](/fr-FR/related-software-installation/nodejs/installation).
:::

### Installer Git

Desktop détecte `node`, `npm` et `git` au démarrage, et le « Projet de démonstration » de la boîte de dialogue « Nouveau projet » de l'interface principale a aussi besoin de Git pour cloner le dépôt d'exemple officiel. Choisissez une méthode d'installation selon votre système :

- **Windows** : exécutez `winget install --id Git.Git -e`, ou téléchargez le programme d'installation depuis [git-scm.com](https://git-scm.com/downloads).
- **macOS** : exécutez `xcode-select --install`, ou utilisez Homebrew avec `brew install git`.
- **Debian / Ubuntu** : exécutez `sudo apt-get install -y git`.
- **Fedora** : exécutez `sudo dnf install -y git`.

Une fois l'installation terminée, rouvrez le terminal et vérifiez que les commandes sont disponibles :

```bash
node --version
npm --version
git --version
```

:::tip[Installez d'abord, lancez Desktop ensuite]
Desktop lit le `PATH` du système au démarrage. Si vous installez Node.js ou Git alors que Desktop est déjà ouvert, quittez complètement Desktop puis relancez-le.
:::

### Agent CLI

HagiCode fonctionne avec un Agent CLI installé localement et déjà connecté. L'assistant d'initialisation ne liste que les CLI détectés sur la machine ; installez donc au moins un CLI et connectez-vous avant d'ouvrir l'assistant. Les CLI pris en charge, leurs modes d'installation et leurs points d'entrée officiels sont maintenus au même endroit, dans [Installation de la CLI de l'agent IA](/fr-FR/related-software-installation/ai-agent-cli/).

## Étapes suivantes

1. Choisissez une méthode d'installation dans le tableau ci-dessus et remplissez d'abord les prérequis.
2. Terminez l'installation et le premier lancement, puis suivez l'[Assistant de configuration](/fr-FR/quick-start/wizard-setup) pour créer le Hagicoder par défaut et votre premier projet.
3. Pour découvrir le flux de proposition OpenSpec, lisez [Introduction à OpenSpec](/fr-FR/related-software-installation/openspec/intro-openspec) et [Créer une session de proposition](/fr-FR/quick-start/proposal-session).
