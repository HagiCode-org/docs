Pour les utilisateurs Windows, Microsoft Store est actuellement le point d’entrée public du client desktop. Cette page couvre uniquement ce chemin Store. Pour le guide général de téléchargement desktop, de gestion des versions et de dépannage, continuez avec [Installation de bureau](/fr-FR/installation/desktop).

L’entrée principale Steam a déjà été retirée. Microsoft Store est donc désormais le canal principal côté Windows. Pour le contexte, consultez [Pourquoi HagiCode n’est pas disponible sur Steam](/fr-FR/faq/steam-distribution-status/).

:::tip[Ce chemin convient bien si]
- vous utilisez Windows 10 ou Windows 11 et souhaitez installer directement depuis le store système
- vous préférez recevoir le paquet applicatif via le Store plutôt que manipuler des fichiers d’installation manuellement
:::

## Avant de commencer

- votre appareil doit pouvoir ouvrir la [page Microsoft Store de HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW)
- un accès réseau doit être disponible au premier lancement, car l’application peut encore devoir télécharger ou préparer les composants nécessaires à Hagicode Server
- selon l’appareil, la région ou la politique d’organisation, une connexion avec un compte Microsoft peut être demandée
- si le Store est bloqué sur votre machine, basculez vers [Installation de bureau](/fr-FR/installation/desktop)

## Préparation avant l'installation

La version Store fonctionne comme Desktop : elle **n’embarque pas Node.js**, que vous devez installer vous-même et rendre accessible dans le `PATH` du système. Préparez les éléments suivants avant le premier lancement :

- **Node.js 24 ou supérieur** (fournit aussi `npm`), voir [Installer Node.js](/fr-FR/related-software-installation/nodejs/installation)
- **Git**, voir [Installer Git](/fr-FR/installation/#installer-git)
- au moins un **Agent CLI** installé et connecté, voir [Installation de la CLI de l’agent IA](/fr-FR/related-software-installation/ai-agent-cli/)

Si vous les installez alors que HagiCode est déjà ouvert, quittez complètement HagiCode puis relancez-le afin qu’il lise le nouveau `PATH`.

## Installer depuis Microsoft Store

1. Ouvrez [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW).
2. Cliquez sur `Obtenir`, `Installer`, ou l’action équivalente affichée par le Store.
3. Attendez que Microsoft Store termine le téléchargement et l’installation.
4. Lancez ensuite HagiCode depuis le menu Démarrer ou directement depuis la page Store.

## Ce qui se passe au premier lancement

Après l’installation, HagiCode continue quand même le flux standard d’initialisation Desktop.

- le premier lancement affiche d’abord le guide « Configuration initiale » de Desktop : choisir la langue, confirmer les documents juridiques et, si nécessaire, télécharger Hagicode Server ; il peut donc sembler plus lent qu’une application ordinaire
- le canal Microsoft Store / MSIX verrouille le réglage « Chemin de stockage des données du runtime », ce qui est le comportement attendu pour ce mode de distribution
- l’application ne se met pas à jour seule de manière indépendante ; la livraison du paquet dépend du canal d’installation, et la distribution Store passe par le canal Microsoft Store

Pour poursuivre avec l’assistant d’initialisation, consultez [Assistant de configuration](/fr-FR/quick-start/wizard-setup).

## Quand choisir un autre canal

- vous ne pouvez pas accéder à Microsoft Store, ou votre organisation interdit les installations via le Store
- vous devez télécharger manuellement des fichiers `.exe` ou `.msix` et contrôler vous-même la source de l’installeur

## Dépannage

### La page Microsoft Store ne s’ouvre pas

Vérifiez d’abord le réseau, les paramètres de région et l’état de connexion à Microsoft Store. Si le lien navigateur s’ouvre mais que le client Store reste indisponible, la cause est souvent une politique système locale. Dans ce cas, utilisez [Installation de bureau](/fr-FR/installation/desktop).

### Certains réglages sont verrouillés

Les installations Store / MSIX verrouillent l’option « Chemin de stockage des données du runtime » et affichent « Verrouillé par Microsoft Store ». Ce n’est pas un échec d’installation, mais une contrainte normale de ce canal de distribution.

### Le premier lancement télécharge ou prépare encore du contenu

Le paquet Store ne livre que le paquet de l’application desktop. Au premier lancement, HagiCode peut encore télécharger ou préparer les composants nécessaires à Hagicode Server et terminer l’initialisation par défaut. Gardez le réseau disponible et laissez l’étape en cours se terminer.
