La prise en charge intégrée d'OmniRoute a été retirée de HagiCode. Le produit ne propose plus d'étapes d'installation, de réglages, de test de connexion ni de synchronisation du catalogue de modèles pour OmniRoute.

Pour connecter des modèles aujourd'hui :

- utilisez un modèle connecté via Magpie, ou
- configurez un fournisseur et un modèle que votre Agent CLI prend en charge nativement.

HagiCode ne migre pas les anciens points de terminaison ni les clés OmniRoute. Sélectionnez un fournisseur et un modèle pris en charge dans votre configuration. Pour l'installation de l'Agent CLI, voir [Installation de l'AI Agent CLI](/fr-FR/related-software-installation/ai-agent-cli/).

## Documentation OmniRoute indépendante

OmniRoute est un projet distinct qui gère sa propre documentation. HagiCode ne le prend pas en charge.
