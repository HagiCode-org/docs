**세션**은 Agent와 함께 완료하는 하나의 작업 단위입니다. 세션 보드는 워크벤치의 중심입니다. 각 세션이 지금 어느 단계에 있는지 보여 주고, 새 세션을 시작하는 버튼을 제공합니다.

## 세션 보드

![Proposal & Review, Execution, Archived 세 개의 레인이 있는 세션 보드. Execution 레인에는 완료된 세션 카드 한 장이 있음](../../img/user-guide/workbench/01-workbench-overview.png)

보드에는 세 개의 레인이 있습니다.

| 레인 | 표시되는 내용 |
| --- | --- |
| **Proposal & Review**(제안 및 검토) | 초안을 작성하고 생성하여 제안으로 검토 중인 아이디어. |
| **Execution**(실행) | 실행 중이거나 완료된 세션. 일반 세션도 포함됩니다. |
| **Archived**(보관됨) | 보관한 세션. 언제든 다시 확인할 수 있습니다. |

각 카드에는 세션 번호, 소속 프로젝트, 유형을 나타내는 아이콘, 제목, 최근 변경 시간, 그리고 **Executing**(실행 중) 또는 **Execution Complete**(실행 완료) 같은 상태 배지가 표시됩니다. 카드를 클릭하면 세션이 열립니다. 각 레인 제목 옆의 숫자는 그 레인에 있는 세션 수를 나타내며, 레인 제목의 화살표를 누르면 레인을 접을 수 있습니다.

### 툴바

레인 위에 있는 툴바에는 네 가지 컨트롤이 있습니다.

- **레이아웃 모드 전환기**(*Session List*(세션 목록) 옆의 작은 아이콘): 다섯 가지 보기를 전환합니다. [보기](/user-guide/views)를 참고하세요.
- **New Idea**(새 아이디어, 새싹 아이콘): 제안을 시작합니다.
- **Create Normal Session**(일반 세션 만들기, 대화 말풍선 아이콘): 대화를 시작합니다.
- **More HagiTasks**(더 많은 HagiTask, 목록 아이콘): 다른 작업 프리셋을 사용할 수 있는 HagiTask 워크스페이스를 엽니다. [스킬과 HagiTask](/user-guide/skills-and-hagitask)를 참고하세요.

**Recent changes**(최근 변경) 메뉴와 **Trophies**(트로피) 위젯은 툴바 오른쪽 끝에 있습니다. [프로젝트](/user-guide/projects)와 [상태 표시줄과 진행 상황](/user-guide/status-bar-and-progress)을 참고하세요.

### 레이아웃 모드

![다섯 가지 보기를 나열한 Choose a view 서랍](../../img/user-guide/views/01-layout-switcher.png)

| 모드 | 배지 | 적합한 용도 |
| --- | --- | --- |
| **Classic**(클래식) | Focused(집중) | 프로젝트 열과 상세 열이 함께 있는 간결한 세션 목록. |
| **Execution Flow Kanban**(실행 흐름 칸반) | Flow(흐름) | 레인과 오른쪽의 전체 작업 영역. 이 가이드가 사용하는 레이아웃입니다. |
| **Dashboard Kanban**(대시보드 칸반) | Compact(간결) | 세션을 상태별로 묶고 개요에 더 넓은 공간을 주는 가벼운 보드. |
| **Project × Status Matrix**(프로젝트 × 상태 매트릭스) | Matrix(매트릭스) | 모든 프로젝트와 그 상태 레인을 하나의 그리드로 보여 주며, 확인이 필요한 항목의 개수를 함께 표시합니다. |
| **Command View**(커맨드 뷰) | Command(커맨드) | 실행 중인 여러 세션을 지켜보고 그 자리에서 질문에 답할 수 있는 실시간 타일 월. |

전환 방법과 각 보기가 보여 주는 내용은 [보기](/user-guide/views)를 참고하세요.

## 새 아이디어(제안) 만들기

**New Idea**를 클릭하면 **Create Proposal**(제안 만들기) 서랍이 열립니다. 계획을 먼저 세우는 편이 좋은 변경에 적합합니다. 원하는 내용을 설명하면 HagiCode가 제안을 작성하고, 실행 전에 여러분이 검토합니다. [제안 세션으로 아이디어를 코드로 바꾸기](/quick-start/proposal-session) 실습에서 제안부터 보관까지의 전체 과정을 단계별로 확인할 수 있습니다.

![아이디어 이름, 프로젝트, 범위, 빠른 요청, POST 엔드포인트 추가 요구 사항이 있는 Create Proposal 서랍](../../img/user-guide/sessions/01-new-idea.png)

**왼쪽 열: Basic Setup**(기본 설정)

- **Idea Name**(아이디어 이름)과 **Project Name**(프로젝트 이름)은 필수입니다.
- **Scope**(범위)에는 두 개의 탭이 있습니다. **Vault** 탭에서는 *Specify Target Vaults (Optional)*(대상 Vault 지정(선택 사항))를 설정합니다. AI가 편집할 수 있는 Vault를 표시하며, 시스템이 관리하는 Vault는 참고용으로만 사용됩니다. **Projects**(프로젝트) 탭에서는 다른 프로젝트를 추가 컨텍스트로 넣을 수 있습니다.
- **Quick Requests**(빠른 요청)는 요구 사항에 한 번의 클릭으로 추가되는 항목입니다. *No docs / tests*(문서·테스트 제외), *Self commit*(직접 커밋), *Output English*(영어로 출력, 인터페이스 언어에 따라 바뀜), *Ask before edit*(편집 전 확인), *No backward compatibility*(이전 버전 호환 안 함)가 있습니다.

**오른쪽 열: Requirement Drafting & Preview**(요구 사항 작성 및 미리 보기)

- **You Request**(요청 내용)에는 변경 사항을 설명합니다. 최대 14,000자까지 입력할 수 있습니다. **Upload Image**(이미지 업로드)로 이미지를 첨부할 수 있습니다.
- **Combined preview**(결합된 미리 보기)에는 AI에 전송될 전체 텍스트가 표시되므로, 제출 전에 확인할 수 있습니다.
- **Submit idea**(아이디어 제출)를 누르면 제안 세션이 만들어집니다. **Load Favorite**(즐겨찾기 불러오기)와 **Save as Favorite**(즐겨찾기로 저장)을 사용하면 저장한 설정을 다시 쓸 수 있습니다.
- 서랍 오른쪽 아래의 **Plan**(계획) 스위치는 "지금 제출"을 "일정에 맞춰 제출"로 바꿉니다. 저장하면 HagiCode가 정해 둔 시간에 이 제안 세션을 자동으로 만듭니다. [예약 계획](/user-guide/scheduled-plans)을 참고하세요.

## 일반 세션 만들기

**Create Normal Session**을 클릭하면 Agent와 일반 대화를 시작합니다. 저장소를 알아보거나 질문하거나, 제안 과정 없이 작은 변경을 할 때 사용하세요.

![프로젝트, 세션 제목, 작업 범위, 요구 사항 한 줄, Available Agents 선택기가 있는 Create Normal Session 서랍](../../img/user-guide/sessions/02-create-normal-session.png)

| 필드 | 설명 |
| --- | --- |
| **Project**(프로젝트) | 필수입니다. 기본값은 현재 선택된 프로젝트입니다. |
| **Session title**(세션 제목) | 선택 사항입니다. 카드에 표시되는 라벨입니다. |
| **Task scope**(작업 범위) | **Repos**(저장소)는 세션을 MonoSpecs 프로젝트의 일부 저장소로 제한합니다. **Vault**와 **Projects**(프로젝트)로 추가 참고 자료를 붙일 수 있습니다. |
| **What do you want to do?**(무엇을 하고 싶나요?) | 필수입니다. 세션의 첫 메시지가 됩니다. **Upload Image**로 이미지를 첨부할 수 있습니다. |

**Available Agents** 패널에는 사용할 수 있는 Agent 목록이 표시됩니다. 하나를 선택하면 세션이 **즉시 시작**됩니다. 첫 번째 항목이 실행 시 기본값입니다. 두 번째 목록에서는 이번 실행에만 다른 Agent를 선택할 수 있습니다. 목록에 Agent가 없다면 먼저 [Agents](/user-guide/agents)에서 만드세요. `Ctrl/⌘ + Enter`를 누르면 키보드로 제출할 수 있습니다.

:::note[읽기 전용 질문으로 시작하기]
이 가이드의 예시 세션은 데모 프로젝트에 읽기 전용 질문을 했습니다. 약 23초 만에 완료되었고 파일은 하나도 수정되지 않았습니다. 편집 모드는 세션마다 따로 제어합니다. 아래를 참고하세요.
:::

## 세션에서 작업하기

카드를 클릭하면 세션 서랍이 열립니다.

![최종 답변, Session Complete 요약, 메시지 상자, Agent 상태 카드가 보이는 세션 서랍](../../img/user-guide/sessions/03-session-detail.png)

**헤더 영역**: 제목, Agent 아바타, 그리고 세션을 Archived 레인으로 옮기는 **Archive**(보관) 버튼, **Delete Session**(세션 삭제) 버튼, **Open Code Server**(Code Server 열기) 버튼과 추가 작업이 들어 있는 **…** 메뉴가 있습니다.

**대화**: 여러분과 Agent의 메시지가 순서대로 표시됩니다. Agent가 작업하는 동안 그 동작을 따라갈 수 있습니다. 도구 호출은 호출마다 한 줄씩 얇은 원장(ledger) 형태로 접혀 표시되며, 도구 이름, 대상(경로, 명령, 검색 패턴), 줄 수와 소요 시간 같은 짧은 요약이 보입니다. 실행 중이거나 실패한 호출에는 표시가 붙고, 행을 클릭하면 전체 내용이 열립니다.

![실행 모드 블록과 Bash 도구 호출 행이 보이는 세션 상단](../../img/user-guide/sessions/04-session-detail-top.png)

실행이 끝나면 **Session Complete**(세션 완료) 카드가 이번 실행의 턴 수, 소요 시간, 비용을 요약해 보여 줍니다. 카드를 클릭하면 자세한 내용을 펼쳐 볼 수 있습니다.

**메시지 상자**: 하단에 있습니다.

- **Edit / Readonly**(편집 / 읽기 전용) 스위치로 편집 모드를 켜거나 끕니다. 편집 모드를 켜면 새 메시지가 파일을 수정할 가능성이 높아집니다. 새로 만든 일반 세션에서 편집 모드를 기본으로 켤지는 **Settings → Sessions and conversation → Chat View**(설정 → 프로세스 및 상호작용 → 채팅 보기)에서 정합니다.
- **이미지**, **Standard Phrases**(표준 문구, `@` 선택기), **Import Recent History**(최근 기록 가져오기) 버튼이 있습니다.
- **Send**(보내기)로 메시지를 제출합니다. `Enter`로 보내고, `Shift + Enter`로 줄을 바꿉니다.

**Agent 상태 카드**: 메시지 상자 오른쪽에 있으며, Agent CLI와 모델(예: `claude-sonnet-5-5`), 현재 상태(예: *Idle*(대기 중)), 경과 시간을 보여 줍니다.
