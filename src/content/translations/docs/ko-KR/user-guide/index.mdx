이 섹션은 HagiCode 워크벤치의 사용 설명서로, 인터페이스 모듈별로 하나씩 설명합니다. 현재 사용 중인 기능에 해당하는 페이지를 바로 열어 보셔도 됩니다.

## 워크벤치 한눈에 보기

워크벤치는 기본적으로 **세션 보드**를 엽니다. 아래 그림은 `orbit-notes`라는 작은 데모 프로젝트를 사용하며, 이 프로젝트에는 완료된 세션이 하나 있습니다.

![HagiCode 워크벤치. 상단 바, 프로젝트 레일, 세 개의 레인이 있는 세션 보드, 프로젝트 패널, 상태 바가 표시되어 있음](../../img/user-guide/workbench/01-workbench-overview.png)

인터페이스는 다섯 개 영역으로 나뉩니다:

| 영역 | 위치 | 용도 | 가이드 |
| --- | --- | --- | --- |
| **상단 바**（Header） | 상단 가장자리 | 워크스페이스 단위 모듈을 엽니다: Agents, Wizard, Skills, HagiTask, Vault, Plans, 설정, 언어, 테마, 프로필 | [상단 바](#顶栏) |
| **프로젝트 레일**（Project rail） | 왼쪽 가장자리 | 전체 프로젝트와 개별 프로젝트 사이를 전환하고 새 프로젝트를 만듭니다 | [프로젝트](/user-guide/projects) |
| **세션 보드**（Session board） | 가운데 | 레인으로 세션을 보여 주고 새 세션 버튼을 제공하며, 다섯 가지 보기로 전환할 수 있습니다 | [세션](/user-guide/sessions), [보기](/user-guide/views) |
| **프로젝트 패널**（Project panel） | 오른쪽 | 선택한 프로젝트의 빠른 작업과 저장소 상태를 보여 줍니다 | [프로젝트](/user-guide/projects) |
| **상태 바**（Status bar） | 하단 가장자리 | 팁, Agent CLI 상태, 실행 중인 세션, 휴식 알림, 일당 카운터, 빌드 버전을 보여 줍니다 | [상태 바와 진행 상황](/user-guide/status-bar-and-progress) |

## 상단 바

상단 바는 항상 표시됩니다. 여기의 버튼은 현재 페이지 위에 드로어나 대화상자를 열기 때문에 보드에서 보던 위치를 잃지 않습니다.

![HagiCode 상단 바. Agents, Wizard, Refresh, Skills, HagiTask, Vault, Plans, Get Support, 언어, 테마, 설정, 프로필 버튼이 있음](../../img/user-guide/workbench/03-header-navigation.png)

| 버튼 | 열리는 내용 |
| --- | --- |
| **Agents**（한국어 인터페이스: Agents） | Agents 워크벤치: 내 Agent, 실행 시나리오, AgentCLI 목록, 모델 카탈로그, 문구 테마, 아바타 갤러리. [Agents](/user-guide/agents)를 참고하세요. |
| **Wizard**（마법사） | 4단계 초기화 마법사. [첫 실행](#首次启动初始化向导)을 참고하세요. |
| **Refresh**（새로고침） | 현재 페이지의 내용을 다시 불러옵니다. |
| **Skills**（스킬） | Local Skills, Gallery, Trusted Providers를 포함한 통합 스킬 모듈. [스킬과 HagiTask](/user-guide/skills-and-hagitask)를 참고하세요. |
| **HagiTask**（한국어 인터페이스: HagiTask） | 작업 프리셋을 관리하는 HagiTask 관리 화면. [스킬과 HagiTask](/user-guide/skills-and-hagitask)를 참고하세요. |
| **Vault**（한국어 인터페이스: Vault） | HagiCode가 탐색하고 미리 볼 수 있는 폴더를 관리하는 Vault 관리자. [Vault](/user-guide/vault)를 참고하세요. |
| **Plans**（계획, 달력 아이콘; 좁은 창에서는 아이콘만 표시되며 Scheduled plans 툴팁이 나타남） | 정해 둔 일정에 따라 세션을 자동으로 시작하는 계획을 관리하는 계획 관리자. [예약 계획](/user-guide/scheduled-plans)을 참고하세요. |
| **Get Support**（기술 지원 받기） | 브라우저에서 커뮤니티 및 지원 페이지를 엽니다. |
| **Language**（언어） | 인터페이스 언어를 전환합니다. HagiCode는 简体中文을 포함해 열 가지 인터페이스 언어를 제공합니다. |
| **Theme**（테마, 잎 아이콘） | 테마 선택기를 엽니다. [외관, 테마 및 언어](/user-guide/settings#外观主题与语言)를 참고하세요. |
| **Settings**（설정, 톱니바퀴 아이콘; 열리는 대화상자 제목은 "설정"） | 설정 대화상자를 엽니다. [설정](/user-guide/settings)을 참고하세요. |
| **Profile**（프로필, 원형 아바타） | 포인트, 기록 타임라인, 빠른 진입점이 있는 프로필 드로어를 엽니다. [상태 바와 진행 상황](/user-guide/status-bar-and-progress#个人资料)을 참고하세요. |

## 첫 실행: 초기화 마법사

새로 설치하면 **Initialization wizard**（초기화 마법사）가 자동으로 열립니다. 언제든지 상단 바의 **Wizard** 버튼으로 다시 열 수 있습니다. 마법사는 총 네 단계이며, 필수 세 단계 중 준비가 끝난 항목 수를 표시합니다.

![초기화 마법사 1단계: 인터페이스 언어와 색상 테마 선택](../../img/user-guide/wizard/01-language-theme.png)

1. **Language & theme**（언어와 테마） – 인터페이스 언어와 계절별 색상 테마를 선택합니다. 두 설정 모두 즉시 적용됩니다.
2. **Hagicoder** – 로컬 Agent CLI와 모델을 선택하고, 첫 Agent를 만든 뒤 **Fallback Crew**（대체 팀）에 추가합니다. 연결 테스트를 권장하지만 필수는 아닙니다.
3. **Project**（프로젝트） – 첫 프로젝트의 폴더를 등록합니다.
4. **Community**（커뮤니티）（선택 사항） – 첫 대화를 시작하거나 "정보" 페이지를 엽니다.

![초기화 마법사 2단계: 기본 Agent를 설정하고 Fallback Crew에 추가](../../img/user-guide/wizard/02-agent.png)

전체 과정과 각 필드의 의미는 [초기화 마법사 설정](/quick-start/wizard-setup)을 참고하세요.
