스킬과 HagiTask는 모두 에이전트의 기능을 확장하며, 두 가지 모두 상단 바에서 열 수 있습니다.

- **스킬**은 에이전트 CLI가 불러오는 재사용 가능한 지침 묶음입니다. 예를 들어 디자인 가이드라인이나 프레임워크 모범 사례가 있습니다.
- **HagiTask**는 HagiCode가 세션 흐름을 통해 실행하는 작업 프리셋입니다. 예를 들어 *Normal Session*(일반 세션)이나 *Research Investigation*(코드 조사)이 있습니다.

## 스킬

상단 바에서 **Skills**(스킬)를 클릭합니다. 드로어에는 탭이 세 개 있습니다. 더 자세한 설명은 [Skills 사용 가이드](/guides/skills)를 참고하세요.

### Local Skills(로컬 스킬)

![Installed, Built-in, Skill bases 분류, 검색, Refresh inventory, Update all, 설치된 스킬 테이블이 포함된 Local Skills 탭](../../img/user-guide/skills/01-local-skills.png)

탭 상단에는 **Installed**, **Built-in**, **Skill bases** 세 가지 분류가 있으며 각각 개수가 표시됩니다. 백엔드는 이 머신에 전역으로 설치된 스킬의 유일한 기준(source of truth)입니다.

- **Refresh inventory**(인벤토리 새로고침)는 머신을 다시 스캔합니다. **Update all**(모두 업데이트)은 업데이트 가능한 모든 스킬을 업데이트합니다.
- 테이블에는 각 **Skill**(스킬), 연결된 **Agents**(에이전트), **Path**(경로), 그리고 사용 가능한 **Actions**(작업)인 **Update**(업데이트)와 **Uninstall**(제거)이 표시됩니다.
- 경고가 표시된 행은 원클릭 업데이트에 필요한 설치 메타데이터 파일이 없으므로, 업데이트 작업이 *Unavailable*(업데이트 불가)로 표시됩니다.

#### Skill bases

![경로 입력란과, 하나의 베이스 아래 스위치가 있는 스킬 목록이 보이는 Skill bases 분류](../../img/user-guide/skills/05-skill-bases.png)

**스킬 베이스(skill base)**는 HagiCode를 실행하는 머신의 폴더이며, `SKILL.md` 파일이 있는 하위 폴더 하나가 스킬 하나입니다. **Folder path on the server**에 경로를 입력하고 **Add base**를 클릭하면 그 안의 스킬을 불러옵니다. 경로는 이 기기가 아니라 HagiCode를 실행하는 머신에서 읽습니다.

- 각 베이스에는 경로, **Status**(Available 또는 Unavailable), 스킬 수가 표시되며 **Rescan**과 **Remove** 작업이 있습니다.
- 각 스킬에는 상태(예: *Ready*)와 스위치가 표시됩니다. 스위치는 스킬의 전역 상태이며, 각 Agent는 자체 설정에서 이를 덮어쓸 수 있습니다.

### Gallery(갤러리)

![검색 상자, 출처 필터, 설치 횟수 순위 목록이 포함된 Gallery 탭](../../img/user-guide/skills/02-gallery.png)

이름, ID, 출처로 스킬 라이브러리를 검색할 수 있으며, GitHub 저장소 URL을 붙여 넣을 수도 있습니다. **Trusted only**(신뢰된 것만)를 선택하면 신뢰하는 제공자의 스킬만 목록에 표시됩니다. 각 행에는 스킬, 출처, 설치 횟수가 표시됩니다. 설치 전에 행을 열면 정확한 설치 명령을 확인할 수 있습니다.

### Trusted Providers(신뢰 제공자)

![규칙 형식 설명과 기본 제공자 테이블이 포함된 Trusted Providers 탭](../../img/user-guide/skills/03-trusted-providers.png)

신뢰 제공자는 어떤 출처에 *Trusted* 라벨을 붙일지 결정합니다. 이 디렉터리에는 검증된 출처만 저장되며, 자격 증명은 저장되지 않습니다. 각 행에 규칙 하나를 작성합니다.

- `prefix:owner/`는 특정 소유자의 모든 저장소를 신뢰합니다.
- `exact:owner/repo`는 단일 저장소를 신뢰합니다.

기본값으로 Vercel, Azure, anthropics, Microsoft 같은 제공자가 포함되어 있습니다. **Add provider**(제공자 추가), **Edit**(편집), **Delete**(삭제), **Reset defaults**(기본값 재설정)를 사용해 목록을 수정할 수 있습니다.

## HagiTask

상단 바에서 **HagiTask**를 클릭하거나, 세션 보드의 **More HagiTasks**(더 많은 HagiTask)를 클릭하면 **HagiTask workspace**가 열립니다. 여기에도 탭이 세 개 있습니다.

### Package management(패키지 관리)

![Create proposal, Normal Session, Research Investigation 프리셋을 나열한 Package management 탭](../../img/user-guide/skills/04-hagitask-packages.png)

목록에는 설치된 각 프리셋과 **Order**(순서), **Name**(이름), **Version**(버전), **Source**(출처), **Enabled**(사용 여부) 토글이 표시됩니다. 토글로 프리셋을 켜거나 끌 수 있습니다.

- **Create proposal**(제안서 작성)은 내장된 특수 작업입니다. 항상 존재하며, 설치하거나 제거할 수 없습니다.
- **Normal Session**(일반 세션)과 **Research Investigation**(코드 조사)은 워크스페이스 프리셋입니다.
- **Change order**(순서 변경)로 목록 순서를 조정할 수 있습니다. **Install community HagiTask**(커뮤니티 HagiTask 설치)는 갤러리로 이동합니다. **Reload list**(목록 다시 불러오기)는 각 출처를 다시 읽습니다.

행을 클릭하면 오른쪽에서 상세 정보를 볼 수 있습니다.

### Community Gallery(커뮤니티 갤러리)

![Install 버튼과 상세 패널이 있는 커뮤니티 HagiTask 프리셋 목록의 Community Gallery 탭](../../img/user-guide/skills/06-hagitask-gallery.png)

HagiCode 팀과 커뮤니티가 게시한 프리셋을 둘러볼 수 있습니다. 예를 들어 *CodeGraph Tasks*, *GitHub Tasks*, *AGENTS.md Update*가 있습니다. 각 항목에는 분류, 버전, 태그, 필요한 CLI 도구가 표시됩니다. **Install**(설치)을 클릭하면 추가됩니다. **Create or contribute a task**(Task 만들기 또는 기여하기)는 기여 가이드를 열고, *Add Community Task* 프리셋은 작업을 단계별로 작성하도록 안내합니다.

### Source management(출처 관리)

**Source management** 탭에는 프리셋을 불러오는 출처가 표시됩니다. 여기에는 내장 프리셋과 커뮤니티 폴더가 포함됩니다. **Add folder source**(폴더 출처 추가)로 다른 폴더를 등록할 수 있고, **Reload sources**(출처 다시 불러오기)로 다시 스캔할 수 있습니다. 로컬 폴더에서 개별 작업을 설치하는 기능은 더 이상 지원되지 않습니다. 커뮤니티 갤러리에서 설치하세요.
