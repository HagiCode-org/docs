워크벤치 하단 가장자리와 상단의 몇몇 위젯은 방해하지 않으면서 언제든 정보를 알려 줍니다. 이 페이지에서는 상태 표시줄, 트로피 및 업적 홀, 그리고 프로필을 설명합니다.

## 상태 표시줄

![상태 표시줄: Microsoft Store 배지, 스크롤 팁, Agent CLI 상태, 실행 중인 세션, 휴식 알림, 일급 카운터, 버전](../../img/user-guide/workbench/04-status-bar.png)

왼쪽에서 오른쪽으로 다음 항목이 표시됩니다:

| 항목 | 표시 내용 |
| --- | --- |
| **Microsoft Store badge** | HagiCode의 Microsoft Store 등록 페이지로 연결되는 링크입니다. |
| **스크롤되는 팁과 프로모션** | 한 번에 하나의 팁이나 프로모션이 스크롤되어 표시됩니다. 팁은 HagiCode 사용법을 설명하고, 프로모션은 관련 프로젝트로 연결됩니다. **Settings → Integration → Status Bar Scroll**(설정 → 통합 → 상태 표시줄 스크롤)에서 스크롤을 끄거나 콘텐츠 출처를 선택할 수 있습니다. |
| **Agent CLI 상태** | `CC`, `CO`, `GC`와 같은 작은 배지로, 각각 Claude Code, Codex, GitHub Copilot을 나타내며 정상일 때는 녹색 점이 표시됩니다. `+N`은 추가로 몇 개의 도구가 더 있는지를 뜻합니다. 이 배지를 클릭하면 상태 점검을 새로 고칩니다. |
| **Running sessions**(실행 중인 세션) | 현재 실행 중인 세션 수입니다. 클릭하면 세부 정보를 볼 수 있습니다. |
| **Break reminder**(휴식 알림) | 물방울 아이콘으로, 현재 알림 간격에서 남은 시간을 보여 줍니다. |
| **Salary tracker**(급여 추적기) | 단위 이모지와 오늘 누적된 금액입니다. 카운터와 상태 표시줄 표시기가 켜져 있을 때 나타납니다. |
| **Version**(버전) | 빌드 버전입니다. 개발 빌드에서는 `dev`로 표시됩니다. |

### 실행 중인 세션

![실행 중인 세션 팝업: 세션 상한, 오버클럭 옵션, 현재 실행 중인 세션이 없는 상태](../../img/user-guide/status/03-running-sessions.png)

HagiCode는 동시에 실행할 수 있는 세션 수를 제한하며, 기본값은 20입니다. 팝업에는 현재 수와 상한을 비교한 값이 표시되고, 실행 중인 세션 목록도 함께 나옵니다.

- **Overclock**(오버클럭)은 상한을 3만큼 올립니다. 현재 상한에 도달한 후에만 사용할 수 있으며, 팝업에 사용 횟수가 표시됩니다.
- TurboEngine DLC를 사용하면 동시 실행 단계를 더 높일 수 있습니다.

### 휴식 알림

![휴식 알림 팝업: 메시지와 Remind me later 및 Take a break 버튼](../../img/user-guide/status/04-break-reminder.png)

타이머가 울리면 현재 알림 주제에 맞는 메시지가 담긴 카드가 나타납니다. **Take a break**(휴식하기)는 알림을 확인했다는 뜻이고, **Remind me later**(나중에 알림)는 알림을 미루는 것입니다. 간격과 어조는 **Settings → Integration → Break Reminder**(설정 → 통합 → 휴식 알림)에서 설정합니다.

### 일급 카운터

![일급 카운터 팝업: 분당 수익, 오늘, 사용한 분, 어제, 누적 총계 표시](../../img/user-guide/status/05-salary-tracker.png)

이모지를 클릭하면 분당 수익, 오늘의 총액, 사용한 분, 어제의 총액, 누적 총액을 볼 수 있습니다. **Open settings**(설정 열기)를 누르면 **Settings → Integration → Salary Tracker**(설정 → 통합 → 급여 추적기)로 이동하며, 여기서 일급과 근무 시간을 설정합니다.

## 트로피 및 업적 홀

세션 보드 오른쪽 상단의 **Trophies**(트로피) 위젯은 별로 진행 상황을 보여 줍니다. 별 4개(星)가 하나의 월(月)을, 월 4개가 하나의 일(日)을, 일 4개가 하나의 관(冠)을 이룹니다. 제목 옆의 숫자는 다음 승급까지 남은 별의 개수입니다.

위젯을 클릭하면 **Achievement Hall**(업적 홀)이 열립니다.

![업적 홀: 일일 점수, 완료율, 오늘의 전황 개요, 온라인 성장 표시](../../img/user-guide/status/01-achievements.png)

- **Daily Achievements**(일일 업적)은 매일 초기화되는 목표입니다. 예를 들어 제안을 시작하고 완료하기, Agent 산출물, 도구 활동 등이 있습니다. 제목에는 `0/17`과 같은 일일 점수가 표시됩니다.
- **Global Achievements**(전역 업적)는 여러 날에 걸쳐 쌓이는 평생 이정표입니다.
- **Mission Board**(미션 보드)는 그날의 상황을 요약합니다. 완료율, 진행 중인 목표, 보상 채널을 확인할 수 있습니다.
- **Online growth**(온라인 성장)는 HagiCode를 실행하는 동안 누적된 진행 상황을 기록합니다.

여기서 얻거나 일상 작업을 하며 얻은 포인트는 프로필에 표시됩니다. 일일 진행 팝업은 **Settings → Game → Achievements**(설정 → 게임 → 업적)에서 끌 수 있습니다.

## 프로필

상단 바의 가장 오른쪽에 있는 원형 아바타를 클릭하면 프로필 서랍이 열립니다.

![프로필 서랍: 아바타, 포인트, 기록 타임라인, 바로가기 표시](../../img/user-guide/status/02-profile.png)

- **Avatar**(아바타) – 10 MB 이하의 JPEG, PNG, WEBP 또는 GIF 이미지를 업로드할 수 있습니다.
- **Points**(포인트) – 업적과 일상 작업에서 얻어 정산된 현재 잔액입니다.
- **History timeline**(기록 타임라인) – 세션 생성이나 삭제 등 최근 시스템 기록입니다. 서랍을 열 때만 불러옵니다.
- **Quick links**(바로가기) – 예를 들어 **View Yesterday's Report**(어제 보고서 보기)를 누르면 어제의 전체 화면 영웅 전투 보고서가 열립니다.
