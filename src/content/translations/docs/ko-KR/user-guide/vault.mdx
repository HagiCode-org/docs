**Vault**는 HagiCode가 프로젝트 저장소 밖에서도 탐색하고 미리 볼 수 있도록 허용된 폴더입니다. 참고 문서, 노트, 조사 결과 등 세션이 읽거나 쓰기를 원하는 내용을 Vault에 보관할 수 있습니다.

상단 바의 **Vault**(중국어 인터페이스: Vault)를 클릭하면 **Vault Workspace**(Vault 워크스페이스)가 열립니다.

![Orbit Notes Docs Vault가 등록되어 있고 System vaults 그룹이 접혀 있는 Vault 워크스페이스](../../img/user-guide/vault/01-vault.png)

## 등록된 Vault와 시스템 Vault

워크스페이스는 두 개의 그룹으로 나뉩니다.

- **Registered vaults**(등록된 Vault)는 직접 추가한 폴더입니다. 각 카드에는 Vault 유형, 이름, 줄여서 표시한 경로, 그리고 브라우저 편집기에서 해당 폴더를 편집할 수 있는 **Open Code Server**(Code Server 열기) 버튼이 표시됩니다.
- **System vaults**(시스템 Vault)는 HagiCode가 생성하고 관리합니다. **Expand**(펼치기)를 클릭하면 목록을 볼 수 있습니다.

![펼친 시스템 Vault 목록. 시스템이 관리하는 읽기 전용 Vault 일곱 개가 표시됨](../../img/user-guide/vault/02-vault-system-expanded.png)

이 드로어에서 시스템 Vault는 **읽기 전용**입니다. 앱 로그, 데이터 디렉터리, prompt 템플릿, 개인 데이터, 프로젝트 데이터, 현재 아카이브, 시스템 프리셋이 여기에 포함됩니다. 세션 범위에서는 참고 자료로만 사용됩니다.

## Vault 추가

**Add vault**(Vault 추가)를 클릭하고 **Vault name**(Vault 이름)과 절대 경로인 **Physical path**(물리적 경로)를 입력한 뒤, **Vault type**(Vault 유형)을 선택하고 **Save vault**(Vault 저장)를 클릭합니다.

![이름과 경로가 입력되고 Folder 유형이 선택된 Add vault 드로어](../../img/user-guide/vault/03-add-vault.png)

| Vault 유형 | 역할 |
| --- | --- |
| **Folder**(폴더) | 기존 로컬 디렉터리를 있는 그대로 등록합니다. |
| **CodeRef**(코드 참조) | `docs/`, `repos/`, `AGENTS.md`, `index.yaml`을 자동으로 만듭니다. 조사 작업의 출력 Vault로 사용할 수 있습니다. |
| **Obsidian** | `.obsidian/`, `app.json`, 미리 볼 수 있는 노트 산출물을 자동으로 만들어, 해당 폴더를 Obsidian Vault로 사용할 수 있게 합니다. |

:::caution[저장 전에 유형을 먼저 선택하세요]
**Save vault**를 클릭하기 전에 세 가지 Vault 유형 중 하나를 선택하세요. 이 가이드를 작성할 때 사용한 버전에서는 유형을 선택하지 않고 저장하면 검증 안내 대신 이해하기 어려운 오류가 표시되며 저장에 실패합니다.
:::

## 세션에서 Vault 사용하기

Vault는 [제안 생성 드로어와 일반 세션 생성 드로어](/user-guide/sessions)의 **범위**(Scope, 인터페이스에서는 "작업 범위"로 표시될 수 있음)에 나타납니다. 작업에서 Vault의 파일을 수정해야 한다면 **편집 가능**(editable)으로 표시하세요. 그렇지 않으면 AI는 해당 Vault를 읽기 전용 참고 자료로 취급합니다. 시스템이 관리하는 Vault는 항상 참고용으로만 사용됩니다.
