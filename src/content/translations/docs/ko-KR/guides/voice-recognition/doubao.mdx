:::

## 개요

### Doubao 음성 입력이란

Doubao 음성 입력은 HagiCode에 통합된 음성 인식 기능으로, 내부적으로 ByteDance Doubao 오픈 플랫폼의 서비스를 사용합니다. 말을 하면 시스템이 음성을 텍스트로 변환합니다. 제품은 현재 프로젝트 컨텍스트도 함께 활용하여 도메인 어휘와 기술 용어를 인식하도록 돕습니다.

### 주요 사용 시나리오

HagiCode에서는 다음과 같은 경우에 음성 입력을 바로 사용하는 것이 더 적합합니다.

- **제안 빠르게 입력**: 타이핑 없이 말로 입력하기만 하면 제안을 빠르게 만들고 제출할 수 있어 효율이 크게 높아집니다
- **코멘트 작성**: 코드 리뷰나 문서 검토 중에 음성으로 코멘트와 피드백을 빠르게 추가합니다
- **메시지 답변**: 대화와 토론에서 음성으로 메시지에 빠르게 답할 수 있어 타이핑이 더 이상 부담이 되지 않습니다
- **장문 콘텐츠 작성**: 프로젝트 문서, 기술 설명, 회의록 같은 장문 콘텐츠를 빠르게 생성합니다

### 실제로 얻는 이점

- **깊은 통합과 컨텍스트 인식**: HagiCode는 Doubao 음성 인식과 깊이 통합되어 현재 프로젝트 컨텍스트(코드 구조, 기술 스택, 도메인 용어 등)를 자동으로 활용하며, 음성 인식에 정밀한 도메인 어휘 인식을 제공하여 기술 용어 인식 정확도가 크게 향상됩니다
- **무료 체험 시간**: Doubao 플랫폼이 20시간의 무료 인식 시간을 제공하므로 부담 없이 음성 입력을 체험할 수 있습니다
- **매우 빠름**: 실시간 인식으로 말하는 동시에 글자를 확인할 수 있어 기다릴 필요가 없습니다
- **높은 정확도**: Doubao의 첨단 음성 인식 모델과 프로젝트 컨텍스트를 결합하여 인식 결과가 정밀하고 믿을 만합니다
- **매끄러운 통합**: HagiCode의 메시지 입력창에 직접 통합되어 있어 애플리케이션을 전환할 필요가 없습니다
- **사용이 간편함**: 마이크를 클릭하면 바로 시작되어 간단하고 직관적입니다

## 빠른 시작

### 사전 조건

Doubao 음성 입력 기능을 사용하기 전에 다음이 필요합니다.

1. **Doubao 오픈 플랫폼 계정 발급**
   - [Doubao 음성 인식 콘솔](https://console.volcengine.com/speech/service/10038)에 접속합니다
   - 계정을 등록하거나 로그인합니다

2. **애플리케이션 생성 및 자격 증명 발급**
   - 플랫폼에서 음성 인식 애플리케이션을 생성합니다
   - `APP ID`와 `Access Token`을 발급받습니다

3. **네트워크 연결 확인**
   - 음성 인식 서비스는 네트워크 연결이 필요합니다
   - 사용하는 기기가 Doubao API 서비스에 접속할 수 있는지 확인합니다

### 기본 사용 흐름

다음은 Doubao 음성 입력을 사용하는 기본 단계입니다.

1. `APP ID`와 `Access Token` 발급
2. 제품에서 음성 인식 설정
3. API Key 테스트
4. 음성 입력창 찾기
5. 마이크 버튼 클릭
6. 마이크 권한 허용
7. 녹음 시작
8. 인식 결과를 실시간으로 확인
9. 클릭하여 녹음 중지
10. 텍스트 삽입 완료

## 기술 요구 사항

### HTTP 환경

Doubao 음성 입력 기능은 HTTP/HTTPS 환경에서 실행되어야 합니다.

| 환경 | 지원 여부 | 설명 |
|------|----------|------|
| **localhost** | ✓ | 로컬 개발 환경(http://localhost 또는 http://127.0.0.1) |
| **HTTPS 원격 서버** | ✓ | 외부 네트워크에 배포되었고 HTTPS를 사용하는 웹 애플리케이션 |
| **HTTP 원격 서버** | ✗ | 외부 네트워크에 배포되었지만 HTTP를 사용하는 웹 애플리케이션 |
| **file:// 프로토콜** | ✗ | HTML 파일을 직접 여는 방식은 지원하지 않음 |

:::caution
Doubao 음성 입력 기능에는 다음과 같은 제한이 있습니다.
1. **외부 네트워크 배포에는 반드시 HTTPS를 사용해야 합니다**: 브라우저 보안 제한 때문에 외부 네트워크에서 접속할 때는 HTTPS 프로토콜을 사용해야 마이크 권한을 얻을 수 있습니다
2. **로컬 주소는 제한이 없습니다**: `localhost` 또는 `127.0.0.1`을 사용하면 HTTP와 HTTPS 모두 지원됩니다
3. **file:// 프로토콜은 지원되지 않습니다**: `file://` 프로토콜 환경에서는 마이크와 WebSocket 연결을 사용할 수 없습니다
:::

### Desktop 버전

HagiCode의 Desktop 버전에는 HTTP 환경이 내장되어 있어 음성 입력 기능을 완전히 지원합니다. 추가 설정 없이 바로 음성 인식을 사용할 수 있습니다.

### Host 모드

로컬 Host 모드는 음성 입력 기능을 지원합니다.
- `localhost` 또는 `127.0.0.1`을 사용하면 HTTP와 HTTPS 모두 지원됩니다
- 외부 네트워크에 배포할 때는 반드시 HTTPS를 사용해야 합니다

## 설정 단계

### APP ID 발급

1. [Doubao 음성 인식 콘솔](https://console.volcengine.com/speech/service/10038)에 접속합니다
2. 로그인하거나 계정을 등록합니다
3. 콘솔에 들어가 새 음성 인식 애플리케이션을 생성합니다
4. 애플리케이션 상세 페이지에서 `APP ID`를 찾아 복사합니다

### Access Token 발급

1. Doubao 오픈 플랫폼 콘솔에서
2. 자신의 음성 인식 애플리케이션으로 들어갑니다
3. API 키 관리 영역을 찾습니다
4. `Access Token`을 생성하거나 복사합니다

:::note
`Access Token`은 안전하게 보관하고 다른 사람에게 노출하지 마십시오. 교체가 필요하면 Doubao 오픈 플랫폼에서 다시 생성할 수 있습니다.
:::

### 제품에서 설정

1. HagiCode 애플리케이션을 엽니다
2. **설정** → **음성 인식 설정**으로 들어갑니다
3. 설정 양식에 다음 정보를 입력합니다.
   - **Provider**: `doubao`(Doubao)를 선택합니다
   - **APP ID**: Doubao 플랫폼에서 발급받은 APP ID를 붙여넣습니다
   - **Access Token**: Doubao 플랫폼에서 발급받은 Access Token을 붙여넣습니다
4. (선택 사항) 필요에 따라 다른 설정 매개변수를 조정합니다
5. **API Key 테스트** 버튼을 클릭하여 설정을 검증합니다
6. 설정 검증에 성공하면 브라우저 로컬에 자동으로 저장됩니다

### API Key 테스트

설정을 마친 후에는 API Key가 유효한지 테스트하는 것을 권장합니다.

1. **API Key 테스트** 버튼을 클릭합니다
2. 시스템이 테스트 인터페이스를 호출하여 설정을 검증합니다
3. 설정이 올바르면 성공 메시지가 표시됩니다
4. 설정이 잘못되었으면 오류 메시지가 표시되므로 다음 사항을 확인하십시오.
   - APP ID와 Access Token이 올바른지
   - 네트워크 연결이 정상인지
   - Access Token이 만료되지 않았는지

:::tip
테스트에 실패하면 먼저 네트워크 연결이 정상인지 확인한 다음, Doubao 오픈 플랫폼의 API 키가 유효하고 만료되지 않았는지 확인하십시오.
:::

## 사용 방법

### 음성 입력 위치 찾기

HagiCode에서는 마이크 아이콘이 있는 텍스트 입력창이면 모두 음성 입력을 지원합니다. 이러한 컴포넌트는 보통 `VoiceTextArea`라고 부릅니다.

자주 사용하는 음성 입력 위치는 다음과 같습니다.
- 메시지 입력창
- 텍스트 편집 영역
- 텍스트 입력이 필요한 각종 양식 필드

### 음성 인식 시작

1. 마이크 아이콘이 있는 입력창을 찾습니다
2. 마이크 버튼을 클릭합니다
3. 브라우저가 마이크 권한을 요청합니다
4. **허용**을 클릭하여 마이크 접근을 허용합니다

:::note
이전에 마이크를 허용한 적이 있다면 브라우저가 권한을 다시 요청하지 않을 수 있습니다. 권한 설정을 확인하거나 변경하려면 브라우저 주소 표시줄 왼쪽의 자물쇠 아이콘에서 볼 수 있습니다.
:::

### 녹음 상태 설명

허용에 성공하면 음성 인식이 자동으로 시작되며 다음을 볼 수 있습니다.

- **파형 애니메이션**: 마이크 버튼 안에 동적인 음파 파형이 표시되어 녹음 중임을 나타냅니다
- **시간 표시**: 버튼 아래에 현재 녹음 시간이 표시됩니다
- **실시간 인식**: 인식된 텍스트가 커서 위치에 임시로 표시됩니다

### 실시간 인식 결과 표시

녹음 중에는 음성 인식 엔진이 음성을 실시간으로 글자로 변환합니다.

- 인식된 텍스트는 입력창에 회색으로 임시 표시됩니다
- 말하는 동안 인식 결과가 계속 갱신됩니다
- 표준 중국어(보통화) 인식을 지원하며 정확도가 높습니다

:::tip
더 나은 인식 결과를 얻으려면 다음을 권장합니다.
- 조용한 환경에서 사용합니다
- 또박또박, 적당한 속도로 말합니다
- 배경 소음을 피합니다
:::

### 인식 중지

음성 인식을 중지하려면 다음 방법을 사용할 수 있습니다.

1. **마이크 버튼 클릭**: 버튼을 다시 클릭하면 녹음이 중지됩니다
2. **입력창 클릭**: 입력창의 다른 영역을 클릭해도 녹음이 중지됩니다

중지하면 최종 인식 텍스트가 입력창에 정식으로 삽입되며, 계속 편집하거나 전송할 수 있습니다.
