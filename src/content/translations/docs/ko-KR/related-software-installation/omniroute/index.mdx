The official Desktop app is now the recommended path: download the Windows, macOS, or Linux installer from [OmniRoute GitHub Releases](https://github.com/diegosouzapw/OmniRoute/releases). The npm procedure below remains available for headless environments.

이 페이지는 권장 OmniRoute 로컬 경로를 설명합니다. `npm install -g omniroute`를 실행한 뒤 `omniroute start`를 실행하고, 대시보드에는 `http://localhost:20128`, OpenAI 호환 기본 URL에는 `http://localhost:20128/v1`을 사용합니다.

:::tip[추천 경로]
대시보드는 `http://localhost:20128`, OpenAI 호환 기본 URL은 `http://localhost:20128/v1`입니다. Docker와 고급 배포 모드는 선택 사항입니다.
:::

## 전제조건

- Node.js는 `>=22.0.0 <23` 또는 `>=24.0.0 <27`이어야 합니다. Node.js 21과 23은 지원되지 않습니다. 완료 [Node.js 설치](/ko-KR/related-software-installation/nodejs/installation) 필요하다면 먼저.
- 로컬 포트 `20128` 및 `20129`를 사용할 수 있으며 아직 점유되지 않았습니다.
- OmniRoute를 통해 라우팅하려는 업스트림 모델 공급자 계정이 하나 이상 있습니다.
- HagiCode, CLI 또는 SDK를 통합하기 전에 다음 두 주소를 별도로 유지하십시오.
  - 대시보드: `http://localhost:20128`
  - OpenAI 호환 기본 URL: `http://localhost:  20128/v1`

## 로컬로 설치 및 실행

권장되는 전역 npm 경로로 시작하세요.

```bash
npm install -g omniroute
omniroute start
```

서비스가 시작된 후 다음 순서로 유효성을 검사합니다.

1. 열기 `http://localhost:20128` 브라우저에서 대시보드가 로드되는지 확인하세요.
2. 로 이동 `Endpoints` 대시보드 페이지에서 API 키를 생성하거나 복사하세요.
3. 나중에 도구에 전달할 기본 URL을 기록해 두십시오. `http://localhost:20128/v1`.

:::note[대시보드로 시작하는 이유]
첫 번째 설정의 경우 대시보드는 OmniRoute가 실행 중인지, 공급자가 연결되어 있는지, API 키가 존재하는지 확인하는 가장 빠른 방법입니다. 이후 클라이언트 호출이 실패하는 경우 일반적으로 대시보드를 먼저 확인하는 것이 SDK 코드를 즉시 디버깅하는 것보다 빠릅니다.
:::

## 실행 중인 서비스 유효성 검사

### 검증 1: 모델 카탈로그를 읽을 수 있는지 확인

열쇠부터 넣어라 `Endpoints` 환경 변수로 페이지를 이동합니다.

```bash
export OMNIROUTE_API_KEY="replace-with-the-key-you-copied-from-the-Endpoints-page"
```

그런 다음 요청 `/v1/models`:

```bash
curl http://localhost:20128/v1/models \
  -H "Authorization: Bearer ${OMNIROUTE_API_KEY}"
```

모델 목록을 다시 받으면 OpenAI 호환 엔드포인트와 인증 흐름이 작동하는 것입니다.

### 검증 2: 최소한의 채팅 요청 보내기

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer ${OMNIROUTE_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "replace-with-a-model-id-from-v1-models",
    "messages": [
      { "role": "user", "content": "Reply with ok." }
    ]
  }'
```

여기서의 목표는 신속한 품질이 아닙니다. 선택한 모델이 이미 OmniRoute를 통해 성공적으로 라우팅될 수 있음을 증명하는 것입니다.
