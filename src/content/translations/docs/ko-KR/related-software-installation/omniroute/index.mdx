HagiCode의 내장 OmniRoute 지원이 제거되었습니다. 제품에는 OmniRoute 설치 단계, 설정 화면, 연결 테스트, 모델 카탈로그 동기화가 더 이상 없습니다.

지금 모델을 연결하려면:

- Magpie로 연결된 모델을 사용하거나,
- Agent CLI가 기본으로 지원하는 제공자와 모델을 설정하세요.

HagiCode는 이전 OmniRoute 엔드포인트나 키를 옮기지 않습니다. 설정에서 지원되는 제공자와 모델을 직접 선택하세요. Agent CLI 설정은 [AI Agent CLI 설치](/ko-KR/related-software-installation/ai-agent-cli/)를 참고하세요.

## 독립된 OmniRoute 문서

OmniRoute는 별도 프로젝트이며 문서는 자체 사이트에서 관리됩니다. HagiCode는 이를 지원하지 않습니다.
