이 페이지는 HagiCode의 통합 AI Agent CLI 로컬 설치 진입점입니다. HagiCode는 현재 11개의 Agent CLI를 활발히 지원합니다: Claude Code, Codex, GitHub Copilot, OpenCode, Hermes, QoderCLI, Kiro, Kimi, Gemini, DeepAgents, Codebuddy.

:::tip[이용 방법]
아래 표에서 각 CLI의 **현재 상태**와 **설치 방식**을 먼저 확인한 다음, 해당 공식 문서로 이동해 설치, 로그인, ACP, 권한, 문제 해결을 진행하세요. 핵심은 **지원 여부**와 **원클릭 설치 지원 여부**가 별개라는 점입니다.
:::

:::note[설치하기 전에 Node.js 24+를 준비하세요]
원클릭 설치를 지원하는 CLI 대부분은 Node.js와 npm에 의존하며, Desktop도 시스템의 `node`와 `npm`을 사용합니다(Desktop은 더 이상 Node.js를 내장하지 않습니다). 먼저 [Node.js 설치](/ko-KR/related-software-installation/nodejs/installation)에 따라 24 이상 버전을 준비하고, 설치를 마친 뒤에는 **로그인 또는 인증을 완료**하세요. 초기화 마법사에는 로컬에서 감지된 CLI만 표시됩니다.
:::

## 상태 설명

- **현재 지원**: HagiCode가 현재 활발히 지원하는 범위에 속하며, 시스템에서 현행 Agent CLI로 사용할 수 있습니다.
- **원클릭 설치**: HagiCode가 안내식 설치 진입점을 제공합니다. 일부 CLI는 설치 후에도 공급업체의 절차에 따라 로그인이나 인증을 계속해야 합니다.
- **수동 설치 / 인증**: 이 CLI는 현재 지원 범위에 있지만, 먼저 로컬 설치, 로그인 또는 인증을 완료한 뒤 HagiCode로 돌아와 사용 가능 상태를 새로 고쳐야 합니다.
- **기존 호환성만 유지**: iFlow CLI는 이전 데이터와의 호환성을 위해서만 유지되며, 현재 활발히 지원하는 목록에 속하지 않고 현행 권장 항목으로 간주해서도 안 됩니다.

- 이 Agent CLI들로 스펙 기반 개발을 시험해 보려면 [Spec Kit 설치 방법](/ko-KR/related-software-installation/spec-kit/installation)을 읽고 [Spec Kit과 OpenSpec 비교](/ko-KR/related-software-installation/spec-kit/vs-openspec)와 견주어 보세요.
- 전체 설치 경로와 Node.js, Git 등 사전 요구 사항이 궁금하다면 [설치 가이드](/ko-KR/installation)로 돌아가세요.
- 과거 글을 통해 이 사이트에 들어왔다면 이 페이지와 설치 개요 페이지의 현행 지원 설명을 기준으로 삼으세요.
