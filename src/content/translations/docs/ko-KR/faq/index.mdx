## 이 섹션에서 다루는 내용

FAQ 섹션은 다음 내용을 한곳에 모읍니다.

- 시작 및 런타임 관련 특별 설명
- Index에서 가져온, 장기적으로 남길 만한 글로 정리하기에 적합한 사용 tips
- 플랫폼, 배포 채널, 패키징 방식 또는 내장 런타임과 관련된 호환성 안내
- 독립된 설명 페이지로 만들기에 적합한 자주 묻는 문제 해결 진입점

HagiCode의 일상 사용 조언을 체계적으로 살펴보고 싶다면 [HagiCode 사용 Tips](/ko-KR/faq/tips)를 읽어 보십시오. Desktop이 어떤 외부 Node를 사용하는지, Agent CLI가 어디에 설치되는지, 또는 Node를 찾을 수 없다는 안내가 나올 때 어떻게 해야 하는지 확인하고 싶다면 [Desktop이 사용자의 Node 환경을 사용하는 방식](/ko-KR/faq/desktop-node-environment)을 읽어 보십시오. 각 Agent CLI와 HagiCode의 관계, 그리고 함께 사용하기를 권장하는 이유가 궁금하다면 [Claude Vs HagiCode](/ko-KR/faq/claude-vs-hagicode), [Copilot Vs HagiCode](/ko-KR/faq/copilot-vs-hagicode), [Codex Vs HagiCode](/ko-KR/faq/codex-vs-hagicode), [Gemini Vs HagiCode](/ko-KR/faq/gemini-vs-hagicode), [OpenCode Vs HagiCode](/ko-KR/faq/opencode-vs-hagicode), [Hermes Vs HagiCode](/ko-KR/faq/hermes-vs-hagicode), [DeepAgents Vs HagiCode](/ko-KR/faq/deepagents-vs-hagicode), [Kimi Vs HagiCode](/ko-KR/faq/kimi-vs-hagicode), [CodeBuddy Vs HagiCode](/ko-KR/faq/codebuddy-vs-hagicode), [QoderCLI Vs HagiCode](/ko-KR/faq/qoder-vs-hagicode) 및 [Kiro Vs HagiCode](/ko-KR/faq/kiro-vs-hagicode)를 읽어 보십시오. HagiCode가 Steam에 출시되지 않은 이유를 알고 싶다면 [HagiCode가 Steam에 출시되지 않은 이유](/ko-KR/faq/steam-distribution-status)를 읽어 보십시오.
