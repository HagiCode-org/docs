대화 세션은 HagiCode에서 가장 가벼운 진입점입니다. 프로젝트를 고르고 질문을 던지면 Agent가 저장소를 읽고 답변합니다. Agent가 파일을 수정할 수 있는지는 세션마다 직접 결정합니다.

## 사전 준비

대화 세션을 시작하기 전에 다음을 확인하세요.

- [설치 가이드](/ko-KR/installation)에 따라 설치 방법(Microsoft Store, Desktop) 중 하나를 완료했습니다
- 첫 번째 Agent와 프로젝트를 최소 하나 만들어 주는 [Wizard Setup](/ko-KR/quick-start/wizard-setup)을 완료했습니다
- 세션 보드에서 해당 프로젝트를 선택했습니다

## 대화 세션은 어떤 용도인가요?

대화 세션은 먼저 이해한 다음 수정하고 싶을 때 가장 적합합니다. 대표적인 사용 사례는 다음과 같습니다.

- 낯선 저장소를 빠르게 분석하기
- 특정 파일, 모듈 또는 오류에 대해 구체적으로 질문하기
- 제안(proposal)으로 계획하지 않고 작은 변경 수행하기
- 전송 전에 이미지, 표준 문구 또는 이전 메시지 첨부하기

작업이 "문제 이해" 단계를 넘어 "구조화된 변경을 계획하고, 검토하고, 보관하는" 단계로 넘어갔다면 [제안 세션 만들기](/ko-KR/quick-start/proposal-session)로 이어가세요. 이 페이지는 대화 세션만 다룹니다.

## 워크플로 개요

| 단계 | 할 일 | 일어나는 일 |
| --- | --- | --- |
| 생성 | **Create Normal Session**을 클릭하고 원하는 내용을 설명합니다 | 드로어에서 프로젝트, 선택 사항인 제목, 범위, 첫 메시지를 입력받습니다 |
| 시작 | **Available Agents**에서 Agent를 선택합니다 | 세션이 즉시 시작되고 **Execution** 레인에 나타납니다 |
| 읽기 | 세션 카드를 엽니다 | Agent가 저장소를 읽고 답변하며, **Session Complete** 카드가 실행 내용을 요약합니다 |
| 결정 | 메시지 입력란 옆의 모드 스위치를 사용합니다 | 읽기 전용 모드를 유지하거나, 편집 모드를 켜서 Agent가 파일을 변경할 수 있게 합니다 |
| 컨텍스트 추가 | 이미지, 표준 문구, 기록 버튼을 사용합니다 | 다음 메시지에 더 풍부한 컨텍스트가 담깁니다 |

## 1단계: 세션 만들기

프로젝트를 선택한 다음, 보드 위 도구 모음에서 **Create Normal Session**(말풍선 아이콘)을 클릭합니다.

![프로젝트, 세션 제목, 작업 범위, 요청 내용, Available Agents 선택기가 있는 Create Normal Session 드로어](../../img/quick-start/conversation-session/01-create-normal-session.png)

드로어를 다음과 같이 채웁니다.

- **Project**(필수) – 기본값은 선택한 프로젝트입니다.
- **Session title** – 선택 사항이며, 보드에 표시되는 카드의 제목이 됩니다.
- **Task scope** – 선택 사항입니다. **Repos**는 세션을 MonoSpecs 프로젝트의 저장소로 좁히고, **Vault**와 **Projects**는 추가 참고 자료를 연결합니다.
- **What do you want to do?**(필수) – 첫 번째 메시지입니다. **Upload Image**로 사진을 첨부할 수 있습니다.

드로어 옆에 **Available Agents** 패널이 열립니다. Agent를 클릭하면 세션이 **즉시 시작됩니다**. 첫 번째 카드는 런타임 기본값이고, 두 번째 목록에서는 이번 실행에만 사용할 다른 Agent를 고를 수 있습니다. 키보드에서 `Ctrl/⌘ + Enter`를 눌러 제출할 수도 있습니다.

:::tip[변경이 아니라 질문으로 시작하세요]
"이 프로젝트가 무엇을 하는지 두 문장으로 설명해 주세요. 파일은 수정하지 마세요."와 같은 첫 메시지는 Agent와 프로젝트가 올바르게 연결되었는지 안전하게 확인하는 방법입니다.
:::

## 2단계: 결과 읽기

새 세션은 상태 배지와 함께 **Execution** 레인에 카드로 나타납니다. 카드를 클릭하면 세션이 열립니다.

![Agent의 답변, Session Complete 요약, 메시지 입력란, Agent 상태 카드가 표시된 세션 드로어](../../img/quick-start/conversation-session/02-session-detail.png)

- **헤더**에는 제목과 Agent가 표시되며, **Archive**, **Delete Session**, **Open Code Server**, **…** 메뉴가 있습니다.
- **대화**에는 사용자의 메시지, 카드 형태의 Agent 도구 호출, 그리고 Agent의 답변이 나열됩니다.
- **Session Complete** 카드는 각 실행을 마무리하며 턴 수, 경과 시간, 비용을 보여줍니다. 클릭하면 세부 정보가 펼쳐집니다.
- 메시지 입력란 오른쪽의 **Agent 상태 카드**에는 Agent CLI, 모델, 상태(예: *Idle*), 경과 시간이 표시됩니다.

메시지 입력란에 후속 질문을 입력하세요. `Enter`로 전송하고 `Shift + Enter`로 줄을 바꿉니다.

## 3단계: 읽기 전용 모드와 편집 모드 선택

메시지 입력란 왼쪽의 스위치는 두 가지 위치가 있습니다. 눈 아이콘은 **읽기 전용**입니다. Agent는 살펴보고 설명할 수 있지만 파일을 변경하지 않습니다. 연필 아이콘은 **편집 모드**입니다. 새 메시지가 파일을 수정하거나 현재 구현을 조정할 가능성이 더 높아집니다.

![연필(편집 모드)이 선택된 메시지 입력란](../../img/quick-start/conversation-session/03-composer-edit.png)

![눈(읽기 전용 모드)이 선택된 메시지 입력란](../../img/quick-start/conversation-session/04-composer-readonly.png)

모드는 현재 세션에 적용되며 메시지 사이에 바꿀 수 있습니다. **새** 일반 세션을 편집 모드로 시작할지는 **Settings → Process & Interaction → Chat View → Default to Edit Mode for Normal Chats**에서 제어합니다. [Settings](/ko-KR/user-guide/settings)를 참고하세요.

더 안전한 방법은 간단합니다. 먼저 읽기 전용 모드에서 방향을 확인한 뒤, 실제로 변경이 필요할 때 편집 모드로 전환하세요.

## 4단계: 전송 전에 컨텍스트 추가

모드 스위치 옆의 버튼 세 개로 다음 메시지에 컨텍스트를 추가할 수 있습니다.

- **Insert an image attachment** – 스크린샷, 오류 캡처, 디자인 참고 자료를 첨부합니다. 이미지는 파일 이름과 크기와 함께 메시지 입력란 위에 표시되며, 전송 전에 **×**로 제거할 수 있습니다.
- **Standard Phrases** – `@` 참조를 삽입합니다. 선택기는 **Projects**(정식 프로젝트 루트 경로), **Vaults**(등록된 vault 경로), **Proposal Sessions**(OpenSpec 변경 폴더), **Recent Items**를 제공합니다.
- **Import Recent History** – 이 세션의 최근 메시지 중 하나를 다시 사용하므로 같은 내용을 다시 입력할 필요가 없습니다.

![위쪽에 첨부된 이미지가 표시된 메시지 입력란](../../img/quick-start/conversation-session/05-composer-image.png)

![메시지 입력란에서 연 표준 문구 선택기: Projects, Vaults, Proposal Sessions, Recent Items](../../img/quick-start/conversation-session/06-standard-phrases.png)

이미지는 다음과 같은 경우에 유용합니다.

- Agent에게 인터페이스 스크린샷을 설명해 달라고 요청할 때
- 오류 스크린샷이나 디자인 목업을 첨부하고 추가 지시를 덧붙일 때
- 편집 모드로 전환하기 전에 시각적 컨텍스트를 제공할 때

## 일반적인 진행 순서

1. 도구 모음에서 세션을 **만들고** Agent를 선택합니다.
2. 프로젝트에 대한 질문으로 **읽기 전용으로 시작합니다**.
3. **답변을 읽고** 후속 질문을 합니다.
4. 파일을 직접 변경해야 할 때만 **편집 모드를 켭니다**.
5. 다음 메시지에 더 많은 컨텍스트를 주기 위해 **이미지, 표준 문구 또는 기록을 추가합니다**.
6. 작업이 끝나면 세션을 **Archive**합니다. 세션이 **Archived** 레인으로 이동합니다.

작업에 계획, 검토, 보관 절차가 필요해졌다면 제안 세션 가이드로 이어가세요.
