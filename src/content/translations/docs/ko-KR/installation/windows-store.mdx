Windows 사용자에게는 Microsoft Store가 현재 공개 데스크톱 진입점입니다. 이 문서는 Store 설치 경로만 설명합니다. 일반 Desktop 다운로드와 설치, 버전 관리, 문제 해결은 [Desktop 설치](/ko-KR/installation/desktop)를 확인하세요.

Steam 메인 앱 항목은 이미 퇴역했기 때문에 현재 Windows의 주요 배포 채널은 Microsoft Store입니다. 배경은 [HagiCode가 Steam에 없는 이유](/ko-KR/faq/steam-distribution-status/)에서 확인할 수 있습니다.

:::tip[이 경로가 잘 맞는 경우]
- Windows 10 또는 Windows 11을 사용하며 시스템 Store에서 바로 설치하고 싶다
- 설치 파일을 수동으로 다루기보다 Store 채널로 앱 패키지를 받고 싶다
- 개인 로컬 환경만 필요하고 Docker Compose 배포는 계획하지 않는다
:::

## 시작 전에 확인할 사항

시작하기 전에 다음 조건을 확인하세요.

- 장치에서 [HagiCode for Windows의 Microsoft Store 페이지](https://apps.microsoft.com/detail/9N3PM0N3SVDW)를 열 수 있어야 합니다
- 첫 실행 시 네트워크 연결이 가능해야 합니다. 프로그램이 Hagicode Server에 필요한 구성요소를 내려받거나 준비해야 할 수 있기 때문입니다
- 장치, 조직 정책, 지역 설정에 따라 Microsoft 계정 로그인을 먼저 요구할 수 있습니다
- 회사 장치에서 Store가 비활성화되어 있다면 [Desktop 설치](/ko-KR/installation/desktop)로 전환하세요

## 설치 전 준비

Store 버전은 Desktop과 같은 방식으로 동작합니다. **Node.js가 내장되어 있지 않으므로** 직접 설치하고 시스템 `PATH`에서 찾을 수 있게 해야 합니다. 첫 실행 전에 다음을 준비하세요.

- **Node.js 24 이상 버전**(`npm`도 함께 제공됩니다): [Node.js 설치](/ko-KR/related-software-installation/nodejs/installation) 참고
- **Git**: [Git 설치](/ko-KR/installation/#git-설치) 참고
- 설치와 로그인이 끝난 **Agent CLI** 최소 하나: [AI Agent CLI 설치](/ko-KR/related-software-installation/ai-agent-cli/) 참고

HagiCode가 이미 열려 있는 상태에서 이들을 설치했다면 HagiCode를 완전히 종료한 뒤 다시 시작해 새로운 `PATH`를 읽게 해야 합니다.

## Microsoft Store에서 설치하기

1. [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW) 페이지를 엽니다.
2. `받기`, `설치`, 또는 Store가 표시하는 동등한 버튼을 누릅니다.
3. Microsoft Store가 다운로드와 설치를 마칠 때까지 기다립니다.
4. 완료되면 시작 메뉴 또는 Store 페이지에서 HagiCode를 실행합니다.

## 첫 실행 시 일어나는 일

설치가 끝나도 HagiCode는 표준 Desktop 초기화 흐름을 계속 진행합니다.

- 첫 실행은 먼저 Desktop의 최초 설정으로 시작합니다. 언어를 선택하고, 법적 문서를 확인하고, 필요하면 Hagicode Server를 내려받으므로 일반 앱보다 느릴 수 있습니다
- Microsoft Store / MSIX 채널은 "런타임 데이터 저장 경로" 설정을 잠급니다. 이 배포 방식에서는 의도된 동작입니다
- 앱 자체는 독립적으로 업데이트하지 않으며, 앱 패키지 업데이트는 설치 채널에 따라 결정됩니다. Store로 설치한 경우 전달 방식은 Microsoft Store 채널에 따릅니다

온보딩을 계속하려면 [초기화 마법사 설정](/ko-KR/quick-start/wizard-setup)을 확인하세요.

## 다른 설치 경로를 써야 하는 경우

다음과 같은 경우에는 다른 채널이 더 적합합니다.

- Microsoft Store에 접근할 수 없거나 회사 장치에서 Store 설치를 명시적으로 금지한 경우
- `.exe` 또는 `.msix` 패키지를 직접 내려받아 설치 파일의 출처를 스스로 관리해야 하는 경우
- 서버, NAS, 팀 공유 환경에 배포하려는 경우로, 이때는 [Docker Compose 배포](/ko-KR/installation/docker-compose)가 더 적합합니다

## 문제 해결

### Microsoft Store 페이지가 열리지 않음

먼저 네트워크, 지역 설정, Microsoft Store 로그인 상태를 확인하세요. 브라우저에서는 페이지가 열리지만 Store 클라이언트를 사용할 수 없다면, 대개 현재 시스템 정책이 Store 기능을 제한하고 있는 경우입니다. 이때는 [Desktop 설치](/ko-KR/installation/desktop)로 전환하세요.

### 일부 설정이 잠겨 있음

Store / MSIX 설치에서는 "런타임 데이터 저장 경로" 옵션이 잠기며 "Microsoft Store에 의해 잠김"이라고 표시됩니다. 이는 설치 오류가 아니라 현재 배포 채널의 제약입니다.

### 첫 실행 때 추가 다운로드나 준비가 계속됨

Store 설치는 데스크톱 앱 패키지만 전달합니다. 첫 실행 시 HagiCode는 Hagicode Server에 필요한 구성요소를 내려받거나 준비하고 기본 초기화를 마칠 수 있습니다. 네트워크 연결을 유지한 채 현재 단계가 끝날 때까지 기다리세요.
