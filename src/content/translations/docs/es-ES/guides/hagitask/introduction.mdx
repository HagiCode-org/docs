**A quién va dirigida:** personas que usan, mantienen o desean contribuir al ecosistema HagiTask.

**Requisitos previos:** ninguno. Para instalar o ejecutar tareas, prepara la aplicación HagiCode y su servicio backend.

## ¿Qué es HagiTask?

HagiTask es el modelo de paquetes de tareas y tareas predefinidas de HagiCode. Un paquete reúne la identidad de la tarea, su panel frontend, los prompts backend, las plantillas, los textos de la interfaz y su presentación en la tienda en un directorio verificable. Así, la aplicación puede descubrir, instalar, gestionar y ejecutar tareas.

Un paquete de tareas no es la propia aplicación ni sustituye su configuración de ejecución. La aplicación carga las tareas y ejecuta las capacidades que estas declaran; el paquete solo aporta recursos organizados según un formato acordado.

## Funciones dentro del ecosistema

| Componente | Responsabilidad |
| --- | --- |
| HagiTask | Mantiene el esquema compartido y los paquetes predefinidos incluidos con el producto; es la fuente de referencia del formato de paquetes. |
| Tareas predefinidas | Tareas suministradas con la aplicación o el entorno de ejecución, como `normal-session` y `research-investigation`. |
| Community Packages | Mantiene los datos fuente de las tareas comunitarias en `data/<taskId>/`. |
| HagiTask Site | Genera el catálogo, los archivos JSON de detalle y los archivos ZIP a partir de los paquetes comunitarios y los publica en la Community Gallery. |
| Aplicación HagiCode | Muestra las tareas, instala paquetes, guarda su estado de activación y ejecuta las tareas. |

Las tareas predefinidas y las comunitarias utilizan el mismo esquema de paquete, pero tienen distintos orígenes y ciclos de vida: las primeras se mantienen en el repositorio HagiTask y las segundas en Community Packages. `/index.json`, los documentos de detalle y los ZIP del sitio son artefactos generados, no archivos fuente que los colaboradores deban editar directamente.

## Gestionar paquetes no es lo mismo que gestionar fuentes

Instalar un ZIP desde la Gallery copia el paquete al directorio de datos de la aplicación y registra su versión, origen y estado de activación. En cambio, la gestión de fuentes del servidor configura directorios visibles para el servidor, donde el entorno de ejecución busca tareas. No sube una carpeta local del navegador como paquete instalable.

Para conocer el alcance de cada operación y el uso de directorios como fuentes, consulta [Usar HagiTask](/es-ES/guides/hagitask/usage). Si vas a instalar un paquete, sigue con [Instalar HagiTask](/es-ES/guides/hagitask/installation); para crear o publicar una tarea, consulta [Contribuir a la comunidad](/es-ES/guides/hagitask/community).

## Responsabilidades de las fuentes de referencia

- La documentación mantiene las explicaciones y guías de uso para usuarios y colaboradores.
- HagiTask mantiene el esquema compartido y las fuentes de las tareas predefinidas.
- Community Packages mantiene los datos fuente de los paquetes comunitarios.
- HagiTask Site publica el catálogo, los detalles y los archivos generados a partir de los paquetes.
