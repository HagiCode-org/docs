---
title: Usar HagiTask
description: Descubre, instala, activa, actualiza y ejecuta tareas HagiTask, y conoce los límites de la gestión de fuentes.
---

**A quién va dirigida:** personas que ya tienen HagiCode instalado y necesitan gestionar o ejecutar tareas.

**Requisitos previos:** has [instalado HagiTask](/es-ES/guides/hagitask/installation) o la aplicación ya incluye tareas predefinidas.

## Descubrir tareas

Abre la interfaz de gestión de HagiTask y tareas comunitarias de la aplicación. Reúne las tareas integradas, los paquetes comunitarios instalados, los paquetes del espacio de trabajo y las fuentes gestionadas, e indica el origen de cada tarea y si se puede eliminar. El catálogo de la Community Gallery sirve para descubrir y obtener paquetes comunitarios; los directorios visibles para el servidor sirven para descubrir fuentes de tareas durante la ejecución.

## Instalar tareas

Selecciona una tarea en la Gallery e instálala, o instala localmente un ZIP admitido que ya hayas obtenido. Una vez instalada, la aplicación registra el ID canónico, la versión, el editor, el origen, el resumen del archivo y el directorio de instalación. Una tarea ya instalada con el mismo ID no se sobrescribe sin avisar: primero hay que gestionar la instalación existente.

## Activar y desactivar

- **Activar:** incorpora una tarea instalada al catálogo activo para que se pueda descubrir y ejecutar.
- **Desactivar:** conserva el registro de instalación y los archivos del paquete, pero retira la tarea del catálogo activo; ya no se puede ejecutar.
- **Desinstalar:** solo es posible con tareas comunitarias que tengan un registro de instalación. Las tareas integradas son entradas informativas y no se pueden desinstalar.

Después de un cambio de estado, la aplicación actualiza el catálogo. Si falla la actualización, la operación debe conservar el estado funcional anterior, en lugar de dejar el catálogo actualizado a medias.

## Actualizar y ejecutar

Utiliza la acción de actualizar para volver a leer el catálogo actual de tareas. Si fuerzas la actualización del catálogo de la Gallery, la aplicación lo descarga y verifica de nuevo; si falla temporalmente la fuente, puede seguir usando una caché válida que ya exista. La actualización no cambia automáticamente ni el estado de activación ni la versión de las tareas.

Antes de ejecutar una tarea, confirma que está activada y que se cumplen sus dependencias; después, iníciala desde su panel o la opción de ejecución correspondiente. Si no aparece, actualiza primero el catálogo y revisa el estado de instalación, el ID de la tarea y los avisos de compatibilidad. Si el esquema o los recursos del paquete no son válidos, consulta la [guía para contribuir a la comunidad](/es-ES/guides/hagitask/community).

## Gestión de paquetes y gestión de fuentes del servidor

Estas dos operaciones suelen confundirse:

| Función | Finalidad | Significado de la ruta |
| --- | --- | --- |
| Gestión de paquetes | Instalar, activar, desactivar y desinstalar paquetes HagiTask locales. | Directorio de datos gestionado por la aplicación. |
| Gestión de fuentes del servidor | Configurar las fuentes donde el entorno de ejecución descubre tareas. | Directorio visible para el servidor. |

El backend lee las rutas de las fuentes del servidor para descubrir paquetes de tareas en esos directorios: no son rutas del navegador ni controles para subir archivos. El proceso de instalación actual no sube directamente carpetas locales del navegador como paquetes de la Community Gallery. Para instalar un paquete, utiliza la Gallery o el procedimiento admitido para ZIP locales.

## Si una tarea no está disponible

1. Comprueba que el ID, la versión y el registro de instalación de la tarea siguen existiendo.
2. Confirma que la tarea está activada y que los agentes, skills y herramientas CLI necesarios están preparados.
3. Actualiza el catálogo de tareas y vuelve a abrir la interfaz de gestión.
4. Si la fuente es un directorio del servidor, comprueba que el proceso backend tiene permisos de lectura sobre la ruta.
5. Si falla la verificación del archivo o de los recursos del paquete, vuelve a la [solución de problemas de instalación](/es-ES/guides/hagitask/installation). Si mantienes el paquete, consulta [Contribuir a la comunidad](/es-ES/guides/hagitask/community).
