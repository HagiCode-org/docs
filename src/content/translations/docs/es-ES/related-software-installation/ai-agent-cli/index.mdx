Esta página es la entrada unificada de HagiCode para la instalación local de AI Agent CLI. HagiCode admite actualmente de forma activa 11 Agent CLI: Claude Code, Codex, GitHub Copilot, OpenCode, Hermes, QoderCLI, Kiro, Kimi, Gemini, DeepAgents y Codebuddy.

:::tip[Cómo utilizar esta página]
Primero consulte la tabla para conocer el **estado actual** y el **modo de configuración** de cada CLI; después continúe con la documentación oficial correspondiente para la instalación, la autenticación, ACP, los permisos y la solución de problemas. Lo importante es que **si está admitido** y **si admite la instalación con un clic** son dos cuestiones distintas.
:::

:::note[Prepare primero Node.js 24+]
La mayoría de los CLI que admiten la instalación con un clic dependen de Node.js y npm, y Desktop también usa los `node` y `npm` de su sistema (Desktop ya no incluye Node.js). Prepare primero la versión 24 o superior siguiendo [Instalar Node.js](/es-ES/related-software-installation/nodejs/installation) y, cuando termine la instalación, **inicie sesión o autentíquese**: el asistente de inicialización solo lista los CLI detectados en la máquina.
:::

## Descripción de los estados

- **Actualmente compatible** significa que la CLI pertenece al rango de soporte activo actual de HagiCode y puede usarse en el sistema como un Agent CLI vigente.
- **Instalación con un clic** significa que HagiCode proporciona un punto de entrada de instalación guiada; algunas CLI aún requieren un paso de autenticación o inicio de sesión del proveedor después de la instalación.
- **Instalación manual/autenticación** significa que la CLI está dentro del rango de soporte actual, pero debe finalizar usted mismo la instalación local, el inicio de sesión o la autenticación antes de volver a HagiCode y actualizar el estado de disponibilidad.
- **Solo compatibilidad heredada** significa que iFlow CLI se conserva únicamente por compatibilidad con datos antiguos; no forma parte de la lista de soporte activo actual y no debe considerarse una opción recomendada vigente.
