Se ha eliminado el soporte integrado de OmniRoute en HagiCode. El producto ya no incluye pasos de instalación, ajustes, pruebas de conexión ni sincronización del catálogo de modelos de OmniRoute.

Para conectar modelos ahora:

- usa un modelo conectado mediante Magpie, o
- configura un proveedor y un modelo que tu Agent CLI admita de forma nativa.

HagiCode no migra los endpoints ni las claves antiguos de OmniRoute. Selecciona un proveedor y un modelo compatibles en tu configuración. Para la instalación de la Agent CLI, consulta [Instalación de AI Agent CLI](/es-ES/related-software-installation/ai-agent-cli/).

## Documentación independiente de OmniRoute

OmniRoute es un proyecto independiente con su propio sitio de documentación. HagiCode no lo admite.
