HagiCode evita que la IA pierda el contexto cuando modifica tu código: **primero comprende el repositorio, define el alcance y después ejecuta dejando un rastro trazable.** Es un espacio de trabajo con IA para el desarrollo de proyectos que conecta los Agent CLI y modelos que ya utilizas, de modo que no necesitas cambiar de editor.

No hace falta crear una propuesta para cada tarea: si solo quieres explorar el código o resolver algo sencillo, comienza con una sesión de conversación. HagiCode ofrece un camino trazable cuando una tarea necesita más contexto.

## Funciones en detalle

### Comprender antes de actuar

HagiCode separa «leer el código» de «modificar el código», de modo que puedes elegir según el tamaño de la tarea en lugar de dejar que la IA edite todo directamente.

- **Sesión de conversación:** de solo lectura de forma predeterminada. Úsala para explorar un repositorio, investigar un problema o preguntar dónde está cierta lógica. Cambia al modo de edición solo cuando necesites modificar archivos.
- **Sesión de propuesta:** para cambios complejos. Elige el proyecto y el alcance de repositorios, define los objetivos, las tareas y los pasos de verificación, y pasa a la ejecución cuando el plan te convenza.
- **Tablero de sesiones:** los carriles Proposal & Review, Execution y Archived muestran de un vistazo en qué punto está cada sesión. Puedes alternar entre las disposiciones Classic, Execution Flow Kanban y Dashboard Kanban.

Más información: [Crear una sesión de conversación](/es-ES/quick-start/conversation-session) · [Crear una sesión de propuesta](/es-ES/quick-start/proposal-session) · [El tablero de sesiones](/es-ES/user-guide/sessions)

### Un solo alcance entre repositorios

Cuando una solicitud afecta a la vez al frontend, al backend y a la documentación, MonoSpecs permite que HagiCode los entienda como un único proyecto.

- Registra las ubicaciones de los subrepositorios, las URL de Git y los nombres visibles en `.hagicode/monospecs.yaml`.
- Las especificaciones de cambio (OpenSpec) viven en el repositorio principal, así que los directorios de código de los subrepositorios se mantienen limpios.
- Al crear una propuesta, elige qué subrepositorios involucra. La página del proyecto muestra la rama y los cambios sin confirmar de cada repositorio.

![Página de un proyecto MonoSpecs con la rama y el estado de cambios de 11 repositorios, y acciones de VS Code, Git y AI Compose Commit](../img/screenshots/monospecs/hover-project-show-repository-status/original.png)

Más información: [Guía de MonoSpecs](/es-ES/guides/monospecs)

### Conserva tu Agent CLI

HagiCode no sustituye tu conjunto de herramientas: lo reúne en un único espacio de trabajo.

- **Un Agent es un CLI, un modelo y un texto de personalidad opcional.** Crea varios Agents, asígnalos a escenarios de ejecución y configura grupos de respaldo.
- Es compatible con 11 Agent CLI, entre ellos Claude Code, Codex y GitHub Copilot. El espacio de trabajo muestra la versión, el tiempo de respuesta y el estado de cada CLI.
- Con [OmniRoute](/es-ES/related-software-installation/omniroute/) puedes conectar varias herramientas y modelos compatibles con OpenAI a una única pasarela local, mientras que las conexiones del CLI y de los modelos se gestionan por separado.

![Ventana emergente de AI Monitoring con Claude Code, Codex, GitHub Copilot y otros Agent CLI, con su versión, tiempo de respuesta y estado](../img/screenshots/shared/status-of-agent-clis/original.png)

Más información: [Espacio de trabajo de Agents](/es-ES/user-guide/agents) · [Instalación y compatibilidad de AI Agent CLI](/es-ES/related-software-installation/ai-agent-cli/)

### Skills

El panel de Skills reúne en un único acceso los skills que ya tienes en tu equipo y los que puedes instalar desde la galería.

- **Local Skills:** consulta lo que hay instalado en este equipo y busca actualizaciones por lotes.
- **Gallery:** busca por palabra clave y origen, y comprueba si un skill ya está instalado.
- **Trusted Providers:** antes de instalar, confirma el origen, su nivel de confianza y el comando que se ejecutará realmente, y decide qué orígenes se consideran de confianza.

![Galería de Skills con un campo de búsqueda, filtros de origen y una tabla de skills, orígenes y número de instalaciones](../img/screenshots/shared/skills-gallary/original.png)

Más información: [Guía de Skills](/es-ES/guides/skills)

### Vault y Code Server

- Un **Vault** es una carpeta ajena a los repositorios de tu proyecto que HagiCode puede explorar. Úsalo para documentos de referencia, notas y resultados de investigación. Admite tres tipos: Folder, CodeRef y Obsidian.
- Al crear una sesión, elige qué Vaults incluir en su alcance. Marca uno como editable para que la IA pueda escribir en él; de lo contrario, es solo material de referencia de solo lectura.
- **Code Server** ofrece un punto de edición en el navegador al que puedes acceder directamente desde un Vault o un proyecto.

### AI Compose Commit

Haz clic en «AI Compose Commit» en la pestaña Git y HagiCode lee tus cambios actuales y redacta los mensajes de commit en formato Conventional Commits.

- Los cambios relacionados se agrupan en varios commits en lugar de uno solo que lo abarque todo.
- En los proyectos MonoSpecs, los cambios se confirman en el subrepositorio correcto.
- Se añade automáticamente una etiqueta Co-Authored-By, cuyo nombre y correo se pueden definir por proyecto o de forma global.

![El botón AI Compose Commit en la pestaña Git](../img/screenshots/ai-compose-commit/trigger-ai-compose-commit-button/original.png)

Más información: [Guía de AI Compose Commit](/es-ES/guides/ai-compose-commit)

### Progreso visible

HagiCode convierte héroes, logros, informes diarios y métricas Token en información de seguimiento para que el estado y el progreso sean más fáciles de ver con el tiempo, y esto es una de las cosas que lo distingue de las herramientas de programación con IA habituales. En la [introducción al Equipo de Aventureros](/es-ES/adventure-team-introduction) puedes ver cómo se agrupan los héroes y cómo avanzan las mazmorras; para conocer el planteamiento del diseño, consulta el [artículo sobre el diseño de la gamificación](/es-ES/blog/2026-03-16-gamifying-ai-coding/). Forma parte de la experiencia del espacio de trabajo, y puedes seguir usando HagiCode como una herramienta de desarrollo normal sin ella.

![Sala de logros con el progreso diario y global, el estado del ciclo y las métricas del ciclo de vida de las propuestas](../img/screenshots/shared/achivement-view/original.png)

Más información: [Barra de estado y progreso](/es-ES/user-guide/status-bar-and-progress)

## Para quién es

- **Encaja bien con:** desarrolladores y equipos que mantienen varios repositorios y quieren planificar los cambios complejos antes de ejecutarlos, y personas que ya usan Agent CLI como Claude Code o Codex y quieren tenerlos en un único espacio de trabajo.
- **No es imprescindible:** si solo necesitas completar unas pocas líneas en tu editor, tus herramientas actuales son suficientes.

## Ediciones y precios

Las funciones básicas son gratuitas. Desktop y Microsoft Store son dos formas distintas de obtener HagiCode, no dos niveles de pago. El canal de Microsoft Store ofrece además Turbo Engine, una compra única independiente que desbloquea un límite más alto de propuestas simultáneas y mejoras como temas para la documentación, atribución personalizada, elementos de marca y avatares. Consulta el [complemento Turbo Engine](/es-ES/dlc/turbo-engine-dlc/) para conocer las funciones concretas que desbloquea.

| Tu entorno | Opción recomendada |
| --- | --- |
| Windows con acceso a Microsoft Store | [Instalar desde Microsoft Store](/es-ES/installation/windows-store) |
| Instalación manual en Windows o uso local en macOS o Linux | [Instalar Desktop](/es-ES/installation/desktop) |

La aplicación principal de Steam se ha retirado y ya no es un canal de instalación. Consulta el [estado de distribución en Steam](/es-ES/faq/steam-distribution-status/).

## ¿Por qué un espacio de trabajo?

Soy Kun Yu, el creador de HagiCode. Una pregunta con su respuesta puede resolver un problema inmediato, pero el desarrollo real también exige comprender el proyecto, delimitar el trabajo, llevar a cabo los cambios y revisar el resultado. Quise reunir estos pasos antes dispersos; la información gamificada ayuda a ver el progreso en el trabajo de larga duración. Puedes usar solo algunas de estas funciones: no tienes que aprender todos los módulos antes de empezar a programar.
