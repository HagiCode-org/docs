HagiCode es un espacio de trabajo con IA para desarrollar proyectos. Puedes empezar con una sesión para comprender un repositorio, definir los requisitos y su alcance, dejar que la IA realice los cambios y, desde el mismo lugar, consultar el progreso, preparar commits y reutilizar el conocimiento del proyecto. Conecta los Agent CLI y modelos que ya utilizas, sin exigirte un editor de código concreto.

**¿Es tu primera vez?** [Elige cómo instalarlo](/es-ES/installation/), completa el [asistente de configuración](/es-ES/quick-start/wizard-setup), crea un proyecto y empieza con una [sesión de conversación](/es-ES/quick-start/conversation-session). Si la tarea requiere planificar antes de implementarla, utiliza una [sesión de propuesta](/es-ES/quick-start/proposal-session).

## Cómo se desarrolla una tarea

Por ejemplo, supongamos que necesitas modificar una función que afecta a varios repositorios:

1. **Primero, comprende el código:** Analiza el código existente en una [sesión de conversación](/es-ES/quick-start/conversation-session). Estas sesiones son de solo lectura de forma predeterminada; cambia al modo de edición cuando necesites modificar archivos.
2. **Después, define el alcance:** Para un cambio complejo, selecciona el proyecto y los repositorios en una [sesión de propuesta](/es-ES/quick-start/proposal-session). Define los objetivos, las tareas y cómo verificar el resultado antes de pasar a la ejecución.
3. **Sigue el resultado:** Consulta las sesiones y el estado de ejecución en el espacio de trabajo. Si necesitas preparar un commit, utiliza [AI Compose Commit](/es-ES/guides/ai-compose-commit).
4. **Conserva el contexto:** Puedes consultar más adelante las propuestas y el historial de commits. Para trabajar entre repositorios, usa [MonoSpecs](/es-ES/guides/monospecs) a fin de gestionar sus relaciones y el alcance de los cambios.

No hace falta crear una propuesta para cada tarea: si solo quieres explorar el código o resolver algo sencillo, comienza con una sesión de conversación. HagiCode ofrece un proceso que puedes seguir cuando una tarea necesita más contexto.

Vault reúne repositorios de referencia, carpetas y notas para reutilizarlos más adelante; Code Server proporciona acceso a la edición desde el navegador. No necesitas ninguno de los dos para empezar a usar HagiCode. Si quieres conocer el diseño, consulta [la base de conocimientos Vault](/es-ES/blog/2026-04-10-vault-system-ai-knowledge-base/) y [la integración de la edición en el navegador](/es-ES/blog/2026-04-13-vscode-web-integration-browser-editing/).

HagiCode también ofrece información sobre el progreso mediante héroes, logros, informes diarios y métricas Token, para que el estado del trabajo continuado sea más visible. Forman parte de la experiencia del espacio de trabajo, pero no son necesarios para usarlo como una herramienta de desarrollo normal. Consulta el [artículo sobre el diseño de la gamificación](/es-ES/blog/2026-03-16-gamifying-ai-coding/).

## Ediciones y precios

**Desktop, Container y Microsoft Store son distintas formas de obtener o desplegar HagiCode, no tres niveles de pago.** Las funciones básicas se pueden usar gratis. Turbo Engine, en el canal de Microsoft Store, es una licencia independiente de pago único que aumenta el límite de propuestas simultáneas y desbloquea mejoras como temas para la documentación, atribución personalizada, elementos de marca y avatares. Consulta el [complemento Turbo Engine](/es-ES/dlc/turbo-engine-dlc/) para conocer las funciones concretas que desbloquea.

| Tu entorno | Opción recomendada |
| --- | --- |
| Windows con acceso a Microsoft Store | [Instalar desde Microsoft Store](/es-ES/installation/windows-store) |
| Instalación manual en Windows o uso local en macOS o Linux | [Instalar Desktop](/es-ES/installation/desktop) |
| Servidor, NAS o despliegue para equipos | [Instalar con Docker Compose](/es-ES/installation/docker-compose) |

La aplicación principal de Steam se ha retirado y ya no es un canal de instalación. Consulta el [estado de distribución en Steam](/es-ES/faq/steam-distribution-status/).

## ¿Por qué un espacio de trabajo?

Soy Kun Yu, el creador de HagiCode. Una pregunta con su respuesta puede resolver un problema inmediato, pero el desarrollo real también exige comprender el proyecto, delimitar el trabajo, llevar a cabo los cambios y revisar el resultado. Quise reunir estos pasos antes dispersos; la información gamificada ayuda a ver el progreso del trabajo a largo plazo. Puedes usar solo algunas funciones: no tienes que aprender todos los módulos antes de empezar a programar.
