Esta página explica cómo instalar y usar Hagicode Desktop. Es el cliente de escritorio oficial y reúne en un mismo lugar el flujo de instalación local predeterminado y los controles de uso diario.

:::tip[Método recomendado]
Para uso local personal en macOS, Linux y Windows sin Microsoft Store, se recomienda Desktop:
- La guía del primer arranque enlaza la descarga y el inicio en un mismo flujo
- La aplicación gestiona de forma unificada el inicio, la parada y las versiones de Hagicode Server
- La interfaz gráfica facilita consultar el estado y realizar operaciones
- La gestión de versiones integrada permite cambiar entre versiones
- Los datos permanecen en local por defecto, bajo su propio control

Si usa Windows, considere primero la [Instalación desde Microsoft Store](/es-ES/installation/windows-store); para despliegues en servidor o en equipo, use [Docker Compose](/es-ES/installation/docker-compose).
:::

## ¿Qué es Hagicode Desktop?

Hagicode Desktop es la aplicación de escritorio oficial de Hagicode y es compatible con Windows, macOS y Linux. Se encarga de descargar, iniciar y gestionar el Hagicode Server de su equipo, y ofrece gestión de versiones y los puntos de entrada para el uso diario.

### Principales ventajas

- **Runtime de .NET integrado**: el `.NET` necesario para ejecutar Hagicode Server se incluye con Desktop, por lo que no hay que instalarlo por separado
- **Gestión del servicio**: gestión integrada de Hagicode Server para iniciar y detener el servicio fácilmente
- **Cambio de versión**: admite varias versiones y permite cambiar libremente entre ellas
- **Ejecución local**: todos los datos se almacenan en local, lo que protege su privacidad
- **Detección de versiones**: detecta automáticamente las nuevas versiones disponibles

### Escenarios aplicables

Priorice Desktop en estos casos:
- Desarrolladores individuales que quieren usar Hagicode en local
- Usuarios que prefieren que sus datos y proyectos permanezcan en su propio equipo
- Usuarios que prefieren una interfaz gráfica y no quieren escribir configuraciones de despliegue a mano
- Desarrolladores que necesitan cambiar con frecuencia entre distintas versiones

## Requisitos previos

Desktop **no incluye Node.js** y tampoco ofrece ya un entorno de ejecución de Node propio. Usa los `node` y `npm` del `PATH` del sistema e instala los paquetes gestionados, como los Agent CLI, en el directorio global de npm de su equipo. Antes de empezar, prepare lo siguiente:

| Dependencia | Requisito | Descripción |
| --- | --- | --- |
| Node.js | **24 o superior** | También proporciona `npm`; consulte [Instalar Node.js](/es-ES/related-software-installation/nodejs/installation) |
| Git | Cualquier versión estable actual | Se comprueba al iniciar; el "Proyecto de demostración" del cuadro de diálogo "Nuevo proyecto" lo necesita para clonar el repositorio de ejemplo; consulte [Instalar Git](/es-ES/installation/#instalar-git) |
| Agent CLI | Al menos uno, con la sesión iniciada | El asistente solo lista los CLI detectados en el equipo; consulte [Instalación de AI Agent CLI](/es-ES/related-software-installation/ai-agent-cli/) |

Compruebe primero las versiones en la terminal:

```bash
node --version   # Se requiere v24.0.0 o superior
npm --version
git --version
```

:::caution[Instálelos antes de iniciar, o reinicie Desktop]
Desktop lee el `PATH` del sistema al iniciarse. Si instala Node.js o Git con Desktop ya abierto, ciérrelo por completo y vuelva a iniciarlo; después actualice la página de dependencias.
:::

### Descarga rápida

En Windows se recomienda usar primero la instalación desde Microsoft Store; utilice el acceso de descarga manual que aparece más abajo solo si necesita un paquete de instalación manual, un archivo de una versión concreta o si la Store no está disponible.

:::note[Si la lista de descargas no se carga]
Si la lista de instaladores de Desktop no se puede cargar por el momento, el punto de entrada de instalación no mostrará un enlace de descarga no válido, sino que le dirigirá a la página oficial del historial de versiones: [index.hagicode.com/desktop/history](https://index.hagicode.com/desktop/history/). ### Otras formas de obtenerlo

También puede obtener el instalador de Hagicode Desktop en los siguientes canales:

1. **Opción recomendada por defecto en Windows**: visite la [Instalación desde Microsoft Store](/es-ES/installation/windows-store) para usar el canal de distribución de la tienda oficial
2. **Página oficial de versiones**: visite [Hagicode GitHub Releases](https://github.com/Hagicode-org/releases/releases) para descargar el paquete de instalación manual
3. **Sitio web oficial**: visite el [sitio web de Hagicode](https://www.hagicode.com/) para obtener los enlaces de descarga y las instrucciones de instalación

### Elija la versión correcta

Seleccione el instalador correspondiente a su sistema operativo:

- **Windows**: use preferentemente Microsoft Store; si necesita un archivo de instalación manual, descargue el instalador `.exe` o el paquete `.msix`
- **macOS**: descargue el instalador `.dmg`
- **Linux**: descargue el paquete de instalación `.AppImage` o `.tar.gz`

:::note[Requisitos del sistema]
- **Windows**: Windows 10 o superior (64 bits)
- **macOS**: macOS 10.15 o superior
- **Linux**: distribuciones Linux habituales (Ubuntu 20.04+, Fedora 33+, etc.)
:::

:::tip[Dependencias que debe preparar usted]
Desktop ya incluye el runtime de `.NET` necesario para ejecutar Hagicode Server y completa la inicialización predeterminada con la ruta SQLite local actualmente admitida, por lo que no necesita instalar `.NET` por separado. Sin embargo, **Node.js 24+ y Git los debe instalar usted mismo**; consulte los [Requisitos previos](#requisitos-previos) anteriores.
:::

## Notas de instalación y lanzamiento

:::caution[Aviso de Gatekeeper en macOS]
Si ya instaló la aplicación en la ruta predeterminada `/Applications/Hagicode.app`, pero en el primer arranque aparece "la aplicación está dañada", "no se puede abrir" o un aviso de Gatekeeper similar, la causa habitual es el atributo de cuarentena `com.apple.quarantine` que macOS añade a las aplicaciones descargadas de Internet, y no un fallo del asistente de instalación de Hagicode Desktop.

Puede ejecutar el siguiente comando en la terminal. Requiere privilegios de administrador y elimina de forma recursiva el atributo de cuarentena de la aplicación en la ruta de instalación predeterminada:

```bash
sudo xattr -dr com.apple.quarantine /Applications/Hagicode.app
```

Cuando termine, reinicie Hagicode Desktop.
:::

## Ejecutar Desktop

Tras la descarga, abra el instalador o el paquete de la aplicación para completar la instalación y, después, inicie Hagicode Desktop.

:::note[Requisitos de red]
Asegúrese de que su conexión de red funciona. Desktop necesita obtener de Internet la información de versiones y el paquete de instalación de Hagicode Server; si la descarga falla, revise la configuración de red, proxy o cortafuegos y vuelva a intentarlo.
:::

## Guía de primer arranque

La primera vez que abra Desktop, accederá primero a la guía "Configuración por primera vez" que incluye Desktop. Su única función es instalar e iniciar Hagicode Server, y consta de los siguientes pasos, en este orden:

1. **Elegir idioma**: seleccione el idioma que usará Desktop. El primer arranque del backend integrado también adoptará el idioma predeterminado correspondiente.
2. **Bienvenida**: conozca los preparativos que completará esta guía.
3. **Confirmar los documentos legales**: confirme las revisiones actuales del CLUF (EULA) y de la Política de privacidad; los documentos oficiales se abren en el navegador para su lectura.
4. **Descargar Hagicode Server**: descargue el último paquete de instalación de Server y verifique su resumen (hash).

Cuando termine la descarga, vuelva a la página de inicio de Desktop y haga clic en "Iniciar servicio" para arrancar Hagicode Server; después, siga las indicaciones de la página de inicio para abrir la interfaz web.

:::note[Puede que no aparezcan todos los pasos]
En algunos canales de distribución (por ejemplo, las versiones cuyo paquete de instalación ya incluye Server), o cuando tras una actualización de versión solo hace falta volver a confirmar los documentos legales, la guía muestra únicamente una parte de estos pasos.
:::

## Gestión de versiones

Hagicode Desktop admite la gestión de varias versiones, lo que le permite cambiar libremente entre ellas.

![Gestión de versiones](../../img/screenshots/installation/install-desktop/12-version-management/original.png)

### Cambiar de versión

1. Abra Hagicode Desktop
2. Vaya a la página "Gestión de versiones"
3. Seleccione la versión a la que quiere cambiar
4. Haga clic en el botón "Cambiar"
5. Espere a que termine el cambio

:::note[Notas sobre el cambio de versión]
- Cambiar de versión reinicia automáticamente Hagicode Server
- Guarde todo su trabajo antes de cambiar
- La configuración de los proyectos puede diferir entre versiones
:::

## Iniciar y detener el servicio

Hagicode Desktop ofrece una forma sencilla de gestionar el servicio Hagicode Server.

### Iniciar el servicio

En la página de inicio de la aplicación Desktop, haga clic en el botón "Iniciar servicio" para arrancar Hagicode Server.

![Iniciar servicio](../../img/screenshots/installation/install-desktop/13-start-service-homepage/original.png)

### Detener el servicio

Para detener Hagicode Server, haga clic en el botón "Detener servicio" de la página de inicio.

:::tip[Estado del servicio]
La aplicación Desktop muestra en tiempo real el estado de ejecución de Hagicode Server, que incluye:
- El estado del servicio (en ejecución / detenido)
- El número de puerto del servicio
- La información de la versión actual
:::

## Solución de problemas

### Fallo de instalación

Si surgen problemas durante la instalación:

1. **Compruebe la conexión de red**: asegúrese de poder acceder a Internet
2. **Compruebe el espacio en disco**: asegúrese de que hay suficiente espacio libre
3. **Ejecute como administrador**: en Windows, haga clic con el botón derecho en el instalador y seleccione "Ejecutar como administrador"
4. **Revise los mensajes del instalador**: anote el mensaje de error que muestra el instalador y adjúntelo al enviar un informe del problema

### No se encuentra Node.js, npm o Git

Si Desktop indica que faltan `node`, `npm` o `git`, o que la versión de Node.js es demasiado antigua:

1. **Confirme que están instalados**: ejecute `node --version`, `npm --version` y `git --version` en la terminal. Node.js debe ser la versión 24 o superior; para instalarlos, consulte [Instalar Node.js](/es-ES/related-software-installation/nodejs/installation) e [Instalar Git](/es-ES/installation/#instalar-git).
2. **Reinicie Desktop**: Desktop lee el `PATH` del sistema al iniciarse. Tras la instalación, ciérrelo por completo y vuelva a iniciarlo; después actualice la página de dependencias.
3. **Revise el PATH**: si funciona en la terminal pero Desktop no lo encuentra, normalmente es porque el `PATH` solo se define en la configuración de un shell (por ejemplo, con nvm o fnm en `.bashrc` / `.zshrc`). Use una instalación a nivel de sistema o asegúrese de iniciar Desktop desde un entorno que pueda leer ese `PATH`.
4. **Instale manualmente el paquete CLI**: cuando Desktop indique que hay que instalar un paquete CLI de forma manual, ejecute el comando que muestra en una terminal ajena a Desktop y, al terminar, vuelva a Desktop y actualice. Para el comportamiento del entorno externo de Node / npm y del `PATH`, consulte [Cómo usa Desktop su entorno de Node](/es-ES/faq/desktop-node-environment).

### Fallo de inicio del servicio

Si Hagicode Server no se inicia:

1. **Compruebe si el puerto está ocupado**: Desktop usa por defecto el puerto **36556** (la página de inicio muestra el puerto real en uso); asegúrese de que no lo ocupa otro programa
2. **Revise la configuración del cortafuegos**: asegúrese de que el cortafuegos permite el acceso a la red de Hagicode Server
3. **Reinicie la aplicación**: pruebe a reiniciar Hagicode Desktop
4. **Consulte los registros**: revise los registros de errores detallados en la aplicación Desktop
