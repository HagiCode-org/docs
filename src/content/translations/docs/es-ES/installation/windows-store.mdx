Para los usuarios de Windows, Microsoft Store es actualmente el punto de entrada público del cliente de escritorio. Esta página cubre solo esa ruta Store. Para la guía general de descarga, gestión de versiones y solución de problemas de Desktop, continúa con [Instalación de Desktop](/es-ES/installation/desktop).

La entrada principal de Steam ya fue retirada, así que Microsoft Store es ahora el canal principal para Windows. Para más contexto, consulta [Por qué HagiCode no está disponible en Steam](/es-ES/faq/steam-distribution-status/).

:::tip[Este camino encaja bien si]
- usas Windows 10 o Windows 11 y quieres instalar directamente desde la tienda del sistema
- prefieres recibir el paquete de la aplicación desde la Store en lugar de manejar instaladores manualmente
- solo necesitas un entorno local personal y no planeas un despliegue con Docker Compose
:::

## Antes de empezar

Antes de comenzar, confirma estas condiciones:

- el dispositivo debe poder abrir la [página de Microsoft Store de HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW)
- debe haber red disponible en el primer arranque, porque la aplicación puede necesitar descargar o preparar los componentes que requiere Hagicode Server
- algunos dispositivos, regiones o políticas de organización pueden pedir que inicies sesión antes con una cuenta Microsoft
- si la Store está deshabilitada en tu dispositivo de empresa, cambia a [Instalación de Desktop](/es-ES/installation/desktop)

## Requisitos previos

La versión de la Store funciona igual que Desktop: **no incluye Node.js**, así que debes instalarlo tú y hacer que aparezca en el `PATH` del sistema. Prepara lo siguiente antes del primer arranque:

- **Node.js 24 o superior** (que también proporciona `npm`); consulta [Instalar Node.js](/es-ES/related-software-installation/nodejs/installation)
- **Git**; consulta [Instalar Git](/es-ES/installation/#instalar-git)
- Al menos un **Agent CLI** instalado y con la sesión iniciada; consulta [Instalación de AI Agent CLI](/es-ES/related-software-installation/ai-agent-cli/)

Si los instalas después de que HagiCode ya esté abierto, cierra HagiCode por completo y vuelve a iniciarlo para que lea el nuevo `PATH`.

## Instalar desde Microsoft Store

1. Abre [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW).
2. Haz clic en `Obtener`, `Instalar` o la acción equivalente que muestre la Store.
3. Espera a que Microsoft Store termine la descarga y la instalación.
4. Después inicia HagiCode desde el menú Inicio o directamente desde la página de la Store.

## Qué ocurre en el primer arranque

Después de la instalación, HagiCode todavía continúa con el flujo estándar de inicialización de Desktop.

- el primer arranque entra primero en la guía de primer uso de Desktop: elegir idioma, confirmar los documentos legales y, si hace falta, descargar Hagicode Server; por eso puede ser más lento que una aplicación normal
- el canal Microsoft Store / MSIX bloquea intencionadamente el ajuste "Ruta de almacenamiento de datos del runtime", un comportamiento esperado de este modo de distribución
- la aplicación no se actualiza sola de forma independiente; la entrega del paquete depende del canal de instalación, y en la versión Store queda ligada al canal Microsoft Store

Si quieres seguir con el asistente de inicialización, revisa [Configuración del asistente](/es-ES/quick-start/wizard-setup).

## Cuándo usar otro canal

Estos casos encajan mejor con otro canal:

- no puedes acceder a Microsoft Store o tu organización bloquea expresamente la instalación desde la Store
- necesitas descargar manualmente archivos `.exe` o `.msix` y controlar por tu cuenta la fuente del instalador
- vas a desplegar en un servidor, NAS o entorno de equipo, en cuyo caso es mejor consultar [Implementación con Docker Compose](/es-ES/installation/docker-compose)

## Solución de problemas

### La página de Microsoft Store no se abre

Primero comprueba la red, la configuración de región y el estado de inicio de sesión de Microsoft Store. Si el enlace del navegador se abre pero el cliente Store sigue sin estar disponible, lo más habitual es una política local del sistema. En ese caso, usa [Instalación de Desktop](/es-ES/installation/desktop).

### Por qué algunos ajustes aparecen en gris

Las instalaciones Store / MSIX bloquean la opción "Ruta de almacenamiento de datos del runtime" y muestran "Bloqueado por Microsoft Store". No es un fallo de instalación, sino una restricción del canal de distribución actual.

### Por qué el primer arranque sigue descargando o preparando contenido

La instalación desde la Store solo entrega el paquete de la aplicación de escritorio. En el primer arranque, HagiCode todavía puede descargar o preparar los componentes que necesita Hagicode Server y completar la inicialización por defecto. Mantén la red disponible y espera a que finalice el paso actual.
