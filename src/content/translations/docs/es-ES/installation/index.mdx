## Requisitos previos

Cada ruta tiene requisitos previos distintos:

| Método de instalación | Node.js | Git |
| --- | --- | --- |
| Microsoft Store / Desktop | Debe instalarlo usted mismo: **versión 24 o superior** | Debe instalarlo usted mismo |
| Docker Compose | No es necesario en el host | No es necesario en el host |

:::caution[Desktop ya no incluye Node.js]
Desktop solo incluye el runtime de .NET necesario para ejecutar HagiCode Server y **ya no proporciona Node.js**. Busca `node` y `npm` en el `PATH` del sistema e instala los paquetes gestionados, como los Agent CLI, en el directorio global de npm de su equipo. Instale Node.js 24 o superior antes de iniciar Desktop por primera vez; consulte [Instalar Node.js](/es-ES/related-software-installation/nodejs/installation).
:::

### Instalar Git

Desktop comprueba `node`, `npm` y `git` al iniciarse, y el "Proyecto de demostración" del cuadro de diálogo "Nuevo proyecto" de la interfaz principal también necesita Git para clonar el repositorio de ejemplo oficial. Elija una forma de instalarlo según su sistema:

- **Windows**: ejecute `winget install --id Git.Git -e` o descargue el instalador desde [git-scm.com](https://git-scm.com/downloads).
- **macOS**: ejecute `xcode-select --install` o, con Homebrew, `brew install git`.
- **Debian / Ubuntu**: ejecute `sudo apt-get install -y git`.
- **Fedora**: ejecute `sudo dnf install -y git`.

Cuando termine la instalación, vuelva a abrir la terminal y confirme que los comandos funcionan:

```bash
node --version
npm --version
git --version
```

:::tip[Inicie Desktop después de instalarlos]
Desktop lee el `PATH` del sistema al iniciarse. Si instala Node.js o Git con Desktop ya abierto, ciérrelo por completo y vuelva a iniciarlo.
:::

### Agent CLI

HagiCode funciona con los Agent CLI que estén instalados y con la sesión iniciada en su equipo. El asistente de inicialización solo lista los CLI detectados localmente, así que instale al menos uno e inicie sesión antes de entrar en el asistente. Los CLI admitidos, sus métodos de instalación y los puntos de entrada oficiales se mantienen en [Instalación de AI Agent CLI](/es-ES/related-software-installation/ai-agent-cli/).
