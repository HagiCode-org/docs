Un **Agent** en HagiCode es un trabajador listo para usar, formado por una Agent CLI (por ejemplo, Claude Code), un modelo y un texto de personalidad opcional. Las sesiones las ejecuta un Agent, así que necesita al menos un Agent antes de empezar a trabajar.

Haga clic en **Agents** (interfaz en chino: Agents) en la barra superior para abrir el **Agents Workspace** (espacio de trabajo de Agents). Tiene seis pestañas.

| Pestaña | Uso |
| --- | --- |
| [Agents](#agents-标签页) | Crear y administrar sus Agents. |
| [Execution Scenarios (Escenarios de ejecución)](#执行场景) | Decidir qué Agents ejecutan cada tipo de trabajo. |
| [AgentCLI](#agentcli) | Ver qué Agent CLI están instaladas, si están sanas y si están habilitadas. |
| [Model (Modelo)](#模型) | Explorar y ampliar el catálogo de modelos de cada Agent CLI. |
| [Document Theme (Tema de documento)](#文案主题) | Elegir el tema de textos de la interfaz. |
| [Avatar Gallery (Galería de avatares)](#头像画廊) | Explorar los paquetes de avatares. |

:::note
AgentCLI y el catálogo de modelos son de nivel de sistema. La pestaña Agents solo guarda sus Agents actuales y sus equipos.
:::

## Agents 标签页

![Pestaña Agents, con la lista My Agents agrupada por Agent CLI y mostrando el Agent Hagicoder](../img/user-guide/agents/01-agents.png)

**My Agents** (Mis Agents) enumera sus Agents y los agrupa según la Agent CLI que usan. Cada tarjeta muestra el avatar, el nombre, el modelo y un pequeño distintivo que representa la CLI.

- **New Agent** (Nuevo Agent) abre el cajón de creación.
- **Batch create Agents** (Crear Agents en lote) crea varios a la vez.
- **Search** (Buscar) filtra por nombre del Agent, Agent CLI o descripción.
- **Select all visible** (Seleccionar todo lo visible), **Clear visible** (Limpiar lo visible) y **Delete N selected** (Eliminar N seleccionados) sirven para la eliminación por lotes.

### 创建 Agent

![Cajón New Agent, con las secciones de equipamiento del Agent, rasgos y alma](../img/user-guide/agents/02-new-agent.png)

El cajón crea un Agent cada vez. Hasta que la creación tenga éxito, la vista Agents no cambia.

- **Name and avatar** (Nombre y avatar): se sugiere un nombre aleatorio de un conjunto de nombres. Subir un avatar personalizado requiere el DLC de TurboEngine.
- **Agent loadout** (Equipamiento del Agent): dos ranuras obligatorias. Haga clic en un icono candidato para equiparlo:
  - **AgentCLI**: la herramienta de línea de comandos que ejecuta el Agent.
  - **Model** (Modelo): el modelo que usa esa CLI. La lista solo muestra modelos compatibles con la CLI seleccionada.
- **Trait · knowledge and behavior** (Rasgo · conocimiento y comportamiento): texto libre, o un rasgo de la Trait platform (plataforma de rasgos), que da forma a la manera de trabajar del Agent.
- **Soul · language style** (Alma · estilo de lenguaje): texto libre, o un alma de la Soul platform (plataforma de almas), que da forma al estilo de habla del Agent.
- Interruptor **Battle ready** (Listo para combate): habilita o deshabilita el Agent.

## 执行场景

Corresponde a la pestaña **Execution Scenarios**.

![Pestaña Execution Scenarios, con los escenarios de propuesta, HagiTask y chat, y el editor de equipos](../img/user-guide/agents/03-execution-scenarios.png)

Un escenario decide qué Agent se usa para cada tipo de trabajo. Los escenarios se agrupan según dónde aparecen:

| Grupo | Escenarios |
| --- | --- |
| **Proposal** (Escenarios de ejecución de propuestas) | Optimize Proposal (Optimizar propuesta), Generate Proposal (Generar propuesta), Execute Proposal (Ejecutar propuesta), Archive Proposal (Archivar propuesta) |
| **HagiTask** (Escenarios de ejecución de Hagitask) | AI commit (Commit con IA), Create Normal Session (Crear sesión normal), Create Research Investigation Task (Crear tarea de investigación de código) |
| **Chat** (Escenarios de ejecución de chat) | Conversation Title Optimization (Optimización del título de la conversación) |

**Fallback Crew** (Tripulación de respaldo) es la red de seguridad. Cuando el equipo propio de un escenario no tiene un Agent adecuado, HagiCode prueba miembros elegibles de la tripulación de respaldo en orden aleatorio. Es obligatoria: **todos los demás escenarios permanecen bloqueados hasta que la tripulación de respaldo tenga al menos un Agent habilitado.** El asistente de inicialización agrega automáticamente su primer Agent.

Haga clic en un escenario para editarlo. **Assigned Agents** (Agents asignados) muestra quién está en el equipo, **Available Agents** (Agents disponibles) muestra quién puede unirse, y las etiquetas de filtro reducen la lista por Agent CLI. El tiempo de ejecución prueba los miembros elegibles en orden aleatorio, así que el orden que ve en pantalla no indica prioridad.

## AgentCLI

![Tabla de administración de AgentCLI, con el estado de habilitación, disponibilidad, versión y monitoreo de cada CLI](../img/user-guide/agents/04-agentcli.png)

Esta pestaña enumera todas las herramientas de línea de comandos que HagiCode puede controlar: Claude Code, Codebuddy, Codex, DeepAgents, DSH, Gemini, GitHub Copilot, Hermes, Junie, Kimi, Kiro, OMP, OpenCode, Pi, QoderCLI y Reasonix.

Para cada CLI puede ver:

- **Enabled** (Habilitado) y **Availability** (Disponibilidad): la CLI debe estar instalada en la máquina que ejecuta HagiCode para estar disponible.
- **CLI version** (Versión de la CLI): la versión detectada; muestra *Not detected* (No detectada) si no se encuentra el ejecutable.
- **Monitoring** (Monitoreo): la última comprobación de salud, por ejemplo *Healthy* (Sana).
- **Show diagnostics** (Mostrar diagnósticos): los detalles detrás del resultado de la comprobación, útiles cuando la CLI no se detecta.
- Un **interruptor** para habilitar o deshabilitar la CLI. Use las casillas junto con **Enable selected** (Habilitar seleccionados) y **Disable selected** (Deshabilitar seleccionados) para cambiar varias a la vez. Los filtros pueden mostrar solo las CLI *Available* (Disponibles) o *Unavailable* (No disponibles).

Si una CLI instalada no se detecta, confirme que su ejecutable esté en el `PATH` del proceso que ejecuta HagiCode y luego recargue. Consulte [Instalación de AI Agent CLI](/related-software-installation/ai-agent-cli).

## 模型

Corresponde a la pestaña **Model**.

![Pestaña Model, con el catálogo de modelos de Claude Code y el formulario Create Model](../img/user-guide/agents/05-model.png)

Seleccione una **AgentCLI** en la parte superior para ver sus modelos. La tabla muestra el nombre de cada modelo, su ID, su origen y si admite imágenes.

- Las entradas **System defaults** (Valores predeterminados del sistema) son de solo lectura y las mantiene HagiCode.
- Las entradas **Custom** (Personalizadas) son suyas. Créelas con el formulario **Create Model** (Nuevo modelo): *Display name* (Nombre para mostrar), *Summary* (Resumen), *Icon* (Icono), *Model value* (Valor del modelo) requerido por la CLI, y si *Supports images* (Admite imágenes). **Create blank entry** (Crear entrada en blanco) empieza con una fila vacía.
- Puede filtrar por nombre o ID del modelo, por origen (*All sources* (Todos los orígenes), *Custom* (Personalizado), *System default* (Predeterminado del sistema), o mostrar solo los modelos con *Support images only* (Solo compatibles con imágenes).

## 文案主题

Corresponde a la pestaña **Document Theme**.

![Pestaña Document Theme, con el tema AgentCLI Baseline activo y los demás temas bloqueados](../img/user-guide/agents/06-document-theme.png)

El tema de textos cambia la redacción de la interfaz. **AgentCLI Baseline** (Base de AgentCLI) usa un lenguaje neutro, por ejemplo *Agents*, *Jobs* (Trabajos) y *Workspace* (Espacio de trabajo), y es el tema predeterminado. Otros temas, como la redacción de *Fantasy Adventure* (Aventura de fantasía), requieren el DLC de TurboEngine; sus vistas previas siguen visibles, pero están bloqueadas. **Restore default theme** (Restaurar tema predeterminado) vuelve al tema base.

## 头像画廊

Corresponde a la pestaña **Avatar Gallery**.

![Galería de avatares, con los paquetes de avatares a la izquierda y la vista previa ampliada del avatar seleccionado a la derecha](../img/user-guide/agents/07-avatar-gallery.png)

Explore los paquetes de avatares disponibles para los Agents. Seleccione un paquete y un avatar para ver su vista previa, su origen de plugin, su versión y su ID estable.
