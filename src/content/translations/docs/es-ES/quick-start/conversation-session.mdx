Las sesiones de conversación son el punto de entrada más ligero de HagiCode. Elige un proyecto, haz una pregunta y deja que un Agent lea el repositorio y responda. Tú decides, sesión por sesión, si el Agent puede modificar archivos.

## Requisitos previos

Antes de iniciar una sesión de conversación, asegúrate de haber:

- completado cualquiera de los métodos de instalación (Microsoft Store o Desktop) siguiendo la [Guía de instalación](/es-ES/installation)
- completado la [configuración con el asistente](/es-ES/quick-start/wizard-setup), que crea tu primer Agent y al menos un proyecto
- seleccionado ese proyecto en el tablero de sesiones

## ¿Para qué sirve una sesión de conversación?

Una sesión de conversación funciona mejor cuando quieres entender primero y editar después. Usos habituales:

- analizar rápidamente un repositorio que no conoces
- hacer una pregunta concreta sobre un archivo, un módulo o un error
- hacer un cambio pequeño sin planificarlo como una propuesta
- adjuntar imágenes, frases estándar o mensajes anteriores antes de enviar

Si tu tarea ya ha pasado de «entender el problema» a «planificar, revisar y archivar un cambio estructurado», continúa con [Crear una sesión de propuesta](/es-ES/quick-start/proposal-session). Esta página solo trata las sesiones de conversación.

## Resumen del flujo de trabajo

| Etapa | Qué haces | Qué ocurre |
| --- | --- | --- |
| Crear | Haz clic en **Create Normal Session** y describe lo que quieres | El panel recoge el proyecto, un título opcional, el alcance y tu primer mensaje |
| Iniciar | Elige un Agent en **Available Agents** | La sesión empieza de inmediato y aparece en la columna **Execution** |
| Leer | Abre la tarjeta de la sesión | El Agent lee el repositorio y responde; una tarjeta **Session Complete** resume la ejecución |
| Decidir | Usa el interruptor de modo junto al cuadro de mensaje | Permanece en modo de solo lectura o activa el modo de edición para que el Agent pueda cambiar archivos |
| Añadir contexto | Usa los botones de imagen, frases estándar e historial | Tu siguiente mensaje lleva más contexto |

## Paso 1: Crear la sesión

Selecciona tu proyecto y haz clic en **Create Normal Session** (el icono de bocadillo de diálogo) en la barra de herramientas situada sobre el tablero.

![Panel Create Normal Session con un proyecto, el título de la sesión, el alcance de la tarea, una solicitud y el selector Available Agents](../../img/quick-start/conversation-session/01-create-normal-session.png)

Rellena el panel:

- **Project** (obligatorio): por defecto es el proyecto seleccionado.
- **Session title**: opcional; se convierte en el título de la tarjeta en el tablero.
- **Task scope**: opcional. **Repos** limita la sesión a los repositorios de un proyecto MonoSpecs, mientras que **Vault** y **Projects** adjuntan material de referencia adicional.
- **What do you want to do?** (obligatorio): tu primer mensaje. **Upload Image** adjunta una imagen.

El panel **Available Agents** se abre junto al panel de creación. Haz clic en un Agent y la sesión **empieza de inmediato**. La primera tarjeta es el valor predeterminado del entorno de ejecución; la segunda lista te permite elegir un Agent distinto solo para esta ejecución. También puedes pulsar `Ctrl/⌘ + Enter` para enviar desde el teclado.

:::tip[Empieza con una pregunta, no con un cambio]
Un primer mensaje como «En dos frases, ¿qué hace este proyecto? No modifiques ningún archivo.» es una forma segura de comprobar que tu Agent y tu proyecto están bien configurados.
:::

## Paso 2: Leer el resultado

La nueva sesión aparece como una tarjeta en la columna **Execution** con una insignia de estado. Haz clic en ella para abrir la sesión.

![Panel de la sesión con la respuesta del Agent, el resumen Session Complete, el cuadro de mensaje y la tarjeta de estado del Agent](../../img/quick-start/conversation-session/02-session-detail.png)

- La **cabecera** muestra el título y el Agent, junto con **Archive**, **Delete Session**, **Open Code Server** y un menú **…**.
- La **conversación** enumera tu mensaje, las llamadas a herramientas del Agent como filas compactas de un registro y su respuesta.
- Una tarjeta **Session Complete** cierra cada ejecución con el número de turnos, el tiempo transcurrido y el coste. Haz clic en ella para ver los detalles.
- La **tarjeta de estado del Agent**, a la derecha del cuadro de mensaje, muestra el CLI del Agent, el modelo, su estado (por ejemplo, *Idle*) y el tiempo transcurrido.

Escribe una pregunta de seguimiento en el cuadro de mensaje. Pulsa `Enter` para enviar y `Shift + Enter` para insertar un salto de línea.

## Paso 3: Elegir solo lectura o modo de edición

El interruptor situado a la izquierda del cuadro de mensaje tiene dos posiciones. El ojo es el modo de **solo lectura**: el Agent puede inspeccionar y explicar, pero no modifica archivos. El lápiz es el **modo de edición**: es más probable que los mensajes nuevos modifiquen archivos o ajusten la implementación actual.

![Cuadro de mensaje con el lápiz (modo de edición) seleccionado](../../img/quick-start/conversation-session/03-composer-edit.png)

![Cuadro de mensaje con el ojo (modo de solo lectura) seleccionado](../../img/quick-start/conversation-session/04-composer-readonly.png)

El modo se aplica a la sesión en la que estás y puedes cambiarlo entre mensajes. Que las sesiones normales **nuevas** empiecen en modo de edición se controla en **Settings → Sessions and conversation → Chat View → Default to Edit Mode for Normal Chats**. Consulta [Configuración](/es-ES/user-guide/settings).

El patrón más seguro es sencillo: confirma primero la dirección en modo de solo lectura y cambia al modo de edición cuando realmente quieras cambios.

## Paso 4: Añadir contexto antes de enviar

Tres botones junto al interruptor de modo añaden contexto a tu siguiente mensaje:

- **Insert an image attachment** (insertar una imagen adjunta): adjunta una captura de pantalla, una captura de un error o una referencia de diseño. La imagen aparece sobre el cuadro de mensaje con su nombre de archivo y tamaño, y puedes quitarla con la **×** antes de enviar.
- **Standard Phrases** (frases estándar): inserta una referencia con `@`. El selector ofrece **Projects** (la ruta raíz canónica de un proyecto), **Vaults** (la ruta de un vault registrado), **Proposal Sessions** (una carpeta de cambio de OpenSpec) y **Recent Items**.
- **Import Recent History** (importar historial reciente): reutiliza uno de los mensajes recientes de esta sesión para no tener que escribirlo de nuevo.

![Cuadro de mensaje con una imagen adjunta mostrada encima](../../img/quick-start/conversation-session/05-composer-image.png)

![Selector de frases estándar abierto desde el cuadro de mensaje, con Projects, Vaults, Proposal Sessions y Recent Items](../../img/quick-start/conversation-session/06-standard-phrases.png)

Las imágenes son útiles cuando quieres:

- pedirle al Agent que explique una captura de una interfaz
- adjuntar una captura de un error o una maqueta de diseño y añadir instrucciones complementarias
- dar contexto visual antes de pasar al modo de edición

## Progresión típica

1. **Crea** la sesión desde la barra de herramientas y elige un Agent.
2. **Empieza en solo lectura** con una pregunta sobre el proyecto.
3. **Lee la respuesta** y haz preguntas de seguimiento.
4. **Activa el modo de edición** solo cuando necesites cambios directos en los archivos.
5. **Añade imágenes, frases estándar o historial** para dar más contexto al siguiente mensaje.
6. **Archiva** la sesión cuando termines; pasará a la columna **Archived**.

Si la tarea ahora requiere disciplina de planificación, revisión y archivado, continúa con la guía de sesiones de propuesta.
