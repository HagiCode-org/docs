**Vault** — это папки, которые HagiCode может просматривать и предпросматривать за пределами репозитория проекта. Vault можно использовать для справочных документов, заметок, результатов исследований и любого другого содержимого, которое вы хотите, чтобы сессии читали или записывали.

Нажмите **Vault** в верхней панели (в китайском интерфейсе: Vault), чтобы открыть **Vault Workspace** (рабочую область Vault).

![Рабочая область Vault со списком зарегистрированных Vault Orbit Notes и Docs и свёрнутой группой System vaults](../img/user-guide/vault/01-vault.png)

## Зарегистрированные Vault и системные Vault

Рабочая область состоит из двух групп:

- **Registered vaults** (зарегистрированные Vault) — это папки, которые вы добавили. Каждая карточка показывает тип Vault, его имя, сокращённый путь и кнопку **Open Code Server** (открыть Code Server). Она открывает папку в браузерном редакторе.
- **System vaults** (системные Vault) создаются и поддерживаются HagiCode. Нажмите **Expand** (развернуть), чтобы их просмотреть.

![Развёрнутые системные Vault, показывающие семь управляемых системой Vault только для чтения](../img/user-guide/vault/02-vault-system-expanded.png)

В этом разделе системные Vault доступны **только для чтения**. К ним относятся журналы приложения, каталог данных, шаблоны промптов, личные данные, данные проекта, текущие архивы и системные пресеты. В области сессии они считаются только справочными материалами.

## Добавление Vault

Нажмите **Add vault** (добавить Vault), заполните **Vault name** (имя Vault) и **Physical path** (физический путь, абсолютный), выберите **Vault type** (тип Vault), затем нажмите **Save vault** (сохранить Vault).

![Панель Add vault с полями имени и пути, где выбран тип Folder](../img/user-guide/vault/03-add-vault.png)

| Тип Vault | Назначение |
| --- | --- |
| **Folder** (папка) | Регистрирует любой существующий локальный каталог без изменений. |
| **CodeRef** (ссылка на код) | Автоматически создаёт `docs/`, `repos/`, `AGENTS.md` и `index.yaml`. Можно использовать как выходной Vault для задач исследования. |
| **Obsidian** | Автоматически создаёт `.obsidian/`, `app.json` и предпросматриваемые заметки, чтобы папку можно было использовать как Obsidian Vault. |

:::caution[Выберите тип перед сохранением]
Прежде чем нажимать **Save vault**, выберите один из трёх типов Vault. В версии, для которой написано это руководство, сохранение без выбранного типа завершается ошибкой с непонятным сообщением вместо подсказки о проверке.
:::

## Использование Vault в сессиях

Vault появляется в разделе **Scope** (область, в интерфейсе также «область применения» или «диапазон задачи») в [панели создания предложения и панели создания обычной сессии](/user-guide/sessions). Если задача должна обновлять файлы в Vault, отметьте её как **editable** (редактируемая). Иначе ИИ будет считать Vault справочным материалом только для чтения. Системные Vault всегда используются только как справка.
