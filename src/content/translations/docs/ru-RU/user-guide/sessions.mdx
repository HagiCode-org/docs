**Сессия** — это единица работы, выполняемая совместно с Агентом. Доска сессий является центром рабочего пространства: она показывает, на каком этапе находится каждая сессия, и содержит кнопки для запуска новых сессий.

## Доска сессий

![Доска сессий с тремя дорожками: Proposal & Review, Execution и Archived; в дорожке Execution есть карточка завершённой сессии](../../img/user-guide/workbench/01-workbench-overview.png)

На доске три дорожки:

| Дорожка | Что здесь появляется |
| --- | --- |
| **Proposal & Review** (Предложения и проверка) | Идеи, которые составляются, генерируются и проверяются как предложения. |
| **Execution** (Выполнение) | Запущенные или завершённые сессии, включая обычные сессии. |
| **Archived** (Архив) | Сессии, которые вы заархивировали; их всегда можно просмотреть. |

Каждая карточка показывает номер сессии, проект, значок типа, заголовок, время последнего изменения и значок статуса, например **Executing** (Выполняется) или **Execution Complete** (Выполнение завершено). Нажмите на карточку, чтобы открыть сессию. Счётчик рядом с заголовком дорожки показывает количество сессий в ней, а стрелка в заголовке дорожки сворачивает её.

### Панель инструментов

Над дорожками находятся четыре элемента управления:

- **Переключатель режима макета** (небольшой значок рядом с *Session List* (Список сессий)): переключает между пятью видами. См. [Виды](/user-guide/views).
- **New Idea** (Новая идея, значок ростка): начинает предложение.
- **Create Normal Session** (Создать обычную сессию, значок диалога): начинает разговор.
- **More HagiTasks** (Ещё HagiTask, значок списка): открывает рабочее пространство HagiTask с другими пресетами задач. См. [Навыки и HagiTask](/user-guide/skills-and-hagitask).

Меню **Recent changes** (Последние изменения) и виджет **Trophies** (Трофеи) находятся в правой части панели инструментов. См. [Проекты](/user-guide/projects) и [Строка состояния и прогресс](/user-guide/status-bar-and-progress).

### Режимы макета

![Выдвижная панель Choose a view со списком пяти видов](../../img/user-guide/views/01-layout-switcher.png)

| Режим | Значок | Когда использовать |
| --- | --- | --- |
| **Classic** (Классический) | Focused (Сфокусированный) | Компактный список сессий рядом с колонками проекта и подробностей. |
| **Execution Flow Kanban** (Канбан потока выполнения) | Flow (Поток) | Дорожки и полноценная область действий справа. В этом руководстве используется именно этот макет. |
| **Dashboard Kanban** (Канбан-панель) | Compact (Компактный) | Более легковесная доска, которая группирует сессии по статусу и оставляет больше места для обзора. |
| **Project × Status Matrix** (Матрица «проект × статус») | Matrix (Матрица) | Единая сетка всех проектов по дорожкам статуса со счётчиками того, что требует внимания. |
| **Command View** (Командный вид) | Command (Команда) | Стена из живых плиток для наблюдения за несколькими запущенными сессиями и ответов на их вопросы на месте. |

См. [Виды](/user-guide/views): как переключать виды и что показывает каждый из них.

## Новая идея (предложение)

Нажмите **New Idea**, чтобы открыть выдвижную панель **Create Proposal** (Создать предложение). Это подходит для изменений, которые стоит сначала спланировать: вы описываете нужное, HagiCode составляет предложение, а вы проверяете его перед выполнением. Руководство [Превращение идеи в код с помощью сессии предложения](/quick-start/proposal-session) проведёт вас через весь путь от предложения до архива.

![Панель Create Proposal с названием идеи, проектом, областью действия, быстрыми требованиями и требованием о добавлении POST-эндпоинта](../../img/user-guide/sessions/01-new-idea.png)

**Левая колонка: Basic Setup** (Базовая настройка)

- **Idea Name** (Название идеи) и **Project Name** (Название проекта) обязательны для заполнения.
- **Scope** (Область действия) имеет две вкладки. **Vault** позволяет *Specify Target Vaults (Optional)* (Указать целевые Vault (необязательно)): отметьте Vault, которые ИИ может редактировать; системные Vault доступны только для чтения. **Projects** (Проекты) позволяет добавить другие проекты как контекст.
- **Quick Requests** (Быстрые требования) — это пункты, которые добавляются в ваше требование одним нажатием: *No docs / tests* (Без документации и тестов), *Self commit* (Самостоятельный коммит), *Output English* (Вывод на китайском языке, меняется вместе с языком интерфейса), *Ask before edit* (Спрашивать перед редактированием) и *No backward compatibility* (Без обратной совместимости).

**Правая колонка: Requirement Drafting & Preview** (Составление требований и предпросмотр)

- **You Request** (Ваш запрос) предназначен для описания изменения, до 14 000 символов. С помощью **Upload Image** (Загрузить изображение) можно приложить картинку.
- **Combined preview** (Объединённый предпросмотр) показывает полный текст, который будет отправлен ИИ, чтобы вы могли проверить его перед отправкой.
- **Submit idea** (Отправить идею) создаёт сессию предложения. **Load Favorite** (Загрузить избранное) и **Save as Favorite** (Сохранить в избранное) позволяют повторно использовать сохранённые настройки.
- Переключатель **Plan** (План) в правом нижнем углу панели заменяет «отправить сейчас» на «отправить по расписанию»: после сохранения HagiCode автоматически создаст эту сессию предложения в заданное вами время. См. [Запланированные планы](/ru-RU/user-guide/scheduled-plans).

## Новая обычная сессия

Нажмите **Create Normal Session**, чтобы начать обычный диалог с Агентом. Используйте его, чтобы изучить репозиторий, задать вопрос или внести небольшое изменение без составления предложения.

![Панель Create Normal Session с проектом, названием сессии, областью задач, одним требованием и выбором Available Agents](../../img/user-guide/sessions/02-create-normal-session.png)

| Поле | Описание |
| --- | --- |
| **Project** (Проект) | Обязательно. По умолчанию выбран текущий проект. |
| **Session title** (Название сессии) | Необязательно; служит меткой на карточке. |
| **Task scope** (Область задачи) | **Repos** (Репозитории) ограничивает сессию репозиториями проекта MonoSpecs. **Vault** и **Projects** (Проекты) позволяют прикрепить дополнительные справочные материалы. |
| **What do you want to do?** (Что вы хотите сделать?) | Обязательно; это первое сообщение сессии. С помощью **Upload Image** можно приложить изображение. |

Панель **Available Agents** показывает ваших Агентов. Выберите одного из них, и сессия **сразу начнётся**; первый пункт — значение по умолчанию для среды выполнения. Второй список позволяет выбрать другого Агента только для этого запуска. Если Агенты не отображаются, сначала создайте их в разделе [Agents](/user-guide/agents). Отправить с клавиатуры можно сочетанием `Ctrl/⌘ + Enter`.

:::note[Начните с вопроса только для чтения]
Пример сессии в этом руководстве задаёт демонстрационному проекту вопрос только для чтения. Он выполняется примерно за 23 секунды и не изменяет никаких файлов. Режим редактирования настраивается отдельно для каждой сессии; см. ниже.
:::

## Работа в сессии

Нажмите на карточку, чтобы открыть панель сессии.

![Панель сессии с итоговым ответом, сводкой Session Complete, полем сообщения и карточкой состояния Агента](../../img/user-guide/sessions/03-session-detail.png)

**Заголовок**: название, аватар Агента, кнопки **Archive** (Архивировать, переносит сессию в дорожку Archived), **Delete Session** (Удалить сессию), **Open Code Server** (Открыть Code Server) и меню **…** с дополнительными действиями.

**Диалог**: ваши сообщения и ответы Агента идут по порядку. Пока Агент работает, вы можете следить за его действиями: вызовы инструментов отображаются в виде карточек.

![Начало сессии с блоком режима работы и карточкой вызова инструмента Bash](../../img/user-guide/sessions/04-session-detail-top.png)

По завершении запуска карточка **Session Complete** (Сессия завершена) суммирует количество ходов, время и стоимость. Нажмите на неё, чтобы раскрыть подробности.

**Поле сообщения**: находится внизу.

- Переключатель **Edit / Readonly** (Редактирование / Только чтение) включает или выключает режим редактирования. При включённом режиме редактирования новые сообщения с большей вероятностью изменят файлы. Включён ли режим редактирования по умолчанию для новых обычных сессий, задаётся в разделе **Settings → Process & Interaction → Chat View** (Настройки → Процесс и взаимодействие → Вид чата).
- Есть кнопки для **изображений**, **Standard Phrases** (Стандартные фразы, то есть селектор `@`) и **Import Recent History** (Импорт недавней истории).
- **Send** (Отправить) отправляет сообщение. `Enter` отправляет, `Shift + Enter` переносит строку.

**Карточка состояния Агента**: находится справа от поля сообщения и показывает CLI и модель Агента (например, `claude-sonnet-5-5`), текущее состояние (например, *Idle* (Простаивает)) и время, прошедшее с начала работы.
