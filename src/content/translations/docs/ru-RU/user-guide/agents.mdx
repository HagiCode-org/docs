**Agent** в HagiCode — это готовый к работе исполнитель. Он состоит из Agent CLI (например, Claude Code), модели и необязательного текста характера. Сессии выполняются агентами, поэтому перед началом работы нужен хотя бы один агент.

Нажмите **Agents** в верхней панели (в китайском интерфейсе: Agents), чтобы открыть **Agents Workspace** (рабочее пространство Agents). В нём шесть вкладок.

| Вкладка | Назначение |
| --- | --- |
| [Agents](#вкладка-agents) | Создание и управление вашими агентами. |
| [Execution Scenarios (сценарии выполнения)](#сценарии-выполнения) | Определяет, какие агенты выполняют каждый тип работы. |
| [AgentCLI](#agentcli) | Показывает, какие Agent CLI установлены, исправны и включены. |
| [Model (модели)](#модели) | Просмотр и расширение каталога моделей для каждого Agent CLI. |
| [Document Theme (тема текстов)](#тема-текстов) | Выбор темы текстов интерфейса. |
| [Avatar Gallery (галерея аватаров)](#галерея-аватаров) | Просмотр наборов аватаров. |

:::note
AgentCLI и каталог моделей относятся к уровню системы. Вкладка Agents хранит только ваших текущих агентов и их команды.
:::

## Вкладка Agents

![Вкладка Agents: список My Agents сгруппирован по Agent CLI, показан агент Hagicoder](../../img/user-guide/agents/01-agents.png)

**My Agents** (мои агенты) — список ваших агентов, сгруппированных по используемому Agent CLI. Каждая карточка показывает аватар, имя, модель и небольшой значок, обозначающий CLI.

- **New Agent** (новый агент) открывает панель создания.
- **Batch create Agents** (пакетное создание агентов) создаёт сразу несколько агентов.
- **Search** (поиск) фильтрует по имени агента, AgentCLI или описанию.
- **Select all visible** (выбрать все видимые), **Clear visible** (снять выделение с видимых) и **Delete N selected** (удалить выбранные: N) используются для массового удаления.

### Создание агента

![Панель New Agent с разделами снаряжения агента, черт и души](../../img/user-guide/agents/02-new-agent.png)

Панель создаёт одного агента за раз. Вкладка Agents не меняется, пока создание не завершится успешно.

- **Name and avatar** (имя и аватар) – имя предлагается случайно из пула имён. Загрузка собственного аватара требует DLC TurboEngine.
- **Agent loadout** (снаряжение агента) – два обязательных слота. Нажмите на значок кандидата, чтобы экипировать его:
  - **AgentCLI** – инструмент командной строки, который запускает агента.
  - **Model** (модель) – модель, которую использует этот CLI. Список показывает только модели, совместимые с выбранным CLI.
- **Trait · knowledge and behavior** (черта · знания и поведение) – свободный текст или черта из Trait platform, которая задаёт, как агент работает.
- **Soul · language style** (душа · стиль речи) – свободный текст или душа из Soul platform, которая задаёт, как агент говорит.
- **Battle ready** (готовность к работе) – переключатель, который включает или отключает агента.

## Сценарии выполнения

Соответствует вкладке **Execution Scenarios**.

![Вкладка Execution Scenarios с сценариями предложений, HagiTask и чата, а также редактор команды](../../img/user-guide/agents/03-execution-scenarios.png)

Сценарий определяет, какой агент выбирается для каждого типа работы. Сценарии сгруппированы по месту их появления:

| Группа | Сценарии |
| --- | --- |
| **Proposal** (сценарии выполнения предложений) | Optimize Proposal (оптимизация предложения), Generate Proposal (генерация предложения), Execute Proposal (выполнение предложения), Archive Proposal (архивация предложения) |
| **HagiTask** (сценарии выполнения Hagitask) | Super Commit, Create Normal Session (создание обычной сессии), Create Research Investigation Task (создание задачи исследования кода) |
| **Chat** (сценарии выполнения чата) | Conversation Title Optimization (оптимизация названия беседы) |

**Fallback Crew** (резервная команда) — страховочная сеть. Если в собственной команде сценария нет подходящего агента, HagiCode случайным образом пробует подходящих членов резервной команды. Она обязательна: **пока в резервной команде нет хотя бы одного включённого агента, все остальные сценарии заблокированы.** Мастер первоначальной настройки автоматически добавляет туда вашего первого агента.

Нажмите на сценарий, чтобы его изменить. **Assigned Agents** (назначенные агенты) показывает состав команды, а **Available Agents** (доступные агенты) — тех, кого можно добавить. Фильтры по Agent CLI сужают список. Выполнение случайным образом пробует подходящих участников, поэтому порядок на экране не отражает приоритет.

## AgentCLI

![Таблица управления AgentCLI, показывающая для каждого CLI статус включения, доступность, версию и состояние мониторинга](../../img/user-guide/agents/04-agentcli.png)

На этой вкладке перечислены все инструменты командной строки, которыми может управлять HagiCode: Claude Code, Codebuddy, Codex, DeepAgents, DSH, Gemini, GitHub Copilot, Hermes, Junie, Kimi, Kiro, OMP, OpenCode, Pi, QoderCLI и Reasonix.

Для каждого CLI вы видите:

- **Enabled** (включён) и **Availability** (доступность) – CLI должен быть установлен на машине, где запущен HagiCode, чтобы быть доступным.
- **CLI version** (версия CLI) – обнаруженная версия. Если исполняемый файл не найден, показывается *Not detected* (не обнаружен).
- **Monitoring** (мониторинг) – последняя проверка работоспособности, например *Healthy* (исправен).
- **Show diagnostics** (показать диагностику) – подробности результатов проверки, полезные, когда CLI не обнаружен.
- **Переключатель**, который включает или отключает CLI. Чтобы изменить несколько сразу, используйте флажки вместе с **Enable selected** (включить выбранные) и **Disable selected** (отключить выбранные). Фильтры могут показывать только *Available* (доступные) или *Unavailable* (недоступные) CLI.

Если установленный CLI не обнаружен, убедитесь, что его исполняемый файл находится в `PATH` процесса, в котором запущен HagiCode, и затем перезагрузите страницу. См. [Установка AI Agent CLI](/related-software-installation/ai-agent-cli).

## Модели

Соответствует вкладке **Model**.

![Вкладка Model с каталогом моделей Claude Code и формой Create Model](../../img/user-guide/agents/05-model.png)

Выберите **AgentCLI** вверху, чтобы увидеть его модели. В таблице показаны название модели, ID модели, источник и поддержка изображений.

- Записи **System defaults** (системные по умолчанию) доступны только для чтения и поддерживаются HagiCode.
- Записи **Custom** (пользовательские) принадлежат вам. Их создают через форму **Create Model** (новая модель): *Display name* (отображаемое имя), *Summary* (описание), *Icon* (значок), *Model value* (значение модели, которое требует CLI) и *Supports images* (поддержка изображений). **Create blank entry** (создать пустую запись) начинает с пустой строки.
- Модели можно фильтровать по имени или ID, по источнику (*All sources* (все источники), *Custom*, *System default*) либо показать только те, что *Support images only* (поддерживают изображения).

## Тема текстов

Соответствует вкладке **Document Theme**.

![Вкладка Document Theme, где текущей темой является AgentCLI Baseline, а остальные темы заблокированы](../../img/user-guide/agents/06-document-theme.png)

Тема текстов меняет формулировки интерфейса. **AgentCLI Baseline** (базовая тема AgentCLI) использует нейтральные формулировки, например *Agents*, *Jobs* (задания) и *Workspace* (рабочее пространство). Она является темой по умолчанию. Другие темы, например с формулировками *Fantasy Adventure* (фэнтези-приключение), требуют DLC TurboEngine. Их предпросмотр виден, но они заблокированы. **Restore default theme** (вернуть тему по умолчанию) возвращает базовую тему.
