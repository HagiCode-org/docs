Небольшие виджеты у нижнего края и в верхней части рабочей области сообщают о состоянии, не отвлекая вас. На этой странице описаны строка состояния, Зал трофеев и достижений, а также ваш профиль.

## Строка состояния

![Строка состояния с значком Microsoft Store, прокруткой подсказок, состоянием Agent CLI, активными сессиями, напоминанием о перерыве, счётчиком дневного заработка и версией](../../img/user-guide/workbench/04-status-bar.png)

Слева направо расположены:

| Элемент | Что показывает |
| --- | --- |
| **Microsoft Store badge** | Ссылка на страницу HagiCode в Microsoft Store. |
| **Прокрутка подсказок и промо** | Одна подсказка или промо-сообщение за раз. Подсказки объясняют, как пользоваться HagiCode; промо ведут к связанным проектам. Прокрутку можно отключить или выбрать источник содержимого в **Settings → Integration → Status Bar Scroll** (Настройки → Интеграция → Прокрутка строки состояния). |
| **Состояние Agent CLI** | Небольшие значки, например `CC`, `CO` и `GC`, обозначают Claude Code, Codex и GitHub Copilot; зелёная точка означает, что инструмент работает исправно. `+N` показывает, сколько ещё инструментов есть сверх отображаемых. Нажатие на значки обновляет проверку состояния. |
| **Running sessions** (Активные сессии) | Количество сессий, которые сейчас выполняются. Нажмите, чтобы увидеть подробности. |
| **Break reminder** (Напоминание о перерыве) | Значок капли показывает, сколько осталось до следующего напоминания. |
| **Salary tracker** (Счётчик заработка) | Эмодзи юнита и сумма, накопленная за сегодня. Отображается, когда счётчик и его индикатор в строке состояния включены. |
| **Version** (Версия) | Номер сборки, например `dev` для сборок разработки. |

### Активные сессии

![Всплывающее окно активных сессий с лимитом сессий, опцией разгона и сообщением о том, что сейчас нет активных сессий](../../img/user-guide/status/03-running-sessions.png)

HagiCode ограничивает количество одновременно выполняемых сессий; по умолчанию это 20. Всплывающее окно показывает текущее количество в сравнении с лимитом и перечисляет активные сессии.

- **Overclock** (Разгон) повышает лимит на 3. Опция доступна только после того, как достигнут текущий лимит; во всплывающем окне показано, сколько раз она уже использована.
- DLC TurboEngine позволяет поднять уровень параллельности ещё выше.

### Напоминание о перерыве

![Всплывающее окно напоминания о перерыве с сообщением и кнопками Remind me later и Take a break](../../img/user-guide/status/04-break-reminder.png)

Когда срабатывает таймер, появляется карточка с сообщением в выбранном для напоминания стиле. **Take a break** (Сделать перерыв) подтверждает перерыв, **Remind me later** (Напомнить позже) откладывает напоминание. Интервал и тон сообщений настраиваются в **Settings → Integration → Break Reminder** (Настройки → Интеграция → Напоминание о перерыве).

### Счётчик дневного заработка

![Всплывающее окно счётчика дневного заработка с доходом в минуту, суммой за сегодня, прошедшими минутами, суммой за вчера и общей суммой за всё время](../../img/user-guide/status/05-salary-tracker.png)

Нажмите на эмодзи, чтобы увидеть доход в минуту, итог за сегодня, количество отработанных минут, итог за вчера и общий итог за всё время. Кнопка **Open settings** (Открыть настройки) ведёт в **Settings → Integration → Salary Tracker** (Настройки → Интеграция → Счётчик заработка), где задаются дневной заработок и рабочее время.

## Трофеи и Зал достижений

Виджет **Trophies** (Трофеи) в правом верхнем углу доски сессий показывает ваш прогресс в виде звёзд. Четыре звезды (звезда) образуют месяц (месяц), четыре месяца образуют день (день), четыре дня образуют корону (корона). Число рядом с заголовком показывает, сколько звёзд осталось до следующего повышения.

Нажмите на виджет, чтобы открыть **Achievement Hall** (Зал достижений).

![Зал достижений с дневными очками, процентом выполнения, обзором сегодняшнего дня и онлайн-ростом](../../img/user-guide/status/01-achievements.png)

- **Daily Achievements** (Дневные достижения) — цели, которые обнуляются каждый день, например начать и завершить предложение, результаты работы Agent и активность инструментов. В заголовке показаны дневные очки, например `0/17`.
- **Global Achievements** (Глобальные достижения) — долгосрочные вехи, которые накапливаются от дня к дню.
- **Mission Board** (Доска миссий) — сводка за день: процент выполнения, активные цели и каналы наград.
- **Online growth** (Онлайн-рост) — прогресс, накопленный за время работы HagiCode.

Очки, которые вы получаете здесь и в ежедневной работе, отображаются в профиле. Всплывающие подсказки о ежедневном прогрессе можно отключить в **Settings → Game → Achievements** (Настройки → Игра → Достижения).

## Профиль

Нажмите на круглый аватар в правом краю верхней панели, чтобы открыть выдвижную панель профиля.

![Выдвижная панель профиля с аватаром, очками, историей и быстрыми ссылками](../../img/user-guide/status/02-profile.png)

- **Avatar** (Аватар) — загрузите изображение JPEG, PNG, WEBP или GIF размером не более 10 МБ.
- **Points** (Очки) — ваш подтверждённый баланс, сформированный достижениями и ежедневной работой.
- **History timeline** (Лента истории) — недавние системные события, например создание или удаление сессий. Загружается только при открытии панели.
- **Quick links** (Быстрые ссылки) — например **View Yesterday's Report** (Открыть отчёт за вчера), который открывает полноэкранный отчёт о героических свершениях за прошлый день.
