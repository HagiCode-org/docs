Навыки и HagiTask расширяют возможности агента, и оба открываются из верхней панели.

- **Навыки** — это переиспользуемые наборы инструкций, которые загружает Agent CLI, например стандарты дизайна или лучшие практики фреймворка.
- **HagiTask** — это пресеты задач, которые HagiCode выполняет через поток сессии, например *Normal Session* (обычная сессия) или *Research Investigation* (исследование кода).

## Навыки

Нажмите **Skills** (Навыки) в верхней панели. В выдвижной панели три вкладки. Более подробное пошаговое руководство см. в [руководстве по использованию Skills](/guides/skills).

### Local Skills (Локальные навыки)

![Вкладка Local Skills с поиском, Refresh inventory, Update all и таблицей установленных навыков](../../img/user-guide/skills/01-local-skills.png)

Бэкенд является единственным надёжным источником информации об установленных глобальных навыках на этом компьютере.

- **Refresh inventory** (Обновить инвентарь) заново сканирует компьютер. **Update all** (Обновить все) обновляет все навыки, для которых доступно обновление.
- В таблице для каждого навыка показаны **Skill** (Навык), **Agents** (Агенты), к которым он привязан, **Path** (Путь), а также доступные **Actions** (Действия): **Update** (Обновить) и **Uninstall** (Удалить).
- В строках с предупреждением отсутствует файл метаданных установки, необходимый для обновления в один клик, поэтому в действии обновления отображается *Unavailable* (Обновление недоступно).

### Gallery (Галерея)

![Вкладка Gallery с полем поиска, фильтром по источнику и списком популярных навыков с количеством установок](../../img/user-guide/skills/02-gallery.png)

Искать в библиотеке навыков можно по имени, ID или источнику, а также вставить URL репозитория GitHub. **Trusted only** (Только доверенные) ограничивает список навыками доверенных вами провайдеров. В каждой строке показаны навык, его источник и количество установок. Чтобы увидеть точную команду установки до её запуска, откройте нужную строку.

### Trusted Providers (Доверенные провайдеры)

![Вкладка Trusted Providers с описанием формата правил и таблицей предустановленных провайдеров](../../img/user-guide/skills/03-trusted-providers.png)

Доверенные провайдеры определяют, какие источники получают метку *Trusted*. Каталог хранит только проверенные источники и никогда не сохраняет учётные данные. Каждая строка описывает одно правило:

- `prefix:owner/` доверяет всем репозиториям одного владельца.
- `exact:owner/repo` доверяет одному конкретному репозиторию.

По умолчанию есть предустановленные провайдеры, например Vercel, Azure, anthropics и Microsoft. Чтобы изменить список, используйте **Add provider** (Добавить провайдера), **Edit** (Изменить), **Delete** (Удалить) или **Reset defaults** (Сбросить к значениям по умолчанию).

## HagiTask

Нажмите **HagiTask** в верхней панели или **More HagiTasks** (Ещё HagiTask) на доске сессий, чтобы открыть **HagiTask workspace** (рабочее пространство HagiTask). В нём тоже три вкладки.

### Package management (Управление пакетами)

![Вкладка Package management со списком пресетов Create proposal, Normal Session и Research Investigation](../../img/user-guide/skills/04-hagitask-packages.png)

В списке показан каждый установленный пресет с его **Order** (Порядок), **Name** (Название), **Version** (Версия), **Source** (Источник) и переключателем **Enabled** (Включён). Переключатель включает или отключает пресет.

- **Create proposal** (Создать предложение) — это встроенное специальное действие. Оно всегда присутствует и не может быть установлено или удалено.
- **Normal Session** (Обычная сессия) и **Research Investigation** (Исследование кода) — это пресеты рабочего пространства.
- **Change order** (Изменить порядок) меняет порядок в списке. **Install community HagiTask** (Установить HagiTask из сообщества) открывает галерею. **Reload list** (Перезагрузить список) заново считывает все источники.

Нажмите на строку, чтобы открыть её подробности справа.

### Community Gallery (Галерея сообщества)

![Вкладка Community Gallery со списком пресетов сообщества, кнопками Install и панелью подробностей](../../img/user-guide/skills/06-hagitask-gallery.png)

Здесь можно просмотреть пресеты, опубликованные командой HagiCode и сообществом, например *CodeGraph Tasks*, *GitHub Tasks* и *AGENTS.md Update*. Каждая запись показывает категорию, версию, теги и необходимые инструменты CLI. Нажмите **Install** (Установить), чтобы добавить пресет. **Create or contribute a task** (Создать или предложить задачу) открывает руководство для участников, а пресет *Add Community Task* проведёт вас через создание задачи по шагам.

### Source management (Управление источниками)

Вкладка **Source management** показывает источники, из которых загружаются пресеты: встроенные пресеты и папки сообщества. **Add folder source** (Добавить папку-источник) регистрирует ещё одну папку, а **Reload sources** (Перезагрузить источники) заново сканирует их. Установка отдельной задачи из локальной папки больше не поддерживается; устанавливайте задачи из галереи сообщества.
