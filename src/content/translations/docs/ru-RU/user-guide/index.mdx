Этот раздел — справочник по рабочей области HagiCode, в котором каждый элемент интерфейса описан отдельно. Можно сразу открыть страницу, которая относится к функции, с которой вы работаете.

## Обзор рабочей области

По умолчанию рабочая область открывается на **доске сессий**. На иллюстрации показан небольшой демонстрационный проект `orbit-notes`, в котором есть одна завершённая сессия.

![Рабочая область HagiCode: верхняя панель, панель проектов, доска сессий с тремя дорожками, панель проекта и строка состояния](../../img/user-guide/workbench/01-workbench-overview.png)

Интерфейс разделён на пять областей:

| Область | Расположение | Назначение | Руководство |
| --- | --- | --- | --- |
| **Верхняя панель** (Header) | Верхний край | Открывает модули уровня рабочей области: Agents, Wizard, Skills, HagiTask, Vault, Plans, настройки, язык, тему и профиль | [Верхняя панель](#顶栏) |
| **Панель проектов** (Project rail) | Левый край | Переключение между всеми проектами и отдельным проектом, создание нового проекта | [Проекты](/user-guide/projects) |
| **Доска сессий** (Session board) | Центр | Показывает сессии по дорожкам и содержит кнопку создания новой сессии | [Сессии](/user-guide/sessions) |
| **Панель проекта** (Project panel) | Правый край | Быстрые действия для выбранного проекта и состояние репозитория | [Проекты](/user-guide/projects) |
| **Строка состояния** (Status bar) | Нижний край | Подсказки, состояние здоровья Agent CLI, выполняющиеся сессии, напоминания об отдыхе, счётчик дневной оплаты и версия сборки | [Строка состояния и прогресс](/user-guide/status-bar-and-progress) |

## Верхняя панель

Верхняя панель всегда видна. Её кнопки открывают выдвижные панели или диалоги поверх текущей страницы, поэтому ваше положение на доске не теряется.

![Верхняя панель HagiCode с кнопками Agents, Wizard, Refresh, Skills, HagiTask, Vault, Plans, Get Support, языка, темы, настроек и профиля](../../img/user-guide/workbench/03-header-navigation.png)

| Кнопка | Что открывает |
| --- | --- |
| **Agents** (в китайском интерфейсе: Agents) | Рабочую область Agents: ваших Agent, сценарии выполнения, список AgentCLI, каталог моделей, темы текстов и галерею аватаров. См. [Agents](/user-guide/agents). |
| **Wizard** (Мастер) | Четырёхшаговый мастер первоначальной настройки. См. [Первый запуск](#首次启动初始化向导). |
| **Refresh** (Обновить) | Перезагружает содержимое текущей страницы. |
| **Skills** (Навыки) | Единый модуль навыков: Local Skills, Gallery и Trusted Providers. См. [Навыки и HagiTask](/user-guide/skills-and-hagitask). |
| **HagiTask** (в китайском интерфейсе: HagiTask) | Управление HagiTask для работы с пресетами задач. См. [Навыки и HagiTask](/user-guide/skills-and-hagitask). |
| **Vault** (в китайском интерфейсе: Vault) | Менеджер Vault для управления папками, которые HagiCode может просматривать и предпросматривать. См. [Vault](/user-guide/vault). |
| **Plans** (Планы; значок календаря; в узком окне только значок, с подсказкой Scheduled plans) | Менеджер планов — планов, которые автоматически запускают сессии по расписанию. См. [Запланированные планы](/ru-RU/user-guide/scheduled-plans). |
| **Get Support** (Получить техподдержку) | Открывает в браузере страницу сообщества и поддержки. |
| **Language** (Язык) | Переключает язык интерфейса. HagiCode поддерживает десять языков интерфейса, включая упрощённый китайский. |
| **Theme** (Тема, значок листа) | Открывает выбор темы. См. [Внешний вид, темы и язык](/user-guide/settings#外观主题与语言). |
| **Settings** (Настройки, значок шестерёнки; заголовок открывающегося диалога — «设置») | Открывает диалог настроек. См. [Настройки](/user-guide/settings). |
| **Profile** (Профиль, круглый аватар) | Открывает выдвижную панель профиля с баллами, лентой истории и быстрыми ссылками. См. [Строка состояния и прогресс](/user-guide/status-bar-and-progress#个人资料). |

## Первый запуск: мастер инициализации

После свежей установки автоматически открывается **Initialization wizard** (мастер инициализации). Открыть его снова можно в любой момент кнопкой **Wizard** в верхней панели. Мастер состоит из четырёх шагов и показывает, сколько из трёх обязательных шагов уже выполнено.

![Шаг 1 мастера инициализации: выбор языка интерфейса и цветовой темы](../../img/user-guide/wizard/01-language-theme.png)

1. **Language & theme** (Язык и тема) – выберите язык интерфейса и сезонную цветовую тему. Оба параметра применяются сразу.
2. **Hagicoder** – выберите локальный Agent CLI и модель, создайте первого Agent и добавьте его в **Fallback Crew** (резервную команду). Рекомендуется проверить подключение, но это не обязательно.
3. **Project** (Проект) – зарегистрируйте папку первого проекта.
4. **Community** (Сообщество) (необязательно) – начните первый диалог или откройте страницу «О программе».

![Шаг 2 мастера инициализации: настройка Agent по умолчанию и добавление его в Fallback Crew](../../img/user-guide/wizard/02-agent.png)

Полный порядок действий и значение каждого поля см. в разделе [Настройка мастера инициализации](/quick-start/wizard-setup).
