## Что будет в этом разделе

Раздел FAQ предназначен для сбора следующих материалов:

- особые пояснения по запуску и работе
- советы по использованию из Index, которые стоит превратить в долгоживущие статьи
- подсказки по совместимости, связанные с платформами, каналами распространения, способами упаковки или встроенной средой выполнения
- точки входа для устранения неполадок, из которых удобно сделать отдельные страницы с пояснениями

Если вы хотите систематически изучить рекомендации по повседневному использованию HagiCode, прочитайте [Советы по использованию HagiCode](/ru-RU/faq/tips). Если вы хотите выяснить, какой внешний Node использует Desktop, где установлены Agent CLI или что делать, когда появляется сообщение, что Node не найден, прочитайте [Как Desktop использует вашу среду Node](/ru-RU/faq/desktop-node-environment). Если вы хотите узнать, как соотносятся различные Agent CLI и HagiCode и почему рекомендуется использовать их вместе, прочитайте [Claude Vs HagiCode](/ru-RU/faq/claude-vs-hagicode), [Copilot Vs HagiCode](/ru-RU/faq/copilot-vs-hagicode), [Codex Vs HagiCode](/ru-RU/faq/codex-vs-hagicode), [Gemini Vs HagiCode](/ru-RU/faq/gemini-vs-hagicode), [OpenCode Vs HagiCode](/ru-RU/faq/opencode-vs-hagicode), [Hermes Vs HagiCode](/ru-RU/faq/hermes-vs-hagicode), [DeepAgents Vs HagiCode](/ru-RU/faq/deepagents-vs-hagicode), [Kimi Vs HagiCode](/ru-RU/faq/kimi-vs-hagicode), [CodeBuddy Vs HagiCode](/ru-RU/faq/codebuddy-vs-hagicode), [QoderCLI Vs HagiCode](/ru-RU/faq/qoder-vs-hagicode) и [Kiro Vs HagiCode](/ru-RU/faq/kiro-vs-hagicode). Если вы хотите узнать, почему HagiCode нет в Steam, прочитайте [Почему HagiCode нет в Steam](/ru-RU/faq/steam-distribution-status).
