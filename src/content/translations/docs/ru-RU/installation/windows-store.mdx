Для пользователей Windows Microsoft Store сейчас является публичной точкой входа для настольного клиента. Эта страница описывает только путь установки через Store; общее описание загрузки и установки Desktop, управления версиями и устранения неполадок читайте в [Установка Desktop](/ru-RU/installation/desktop).

Основная запись приложения в Steam выведена из эксплуатации, поэтому главным каналом для Windows сейчас является Microsoft Store. Контекст можно посмотреть в статье [Почему HagiCode недоступен в Steam](/ru-RU/faq/steam-distribution-status/).

:::tip[Когда этот путь подходит]
- вы используете Windows 10 или Windows 11 и хотите установить приложение напрямую из системного магазина
- вы предпочитаете, чтобы пакет приложения доставлялся через магазин, а не работать с установочными файлами вручную
- вам нужна только личная локальная установка, а развертывание через Docker Compose не планируется
:::

## Что проверить заранее

Прежде чем начать, убедитесь, что выполнены следующие условия:

- устройство может нормально открыть [страницу HagiCode for Windows в Microsoft Store](https://apps.microsoft.com/detail/9N3PM0N3SVDW)
- при первом запуске доступна сеть, потому что приложению может потребоваться скачать или подготовить компоненты, необходимые Hagicode Server
- на некоторых устройствах, по политике организации или в зависимости от региона может потребоваться сначала войти в учетную запись Microsoft
- если на вашем рабочем устройстве Store отключен, используйте [Установка Desktop](/ru-RU/installation/desktop)

## Подготовка перед установкой

Версия из Store работает так же, как Desktop: она **не включает Node.js**, поэтому вам нужно установить его самостоятельно и сделать так, чтобы он был доступен в системной переменной `PATH`. Подготовьте следующее до первого запуска:

- **Node.js 24 или выше** (вместе с ним устанавливается `npm`), см. [Установка Node.js](/ru-RU/related-software-installation/nodejs/installation)
- **Git**, см. [Установка Git](/ru-RU/installation/#установка-git)
- хотя бы один установленный **Agent CLI**, в котором выполнен вход, см. [Установка AI Agent CLI](/ru-RU/related-software-installation/ai-agent-cli/)

Если вы установили их, когда HagiCode уже был открыт, полностью закройте HagiCode и запустите его заново, чтобы он прочитал новый `PATH`.

## Установка из Microsoft Store

1. Откройте страницу [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW).
2. Нажмите `Получить`, `Установить` или аналогичную кнопку на странице магазина.
3. Дождитесь, пока Microsoft Store завершит загрузку и установку.
4. После установки запустите HagiCode из меню «Пуск» или прямо со страницы магазина.

## Что происходит при первом запуске

После установки HagiCode по-прежнему проходит стандартный процесс инициализации Desktop.

- первый запуск начинается с руководства первого использования Desktop (в приложении оно называется «Первоначальная настройка»): выбор языка, подтверждение юридических документов и, при необходимости, загрузка Hagicode Server, поэтому он может быть медленнее обычного приложения
- канал Microsoft Store / MSIX блокирует настройку «Путь хранения данных среды выполнения»; это ожидаемое поведение для данного способа распространения
- приложение не обновляется самостоятельно: обновление пакета определяется каналом установки, а для установки из Store доставка зависит от канала Microsoft Store

Если вам нужно продолжить мастер инициализации, сразу переходите к статье [Настройка мастера инициализации](/ru-RU/quick-start/wizard-setup).

## Когда лучше выбрать другой способ установки

В таких случаях лучше использовать другой канал:

- вы не можете открыть Microsoft Store, или на рабочем устройстве установка через магазин явно запрещена
- вам нужно вручную скачать пакет `.exe` или `.msix` и самостоятельно контролировать источник установочного файла
- вы разворачиваете систему на сервере, NAS или в среде для командной работы — тогда смотрите [Развертывание Docker Compose](/ru-RU/installation/docker-compose)

## Устранение проблем

### Страница Microsoft Store не открывается

Сначала проверьте сеть, региональные настройки и состояние входа в Microsoft Store. Если в браузере страница открывается, а клиент Store по-прежнему недоступен, обычно это значит, что возможности магазина ограничены политикой системы; в таком случае используйте [Установка Desktop](/ru-RU/installation/desktop).

### Почему некоторые настройки неактивны

Установка из Store / MSIX блокирует параметр «Путь хранения данных среды выполнения» и показывает метку «Заблокировано Microsoft Store». Это не ошибка установки, а ограничение текущего канала распространения.

### Почему при первом запуске что-то еще скачивается или готовится

Установка из магазина доставляет только пакет настольного приложения. При первом запуске HagiCode по-прежнему может скачивать или готовить компоненты, необходимые Hagicode Server, и завершать инициализацию по умолчанию. Оставьте сеть доступной и дождитесь завершения текущего шага.
