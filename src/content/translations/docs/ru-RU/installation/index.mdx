## Подготовка перед установкой

Для разных путей установки нужны разные предварительные условия:

| Способ установки | Node.js | Git |
| --- | --- | --- |
| Microsoft Store / Desktop | Нужно установить самостоятельно, **версия 24 или выше** | Нужно установить самостоятельно |

:::caution[Desktop больше не включает Node.js]
Desktop включает только среду выполнения .NET, необходимую для запуска HagiCode Server, и **больше не поставляет Node.js**. Он ищет `node` и `npm` в системной переменной `PATH` и устанавливает управляемые пакеты, например Agent CLI, в глобальный каталог npm на вашем компьютере. Установите Node.js 24 или выше до первого запуска Desktop; подробности смотрите в разделе [Установка Node.js](/ru-RU/related-software-installation/nodejs/installation).
:::

### Установка Git

Desktop при запуске проверяет наличие `node`, `npm` и `git`, а «Демо-проект» в диалоге «Новый проект» главного интерфейса также использует Git, чтобы клонировать официальный репозиторий с примером. Выберите подходящий для вашей системы способ установки:

- **Windows**: выполните `winget install --id Git.Git -e` или скачайте установщик с [git-scm.com](https://git-scm.com/downloads).
- **macOS**: выполните `xcode-select --install` или, если вы используете Homebrew, `brew install git`.
- **Debian / Ubuntu**: выполните `sudo apt-get install -y git`.
- **Fedora**: выполните `sudo dnf install -y git`.

После установки заново откройте терминал и убедитесь, что команды доступны:

```bash
node --version
npm --version
git --version
```

:::tip[Сначала установите, потом запускайте Desktop]
Desktop читает системную переменную `PATH` при запуске. Если вы установили Node.js или Git, когда Desktop уже был открыт, полностью закройте Desktop и запустите его заново.
:::

### Agent CLI

HagiCode работает через Agent CLI, которые установлены на вашем компьютере и в которых уже выполнен вход. Мастер инициализации показывает только те CLI, которые обнаружены на этом компьютере, поэтому перед входом в мастер установите хотя бы один из них и выполните вход. Список поддерживаемых CLI, способы установки и официальные точки входа собраны в одном месте: [Установка AI Agent CLI](/ru-RU/related-software-installation/ai-agent-cli/).

## Дальнейшие шаги

1. Выберите способ установки по таблице выше и сначала выполните его предварительные требования.
2. Завершите установку и запустите HagiCode в первый раз, а затем по инструкции [Настройка мастера инициализации](/ru-RU/quick-start/wizard-setup) создайте Hagicoder по умолчанию и первый проект.
3. Чтобы познакомиться с процессом предложений OpenSpec, прочитайте [Введение в OpenSpec](/ru-RU/related-software-installation/openspec/intro-openspec) и [Создать сеанс предложений](/ru-RU/quick-start/proposal-session).
