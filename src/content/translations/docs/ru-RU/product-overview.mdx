HagiCode не даёт ИИ терять контекст при изменении вашего кода: **сначала изучить репозиторий, затем определить границы, после чего выполнять работу с отслеживаемой историей.** Это рабочее пространство с ИИ для разработки проектов, которое подключает привычные вам Agent CLI и модели, поэтому переключаться между редакторами не нужно.

**[Установить HagiCode](/ru-RU/installation/)** · [Посмотреть демонстрационное видео](#product-video-showcase-en)

Поддерживает 11 Agent CLI (Claude Code, Codex, GitHub Copilot и другие) · Работает в Windows, macOS и Linux · Базовые возможности бесплатны

## Как проходит работа над задачей

Предположим, нужно изменить функцию, затрагивающую несколько репозиториев:

1. **Сначала разобраться:** Изучите существующий код в [обычном сеансе](/ru-RU/quick-start/conversation-session). По умолчанию такие сеансы доступны только для чтения; переключитесь в режим редактирования, когда потребуется изменить файлы.
2. **Определить границы:** Для сложного изменения выберите проект и репозитории в [сеансе предложений](/ru-RU/quick-start/proposal-session). Прежде чем перейти к выполнению, опишите цели, задачи и способы проверки.

   ![Панель создания предложения с выбором репозиториев и предварительным просмотром предложения](../img/screenshots/shared/create-proposal-drawser/original.png)

3. **Следить за результатом:** Просматривайте сеансы и состояние выполнения в рабочем пространстве. Когда потребуется подготовить коммит, воспользуйтесь [AI Compose Commit](/ru-RU/guides/ai-compose-commit).

   ![Подробности сеанса после завершения выполнения процесса предложения](../img/screenshots/shared/classic-proposal-view/original.png)

4. **Сохранить контекст:** К предложениям и истории коммитов можно вернуться позже. При работе с несколькими репозиториями используйте [MonoSpecs](/ru-RU/guides/monospecs) для управления связями между ними и областью изменений.

Не для каждой задачи нужно создавать предложение. Начните с обычного сеанса, если вы хотите просто изучить код или решить несложный вопрос. Если задаче требуется больше контекста, HagiCode предоставляет отслеживаемый путь работы.

## Для кого это подходит

- **Хорошо подходит:** разработчикам и командам, которые поддерживают несколько репозиториев и хотят планировать сложные изменения до их выполнения, а также тем, кто уже пользуется Agent CLI, такими как Claude Code или Codex, и хочет собрать их в одном рабочем пространстве.
- **Не обязательно:** если вам нужно лишь дописать несколько строк в редакторе, вам хватит текущих инструментов.

## Возможности по задачам

| Если вы хотите… | Что это | Начните здесь |
| --- | --- | --- |
| Разобраться в коде, прежде чем решать, менять ли его | Обычный сеанс: по умолчанию только чтение, при необходимости переключение в режим редактирования | [Создать обычный сеанс](/ru-RU/quick-start/conversation-session) |

| Помочь ИИ разобраться в связях между репозиториями | MonoSpecs: управляет связями между репозиториями и областью изменений | [Руководство по MonoSpecs](/ru-RU/guides/monospecs) |
| Находить, устанавливать и управлять расширениями | Skills: расширения, которые можно искать и устанавливать | [Руководство по Skills](/ru-RU/guides/skills) |
| Пользоваться привычным Agent CLI | Agent CLI: ИИ-инструменты командной строки, такие как Claude Code и Codex | [Установка AI Agent CLI и поддерживаемые варианты](/ru-RU/related-software-installation/ai-agent-cli/) |
| Управлять подключениями CLI и моделей по отдельности | OmniRoute: подключает несколько OpenAI-совместимых инструментов к одному локальному шлюзу | [Установка OmniRoute и проверка запуска](/ru-RU/related-software-installation/omniroute/) |

Vault собирает справочные репозитории, папки и заметки для дальнейшего использования; Code Server даёт возможность редактировать код через браузер. Для начала работы с HagiCode ни то ни другое не требуется. Подробнее об этих решениях читайте в статьях о [базе знаний Vault](/ru-RU/blog/2026-04-10-vault-system-ai-knowledge-base/) и [редактировании в браузере](/ru-RU/blog/2026-04-13-vscode-web-integration-browser-editing/).

## Сделать долгосрочный прогресс видимым

HagiCode превращает героев, достижения, ежедневные отчёты и метрики Token в обратную связь, чтобы состояние и прогресс было проще видеть со временем; этим он отличается от обычных инструментов программирования с ИИ. В [описании Команды искателей приключений](/ru-RU/adventure-team-introduction) показано, как группируются герои и как продвигаются подземелья; о замысле читайте в [статье о геймификации](/ru-RU/blog/2026-03-16-gamifying-ai-coding/). Это часть рабочего пространства, но использовать HagiCode как обычный инструмент разработки можно и без неё.

## Редакции и цены

Базовые возможности бесплатны. Desktop и Microsoft Store — два разных способа получения HagiCode, а не два платных тарифа. В канале Microsoft Store также доступен Turbo Engine — отдельная покупка с разовой оплатой: она повышает предел одновременно выполняемых предложений и открывает дополнительные возможности, включая темы документации, собственную подпись, оформление бренда и аватары. Какие именно функции он открывает, см. на странице [дополнения Turbo Engine](/ru-RU/dlc/turbo-engine-dlc/).

| Ваша среда | Рекомендуемый вариант |
| --- | --- |
| Windows с доступом к Microsoft Store | [Установка через Microsoft Store](/ru-RU/installation/windows-store) |
| Ручная установка в Windows или локальное использование на macOS либо Linux | [Установка Desktop](/ru-RU/installation/desktop) |

Основное приложение в Steam снято с распространения и больше не служит способом установки. См. [статус распространения в Steam](/ru-RU/faq/steam-distribution-status/).

## Зачем нужно рабочее пространство?

Я Кунь Юй, создатель HagiCode. Один вопрос и ответ могут решить текущую проблему, но при разработке также приходится разбираться в проекте, определять границы задачи, доводить изменения до конца и оценивать результат. Мне хотелось связать эти разрозненные этапы; игровые элементы обратной связи помогают видеть прогресс длительной работы. Можно пользоваться только частью этих возможностей: изучать все модули перед тем, как начать писать код, необязательно.
