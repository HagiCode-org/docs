Эта страница — единая точка входа для локальной установки AI Agent CLI в HagiCode. Сейчас HagiCode активно поддерживает 11 Agent CLI: Claude Code, Codex, GitHub Copilot, OpenCode, Hermes, QoderCLI, Kiro, Kimi, Gemini, DeepAgents, Codebuddy.

:::tip[Как пользоваться этой страницей]
Сначала по таблице ниже определите **текущий статус** и **способ установки** нужного CLI, а затем перейдите в соответствующую официальную документацию, чтобы выполнить установку, вход, настройку ACP, прав доступа и устранение неполадок. Главное: **поддерживается ли CLI** и **поддерживается ли установка в один клик** — это два разных вопроса.
:::

:::note[Сначала подготовьте Node.js 24+]
Большинство CLI, поддерживающих установку в один клик, зависят от Node.js и npm, а Desktop тоже использует `node` и `npm` из вашей системы (Desktop больше не включает Node.js). Сначала подготовьте версию 24 или выше по инструкции [Установка Node.js](/ru-RU/related-software-installation/nodejs/installation), а после установки CLI **выполните вход или аутентификацию**: мастер инициализации показывает только те CLI, которые обнаружены на этом компьютере.
:::

## Описание статусов

- **В настоящее время поддерживается** — CLI входит в текущий диапазон активной поддержки HagiCode и может использоваться в системе как действующий Agent CLI.
- **Установка в один клик** — HagiCode предоставляет управляемую точку входа для установки; после установки некоторые CLI все равно требуют входа или аутентификации по процедуре поставщика.
- **Ручная установка / аутентификация** — CLI входит в текущий диапазон поддержки, но вам нужно сначала самостоятельно выполнить локальную установку, вход или аутентификацию, а затем вернуться в HagiCode и обновить состояние доступности.
- **Сохранено для исторической совместимости** — iFlow CLI сохранен только для совместимости со старыми данными, не входит в текущий список активной поддержки и не должен считаться рекомендуемым вариантом.

- Чтобы увидеть общий путь установки и предварительные требования, такие как Node.js и Git, вернитесь в [Руководство по установке](/ru-RU/installation).
