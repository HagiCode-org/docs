Встроенная поддержка OmniRoute удалена из HagiCode. В продукте больше нет шагов установки, настроек, проверки подключения и синхронизации каталога моделей для OmniRoute.

Чтобы подключить модели сейчас:

- используйте модель, подключённую через Magpie, или
- настройте провайдера и модель, которые ваш Agent CLI поддерживает нативно.

HagiCode не переносит старые адреса и ключи OmniRoute. Выберите поддерживаемого провайдера и модель в настройках. Установку Agent CLI см. в разделе [Установка AI Agent CLI](/ru-RU/related-software-installation/ai-agent-cli/).

## Отдельная документация OmniRoute

OmniRoute — самостоятельный проект с собственным сайтом документации. HagiCode его не поддерживает.
