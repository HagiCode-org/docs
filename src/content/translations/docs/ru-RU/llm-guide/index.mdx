## Зачем нужно руководство по большим языковым моделям

В сценариях генерации кода разные модели заметно различаются по стабильности, скорости, качеству кода и стоимости. Этот раздел предлагает единую рамку сравнения, которая помогает быстро выбрать модель на разных этапах проекта.

## Рекомендуемый порядок чтения

1. Сначала прочитайте статью «[Сравнение и оценка моделей, используемых в HagiCode](./model-comparison-evaluation/)», чтобы познакомиться с критериями сравнения.
2. Выберите модели-кандидаты в соответствии с целью проекта (приоритет качества, стоимости или скорости).
3. Сверьтесь с датами обновления и описанием сценариев в тексте, чтобы убедиться, что выводы по-прежнему применимы к вашей задаче.

## Принципы сопровождения

- Обновляйте выводы оценки при каждом заметном изменении возможностей моделей.
- Проверяйте дату тестирования и границы применимости выводов не реже одного раза в месяц.
- Поддерживайте одинаковую структуру разделов в документах на китайском и английском языках.
