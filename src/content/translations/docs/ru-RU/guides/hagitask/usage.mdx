**Для кого:** Для пользователей, которые уже установили HagiCode и хотят управлять задачами или запускать их.

**Предварительные требования:** Выполните [Установку HagiTask](/ru-RU/guides/hagitask/installation) либо используйте встроенные шаблоны, уже доступные в приложении.

## Поиск задач

Откройте в приложении интерфейс управления задачами HagiTask или задачами сообщества. В нём вместе отображаются встроенные шаблоны, установленные пакеты сообщества, пакеты рабочего пространства и управляемые источники; для каждой задачи указаны её источник и возможность удаления. Каталог Community Gallery предназначен для поиска и получения пакетов сообщества, а доступные серверу каталоги — для обнаружения источников задач средой выполнения.

## Установка задач

Выберите задачу в Gallery и установите её либо воспользуйтесь установкой поддерживаемого локального ZIP-архива, который уже получили. После установки приложение сохраняет канонический ID, версию, издателя, источник, хеш архива и каталог установки. Уже установленная задача с тем же ID не заменяется без уведомления: сначала нужно разобраться с существующей установкой.

## Включение и отключение

- **Включить:** Добавить установленную задачу в активный каталог, чтобы её можно было обнаружить и запустить.
- **Отключить:** Сохранить запись об установке и файлы пакета, но убрать задачу из активного каталога, чтобы она не запускалась.
- **Удалить:** Доступно только для задач сообщества с записью об установке; встроенные задачи показываются для справки и не подлежат удалению.

После изменения состояния приложение обновляет каталог. Если обновление не удаётся, операция должна сохранять прежнее работоспособное состояние, а не оставлять каталог частично обновлённым.

## Обновление каталога и запуск

Используйте действие обновления, чтобы перечитать текущий каталог задач. При принудительном обновлении каталога Gallery приложение снова получает и проверяет данные; действительный кеш может оставаться доступным, если удалённый источник временно не отвечает. Обновление каталога не меняет автоматически состояние включения или версию задач.

Перед запуском убедитесь, что задача включена и её зависимости доступны, затем запустите её из панели задачи или через соответствующий интерфейс запуска. Если задача не отображается, обновите каталог и проверьте состояние установки, ID задачи и уведомления о совместимости. Если схема или ресурсы пакета некорректны, см. [руководство для участников сообщества](/ru-RU/guides/hagitask/community).

## Управление пакетами и серверными источниками

Эти две операции часто путают:

| Функция | Назначение | Что означает путь |
| --- | --- | --- |
| Управление пакетами | Установка, включение, отключение и удаление локальных пакетов HagiTask. | Каталог данных, которым управляет приложение. |
| Управление серверными источниками | Настройка источников задач, по которым среда выполнения обнаруживает задачи в каталоге. | Каталог должен быть доступен серверу. |

Серверная часть читает путь к серверному источнику и обнаруживает пакеты задач в указанном каталоге; это не путь в браузере и не форма загрузки файлов. Текущий процесс установки не загружает локальную папку из браузера напрямую как пакет Community Gallery. Для установки используйте Gallery или поддерживаемый процесс с локальным ZIP.

## Если задача недоступна

1. Убедитесь, что ID задачи, версия и запись об установке по-прежнему существуют.
2. Убедитесь, что задача включена, а необходимые агенты, skills и инструменты CLI подготовлены.
3. Обновите каталог задач и снова откройте интерфейс управления.
4. Если источником служит каталог на сервере, проверьте, что серверный процесс имеет право читать этот путь.
5. Если проверка архива или ресурсов пакета завершается ошибкой, вернитесь к [решению проблем с установкой](/ru-RU/guides/hagitask/installation); если вы сопровождаете пакет, прочитайте [руководство для участников сообщества](/ru-RU/guides/hagitask/community).
