**Для кого:** Для пользователей, сопровождающих и участников сообщества, которые хотят познакомиться с экосистемой HagiTask.

**Предварительные требования:** Нет. Для установки и запуска задач потребуются приложение HagiCode и его серверная служба.

## Что такое HagiTask

HagiTask — это модель пакетов задач и готовых задач для HagiCode. Пакет объединяет идентификатор задачи, панель интерфейса, серверные промпты, шаблоны, тексты интерфейса и описание для каталога в одном каталоге, содержимое которого можно проверить. Благодаря этому приложение может находить, устанавливать, управлять задачами и запускать их.

Пакет задач не является приложением и не заменяет его конфигурацию среды выполнения. Приложение загружает задачи и выполняет объявленные ими функции; пакет лишь предоставляет ресурсы, организованные в согласованном формате.

## Роли в экосистеме

| Компонент | Ответственность |
| --- | --- |
| HagiTask | Поддерживает общую схему (Schema) и пакеты встроенных шаблонов, поставляемых с продуктом; это основной источник формата пакетов. |
| Встроенные шаблоны | Готовые задачи, поставляемые с приложением или средой выполнения, например `normal-session` и `research-investigation`. |
| Community Packages | Поддерживает исходные данные задач сообщества в `data/<taskId>/`. |
| HagiTask Site | Создаёт из исходных пакетов сообщества каталог, JSON-файлы с подробностями и ZIP-архивы и публикует их в Community Gallery. |
| Приложение HagiCode | Показывает задачи, устанавливает пакеты, сохраняет состояние включения и запускает задачи. |

Встроенные шаблоны и задачи сообщества используют одну схему пакетов, но различаются источником и жизненным циклом: встроенные шаблоны сопровождаются в репозитории HagiTask, а задачи сообщества — в репозитории Community Packages. Файл `/index.json`, документы с подробностями и ZIP-архивы на сайте создаются автоматически; участники сообщества не редактируют их как исходные файлы.

## Управление пакетами и управление источниками — разные вещи

При установке ZIP-архива из Gallery пакет копируется в каталог данных приложения, а его версия, источник и состояние включения регистрируются. Управление серверными источниками, напротив, настраивает каталоги, доступные серверу, чтобы среда выполнения могла обнаруживать в них задачи; оно не загружает локальную папку из браузера как установочный пакет.

О различиях между этими операциями и источниках в виде папок читайте в разделе [Использование HagiTask](/ru-RU/guides/hagitask/usage). Чтобы приступить к установке, откройте [Установку HagiTask](/ru-RU/guides/hagitask/installation); чтобы создать или опубликовать задачу, прочитайте [Руководство для участников сообщества](/ru-RU/guides/hagitask/community).

## За что отвечают основные источники

- Документация содержит объяснения и практические руководства для пользователей и участников сообщества.
- HagiTask поддерживает общую схему и исходники встроенных шаблонов.
- Community Packages поддерживает исходные данные пакетов сообщества.
- HagiTask Site публикует созданные из исходных пакетов каталог, подробности и архивы.
