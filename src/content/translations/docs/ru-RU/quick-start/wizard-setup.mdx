Независимо от того, установили ли вы HagiCode через [Microsoft Store](/ru-RU/installation/windows-store), [Desktop](/ru-RU/installation/desktop) или [Docker Compose](/ru-RU/installation/docker-compose), при первом открытии веб-интерфейса HagiCode вы попадете в **мастер инициализации**. После его завершения у вас будет рабочий Hagicoder по умолчанию и хотя бы один проект, и вы сможете сразу начать первый сеанс.

:::note[Он отличается от руководства первого использования Desktop]
«Руководство первого использования» Desktop при первом запуске (выбор языка, подтверждение юридических документов, загрузка Hagicode Server) проходит до появления веб-интерфейса, см. [Установка Desktop](/ru-RU/installation/desktop#руководство-первого-запуска). На этой странице описан мастер инициализации, который появляется позже, уже в веб-интерфейсе.
:::

## Перед началом

Сначала убедитесь, что:

- **Установлен хотя бы один Agent CLI и в нем выполнен вход**. Мастер показывает только те CLI, которые обнаружены на машине, где запущен Hagicode Server; если ни один не обнаружен, создать Hagicoder не получится. Поддерживаемые CLI и способы их установки описаны в [Установка AI Agent CLI](/ru-RU/related-software-installation/ai-agent-cli/).
- **Пользователям Desktop / Store**: Node.js 24+ и Git установлены согласно [Руководству по установке](/ru-RU/installation/#подготовка-перед-установкой).
- **Пользователям Docker**: поставщик API и Token уже настроены в Docker Compose Builder.
- Подготовьте локальный репозиторий или рабочий каталог, который нужно подключить: на шаге 3 вы его зарегистрируете.

## Обзор мастера

Мастер состоит из 4 шагов; текущий прогресс отображается в левой навигации:

| Шаг | Цель | Признак завершения |
| --- | --- | --- |
| 1. Первичная настройка | Выбрать язык интерфейса и тему | Нажата кнопка «Далее: создать проект» |
| 2. Настроить Hagicoder | Выбрать CLI и модель, создать Hagicoder по умолчанию | Нажата кнопка «Подтвердить и создать Hagicoder» либо уже есть доступный Agent |
| 3. Создать проект | Создать хотя бы один проект | На шаге проекта отображается «Этап проекта завершен» |
| 4. Путеводитель по сообществу | Узнать о точках входа в сообщество | Нажата кнопка «Начните использовать HagiCode» |

## Шаг 1: Первичная настройка

**Цель**: определить язык интерфейса и тему.

1. В блоке «Выбрать язык интерфейса» выберите язык. Меняется только текст интерфейса, стиль речи Hagicoder не изменится.
2. В блоке «Выбрать тему» выберите тему. Сейчас доступны «Весенняя светлая» и «Весенняя тёмная».
3. Нажмите «Далее: создать проект».

## Шаг 2: Настроить Hagicoder

**Цель**: создать Agent по умолчанию, имя которого фиксировано — **Hagicoder**.

Если в системе уже есть Agent, на этом шаге появится сообщение «Найдены существующие Агенты» — просто оставьте существующий состав. В противном случае:

1. **Выберите основной AgentCLI**: в раскрывающемся списке отображаются только те CLI, которые обнаружены на этом компьютере. Если появилось сообщение, что доступный CLI не обнаружен, сначала установите его и выполните вход по инструкции [Установка AI Agent CLI](/ru-RU/related-software-installation/ai-agent-cli/), а затем вернитесь и обновите страницу.
2. **Выберите основную модель**:
   - **Выбрать существующий шаблон**: используйте готовые шаблоны моделей этого CLI; поиск возможен по названию или ID модели.
   - **Ввести пользовательскую модель**: введите название модели вручную, например `gpt-5.5`, `glm-5.1`, `claude-opus-4-7`; при создании Hagicoder соответствующий шаблон будет автоматически использован повторно или создан.
3. **(Необязательно) Нажмите «Проверить доступность»**: на выбранный CLI и модель отправляется проверка ping-pong, чтобы убедиться, что модель возвращает `pong`. Результат теста действителен только для текущего сочетания CLI и модели, после изменений тест нужно выполнить заново; для создания Hagicoder успешное прохождение теста не требуется.
4. **(Необязательно) Нажмите «Перемешать»**, чтобы сменить внешний вид по умолчанию: аватар случайно выбирается из галереи.
5. Нажмите «Подтвердить и создать Hagicoder». После успешного создания Hagicoder добавляется в аварийную команду, а выбранные CLI и модель записываются в его конфигурацию по умолчанию.

:::tip[Какие CLI поддерживаются]
Какие CLI можно выбрать в мастере, зависит от Agent CLI, которые установлены на этом компьютере и обнаружены системой; список не ограничен каким-то одним CLI. Полный список поддерживаемых CLI и способы их установки смотрите в [Установка AI Agent CLI](/ru-RU/related-software-installation/ai-agent-cli/); при этом для Hermes, Gemini и DeepAgents сначала нужно выполнить ручную установку или аутентификацию.
:::

**Частые проблемы**

- **Моего CLI нет в списке**: убедитесь, что он установлен и доступен в среде, где работает Hagicode Server; пользователям Desktop нужно перезапустить Desktop, чтобы обновить `PATH`.
- **Тест доступности не пройден**: частые причины — в CLI еще не выполнен вход, токен недействителен или название модели не поддерживается этим CLI. Сначала запустите в терминале минимальный диалог с этим CLI и убедитесь, что он сам по себе работает.
- **Не удалось добавить в аварийную команду**: на странице появится кнопка «Повторить добавление в аварийную команду» — нажмите ее, чтобы повторить попытку.

## Шаг 3: Создать проект

**Цель**: зарегистрировать хотя бы один проект, чтобы у последующих сеансов был рабочий каталог, который можно читать. Мастер сначала проверяет, есть ли уже локальный проект: если есть, показывается краткое описание текущего проекта, если нет — сначала нужно зарегистрировать один.

1. В блоке «Зарегистрируйте один локальный проект» укажите название проекта, путь к папке и, при желании, описание проекта. Поля и проверка пути полностью совпадают с диалогом «Новый проект» в основном интерфейсе.
2. Нажмите «Создать и продолжить», чтобы перейти к следующему шагу; если хотите остаться на этом шаге и добавить еще проекты, нажмите «Создать проект».
3. Если проект уже есть, можно сразу нажать «Продолжить сообщество», либо «Создать еще один проект», либо вернуться к настройке («Вернуться к настройке»).

:::tip[Хотите сначала попробовать пример проекта?]
В мастере можно только зарегистрировать локальный проект. «Демо-проект» находится в основном интерфейсе, в диалоге «Новый проект», на вкладке «Демо-проект»: он автоматически клонирует и регистрирует официальный репозиторий MonoSpecs Demo, путь по умолчанию — `data/repos/monospecs-demo`, а фактический каталог определяется конфигурацией каталога данных времени выполнения (DataDir). Для этого способа нужен Git и доступ к GitHub.
:::

**Частые проблемы**

- **Не пройдена проверка пути**: убедитесь, что путь к папке указан верно и папка действительно существует; при развертывании в Docker нужно указывать каталог, смонтированный внутри контейнера, а не путь на хосте.

## Шаг 4: Путеводитель по сообществу

**Цель**: держать точки входа в сообщество под рукой.

На странице «О программе» официального сайта собраны все точки входа в сообщество. Ссылки открываются в новой вкладке; после просмотра вернитесь в мастер и нажмите «Начните использовать HagiCode», чтобы перейти в рабочее пространство. Мастер можно открыть заново в любой момент и после этого шага.
