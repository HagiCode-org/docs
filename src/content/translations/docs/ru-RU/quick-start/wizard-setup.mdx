Независимо от того, установили ли вы HagiCode через [Microsoft Store](/ru-RU/installation/windows-store), [Desktop](/ru-RU/installation/desktop) или [Docker Compose](/ru-RU/installation/docker-compose), при первом открытии веб-интерфейса HagiCode автоматически появляется **мастер инициализации**. После его завершения у вас будет рабочий Hagicoder по умолчанию и хотя бы один проект, и вы сможете сразу начать первый сеанс.

:::note[Он отличается от руководства первого использования Desktop]
«Руководство первого использования» Desktop при первом запуске (выбор языка, подтверждение юридических документов, загрузка Hagicode Server) проходит до появления веб-интерфейса, см. [Установка Desktop](/ru-RU/installation/desktop#руководство-первого-запуска). На этой странице описан мастер инициализации, который появляется позже, уже в веб-интерфейсе.
:::

## Перед началом

Сначала убедитесь в следующем:

- **Установлен хотя бы один Agent CLI и в нем выполнен вход**. Мастер показывает только те CLI, которые обнаружены на машине, где запущен Hagicode Server; если ни один не обнаружен, создать Hagicoder не получится. Поддерживаемые CLI и способы их установки описаны в [Установка AI Agent CLI](/ru-RU/related-software-installation/ai-agent-cli/).
- **Пользователям Desktop / Store**: Node.js 24+ и Git установлены согласно [Руководству по установке](/ru-RU/installation/#подготовка-перед-установкой).
- **Пользователям Docker**: поставщик API и Token уже настроены в Docker Compose Builder.
- Подготовьте локальный репозиторий или рабочий каталог, который хотите подключить: на шаге 3 вам предложат его зарегистрировать, и указанный путь должен существовать.

## Обзор мастера

Мастер состоит из 4 шагов; навигация слева показывает текущий прогресс, а значок вверху отображает «Готово шагов: N из 3». Первые 3 шага — **обязательные**, а шаг 4 «Сообщество» помечен как **необязательный** («Необязательно»):

| Шаг | Цель | Признак завершения |
| --- | --- | --- |
| 1. Язык и тема | Выбрать язык интерфейса и сезонную цветовую тему | Нажать «Продолжить», чтобы подтвердить язык |
| 2. Hagicoder | Выбрать CLI и модель и создать Hagicoder по умолчанию | У Агента отображается «Агент уже в Резервный экипаж» |
| 3. Проект | Зарегистрировать хотя бы один локальный проект | На шаге проекта отображается «Шаг проекта завершён» |
| 4. Сообщество (необязательно) | Начать первый диалог или посмотреть входы в сообщество | Нажать «Готово» |

Кнопка «Напомнить позже» в левом нижнем углу пока скрывает мастер и напомнит о нём позже; «Больше не показывать» отключает автоматическое появление. В обоих случаях мастер можно в любой момент открыть снова через пункт «Волшебник» в верхней части страницы, а незавершённые шаги останутся ожидающими.

## Шаг 1: Язык и тема

**Цель**: определить язык интерфейса и цветовую тему.

![Шаг 1 мастера инициализации: список языков, темы четырёх времён года и кнопка «Продолжить»](../../img/screenshots/quick-start/wizard-setup/step1-language-theme/original.png)

1. В разделе «Выберите язык интерфейса» выберите язык (доступно 10 языков). Меняется только язык интерфейса приложения; герои и проекты не затрагиваются.
2. В разделе «Выберите цветовую тему» для любого времени года — весны, лета, осени или зимы — выберите вариант «Свет» или «Темный». Тема применяется сразу, позже её можно сменить через пункт выбора темы в верхней части страницы.
3. Нажмите «Продолжить». После подтверждения языка вы перейдёте к следующему шагу — Hagicoder.

## Шаг 2: Настроить Hagicoder

**Цель**: создать Агента по умолчанию, имя которого всегда **Hagicoder**, и добавить его в резервный экипаж.

Если в системе уже есть Агенты, на этом шаге отобразится «Найдены Агенты» или сразу «Агент уже в Резервный экипаж»:

- Если есть Агент, не входящий в резервный экипаж, можно нажать «Добавить в Резервный экипаж» или выбрать «Создать нового Агент». Мастер не добавляет его автоматически.
- Если он уже входит в резервный экипаж, просто нажмите «Далее: создать проект».

В противном случае создайте его по следующей схеме:

1. **Выберите основной AgentCLI**: показываются только CLI, обнаруженные на этом компьютере; у выбранной карточки справа появляется галочка.
2. **Выберите основной Модель**:
   - Выберите существующую модель в списке; её можно отфильтровать по имени или ID модели с помощью поля поиска выше.
   - Либо вручную введите имя модели в поле «Ввести свою модель», например `gpt-5.5`, `glm-5.1`, `claude-opus-4-7`; при создании бэкенд использует подходящий шаблон или создаст его.

   ![Шаг 2: выбор Claude Code и Sonnet 5.5](../../img/screenshots/quick-start/wizard-setup/step2-cli-model/original.png)

3. **(Рекомендуется) Нажмите «Запустить проверку подключения»**: проверяет, доступен ли выбранный CLI. Она **не** отправляет модели запрос, поэтому подтверждает только то, что CLI можно вызвать, но не ответы модели. Результат «CLI доступен» означает, что проверка пройдена; если проверка не пройдена или время истекло, это не мешает создать Агента, но он может не работать должным образом, пока CLI не будет исправлен.
4. **(Необязательно) Выберите портрет по умолчанию**: выберите один из предложенных портретов или нажмите «Перемешать», чтобы увидеть другие варианты.
5. Нажмите «Создать Агент». При успехе на странице отобразится «Агент уже в Резервный экипаж», а выбранные CLI и модель будут записаны в конфигурацию Hagicoder по умолчанию.

   ![Шаг 2: проверка подключения пройдена, портрет по умолчанию и кнопка «Создать Агент»](../../img/screenshots/quick-start/wizard-setup/step2-connection-test/original.png)

6. Нажмите «Далее: создать проект».

:::tip[Какие CLI поддерживаются]
Какие CLI можно выбрать в мастере, зависит от Agent CLI, которые установлены на этом компьютере и обнаружены системой; список не ограничен каким-то одним CLI. Полный список поддерживаемых CLI и способы их установки смотрите в [Установка AI Agent CLI](/ru-RU/related-software-installation/ai-agent-cli/); при этом для Hermes, Gemini и DeepAgents сначала нужно выполнить ручную установку или аутентификацию.
:::

**Частые проблемы**

- **Появилось сообщение «Локальный CLI не найден»**: сначала установите CLI на этом компьютере и выполните вход по инструкции [Установка AI Agent CLI](/ru-RU/related-software-installation/ai-agent-cli/), затем нажмите «Найти заново». Можно также нажать «Пропустить пока»: этот шаг останется незавершённым, и мастер напомнит о нём позже.
- **Моего CLI нет в списке**: убедитесь, что он установлен и доступен в среде, где запущен Hagicode Server; пользователям Desktop следует перезапустить Desktop, чтобы обновить `PATH`.
- **Проверка подключения не пройдена**: на странице отображается причина сбоя. Частые причины — в CLI ещё не выполнен вход или токен недействителен. Сначала запустите в терминале минимальный диалог с этим CLI, чтобы убедиться, что он сам работает, а затем нажмите «Повторить».
- **Агент создан, но добавить его в резервный экипаж не удалось**: на странице есть кнопка «Повторить добавление в Резервный экипаж»; повтор добавляет только того же Агента и не создаёт дубликат.

## Шаг 3: Создать проект

**Цель**: зарегистрировать хотя бы один проект, чтобы у последующих сеансов был доступный для чтения рабочий каталог. Мастер сначала проверяет, есть ли уже проекты: если их нет, показывает форму регистрации, если есть — сводку текущего проекта.

![Шаг 3: форма регистрации локального проекта](../../img/screenshots/quick-start/wizard-setup/step3-project-form/original.png)

1. В разделе «Регистрация локального проекта» укажите **название проекта** (обязательно), **путь к папке** (обязательно) и при желании **описание проекта**. Поля и проверка пути полностью совпадают с диалогом «Новый проект» в основном интерфейсе.
2. Нажмите «Создать проект и продолжить». Путь проверяется при сохранении; если проверка пройдена, проект создаётся, и мастер автоматически переходит к следующему шагу.
3. Если вернуться к этому шагу после создания проекта, вы увидите «Текущая сводка проектов» и отметку «Шаг проекта завершён». Теперь можно нажать «Продолжить», чтобы перейти к сообществу, или «Добавить ещё один проект», чтобы зарегистрировать другие проекты (сохраните их кнопкой «Добавить проект» или вернитесь к сводке кнопкой «Отмена»).

![Шаг 3: сводка текущего проекта, когда проекты уже есть](../../img/screenshots/quick-start/wizard-setup/step3-project-done/original.png)

:::tip[Хотите сначала попробовать на демонстрационном проекте?]
В мастере можно только зарегистрировать локальный проект. «Демо-проект» находится на вкладке «Демо-проект» диалога «Новый проект» в основном интерфейсе: он автоматически клонирует и регистрирует официальный репозиторий MonoSpecs Demo; путь по умолчанию — `data/repos/monospecs-demo`, а фактический каталог определяется настройкой каталога данных (DataDir) во время выполнения. Для этого способа нужны Git и доступ к GitHub.
:::

**Частые проблемы**

- **Появилось сообщение «Не удалось создать проект»**: убедитесь, что путь к папке указан верно и действительно существует; при развёртывании в Docker нужно указывать смонтированный каталог, доступный внутри контейнера, а не путь на хосте.

## Шаг 4: Сообщество

**Цель**: убедиться, что всё готово, и выбрать, что делать дальше. Этот шаг необязательный.

![Шаг 4: HagiCode готов к работе; можно начать первый диалог или открыть страницу «О программе»](../../img/screenshots/quick-start/wizard-setup/step4-community/original.png)

Когда все три обязательных шага выполнены, на странице отображается «HagiCode готов к работе» и состояние завершения трёх обязательных шагов:

- **Начать первый диалог**: после нажатия мастер закрывается, а в рабочей области открывается окно создания диалога. Для диалога нужен проект; если проекта ещё нет, появится сообщение «Сначала создайте проект» и кнопка «Перейти к шагу „Проект“».
- **О HagiCode**: при нажатии «Открыть страницу „О программе“» в браузере открывается страница «О программе» официального сайта, где собраны все входы в сообщество; мастер остаётся открытым.
- **Готово**: нажатие «Готово» в правом нижнем углу закрывает мастер. Если остаются незавершённые обязательные шаги, они остаются ожидающими, и мастер можно снова открыть через пункт «Волшебник» в верхней части страницы.
