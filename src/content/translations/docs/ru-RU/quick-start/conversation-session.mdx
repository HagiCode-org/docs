Сессии-беседы — самая лёгкая точка входа в HagiCode. Выберите проект, задайте вопрос, и Агент прочитает репозиторий и ответит. Для каждой сессии вы сами решаете, может ли Агент изменять файлы.

## Предварительные требования

Прежде чем начинать сессию-беседу, убедитесь, что вы:

- завершили установку любым из способов (Microsoft Store или Desktop), следуя [руководству по установке](/ru-RU/installation)
- прошли [Wizard Setup](/ru-RU/quick-start/wizard-setup) (мастер настройки), который создаёт вашего первого Агента и как минимум один проект
- выбрали этот проект на доске сессий

## Для чего нужна сессия-беседа?

Сессия-беседа лучше всего подходит, когда сначала нужно разобраться, а потом уже вносить правки. Типичные сценарии:

- быстро проанализировать незнакомый репозиторий
- задать точечный вопрос об одном файле, модуле или ошибке
- внести небольшое изменение, не оформляя его как предложение
- прикрепить изображения, стандартные фразы или прежние сообщения перед отправкой

Если задача уже перешла от этапа «разобраться в проблеме» к этапу «спланировать, проверить и заархивировать структурированное изменение», переходите к разделу [Создание сессии-предложения](/ru-RU/quick-start/proposal-session). Эта страница посвящена только сессиям-беседам.

## Обзор рабочего процесса

| Этап | Что вы делаете | Что происходит |
| --- | --- | --- |
| Создание | Нажмите **Create Normal Session** и опишите, что вам нужно | Панель собирает проект, необязательный заголовок, область задачи и ваше первое сообщение |
| Запуск | Выберите Агента в **Available Agents** | Сессия сразу запускается и появляется в колонке **Execution** |
| Чтение | Откройте карточку сессии | Агент читает репозиторий и отвечает; карточка **Session Complete** подводит итог запуска |
| Решение | Используйте переключатель режима рядом с полем сообщения | Остаться в режиме только чтения или включить режим редактирования, чтобы Агент мог изменять файлы |
| Добавление контекста | Используйте кнопки изображения, стандартных фраз и истории | Ваше следующее сообщение несёт больше контекста |

## Шаг 1. Создайте сессию

Выберите проект и нажмите **Create Normal Session** (значок речевого облачка) на панели инструментов над доской.

![Панель Create Normal Session с проектом, заголовком сессии, областью задачи, запросом и выбором Available Agents](../../img/quick-start/conversation-session/01-create-normal-session.png)

Заполните панель:

- **Project** (обязательно) – по умолчанию выбран текущий проект.
- **Session title** – необязательно; становится заголовком карточки на доске.
- **Task scope** – необязательно. **Repos** ограничивает сессию репозиториями проекта MonoSpecs, а **Vault** и **Projects** добавляют дополнительные справочные материалы.
- **What do you want to do?** (обязательно) – ваше первое сообщение. **Upload Image** прикрепляет картинку.

Рядом с панелью открывается список **Available Agents**. Нажмите на Агента, и сессия **запустится сразу**. Первая карточка — Агент по умолчанию; второй список позволяет выбрать другого Агента только для этого запуска. Отправить сообщение можно и с клавиатуры: `Ctrl/⌘ + Enter`.

:::tip[Начните с вопроса, а не с изменения]
Первое сообщение вроде «В двух предложениях: чем занимается этот проект? Не изменяй файлы.» — безопасный способ убедиться, что Агент и проект настроены правильно.
:::

## Шаг 2. Прочитайте результат

Новая сессия появляется карточкой в колонке **Execution** со значком статуса. Нажмите на неё, чтобы открыть сессию.

![Панель сессии с ответом Агента, итогом Session Complete, полем сообщения и карточкой состояния Агента](../../img/quick-start/conversation-session/02-session-detail.png)

- В **заголовке** показаны название и Агент, а также кнопки **Archive**, **Delete Session**, **Open Code Server** и меню **…**.
- В **беседе** перечислены ваше сообщение, вызовы инструментов Агентом в виде карточек и его ответ.
- Карточка **Session Complete** завершает каждый запуск: она показывает число ходов, затраченное время и стоимость. Нажмите на неё, чтобы развернуть подробности.
- **Карточка состояния Агента** справа от поля сообщения показывает Agent CLI, модель, состояние (например, *Idle*) и затраченное время.

Введите уточняющий вопрос в поле сообщения. `Enter` отправляет сообщение, `Shift + Enter` — переход на новую строку.

## Шаг 3. Выберите режим только чтения или режим редактирования

У переключателя слева от поля сообщения два положения. Глаз — это **режим только чтения**: Агент может изучать и объяснять, но не изменяет файлы. Карандаш — это **режим редактирования**: новые сообщения с большей вероятностью изменят файлы или скорректируют текущую реализацию.

![Поле сообщения с выбранным карандашом (режим редактирования)](../../img/quick-start/conversation-session/03-composer-edit.png)

![Поле сообщения с выбранным глазом (режим только чтения)](../../img/quick-start/conversation-session/04-composer-readonly.png)

Режим относится к текущей сессии, и его можно менять между сообщениями. Будут ли **новые** обычные сессии запускаться в режиме редактирования, определяет параметр **Settings → Sessions and conversation → Chat View → Default to Edit Mode for Normal Chats**. См. [Settings](/ru-RU/user-guide/settings).

Безопаснее действовать просто: сначала согласуйте направление в режиме только чтения, а затем переключитесь в режим редактирования, когда действительно нужны изменения.

## Шаг 4. Добавьте контекст перед отправкой

Три кнопки рядом с переключателем режима добавляют контекст к следующему сообщению:

- **Insert an image attachment** – прикрепите снимок экрана, захват ошибки или макет. Изображение появляется над полем сообщения с именем файла и размером; перед отправкой его можно убрать кнопкой **×**.
- **Standard Phrases** – вставляет ссылку `@`. В списке доступны **Projects** (канонический путь к корню проекта), **Vaults** (путь к зарегистрированному хранилищу), **Proposal Sessions** (папка изменения OpenSpec) и **Recent Items**.
- **Import Recent History** – повторно использует одно из недавних сообщений этой сессии, чтобы не печатать его заново.

![Поле сообщения с прикреплённым изображением над ним](../../img/quick-start/conversation-session/05-composer-image.png)

![Список стандартных фраз, открытый из поля сообщения, с разделами Projects, Vaults, Proposal Sessions и Recent Items](../../img/quick-start/conversation-session/06-standard-phrases.png)

Изображения полезны, когда вы хотите:

- попросить Агента объяснить снимок экрана интерфейса
- прикрепить снимок экрана с ошибкой или макет дизайна и добавить дальнейшие инструкции
- дать визуальный контекст перед переключением в режим редактирования

## Типичная последовательность

1. **Создайте** сессию на панели инструментов и выберите Агента.
2. **Начните в режиме только чтения** с вопроса о проекте.
3. **Прочитайте ответ**, затем задайте уточняющие вопросы.
4. **Включайте режим редактирования** только тогда, когда нужны прямые изменения файлов.
5. **Добавляйте изображения, стандартные фразы или историю**, чтобы дать следующему сообщению больше контекста.
6. **Архивируйте** сессию, когда закончите: она переместится в колонку **Archived**.

Если задача теперь требует планирования, проверки и дисциплины архивирования, переходите к руководству по сессиям-предложениям.
