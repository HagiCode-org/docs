Unabhängig davon, ob Sie HagiCode über den [Microsoft Store](/de-DE/installation/windows-store) oder [Desktop](/de-DE/installation/desktop) installiert haben: Beim ersten Öffnen der HagiCode-Weboberfläche erscheint automatisch der **Initialisierungsassistent**. Danach verfügen Sie über einen nutzbaren Standard-Hagicoder und mindestens ein Projekt und können direkt Ihre erste Sitzung starten.

:::note[Nicht zu verwechseln mit der Ersteinrichtung von Desktop]
Die „Erstmalige Einrichtung“ beim ersten Start von Desktop (Sprache auswählen, rechtliche Dokumente bestätigen, Hagicode Server herunterladen) findet statt, bevor die Weboberfläche erscheint; siehe [Desktop-Installation](/de-DE/installation/desktop#ersteinrichtung-beim-ersten-start). Diese Seite beschreibt den Initialisierungsassistenten, der danach in der Weboberfläche erscheint.
:::

## Bevor Sie beginnen

Bitte stellen Sie zuerst Folgendes sicher:

- **Mindestens eine Agent CLI ist installiert und angemeldet**. Der Assistent listet nur CLIs auf, die auf dem Rechner erkannt wurden, auf dem Hagicode Server läuft. Wird keine erkannt, können Sie keinen Hagicoder erstellen. Unterstützte CLIs und Installationswege finden Sie unter [AI Agent CLI-Installation](/de-DE/related-software-installation/ai-agent-cli/).
- **Desktop-/Store-Nutzer**: Node.js 24+ und Git sind gemäß der [Installationsanleitung](/de-DE/installation/#vorbereitung-vor-der-installation) installiert.
- Halten Sie ein lokales Repository oder Arbeitsverzeichnis bereit, das Sie anbinden möchten: In Schritt 3 registrieren Sie es, und der Pfad muss tatsächlich existieren.

## Überblick über den Assistenten

Der Assistent besteht aus 4 Schritten. Die linke Navigation zeigt den aktuellen Fortschritt, und das Badge oben zeigt „N von 3 Pflichtschritten bereit“. Die ersten 3 Schritte sind **Pflichtschritte**, der 4. Schritt „Community“ ist als **Optional** gekennzeichnet:

| Schritt | Ziel | Abschlusskriterium |
| --- | --- | --- |
| 1. Sprache & Design | Oberflächensprache wählen und ein saisonales Farbthema auswählen | Klick auf „Weiter“ bestätigt die Sprache |
| 2. Hagicoder | CLI und Modell wählen, Standard-Hagicoder erstellen | Der agent zeigt „Der Agent ist in Fallback-Crew“ an |
| 3. Projekt | Mindestens ein lokales Projekt registrieren | Der Projektschritt zeigt „Projektschritt abgeschlossen“ an |
| 4. Community (optional) | Erste Unterhaltung starten oder die Community-Einstiegspunkte ansehen | Klick auf „Fertig“ |

„Später erinnern“ unten links blendet den Assistenten zunächst aus und erinnert Sie später erneut; „Nicht mehr anzeigen“ schaltet das automatische Einblenden ab. In beiden Fällen können Sie den Assistenten jederzeit über den Eintrag „Zauberer“ oben auf der Seite erneut öffnen, und nicht abgeschlossene Schritte bleiben offen.

## Schritt 1: Sprache & Design

**Ziel**: Oberflächensprache und Farbthema festlegen.

![Schritt 1 des Initialisierungsassistenten: Sprachliste, vier Jahreszeitenthemen und die Schaltfläche „Weiter“](../../img/quick-start/wizard-setup/01-language-theme.png)

1. Wählen Sie unter „Oberflächensprache wählen“ eine Sprache (10 werden unterstützt). Dadurch ändert sich nur die UI-Sprache der App; Helden und Projekte bleiben unverändert.
2. Wählen Sie unter „Farbthema wählen“ für eine der Jahreszeiten Frühling, Sommer, Herbst oder Winter die Variante „Licht“ oder „Dunkel“. Die Auswahl wird sofort angewendet und lässt sich später über den Themen-Eintrag oben auf der Seite ändern.
3. Klicken Sie auf „Weiter“. Die Sprache wird bestätigt, und es geht weiter mit dem nächsten Schritt, Hagicoder.

## Schritt 2: Hagicoder einrichten

**Ziel**: Den Standard agent erstellen; sein Name ist fest **Hagicoder**, und er wird der Fallback-Crew hinzugefügt.

Wenn im System bereits ein agent vorhanden ist, zeigt dieser Schritt „Agenten gefunden“ an oder direkt „Der Agent ist in Fallback-Crew“:

- Ist ein agent vorhanden, aber nicht in der Fallback-Crew, können Sie auf „Zu Fallback-Crew hinzufügen“ klicken oder stattdessen „Stattdessen neuen Agent erstellen“ wählen. Der Assistent fügt ihn nicht automatisch hinzu.
- Ist er bereits in der Fallback-Crew, klicken Sie einfach auf „Weiter: Projekt erstellen“.

Andernfalls gehen Sie so vor:

1. **Primäre AgentCLI wählen**: Es werden nur CLIs angezeigt, die auf diesem Rechner erkannt wurden; die ausgewählte Karte zeigt rechts ein Häkchen.
2. **Primäres Modell wählen**:
   - Wählen Sie ein vorhandenes Modell aus der Liste; über das Suchfeld darüber („Modelle durchsuchen“) können Sie nach Name oder Modell-ID filtern.
   - Oder geben Sie unter „Eigenes Modell eingeben“ den Modellnamen manuell ein, zum Beispiel `gpt-5.5`, `glm-5.1` oder `claude-opus-4-7`. Beim Erstellen übernimmt das Backend die passende Vorlage oder legt sie an.

   ![Schritt 2: Claude Code und Sonnet 5.5 auswählen](../../img/quick-start/wizard-setup/02-cli-model.png)

3. **(Empfohlen) Klicken Sie auf „Verbindungstest starten“**: Er prüft, ob die gewählte CLI verfügbar ist. Dabei wird **kein** Prompt an das Modell gesendet; er bestätigt also nur, dass die CLI aufgerufen werden kann, nicht aber Antworten des Modells. Lautet das Ergebnis „Die CLI ist verfügbar“, ist der Test bestanden. Ein fehlgeschlagener oder abgelaufener Test verhindert das Erstellen nicht, aber der agent funktioniert möglicherweise erst, wenn die CLI behoben ist.
4. **(Optional) Standardporträt wählen**: Wählen Sie eines der vorgeschlagenen Porträts oder klicken Sie auf „Mischen“, um andere Optionen zu sehen.
5. Klicken Sie auf „Agent erstellen“. Nach erfolgreicher Erstellung zeigt die Seite „Der Agent ist in Fallback-Crew“ an, und die gewählte CLI sowie das gewählte Modell werden in die Standardkonfiguration des Hagicoders geschrieben.

   ![Schritt 2: bestandener Verbindungstest, Standardporträt und die Schaltfläche „Agent erstellen“](../../img/quick-start/wizard-setup/03-connection-test.png)

6. Klicken Sie auf „Weiter: Projekt erstellen“.

:::tip[Welche CLIs werden unterstützt]
Welche CLIs im Assistenten wählbar sind, hängt von den lokal installierten und erkannten Agent CLIs ab; es gibt keine Beschränkung auf eine bestimmte. Den vollständigen Unterstützungsumfang und die Installationswege finden Sie unter [AI Agent CLI-Installation](/de-DE/related-software-installation/ai-agent-cli/). Hermes, Gemini und DeepAgents erfordern zuvor eine manuelle Installation oder Authentifizierung.
:::

**Häufige Probleme**

- **Die Meldung „Keine lokale CLI verfügbar“ erscheint**: Installieren Sie zuerst gemäß [AI Agent CLI-Installation](/de-DE/related-software-installation/ai-agent-cli/) eine CLI auf diesem Rechner und melden Sie sich an, und klicken Sie dann auf „Erneut erkennen“. Sie können auch auf „Vorerst überspringen“ klicken; dieser Schritt bleibt dann offen, und der Assistent erinnert Sie später daran.
- **Meine CLI erscheint nicht in der Liste**: Stellen Sie sicher, dass sie installiert und in der Umgebung verfügbar ist, in der Hagicode Server läuft. Desktop-Nutzer starten Desktop neu, damit der `PATH` neu eingelesen wird.
- **Der Verbindungstest schlägt fehl**: Die Seite zeigt den Grund an. Häufige Ursachen sind eine noch nicht angemeldete CLI oder ein ungültiges Token. Führen Sie zuerst im Terminal einen minimalen Dialog mit dieser CLI aus, um zu bestätigen, dass sie selbst funktioniert, und klicken Sie dann auf „Erneut ausführen“.
- **Der agent wurde erstellt, aber das Hinzufügen zur Fallback-Crew ist fehlgeschlagen**: Die Seite bietet „Hinzufügen zu Fallback-Crew erneut versuchen“ an. Der erneute Versuch fügt nur denselben agent hinzu und erstellt keinen zweiten.

## Schritt 3: Projekt erstellen

**Ziel**: Mindestens ein Projekt registrieren, damit spätere Sitzungen ein lesbares Arbeitsverzeichnis haben. Der Assistent prüft zuerst, ob bereits ein Projekt vorhanden ist: Ist keines vorhanden, zeigt er das Registrierungsformular an, andernfalls die aktuelle Projektübersicht.

![Schritt 3: Formular zum Registrieren eines lokalen Projekts](../../img/quick-start/wizard-setup/04-project-form.png)

1. Geben Sie unter „Ein lokales Projekt registrieren“ den **Projektnamen** (Pflicht), den **Ordnerpfad** (Pflicht) und optional eine **Projektbeschreibung** an. Felder und Pfadprüfung sind identisch mit dem Dialog „Neues Projekt“ der Hauptoberfläche.
2. Klicken Sie auf „Projekt erstellen und fortfahren“. Der Pfad wird beim Speichern geprüft; nach bestandener Prüfung wird das Projekt erstellt, und der Assistent wechselt automatisch zum nächsten Schritt.
3. Kehren Sie nach dem Erstellen eines Projekts zu diesem Schritt zurück, sehen Sie „Aktuelle Projektübersicht“ und die Markierung „Projektschritt abgeschlossen“. Nun können Sie auf „Weiter“ klicken, um zur Community zu gelangen, oder auf „Weiteres Projekt hinzufügen“, um weitere Projekte zu registrieren (speichern Sie mit „Projekt hinzufügen“ oder kehren Sie mit „Abbrechen“ zur Übersicht zurück).

![Schritt 3: aktuelle Projektübersicht, wenn bereits ein Projekt vorhanden ist](../../img/quick-start/wizard-setup/05-project-summary.png)

:::tip[Lieber zuerst mit einem Beispielprojekt ausprobieren?]
Der Assistent bietet nur das Registrieren eines lokalen Projekts an. Das „Demoprojekt“ finden Sie in der Hauptoberfläche im Dialog „Neues Projekt“ auf der Registerkarte „Demoprojekt“: Es klont und registriert automatisch das offizielle MonoSpecs-Demo-Repository. Der Standardpfad ist `data/repos/monospecs-demo`; das tatsächliche Verzeichnis richtet sich nach der Konfiguration des Laufzeit-Datenverzeichnisses (DataDir). Dieser Weg erfordert Git und Zugriff auf GitHub.
:::

**Häufige Probleme**

- **Die Meldung „Projekt konnte nicht erstellt werden“ erscheint**: Stellen Sie sicher, dass der Ordnerpfad korrekt ist und wirklich existiert.

## Schritt 4: Community

**Ziel**: Bestätigen, dass alles bereit ist, und entscheiden, was als Nächstes geschehen soll. Dieser Schritt ist optional.

![Schritt 4: HagiCode ist einsatzbereit; Sie können die erste Unterhaltung starten oder die Über-Seite öffnen](../../img/quick-start/wizard-setup/06-community.png)

Sind alle drei Pflichtschritte abgeschlossen, zeigt die Seite „HagiCode ist einsatzbereit“ und den Abschlussstatus der drei Pflichtschritte an:

- **Erste Unterhaltung starten**: Nach dem Klick schließt sich der Assistent, und im Arbeitsbereich öffnet sich der Dialog für eine neue Unterhaltung. Eine Unterhaltung braucht ein Projekt; ist noch keines vorhanden, erscheint hier „Lege zuerst ein Projekt an“ samt der Schaltfläche „Zum Schritt Projekt“.
- **Über HagiCode**: Ein Klick auf „Über-Seite öffnen“ öffnet im Browser die Seite „Info“ der offiziellen Website, die alle Community-Einstiegspunkte bündelt; der Assistent bleibt geöffnet.
- **Fertig**: Ein Klick auf „Fertig“ unten rechts schließt den Assistenten. Sind noch Pflichtschritte offen, bleiben sie offen, und Sie können den Assistenten über den Eintrag „Zauberer“ oben auf der Seite erneut öffnen.
