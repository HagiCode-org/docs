Für Windows-Nutzer ist der Microsoft Store derzeit der öffentliche Desktop-Einstiegspunkt. Diese Seite behandelt nur den Store-Pfad. Für die allgemeine Desktop-Download-, Versionsverwaltungs- und Fehlerbehebungsanleitung lesen Sie [Desktop-Installation](/de-DE/installation/desktop).

Der Haupt-App-Eintrag bei Steam wurde bereits eingestellt. Damit ist der Microsoft Store jetzt der primäre Windows-Vertriebskanal. Hintergrund dazu finden Sie unter [Warum HagiCode nicht auf Steam verfügbar ist](/de-DE/faq/steam-distribution-status/).

:::tip[Geeignet für diesen Weg]
- Sie verwenden Windows 10 oder Windows 11 und möchten direkt über den System-Store installieren
- Sie bevorzugen Store-gelieferte App-Pakete statt manuell mit Installationsdateien zu arbeiten
- Sie benötigen nur ein lokales persönliches Setup und planen keine Docker-Compose-Bereitstellung
:::

## Vor dem Start

Bitte stellen Sie vor dem Start sicher, dass die folgenden Bedingungen erfüllt sind:

- Das Gerät muss die [Windows-Store-Seite für HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW) öffnen können
- Beim ersten Start muss das Netzwerk verfügbar sein, da das Programm möglicherweise noch die für Hagicode Server benötigten Komponenten herunterladen oder vorbereiten muss
- Je nach Gerät, Region oder Unternehmensrichtlinie kann eine Microsoft-Konto-Anmeldung erforderlich sein
- Wenn der Store auf Ihrem Rechner blockiert ist, wechseln Sie zu [Desktop-Installation](/de-DE/installation/desktop)

## Vorbereitung vor der Installation

Die Store-Version läuft nach demselben Prinzip wie Desktop: Sie **enthält kein Node.js**. Sie müssen es selbst installieren und dafür sorgen, dass es im System-`PATH` auffindbar ist. Bereiten Sie vor dem ersten Start Folgendes vor:

- **Node.js 24 oder höher** (liefert zugleich `npm`), siehe [Node.js installieren](/de-DE/related-software-installation/nodejs/installation)
- **Git**, siehe [Git installieren](/de-DE/installation/#git-installieren)
- Mindestens eine installierte und angemeldete **Agent CLI**, siehe [AI Agent CLI-Installation](/de-DE/related-software-installation/ai-agent-cli/)

Wenn Sie diese erst installieren, nachdem HagiCode bereits geöffnet war, beenden Sie HagiCode vollständig und starten Sie es neu, damit es den neuen `PATH` einliest.

## Installation aus dem Microsoft Store

1. Öffnen Sie [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW).
2. Klicken Sie auf `Abrufen`, `Installieren` oder die entsprechende Aktion im Store.
3. Warten Sie, bis der Microsoft Store Download und Installation abgeschlossen hat.
4. Starten Sie HagiCode anschließend über das Startmenü oder direkt aus dem Store.

## Was beim ersten Start passiert

Nach der Installation setzt HagiCode weiterhin den normalen Desktop-Initialisierungsablauf fort.

- Der erste Start führt zunächst durch die „Erstmalige Einrichtung“ von Desktop: Sprache auswählen, rechtliche Dokumente bestätigen und bei Bedarf Hagicode Server herunterladen. Deshalb kann er langsamer wirken als bei gewöhnlichen Apps
- Der Microsoft Store-/MSIX-Kanal sperrt die Einstellung „Speicherpfad für Laufzeitdaten“; das ist bei dieser Vertriebsart erwartetes Verhalten
- Die App aktualisiert sich nicht eigenständig; die Paketbereitstellung hängt vom Installationskanal ab, und beim Store-Build erfolgt sie über den Microsoft Store-Kanal

Wenn Sie mit dem Initialisierungsassistenten fortfahren möchten, lesen Sie [Assistent zum Einrichten](/de-DE/quick-start/wizard-setup).

## Wann ein anderer Installationsweg sinnvoller ist

Ein anderer Kanal passt besser in diesen Fällen:

- Sie können den Microsoft Store nicht nutzen oder Store-Installationen sind organisatorisch gesperrt
- Sie müssen `.exe`- oder `.msix`-Dateien manuell herunterladen und die Quelle selbst kontrollieren
- Sie stellen für Server, NAS oder Teams bereit; in diesem Fall passt [Docker Compose-Bereitstellung](/de-DE/installation/docker-compose) besser

## Fehlerbehebung

### Die Microsoft-Store-Seite öffnet sich nicht

Prüfen Sie zuerst Netzwerkzugang, Regionseinstellungen und den Microsoft-Store-Anmeldestatus. Wenn der Browser-Link funktioniert, der Store-Client aber nicht verfügbar ist, liegt die Ursache oft an einer lokalen Systemrichtlinie. Wechseln Sie dann zu [Desktop-Installation](/de-DE/installation/desktop).

### Einige Einstellungen sind ausgegraut

Store-/MSIX-Installationen sperren die Option „Speicherpfad für Laufzeitdaten“ und zeigen „Durch Microsoft Store gesperrt“ an. Das ist kein Installationsfehler, sondern eine Eigenschaft dieses Vertriebskanals.

### Beim ersten Start werden weitere Inhalte heruntergeladen oder vorbereitet

Das Store-Paket liefert nur das Desktop-Anwendungspaket aus. Beim ersten Start kann HagiCode weiterhin die für Hagicode Server benötigten Komponenten herunterladen oder vorbereiten und die Standardinitialisierung abschließen. Lassen Sie die Netzwerkverbindung aktiv und warten Sie, bis der aktuelle Schritt beendet ist.
