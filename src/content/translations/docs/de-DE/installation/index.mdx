HagiCode bietet drei Installationsmethoden. Wählen Sie zuerst anhand Ihres Einsatzszenarios einen Weg, prüfen Sie dann die Voraussetzungen dieses Wegs und fahren Sie schließlich mit der passenden Installationsseite fort.

## Installationsmethode wählen

| Ihr Szenario | Empfohlene Methode |
| --- | --- |
| Persönliche lokale Nutzung unter Windows | [Microsoft Store-Installation](/de-DE/installation/windows-store) |
| Persönliche lokale Nutzung unter macOS / Linux oder unter Windows ohne Zugriff auf den Store | [Desktop-Installation](/de-DE/installation/desktop) |
| Server, NAS, gemeinsame Nutzung im Team oder Bedarf an Umgebungsisolierung | [Docker Compose-Installation](/de-DE/installation/docker-compose) |

## Vorbereitung vor der Installation

Je nach Installationsweg gelten unterschiedliche Voraussetzungen:

| Installationsmethode | Node.js | Git |
| --- | --- | --- |
| Microsoft Store / Desktop | Muss selbst installiert werden, Version **24 oder höher** | Muss selbst installiert werden |
| Docker Compose | Auf dem Host nicht erforderlich | Auf dem Host nicht erforderlich |

:::caution[Desktop enthält kein Node.js mehr]
Desktop liefert nur die .NET-Laufzeit mit, die für den Betrieb von HagiCode Server nötig ist, und **stellt kein Node.js mehr bereit**. Es sucht `node` und `npm` im System-`PATH` und installiert verwaltete Pakete wie Agent CLIs im globalen npm-Verzeichnis Ihres Rechners. Installieren Sie Node.js 24 oder höher, bevor Sie Desktop zum ersten Mal starten. Details finden Sie unter [Node.js installieren](/de-DE/related-software-installation/nodejs/installation).
:::

### Git installieren

Desktop prüft beim Start, ob `node`, `npm` und `git` verfügbar sind. Auch das „Demoprojekt“ im Dialog „Neues Projekt“ der Hauptoberfläche benötigt Git, um das offizielle Beispiel-Repository zu klonen. Installieren Sie Git je nach Betriebssystem auf eine der folgenden Arten:

- **Windows**: Führen Sie `winget install --id Git.Git -e` aus oder laden Sie das Installationsprogramm von [git-scm.com](https://git-scm.com/downloads) herunter.
- **macOS**: Führen Sie `xcode-select --install` aus oder verwenden Sie Homebrew mit `brew install git`.
- **Debian / Ubuntu**: Führen Sie `sudo apt-get install -y git` aus.
- **Fedora**: Führen Sie `sudo dnf install -y git` aus.

Öffnen Sie nach der Installation das Terminal neu und prüfen Sie, ob die Befehle verfügbar sind:

```bash
node --version
npm --version
git --version
```

:::tip[Erst installieren, dann Desktop starten]
Desktop liest den System-`PATH` beim Start. Wenn Sie Node.js oder Git erst installieren, nachdem Desktop bereits geöffnet war, beenden Sie Desktop vollständig und starten Sie es neu.
:::

### Agent CLI

HagiCode arbeitet mit einer Agent CLI, die auf Ihrem Rechner installiert und angemeldet ist. Der Initialisierungsassistent listet nur CLIs auf, die lokal erkannt wurden. Installieren Sie daher mindestens eine CLI und melden Sie sich an, bevor Sie den Assistenten öffnen. Die aktuell unterstützten CLIs, ihre Installationsmethoden und die offiziellen Einstiegspunkte werden zentral unter [AI Agent CLI-Installation](/de-DE/related-software-installation/ai-agent-cli/) gepflegt.

## Nächste Schritte

1. Wählen Sie anhand der obigen Tabelle eine Installationsmethode und erfüllen Sie zuerst die Voraussetzungen.
2. Schließen Sie die Installation ab und starten Sie das Programm zum ersten Mal. Legen Sie anschließend gemäß [Assistent zum Einrichten](/de-DE/quick-start/wizard-setup) den Standard-Hagicoder und Ihr erstes Projekt an.
3. Wenn Sie den Vorschlagsablauf von OpenSpec kennenlernen möchten, lesen Sie [Einführung in OpenSpec](/de-DE/related-software-installation/openspec/intro-openspec) und [Vorschlagssitzung erstellen](/de-DE/quick-start/proposal-session).
