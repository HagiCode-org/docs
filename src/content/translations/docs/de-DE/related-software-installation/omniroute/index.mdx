Die integrierte OmniRoute-Unterstützung in HagiCode wurde entfernt. Die Anwendung enthält keine OmniRoute-Installationsschritte, Einstellungen, Verbindungstests oder Synchronisierung von Modellkatalogen mehr.

Um Modelle jetzt zu verbinden:

- verwenden Sie ein über Magpie verbundenes Modell, oder
- konfigurieren Sie einen Anbieter und ein Modell, die Ihre Agent CLI nativ unterstützt.

HagiCode übernimmt keine alten OmniRoute-Endpunkte oder Schlüssel. Wählen Sie in der Konfiguration einen unterstützten Anbieter und ein unterstütztes Modell. Zur Einrichtung der Agent CLI siehe [AI-Agent-CLI-Installation](/de-DE/related-software-installation/ai-agent-cli/).

## Eigenständige OmniRoute-Dokumentation

OmniRoute ist ein eigenständiges Projekt mit eigener Dokumentationsseite. HagiCode unterstützt es nicht.
