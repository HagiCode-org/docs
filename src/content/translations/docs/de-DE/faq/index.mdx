## Was dieser Abschnitt behandelt

Der FAQ-Bereich ist der Ort für:

- Einschränkungen beim Start und bei der Laufzeit
- Kompatibilitätshinweise zu Plattformen, Vertriebskanälen, Verpackungen oder gebündelten Laufzeiten
- Fehlerbehebungsthemen, die eine stabile eigenständige Erklärungsseite verdienen

Wenn Sie bestätigen möchten, welche externe Node-Version Desktop verwendet, wo Agent CLIs installiert werden oder was zu tun ist, wenn Node nicht gefunden wird, lesen Sie [Wie Desktop Ihre Node-Umgebung verwendet](/de-DE/faq/desktop-node-environment).

Wenn Sie wissen möchten, warum HagiCode nicht auf Steam ist, öffnen Sie [Warum HagiCode nicht auf Steam verfügbar ist](/de-DE/faq/steam-distribution-status).
