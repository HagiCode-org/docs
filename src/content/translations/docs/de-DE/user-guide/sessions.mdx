Eine **Sitzung** ist eine Arbeitseinheit, die Sie gemeinsam mit einem Agenten abschließen. Das Sitzungsboard ist das Zentrum des Arbeitsbereichs: Es zeigt, wo sich jede Sitzung gerade befindet, und enthält die Schaltflächen zum Starten neuer Sitzungen.

## Das Sitzungsboard

![Sitzungsboard mit den drei Spalten Proposal & Review, Execution und Archived; in Execution steht eine abgeschlossene Sitzungskarte](../img/user-guide/workbench/01-workbench-overview.png)

Das Board hat drei Spalten (Swimlanes):

| Spalte | Was dort erscheint |
| --- | --- |
| **Proposal & Review** (Vorschlag und Prüfung) | Ideen, die gerade entworfen, generiert und als Vorschlag geprüft werden. |
| **Execution** (Ausführung) | Sitzungen, die laufen oder abgeschlossen sind, einschließlich normaler Sitzungen. |
| **Archived** (Archiviert) | Archivierte Sitzungen, die Sie jederzeit wieder ansehen können. |

Jede Karte zeigt die Sitzungsnummer, das zugehörige Projekt, ein Symbol für den Typ, den Titel, den Zeitpunkt der letzten Änderung und ein Statusabzeichen, etwa **Executing** (Wird ausgeführt) oder **Execution Complete** (Ausführung abgeschlossen). Ein Klick auf die Karte öffnet die Sitzung. Die Zahl neben dem Spaltentitel gibt an, wie viele Sitzungen sich darin befinden. Mit dem Pfeil am Spaltentitel klappen Sie die Spalte ein.

### Symbolleiste

Über den Spalten befindet sich eine Symbolleiste mit vier Steuerelementen:

- **Layout-Umschalter** (kleines Board-Symbol neben *Session List* (Sitzungsliste)): Ändert die Anordnung des Boards.
- **New Idea** (Neue Idee, Keimblatt-Symbol): Startet einen Vorschlag.
- **Create Normal Session** (Normale Sitzung erstellen, Sprechblasen-Symbol): Startet eine Unterhaltung.
- **More HagiTasks** (Weitere HagiTasks, Listen-Symbol): Öffnet den HagiTask-Arbeitsbereich mit weiteren Aufgabenvorlagen. Siehe [Skills und HagiTask](/user-guide/skills-and-hagitask).

Das Menü **Recent changes** (Letzte Änderungen) und das Widget **Trophies** (Trophäen) befinden sich am rechten Ende der Symbolleiste. Siehe [Projekte](/user-guide/projects) und [Statusleiste und Fortschritt](/user-guide/status-bar-and-progress).

### Layout-Modi

![Layout-Umschalter mit Classic, Execution Flow Kanban und Dashboard Kanban](../img/user-guide/workbench/05-layout-switcher.png)

| Modus | Abzeichen | Geeignet für |
| --- | --- | --- |
| **Classic** (Klassisch) | Focused (Fokussiert) | Eine kompakte Sitzungsliste mit einer Projektspalte und einer Detailspalte daneben. |
| **Execution Flow Kanban** (Ausführungsfluss-Kanban) | Flow (Fluss) | Die Spalten plus der vollständige Aktionsbereich auf der rechten Seite. Dieser Leitfaden verwendet dieses Layout. |
| **Dashboard Kanban** (Dashboard-Kanban) | Compact (Kompakt) | Ein schlankeres Board, das mehr Platz für die Sitzungsübersicht lässt. |

## Neue Idee (Vorschlag)

Klicken Sie auf **New Idea**, um die Schublade **Create Proposal** (Vorschlag erstellen) zu öffnen. Das eignet sich für Änderungen, die Sie zuerst planen möchten: Sie beschreiben, was Sie wollen, HagiCode erstellt einen Vorschlag, und Sie prüfen ihn, bevor etwas ausgeführt wird. Die Anleitung [Eine Idee mit einer Vorschlagssitzung in Code umsetzen](/quick-start/proposal-session) führt Sie durch den gesamten Ablauf vom Vorschlag bis zur Archivierung.

![Schublade Create Proposal mit Ideenname, Projekt, Umfang, Schnellanforderungen und einer Anforderung zum Hinzufügen eines POST-Endpunkts](../img/user-guide/sessions/01-new-idea.png)

**Linke Spalte: Basic Setup** (Grundeinstellungen)

- **Idea Name** (Ideenname) und **Project Name** (Projektname) sind Pflichtfelder.
- **Scope** (Umfang) hat zwei Reiter. Unter **Vault** können Sie *Specify Target Vaults (Optional)* (Ziel-Vaults angeben, optional) festlegen: Markieren Sie Vaults, die die KI bearbeiten darf. Vom System verwaltete Vaults dienen nur als Referenz. Unter **Projects** (Projekte) können Sie weitere Projekte als Kontext hinzufügen.
- **Quick Requests** (Schnellanforderungen) fügen mit einem Klick Zusätze zu Ihrer Anforderung hinzu: *No docs / tests* (Ohne Dokumentation und Tests), *Self commit* (Selbst committen), *Output English* (Ausgabe auf Chinesisch, wechselt mit der Oberflächensprache), *Ask before edit* (Vor dem Bearbeiten nachfragen) und *No backward compatibility* (Keine Abwärtskompatibilität).

**Rechte Spalte: Requirement Drafting & Preview** (Anforderungen formulieren und Vorschau)

- **You Request** (Ihre Anforderung) dient zur Beschreibung der Änderung, bis zu 14.000 Zeichen. Mit **Upload Image** (Bild hochladen) fügen Sie ein Bild hinzu.
- **Combined preview** (Kombinierte Vorschau) zeigt den vollständigen Text, der an die KI gesendet wird, damit Sie ihn vor dem Absenden prüfen können.
- **Submit idea** (Idee absenden) erstellt die Vorschlagssitzung. Mit **Load Favorite** (Favorit laden) und **Save as Favorite** (Als Favorit speichern) verwenden Sie gespeicherte Einstellungen erneut.

## Neue normale Sitzung

Klicken Sie auf **Create Normal Session**, um eine normale Unterhaltung mit einem Agenten zu beginnen. Verwenden Sie das, um ein Repository kennenzulernen, Fragen zu stellen oder kleine Änderungen ohne Vorschlag vorzunehmen.

![Schublade Create Normal Session mit Projekt, Sitzungstitel, Aufgabenumfang, einer Anforderung und der Auswahl verfügbarer Agenten](../img/user-guide/sessions/02-create-normal-session.png)

| Feld | Beschreibung |
| --- | --- |
| **Project** (Projekt) | Pflichtfeld. Standardmäßig das aktuell ausgewählte Projekt. |
| **Session title** (Sitzungstitel) | Optional. Wird als Bezeichnung auf der Karte angezeigt. |
| **Task scope** (Aufgabenumfang) | **Repos** (Repositories) beschränkt die Sitzung auf einzelne Repositories eines MonoSpecs-Projekts. **Vault** und **Projects** (Projekte) können zusätzliches Referenzmaterial anhängen. |
| **What do you want to do?** (Was möchten Sie tun?) | Pflichtfeld. Dies ist die erste Nachricht der Sitzung. Mit **Upload Image** fügen Sie ein Bild hinzu. |

Das Feld **Available Agents** (Verfügbare Agenten) listet Ihre Agenten auf. Wählen Sie einen aus, startet die Sitzung **sofort**. Der erste Eintrag ist die Standardeinstellung der Laufzeitumgebung. Die zweite Liste erlaubt es, für diesen einen Lauf einen anderen Agenten zu wählen. Wenn keine Agenten aufgeführt sind, erstellen Sie zuerst einen unter [Agenten](/user-guide/agents). Mit `Strg/⌘ + Eingabe` senden Sie per Tastatur ab.

:::note[Mit einer schreibgeschützten Frage beginnen]
Die Beispielsitzung in diesem Leitfaden stellt dem Demoprojekt eine schreibgeschützte Frage. Sie ist in etwa 23 Sekunden abgeschlossen und ändert keine Dateien. Der Bearbeitungsmodus wird pro Sitzung gesteuert, siehe unten.
:::

## Arbeiten in einer Sitzung

Klicken Sie auf eine Karte, um die Sitzungsschublade zu öffnen.

![Sitzungsschublade mit der Schlussantwort, der Zusammenfassung Session Complete, dem Nachrichtenfeld und der Statuskarte des Agenten](../img/user-guide/sessions/03-session-detail.png)

**Kopfbereich**: Titel, Avatar des Agenten sowie die Schaltflächen **Archive** (Archivieren, verschiebt die Sitzung in die Spalte Archived), **Delete Session** (Sitzung löschen) und **Open Code Server** (Code-Server öffnen) und ein Menü **…** mit weiteren Aktionen.

**Unterhaltung**: Ihre Nachrichten und die des Agenten erscheinen in chronologischer Reihenfolge. Während der Agent arbeitet, können Sie seine Aktionen verfolgen: Werkzeugaufrufe erscheinen als Karten.

![Oberer Bereich einer Sitzung mit dem Block zum Laufmodus und einer Bash-Werkzeugaufruf-Karte](../img/user-guide/sessions/04-session-detail-top.png)

Nach Ende eines Laufs fasst die Karte **Session Complete** (Sitzung abgeschlossen) Anzahl der Runden, Dauer und Kosten zusammen. Klicken Sie darauf, um die Details einzublenden.

**Nachrichtenfeld**: Es befindet sich unten.

- Der Schalter **Edit / Readonly** (Bearbeiten / Nur lesen) schaltet den Bearbeitungsmodus ein oder aus. Ist er eingeschaltet, kann eine neue Nachricht Dateien ändern. Ob neue normale Sitzungen standardmäßig im Bearbeitungsmodus starten, legen Sie unter **Settings → Process & Interaction → Chat View** (Einstellungen → Ablauf und Interaktion → Chat-Ansicht) fest.
- Es gibt Schaltflächen für **Bilder**, **Standard Phrases** (Standardformulierungen, also die `@`-Auswahl) und **Import Recent History** (Letzten Verlauf importieren).
- **Send** (Senden) übermittelt die Nachricht. `Enter` sendet, `Shift + Enter` fügt einen Zeilenumbruch ein.

**Statuskarte des Agenten**: Sie steht rechts neben dem Nachrichtenfeld und zeigt die Agenten-CLI und das Modell (z. B. `claude-sonnet-5-5`), den aktuellen Status (z. B. *Idle* (Leerlauf)) und die verstrichene Zeit.
