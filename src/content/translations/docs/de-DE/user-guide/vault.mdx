Ein **Vault** ist ein Ordner, den HagiCode außerhalb des Projektrepositorys durchsuchen und in der Vorschau anzeigen darf. Vaults eignen sich für Referenzdokumente, Notizen, Rechercheergebnisse und alles andere, das Sitzungen lesen oder schreiben sollen.

Klicken Sie in der oberen Leiste auf **Vault** (in der chinesischen Oberfläche: Vault), um den **Vault Workspace** (Vault-Arbeitsbereich) zu öffnen.

![Vault-Arbeitsbereich mit den registrierten Vaults Orbit, Notes und Docs sowie einer eingeklappten Gruppe System vaults](../../img/user-guide/vault/01-vault.png)

## Registrierte Vaults und Systemvaults

Der Arbeitsbereich ist in zwei Gruppen gegliedert:

- **Registered vaults** (registrierte Vaults) sind die Ordner, die Sie hinzugefügt haben. Jede Karte zeigt den Vault-Typ, den Namen, den gekürzten Pfad und eine Schaltfläche **Open Code Server** (Code Server öffnen), mit der Sie den Ordner im Browser-Editor bearbeiten können.
- **System vaults** (Systemvaults) werden von HagiCode erstellt und verwaltet. Klicken Sie auf **Expand** (Aufklappen), um sie anzuzeigen.

![Aufgeklappte Systemvaults mit sieben systemverwalteten, schreibgeschützten Vaults](../../img/user-guide/vault/02-vault-system-expanded.png)

In diesem Bereich sind Systemvaults **schreibgeschützt**. Dazu gehören Anwendungslogs, das Datenverzeichnis, Prompt-Vorlagen, persönliche Daten, Projektdaten, der aktuelle Speicherstand und Systemvoreinstellungen. Im Sitzungsumfang gelten sie ausschließlich als Referenzmaterial.

## Vault hinzufügen

Klicken Sie auf **Add vault** (Vault hinzufügen), geben Sie den **Vault name** (Vault-Namen) und den absoluten **Physical path** (physischen Pfad) an, wählen Sie den **Vault type** (Vault-Typ) und klicken Sie anschließend auf **Save vault** (Vault speichern).

![Schublade „Add vault“ mit Name, Pfad und ausgewähltem Typ Folder](../../img/user-guide/vault/03-add-vault.png)

| Vault-Typ | Funktion |
| --- | --- |
| **Folder** (Ordner) | Registriert ein beliebiges vorhandenes lokales Verzeichnis unverändert. |
| **CodeRef** (Code-Referenz) | Erstellt automatisch `docs/`, `repos/`, `AGENTS.md` und `index.yaml`. Kann als Ausgabe-Vault für Rechercheaufgaben verwendet werden. |
| **Obsidian** | Erstellt automatisch `.obsidian/`, `app.json` und vorschaubare Notizartefakte, sodass der Ordner als Obsidian-Vault genutzt werden kann. |

:::caution[Typ vor dem Speichern auswählen]
Wählen Sie vor dem Klick auf **Save vault** einen der drei Vault-Typen aus. In der Version, auf der diese Anleitung basiert, schlägt das Speichern ohne ausgewählten Typ mit einer unverständlichen Fehlermeldung fehl statt mit einem Validierungshinweis.
:::

## Vaults in Sitzungen verwenden

Vaults erscheinen im Bereich **Scope** (Umfang; in der Oberfläche auch als „Umfang“ oder „Aufgabenumfang“ bezeichnet) der [Schublade zum Erstellen eines Vorschlags und der Schublade zum Erstellen einer normalen Sitzung](/user-guide/sessions). Wenn eine Aufgabe Dateien im Vault aktualisieren soll, markieren Sie ihn als **editable** (bearbeitbar). Andernfalls behandelt die KI ihn als schreibgeschütztes Referenzmaterial. Vom System verwaltete Vaults dienen immer nur als Referenz.
