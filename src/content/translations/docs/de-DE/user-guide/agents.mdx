Ein **Agent** in HagiCode ist ein einsatzbereiter Mitarbeiter. Er besteht aus einer Agent-CLI (zum Beispiel Claude Code), einem Modell und optionalem Persönlichkeitstext. Sitzungen werden von Agenten ausgeführt, daher wird mindestens ein Agent benötigt, bevor Sie mit der Arbeit beginnen können.

Klicken Sie in der oberen Leiste auf **Agents** (chinesische Oberfläche: Agents), um den **Agents Workspace** (Agents-Arbeitsbereich) zu öffnen. Er hat sechs Reiter.

| Reiter | Zweck |
| --- | --- |
| [Agents](#agents-标签页) | Erstellen und verwalten Sie Ihre Agenten. |
| [Execution Scenarios (Ausführungsszenarien)](#执行场景) | Legen Sie fest, welche Agenten welche Art von Arbeit übernehmen. |
| [AgentCLI](#agentcli) | Prüfen Sie, welche Agent-CLIs installiert, funktionsfähig und aktiviert sind. |
| [Model (Modell)](#模型) | Durchsuchen und erweitern Sie den Modellkatalog jeder Agent-CLI. |
| [Document Theme (Textthema)](#文案主题) | Wählen Sie das Textthema der Oberfläche. |
| [Avatar Gallery (Avatar-Galerie)](#头像画廊) | Durchsuchen Sie Avatar-Pakete. |

:::note
AgentCLIs und der Modellkatalog sind systemweit. Der Reiter Agents speichert nur Ihre aktuellen Agenten und deren Teams.
:::

## Reiter Agents

![Reiter Agents, Liste My Agents nach Agent-CLI gruppiert, mit dem Agenten Hagicoder](../../img/user-guide/agents/01-agents.png)

**My Agents** (Meine Agents) listet Ihre Agenten auf und gruppiert sie nach der Agent-CLI, die sie verwenden. Jede Karte zeigt Avatar, Namen, Modell und ein kleines Logo für die CLI.

- **New Agent** (Neuer Agent) öffnet die Erstellungsleiste.
- **Batch create Agents** (Agents im Stapel erstellen) erstellt mehrere auf einmal.
- **Search** (Suche) filtert nach Agent-Namen, AgentCLI oder Beschreibung.
- **Select all visible** (Alle sichtbaren auswählen), **Clear visible** (Sichtbare Auswahl aufheben) und **Delete N selected** (N ausgewählte löschen) dienen dem Massenlöschen.

### Agent erstellen

![Leiste New Agent mit den Abschnitten Agent-Ausrüstung, Merkmale und Seele](../../img/user-guide/agents/02-new-agent.png)

Über diese Leiste wird jeweils ein Agent erstellt. Bis zur erfolgreichen Erstellung bleibt die Ansicht Agents unverändert.

- **Name and avatar** (Name und Avatar) – Es wird ein zufälliger Name aus einem Namenspool vorgeschlagen. Das Hochladen eines eigenen Avatars erfordert das TurboEngine-DLC.
- **Agent loadout** (Agent-Ausrüstung) – Zwei Pflichtplätze. Klicken Sie auf ein Kandidatensymbol, um es auszurüsten:
  - **AgentCLI** – Das Kommandozeilenwerkzeug, mit dem der Agent läuft.
  - **Model** (Modell) – Das Modell, das diese CLI verwendet. Die Liste zeigt nur Modelle, die zur gewählten CLI passen.
- **Trait · knowledge and behavior** (Merkmal · Wissen und Verhalten) – Freitext oder ein Merkmal aus der Merkmalsplattform (Trait platform), das die Arbeitsweise des Agenten prägt.
- **Soul · language style** (Seele · Sprachstil) – Freitext oder eine Seele aus der Seelenplattform (Soul platform), die den Sprachstil des Agenten prägt.
- Schalter **Battle ready** (Einsatzbereit) – Aktiviert oder deaktiviert den Agenten.

## Ausführungsszenarien

Entspricht dem Reiter **Execution Scenarios**.

![Reiter Execution Scenarios mit den Szenarien Vorschlag, HagiTask und Chat sowie dem Team-Editor](../../img/user-guide/agents/03-execution-scenarios.png)

Szenarien legen fest, welcher Agent für welche Art von Arbeit ausgewählt wird. Sie sind nach dem Ort gruppiert, an dem sie auftreten:

| Gruppe | Szenarien |
| --- | --- |
| **Proposal** (Ausführungsszenarien der Vorschlagsphase) | Optimize Proposal (Vorschlag optimieren), Generate Proposal (Vorschlag erzeugen), Execute Proposal (Vorschlag ausführen), Archive Proposal (Vorschlag archivieren) |
| **HagiTask** (Ausführungsszenarien für Hagitask) | Super Commit, Create Normal Session (Normale Sitzung erstellen), Create Research Investigation Task (Aufgabe zur Code-Recherche erstellen) |
| **Chat** (Ausführungsszenarien für Chat) | Conversation Title Optimization (Optimierung des Sitzungstitels) |

**Fallback Crew** (Ersatzteam) ist das Sicherheitsnetz. Hat ein Szenario im eigenen Team keinen passenden Agenten, probiert HagiCode zufällig die geeigneten Mitglieder des Ersatzteams aus. Es ist erforderlich: **Alle anderen Szenarien bleiben gesperrt, bis das Ersatzteam mindestens einen aktivierten Agenten hat.** Der Initialisierungsassistent fügt Ihren ersten Agenten automatisch hinzu.

Klicken Sie auf ein Szenario, um es zu bearbeiten. **Assigned Agents** (Zugewiesene Agenten) zeigt, wer im Team ist, **Available Agents** (Verfügbare Agenten) zeigt mögliche Mitglieder, und Filter-Tags verkleinern die Liste nach Agent-CLI. Zur Laufzeit werden passende Mitglieder zufällig ausprobiert. Die Anzeigereihenfolge in der Oberfläche ist daher keine Priorität.

## AgentCLI

![Verwaltungstabelle der AgentCLI mit Aktivierungsstatus, Verfügbarkeit, Version und Überwachungsstatus jeder CLI](../../img/user-guide/agents/04-agentcli.png)

Dieser Reiter listet alle Kommandozeilenwerkzeuge auf, die HagiCode steuern kann: Claude Code, Codebuddy, Codex, DeepAgents, DSH, Gemini, GitHub Copilot, Hermes, Junie, Kimi, Kiro, OMP, OpenCode, Pi, QoderCLI und Reasonix.

Für jede CLI sehen Sie:

- **Enabled** (Aktiviert) und **Availability** (Verfügbarkeit) – Die CLI muss auf dem Rechner installiert sein, auf dem HagiCode läuft, um verfügbar zu sein.
- **CLI version** (CLI-Version) – Die erkannte Version. Wird die ausführbare Datei nicht gefunden, erscheint *Not detected* (Nicht erkannt).
- **Monitoring** (Überwachung) – Die letzte Zustandsprüfung, zum Beispiel *Healthy* (Gesund).
- **Show diagnostics** (Diagnose anzeigen) – Details hinter dem Prüfergebnis. Nützlich, wenn eine CLI nicht erkannt wird.
- Einen **Schalter** zum Aktivieren oder Deaktivieren der CLI. Mit den Kontrollkästchen und **Enable selected** (Ausgewählte aktivieren) sowie **Disable selected** (Ausgewählte deaktivieren) ändern Sie mehrere auf einmal. Filter können nur *Available* (Verfügbar) oder *Unavailable* (Nicht verfügbar) CLIs anzeigen.

Wird eine installierte CLI nicht erkannt, prüfen Sie, ob ihre ausführbare Datei im `PATH` des Prozesses liegt, der HagiCode ausführt, und laden Sie dann neu. Siehe [AI Agent CLI Installation](/related-software-installation/ai-agent-cli).

## Modell

Entspricht dem Reiter **Model**.

![Reiter Model mit dem Modellkatalog von Claude Code und dem Formular Create Model](../../img/user-guide/agents/05-model.png)

Wählen Sie oben eine **AgentCLI**, um deren Modelle anzuzeigen. Die Tabelle zeigt Name, Modell-ID, Quelle jedes Modells und ob Bilder unterstützt werden.

- Einträge unter **System defaults** (Systemstandards) sind schreibgeschützt und werden von HagiCode gepflegt.
- **Custom** (Benutzerdefiniert) Einträge gehören Ihnen. Erstellen Sie sie über das Formular **Create Model** (Modell anlegen) mit *Display name* (Anzeigename), *Summary* (Zusammenfassung), *Icon* (Symbol), dem von der CLI benötigten *Model value* (Modellwert) und der Option *Supports images* (Unterstützt Bilder). **Create blank entry** (Leeren Eintrag erstellen) beginnt mit einer leeren Zeile.
- Sie können nach Name oder Modell-ID filtern, nach Quelle (*All sources* (Alle Quellen), *Custom*, *System default*) filtern oder nur Modelle mit *Support images only* (Nur Bildunterstützung) anzeigen.

## Textthema

Entspricht dem Reiter **Document Theme**.

![Reiter Document Theme, bei dem das Thema AgentCLI Baseline aktiv ist und die anderen Themen gesperrt sind](../../img/user-guide/agents/06-document-theme.png)

Das Textthema ändert die Wortwahl der Oberfläche. **AgentCLI Baseline** (AgentCLI-Basis) verwendet neutrale Begriffe wie *Agents*, *Jobs* (Aufträge) und *Workspace* (Arbeitsbereich) und ist das Standardthema. Andere Themen, zum Beispiel die Formulierungen von *Fantasy Adventure* (Fantasy-Abenteuer), erfordern das TurboEngine-DLC. Ihre Vorschau bleibt sichtbar, sie sind jedoch gesperrt. **Restore default theme** (Standardthema wiederherstellen) kehrt zum Basisthema zurück.

## Avatar-Galerie

Entspricht dem Reiter **Avatar Gallery**.

![Avatar-Galerie mit Avatar-Paketen links und einer großen Vorschau des gewählten Avatars rechts](../../img/user-guide/agents/07-avatar-gallery.png)

Durchsuchen Sie die Avatar-Pakete, die für Agenten verfügbar sind. Wählen Sie ein Paket und einen Avatar, um Vorschau, Plugin-Quelle, Version und stabile ID zu sehen.
