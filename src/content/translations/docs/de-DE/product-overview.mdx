HagiCode ist ein KI-Arbeitsbereich für die Projektentwicklung. In einer Sitzung können Sie zunächst ein Repository verstehen, dann Anforderungen und Auswirkungen eingrenzen, die KI Änderungen ausführen lassen und am selben Ort den Fortschritt verfolgen, Commits vorbereiten und Projektwissen wiederverwenden. HagiCode verbindet die Agent CLI und Modelle, die Sie bereits nutzen, statt einen bestimmten Code-Editor vorauszusetzen.

**Zum ersten Mal hier?** [Wählen Sie eine Installationsart](/de-DE/installation/), schließen Sie den [Einrichtungsassistenten](/de-DE/quick-start/wizard-setup) ab, erstellen Sie ein Projekt und beginnen Sie mit einer [Konversationssitzung](/de-DE/quick-start/conversation-session). Wenn die Aufgabe vor der Umsetzung geplant werden muss, verwenden Sie eine [Vorschlagssitzung](/de-DE/quick-start/proposal-session).

## Ablauf einer Entwicklungsaufgabe

Nehmen wir als Beispiel die Änderung einer Funktion, die mehrere Repositories betrifft:

1. **Zuerst verstehen:** Analysieren Sie den vorhandenen Code in einer [Konversationssitzung](/de-DE/quick-start/conversation-session). Diese Sitzungen sind standardmäßig schreibgeschützt; wechseln Sie erst zum Bearbeitungsmodus, wenn Sie Dateien ändern müssen.
2. **Umfang festlegen:** Wählen Sie bei komplexen Änderungen in einer [Vorschlagssitzung](/de-DE/quick-start/proposal-session) Projekt und Repositories aus. Halten Sie Ziele, Aufgaben und Prüfschritte fest, bevor Sie mit der Ausführung fortfahren.
3. **Ergebnis verfolgen:** Prüfen Sie Sitzungen und Ausführungsstatus im Arbeitsbereich. Wenn Sie einen Commit vorbereiten möchten, nutzen Sie [AI Compose Commit](/de-DE/guides/ai-compose-commit).
4. **Kontext bewahren:** Vorschläge und Commit-Verlauf lassen sich später erneut einsehen. Nutzen Sie bei repositoryübergreifender Arbeit [MonoSpecs](/de-DE/guides/monospecs), um Beziehungen zwischen Repositories und den Änderungsumfang zu verwalten.

Nicht jede Aufgabe braucht einen Vorschlag: Wenn Sie nur Code verstehen oder ein einfaches Problem lösen möchten, beginnen Sie mit einer Konversationssitzung. Für Aufgaben, die mehr Kontext erfordern, bietet HagiCode einen nachvollziehbaren Ablauf.

## Funktionen nach Bedarf entdecken

| Wenn Sie … | Beginnen Sie hier |
| --- | --- |
| Code verstehen möchten, bevor Sie über Änderungen entscheiden | [Konversationssitzung erstellen](/de-DE/quick-start/conversation-session) |
| eine komplexe Aufgabe vor der Umsetzung planen möchten | [Vorschlagssitzung erstellen](/de-DE/quick-start/proposal-session) |
| der KI die Beziehungen zwischen mehreren Repositories vermitteln möchten | [MonoSpecs-Anleitung](/de-DE/guides/monospecs) |
| Erweiterungen suchen, installieren und verwalten möchten | [Skills-Anleitung](/de-DE/guides/skills) |
| eine vertraute Agent CLI verwenden möchten | [Installation und Unterstützung von AI Agent CLI](/de-DE/related-software-installation/ai-agent-cli/) |
| CLI- und Modellanbindungen getrennt verwalten möchten | [OmniRoute installieren und Start überprüfen](/de-DE/related-software-installation/omniroute/) |

Vault sammelt Referenz-Repositories, Ordner und Notizen zur späteren Wiederverwendung; Code Server bietet einen Bearbeitungszugang im Browser. Beides ist für den Einstieg in HagiCode nicht erforderlich. Hintergründe finden Sie in den Artikeln zur [Vault-Wissensdatenbank](/de-DE/blog/2026-04-10-vault-system-ai-knowledge-base/) und zur [Browser-Editor-Integration](/de-DE/blog/2026-04-13-vscode-web-integration-browser-editing/).

HagiCode bietet auch Rückmeldungen durch Helden, Erfolge, Tagesberichte und Token-Metriken, damit Status und Fortschritt bei längerer Nutzung sichtbarer werden. Sie gehören zum Arbeitsbereich, sind aber nicht nötig, um HagiCode als gewöhnliches Entwicklungswerkzeug zu verwenden. Mehr dazu im [Artikel über das Gamification-Design](/de-DE/blog/2026-03-16-gamifying-ai-coding/).

## Editionen und Preise

**Desktop, Container und Microsoft Store sind verschiedene Bezugs- oder Bereitstellungswege, keine drei kostenpflichtigen Stufen.** Die Grundfunktionen können kostenlos genutzt werden. Turbo Engine im Microsoft-Store-Kanal ist eine separat erhältliche, einmalig zu erwerbende Lizenz. Sie schaltet eine höhere Obergrenze für gleichzeitig laufende Vorschläge und Erweiterungen wie Dokumentationsthemen, individuelle Namensnennung, Branding und Avatare frei. Welche Funktionen genau freigeschaltet werden, steht beim [Turbo-Engine-Zusatzpaket](/de-DE/dlc/turbo-engine-dlc/).

| Ihre Umgebung | Empfohlener Einstieg |
| --- | --- |
| Windows mit Zugang zum Microsoft Store | [Über den Microsoft Store installieren](/de-DE/installation/windows-store) |
| Manuelle Windows-Installation oder lokale Nutzung unter macOS oder Linux | [Desktop installieren](/de-DE/installation/desktop) |
| Server, NAS oder Bereitstellung für Teams | [Mit Docker Compose installieren](/de-DE/installation/docker-compose) |

Die Steam-Hauptanwendung wurde eingestellt und ist kein aktueller Installationsweg mehr. Siehe [Status der Steam-Verteilung](/de-DE/faq/steam-distribution-status/).

## Warum ein Arbeitsbereich?

Ich bin Kun Yu, der Entwickler von HagiCode. Eine einzelne Frage mit Antwort kann ein akutes Problem lösen. Zur tatsächlichen Entwicklung gehören aber auch das Verständnis des Projekts, die Abgrenzung der Aufgabe, die Umsetzung von Änderungen und die Prüfung der Ergebnisse. Ich wollte diese bisher getrennten Schritte verbinden; spielerische Rückmeldungen machen Fortschritte bei längerfristiger Arbeit leichter sichtbar. Sie können auch nur einige der Funktionen nutzen und müssen nicht alle Module kennen, bevor Sie mit dem Programmieren beginnen.
