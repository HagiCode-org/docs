## Preparação antes da instalação

Cada caminho tem pré-requisitos diferentes:

| Método de instalação | Node.js | Git |
| --- | --- | --- |
| Microsoft Store / Desktop | Você mesmo precisa instalar a versão **24 ou superior** | Você mesmo precisa instalar |

:::caution[O Desktop não inclui mais o Node.js]
O Desktop inclui apenas o runtime .NET necessário para executar o HagiCode Server e **não fornece mais o Node.js**. Ele procura `node` e `npm` no `PATH` do sistema e instala pacotes gerenciados, como os Agent CLIs, no diretório global do npm da sua máquina. Instale o Node.js 24 ou superior antes de abrir o Desktop pela primeira vez; veja [Instalar o Node.js](/pt-BR/related-software-installation/nodejs/installation).
:::

### Instalar o Git

O Desktop detecta `node`, `npm` e `git` ao iniciar, e o “Projeto de demonstração” da caixa de diálogo “Novo Projeto” da interface principal também precisa do Git para clonar o repositório de exemplo oficial. Escolha uma das opções abaixo de acordo com o seu sistema:

- **Windows**: execute `winget install --id Git.Git -e` ou baixe o instalador em [git-scm.com](https://git-scm.com/downloads).
- **macOS**: execute `xcode-select --install` ou, com o Homebrew, execute `brew install git`.
- **Debian / Ubuntu**: execute `sudo apt-get install -y git`.
- **Fedora**: execute `sudo dnf install -y git`.

Depois de instalar, reabra o terminal e confirme que os comandos estão disponíveis:

```bash
node --version
npm --version
git --version
```

:::tip[Instale tudo antes de abrir o Desktop]
O Desktop lê o `PATH` do sistema ao iniciar. Se você instalar o Node.js ou o Git com o Desktop já aberto, feche-o por completo e abra-o novamente.
:::

### Agent CLI

O HagiCode trabalha com um Agent CLI instalado e já autenticado na sua máquina. O assistente de inicialização lista apenas os CLIs detectados localmente, portanto instale e faça login em pelo menos um antes de entrar no assistente. Os CLIs compatíveis atualmente, as formas de instalação e os pontos de entrada oficiais são mantidos em [Instalação do AI Agent CLI](/pt-BR/related-software-installation/ai-agent-cli/).

## Próximos passos

1. Escolha o método de instalação na tabela acima e conclua primeiro os pré-requisitos.
2. Conclua a instalação e faça a primeira inicialização; em seguida, siga a [Configuração do assistente de inicialização](/pt-BR/quick-start/wizard-setup) para criar o Hagicoder padrão e o seu primeiro projeto.
3. Para conhecer o fluxo de propostas do OpenSpec, leia a [Introdução ao OpenSpec](/pt-BR/related-software-installation/openspec/intro-openspec) e [Criar uma sessão de proposta](/pt-BR/quick-start/proposal-session).
