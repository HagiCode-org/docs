Para usuários do Windows, a Microsoft Store é atualmente a porta de entrada pública do desktop. Este texto cobre apenas esse caminho de instalação pela loja; para o guia geral de download do Desktop, gerenciamento de versões e solução de problemas, continue em [Instalação do Desktop](/pt-BR/installation/desktop).

A entrada principal do aplicativo na Steam já foi retirada, e o canal atual do Windows é principalmente a Microsoft Store. Para o contexto, consulte [Por que o HagiCode não está disponível na Steam](/pt-BR/faq/steam-distribution-status/).

:::tip[Quando este caminho faz sentido]
- Você usa Windows 10 ou Windows 11 e quer instalar diretamente pela loja do sistema
- Você prefere receber o pacote do aplicativo pelo canal da loja, em vez de lidar manualmente com arquivos de instalação
:::

## Antes de começar

Antes de começar, confirme estas condições:

- O dispositivo consegue abrir normalmente a [página do HagiCode for Windows na Microsoft Store](https://apps.microsoft.com/detail/9N3PM0N3SVDW)
- Há rede disponível no primeiro início, porque o programa ainda pode precisar baixar ou preparar os componentes necessários ao Hagicode Server
- Alguns dispositivos, políticas organizacionais ou configurações de região podem exigir que você entre antes com uma conta Microsoft
- Se a loja estiver desativada no seu dispositivo corporativo, use a [Instalação do Desktop](/pt-BR/installation/desktop)

## Preparação antes da instalação

A versão da Store e o Desktop funcionam da mesma forma: **não incluem o Node.js**, e você precisa instalá-lo por conta própria e garantir que ele esteja no `PATH` do sistema. Prepare antes da primeira inicialização:

- **Node.js 24 ou superior** (que já inclui o `npm`); veja [Instalar o Node.js](/pt-BR/related-software-installation/nodejs/installation)
- **Git**; veja [Instalar o Git](/pt-BR/installation/#instalar-o-git)
- Pelo menos um **Agent CLI** instalado e já autenticado; veja [Instalação do AI Agent CLI](/pt-BR/related-software-installation/ai-agent-cli/)

Se você instalar essas ferramentas depois que o HagiCode já estiver aberto, feche o HagiCode por completo e abra-o novamente para que ele leia o novo `PATH`.

## Instalar pela Microsoft Store

1. Abra a página [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW).
2. Clique em `Obter`, `Instalar` ou no botão equivalente exibido na página da loja.
3. Aguarde a Microsoft Store concluir o download e a instalação.
4. Depois de instalado, inicie o HagiCode pelo menu Iniciar ou diretamente pela página da loja.

## O que acontece no primeiro início

Depois da instalação, o HagiCode ainda segue o fluxo padrão de inicialização do Desktop.

- O primeiro início abre antes o guia de primeiro uso do Desktop: escolher o idioma, confirmar os documentos legais e, se necessário, baixar o Hagicode Server; por isso, pode ser mais lento que um aplicativo comum
- O canal Microsoft Store / MSIX bloqueia a configuração “Caminho de armazenamento dos dados de runtime”, o que é o comportamento esperado dessa forma de distribuição
- O software em si não se atualiza sozinho; a atualização do pacote do aplicativo é definida pelo canal de instalação e, no caso da instalação pela Store, a entrega depende do canal da Microsoft Store

Se quiser continuar com o assistente de inicialização, leia a [Configuração do assistente de inicialização](/pt-BR/quick-start/wizard-setup).

## Quando usar outro método de instalação

Nestes casos, é melhor usar outro canal:

- Você não consegue acessar a Microsoft Store, ou o dispositivo corporativo proíbe expressamente a instalação pela loja
- Você precisa baixar manualmente o pacote `.exe` ou `.msix` e controlar por conta própria a origem do arquivo de instalação

## Problemas comuns

### Não consigo abrir a página da Microsoft Store

Primeiro, verifique a rede do sistema, as configurações de região e o estado de login na Microsoft Store. Se o navegador abre a página, mas o cliente da loja continua indisponível, normalmente isso indica que uma política do sistema restringe os recursos da loja; nesse caso, use a [Instalação do Desktop](/pt-BR/installation/desktop).

### Por que algumas configurações aparecem em cinza

A instalação Store / MSIX bloqueia a opção “Caminho de armazenamento dos dados de runtime” e exibe “Bloqueado pela Microsoft Store”. Isso não é uma falha de instalação, e sim uma restrição do canal de distribuição atual.

### Por que o primeiro início ainda baixa ou prepara conteúdo

A instalação pela loja entrega apenas o pacote do aplicativo de desktop. No primeiro início, o HagiCode ainda pode baixar ou preparar os componentes necessários ao Hagicode Server e concluir a inicialização padrão. Mantenha a rede disponível e aguarde o fim da etapa atual.
