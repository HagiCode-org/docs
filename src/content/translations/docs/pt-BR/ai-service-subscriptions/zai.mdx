## Posicionamento do serviço

O Zhipu AI é uma das portas de entrada de assinatura do Claude Code recomendadas no preset atual da documentação. Os planos GLM Coding e o mapeamento para vários modelos são adequados para desenvolvedores que usam o Claude Code como ferramenta principal no dia a dia.

## Para quem é indicado

- Quem quer um plano voltado especificamente para programação
- Quem precisa de um mapeamento bastante completo dos níveis de modelo do Claude
- Quem quer cobrir o Claude Code, o Cline e outras ferramentas com um único serviço

## Pontos para observar primeiro

- No preset atual, o Zhipu AI está marcado como provedor recomendado.
- Oferece uma API compatível com a Anthropic, o que facilita a conexão direta com o Claude Code.
- O preset inclui mapeamentos de modelo padrão como `glm-4.7`, `glm-5` e `glm-4.5-air`.

## Mapeamento padrão de modelos

| Nível do Claude | Modelo padrão |
|-------------|----------|
| Sonnet | `glm-4.7` |
| Opus | `glm-5` |
| Haiku | `glm-4.5-air` |

:::tip
Planos, promoções e benefícios mudam com o tempo; se você se importa mais com os preços em tempo real, consulte diretamente a página de assinatura do provedor.
:::

## Recomendações de configuração

1. Primeiro, confirme o plano ou a forma de ativação da API Key que você quer usar.
2. Depois, abra o item do Claude Code na página unificada de AI Agent CLI e siga para a instalação oficial e a documentação de referência da Anthropic.
3. Ao terminar, você pode verificar se a integração funcionou executando `claude --version` localmente, conferindo o arquivo de configuração ou fazendo uma requisição real.
