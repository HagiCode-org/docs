Um **Vault** é uma pasta que o HagiCode pode navegar e visualizar fora do repositório do projeto. Use Vaults para guardar documentos de referência, notas, resultados de pesquisa e qualquer outro conteúdo que você queira que as sessões leiam ou escrevam.

Clique em **Vault** na barra superior (na interface em chinês, o rótulo é Vault) para abrir o **Vault Workspace** (Espaço de trabalho de Vaults).

![Vault Workspace, listando os Vaults registrados Orbit Notes e Docs e um grupo recolhido System vaults](../../img/user-guide/vault/01-vault.png)

## Vaults registrados e Vaults do sistema

O workspace tem dois grupos:

- **Registered vaults** (Vaults registrados) são as pastas que você adicionou. Cada cartão mostra o tipo do Vault, o nome, o caminho abreviado e um botão **Open Code Server** (Abrir Code Server), que abre a pasta em um editor no navegador.
- **System vaults** (Vaults do sistema) são criados e mantidos pelo HagiCode. Clique em **Expand** (Expandir) para vê-los.

![Vaults do sistema expandidos, mostrando sete Vaults somente leitura gerenciados pelo sistema](../../img/user-guide/vault/02-vault-system-expanded.png)

Nessa gaveta, os Vaults do sistema são **somente leitura**. Eles incluem logs do aplicativo, o diretório de dados, modelos de prompt, dados pessoais, dados do projeto, o arquivo atual e predefinições do sistema. Nos escopos de sessão, eles contam apenas como material de referência.

## Adicionar um Vault

Clique em **Add vault** (Adicionar Vault), preencha **Vault name** (Nome do Vault) e o **Physical path** (Caminho físico) absoluto, escolha o **Vault type** (Tipo de Vault) e clique em **Save vault** (Salvar Vault).

![Gaveta Add vault com nome, caminho e o tipo Folder selecionado](../../img/user-guide/vault/03-add-vault.png)

| Tipo de Vault | Função |
| --- | --- |
| **Folder** (Pasta) | Registra qualquer diretório local existente sem alterações. |
| **CodeRef** (Referência de código) | Cria automaticamente `docs/`, `repos/`, `AGENTS.md` e `index.yaml`. Pode ser usado como Vault de saída para tarefas de pesquisa. |
| **Obsidian** | Cria automaticamente `.obsidian/`, `app.json` e artefatos de notas visualizáveis, para que a pasta possa ser usada como Vault do Obsidian. |

:::caution[Escolha o tipo antes de salvar]
Antes de clicar em **Save vault**, escolha um dos três tipos de Vault. Na versão usada para escrever este guia, salvar sem escolher um tipo falha com uma mensagem de erro pouco clara, em vez de um aviso de validação.
:::

## Usar Vaults em sessões

Os Vaults aparecem no **Escopo** (Scope) das [gavetas de criação de proposta e de criação de sessão comum](/user-guide/sessions). Se a tarefa deve atualizar arquivos do Vault, marque-o como **editable** (editável); caso contrário, a IA o tratará como referência somente leitura. Vaults gerenciados pelo sistema são sempre somente referência.
