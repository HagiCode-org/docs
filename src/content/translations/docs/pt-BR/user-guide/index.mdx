Esta seção é o manual de operação do workbench do HagiCode, explicando cada módulo da interface. Você pode abrir diretamente a página correspondente à função que está usando.

## Visão geral do workbench

O workbench abre por padrão no **quadro de sessões**. A imagem abaixo usa um projeto de demonstração pequeno chamado `orbit-notes`, que tem uma sessão concluída.

![Workbench do HagiCode, mostrando a barra superior, a barra de projetos, o quadro de sessões com três raias, o painel do projeto e a barra de status](../../img/user-guide/workbench/01-workbench-overview.png)

A interface é dividida em cinco áreas:

| Área | Posição | Função | Guia |
| --- | --- | --- | --- |
| **Barra superior** (Header) | Borda superior | Abre os módulos do workspace: Agents, Wizard, Skills, HagiTask, Vault, Plans, configurações, idioma, tema e perfil | [Barra superior](#barra-superior) |
| **Barra de projetos** (Project rail) | Borda esquerda | Alterna entre todos os projetos e um projeto específico, e cria novos projetos | [Projetos](/user-guide/projects) |
| **Quadro de sessões** (Session board) | Centro | Exibe as sessões em raias e oferece o botão para criar uma nova sessão | [Sessões](/user-guide/sessions) |
| **Painel do projeto** (Project panel) | Direita | Ações rápidas e estado do repositório do projeto selecionado | [Projetos](/user-guide/projects) |
| **Barra de status** (Status bar) | Borda inferior | Dicas, estado de saúde da Agent CLI, sessões em execução, lembretes de pausa, contador de diária e versão do build | [Barra de status e progresso](/user-guide/status-bar-and-progress) |

## Barra superior

A barra superior fica sempre visível. Os botões dela abrem gavetas ou caixas de diálogo sobre a página atual, então você não perde sua posição no quadro.

![Barra superior do HagiCode, com os botões Agents, Wizard, Refresh, Skills, HagiTask, Vault, Plans, Get Support, idioma, tema, configurações e perfil](../../img/user-guide/workbench/03-header-navigation.png)

| Botão | O que abre |
| --- | --- |
| **Agents** (na interface em chinês: Agents) | Área de Agents: seus Agents, cenários de execução, lista de AgentCLI, catálogo de modelos, temas de texto e galeria de avatares. Veja [Agents](/user-guide/agents). |
| **Wizard** (assistente) | Assistente de inicialização em quatro etapas. Veja [Primeira execução](#primeira-execução). |
| **Refresh** (atualizar) | Recarrega o conteúdo da página atual. |
| **Skills** (habilidades) | Módulo unificado de habilidades, com Local Skills, Gallery e Trusted Providers. Veja [Habilidades e HagiTask](/user-guide/skills-and-hagitask). |
| **HagiTask** (na interface em chinês: HagiTask) | Gerenciamento de HagiTask, para administrar predefinições de tarefas. Veja [Habilidades e HagiTask](/user-guide/skills-and-hagitask). |
| **Vault** (na interface em chinês: Vault) | Gerenciador de Vault, para administrar as pastas que o HagiCode pode navegar e visualizar. Veja [Vault](/user-guide/vault). |
| **Plans** (planos, ícone de calendário; em janela estreita mostra apenas o ícone, com a dica Scheduled plans) | O gerenciador de planos, para planos que iniciam sessões automaticamente em um horário agendado. Veja [Planos agendados](/pt-BR/user-guide/scheduled-plans). |
| **Get Support** (obter suporte) | Abre a página de comunidade e suporte no navegador. |
| **Language** (idioma) | Troca o idioma da interface. O HagiCode oferece dez idiomas, incluindo chinês simplificado. |
| **Theme** (tema, ícone de folha) | Abre o seletor de temas. Veja [Aparência, tema e idioma](/user-guide/settings#aparência-tema-e-idioma). |
| **Settings** (configurações, ícone de engrenagem; a caixa de diálogo aberta se intitula "Configurações") | Abre a caixa de diálogo de configurações. Veja [Configurações](/user-guide/settings). |
| **Profile** (perfil, avatar circular) | Abre a gaveta de perfil, com pontos, linha do tempo do histórico e atalhos. Veja [Barra de status e progresso](/user-guide/status-bar-and-progress#perfil). |

## Primeira execução: assistente de inicialização

Após uma instalação nova, o **Initialization wizard** (assistente de inicialização) abre automaticamente. Você também pode reabri-lo a qualquer momento pelo botão **Wizard** na barra superior. O assistente tem quatro etapas e mostra quantas das três etapas obrigatórias já estão prontas.

![Etapa 1 do assistente de inicialização: escolha do idioma da interface e do tema de cores](../../img/user-guide/wizard/01-language-theme.png)

1. **Language & theme** (idioma e tema) – Escolha o idioma da interface e o tema de cores sazonal. Ambos são aplicados imediatamente.
2. **Hagicoder** – Escolha a Agent CLI local e o modelo, crie seu primeiro Agent e adicione-o ao **Fallback Crew** (equipe de reserva). Recomenda-se fazer um teste de conexão, mas ele não é obrigatório.
3. **Project** (projeto) – Registre a pasta do seu primeiro projeto.
4. **Community** (comunidade) (opcional) – Inicie sua primeira conversa ou abra a página "Sobre".

![Etapa 2 do assistente de inicialização: definir o Agent padrão e adicioná-lo ao Fallback Crew](../../img/user-guide/wizard/02-agent.png)

Para o fluxo completo e o significado de cada campo, veja [Configuração do assistente de inicialização](/quick-start/wizard-setup).
