Um **Agent** no HagiCode é um trabalhador pronto para uso, composto por uma Agent CLI (por exemplo, Claude Code), um modelo e um texto de personalidade opcional. As sessões são executadas por um Agent, então é preciso ter pelo menos um Agent antes de começar a trabalhar.

Clique em **Agents** (na interface em chinês: Agents) na barra superior para abrir o **Agents Workspace** (Agents Workspace). Ele tem seis abas.

| Aba | Finalidade |
| --- | --- |
| [Agents](#aba-agents) | Crie e gerencie os seus Agents. |
| [Execution Scenarios (Cenários de execução)](#cenários-de-execução) | Define quais Agents executam cada tipo de trabalho. |
| [AgentCLI](#agentcli) | Veja quais Agent CLIs estão instaladas, saudáveis e habilitadas. |
| [Model (Modelo)](#modelo) | Explore e amplie o catálogo de modelos de cada Agent CLI. |
| [Document Theme (Tema de documento)](#tema-de-documento) | Escolha o tema de texto da interface. |
| [Avatar Gallery (Galeria de avatares)](#galeria-de-avatares) | Explore os pacotes de avatares. |

:::note
AgentCLI e o catálogo de modelos são de nível de sistema. A aba Agents guarda apenas os seus Agents atuais e as suas equipes.
:::

## Aba Agents

![Aba Agents, com a lista My Agents agrupada por Agent CLI e mostrando o Agent Hagicoder](../../img/user-guide/agents/01-agents.png)

**My Agents** (Meus Agents) lista os seus Agents, agrupados pela Agent CLI que utilizam. Cada cartão mostra o avatar, o nome, o modelo e um pequeno distintivo que representa a CLI.

- **New Agent** (Novo Agent) abre a gaveta de criação.
- **Batch create Agents** (Criar Agents em lote) cria vários de uma vez.
- **Search** (Pesquisar) filtra por nome do Agent, AgentCLI ou descrição.
- **Select all visible** (Selecionar todos os visíveis), **Clear visible** (Limpar visíveis) e **Delete N selected** (Excluir N selecionados) são usados para exclusão em lote.

### Criar Agent

![Gaveta New Agent, com a barra de equipamento do Agent e as seções de Traço e Alma](../../img/user-guide/agents/02-new-agent.png)

Esta gaveta cria um Agent por vez. Até que a criação seja concluída com sucesso, a visão Agents permanece como está.

- **Name and avatar** (Nome e avatar) – é sugerido um nome aleatório a partir de um conjunto de nomes. Enviar um avatar personalizado requer o TurboEngine DLC.
- **Agent loadout** (Equipamento do Agent) – dois slots obrigatórios. Clique em um ícone candidato para equipá-lo:
  - **AgentCLI** – a ferramenta de linha de comando que executa o Agent.
  - **Model** (Modelo) – o modelo usado por essa CLI. A lista mostra apenas os modelos compatíveis com a CLI selecionada.
- **Trait · knowledge and behavior** (Traço · conhecimento e comportamento) – texto livre ou um traço da plataforma de traços (Trait platform), usado para moldar a forma como o Agent trabalha.
- **Soul · language style** (Alma · estilo de linguagem) – texto livre ou uma alma da plataforma de almas (Soul platform), usada para moldar o estilo de fala do Agent.
- Alternância **Battle ready** (Pronto para batalha) – habilita ou desabilita o Agent.

## Cenários de execução

Corresponde à aba **Execution Scenarios**.

![Aba Execution Scenarios, com os cenários Proposal, HagiTask e Chat, e o editor de equipes](../../img/user-guide/agents/03-execution-scenarios.png)

Os cenários determinam qual Agent é escolhido para cada tipo de trabalho. Eles são agrupados pelo local onde aparecem:

| Grupo | Cenário |
| --- | --- |
| **Proposal** (Cenários de execução da fase de proposta) | Optimize Proposal (Otimizar proposta), Generate Proposal (Gerar proposta), Execute Proposal (Executar proposta), Archive Proposal (Arquivar proposta) |
| **HagiTask** (Cenários de execução do Hagitask) | AI commit (Commit com IA), Create Normal Session (Criar sessão normal), Create Research Investigation Task (Criar tarefa de investigação de código) |
| **Chat** (Cenários de execução do chat) | Conversation Title Optimization (Otimização do título da conversa) |

**Fallback Crew** (Equipe de reserva) é a rede de segurança. Quando nenhum Agent adequado está na equipe de um cenário, o HagiCode tenta, de forma aleatória, os membros elegíveis da equipe de reserva. Ela é obrigatória: **todos os outros cenários permanecem bloqueados até que a equipe de reserva tenha pelo menos um Agent habilitado.** O assistente de inicialização adiciona automaticamente o seu primeiro Agent a ela.

Clique em um cenário para editá-lo. **Assigned Agents** (Agents atribuídos) mostra quem está na equipe, e **Available Agents** (Agents disponíveis) mostra os membros que podem ser adicionados. As abas de filtro reduzem a lista por Agent CLI. Em tempo de execução, os membros elegíveis são tentados de forma aleatória, portanto a ordem exibida na interface não indica prioridade.

## AgentCLI

![Tabela de gerenciamento do AgentCLI, listando o status de habilitação, a disponibilidade, a versão e o monitoramento de cada CLI](../../img/user-guide/agents/04-agentcli.png)

Esta aba lista todas as ferramentas de linha de comando que o HagiCode pode acionar: Claude Code, Codebuddy, Codex, DeepAgents, DSH, Gemini, GitHub Copilot, Hermes, Junie, Kimi, Kiro, OMP, OpenCode, Pi, QoderCLI e Reasonix.

Para cada CLI, você pode ver:

- **Enabled** (Habilitado) e **Availability** (Disponibilidade) – a CLI precisa estar instalada na máquina que executa o HagiCode para ficar disponível.
- **CLI version** (Versão da CLI) – a versão detectada. Quando o executável não é encontrado, aparece *Not detected* (Não detectada).
- **Monitoring** (Monitoramento) – a verificação de saúde mais recente, por exemplo *Healthy* (Saudável).
- **Show diagnostics** (Mostrar diagnósticos) – os detalhes por trás do resultado da verificação, úteis quando a CLI não é detectada.
- Uma **alternância** para habilitar ou desabilitar a CLI. Use as caixas de seleção com **Enable selected** (Habilitar selecionados) e **Disable selected** (Desabilitar selecionados) para alterar várias de uma vez. Os filtros podem mostrar apenas as CLIs *Available* (Disponíveis) ou *Unavailable* (Indisponíveis).

Se uma CLI instalada não for detectada, confirme que o executável está no `PATH` do processo que executa o HagiCode e, em seguida, recarregue. Consulte [Instalação da AI Agent CLI](/related-software-installation/ai-agent-cli).

## Modelo

Corresponde à aba **Model**.

![Aba Model, mostrando o catálogo de modelos do Claude Code e o formulário Create Model](../../img/user-guide/agents/05-model.png)

Selecione um **AgentCLI** na parte superior para ver os respectivos modelos. A tabela mostra o nome de cada modelo, o ID do modelo, a origem e se ele oferece suporte a imagens.

- As entradas **System defaults** (Padrões do sistema) são somente leitura e mantidas pelo HagiCode.
- As entradas **Custom** (Personalizadas) são suas. Crie-as com o formulário **Create Model** (Criar modelo): *Display name* (Nome de exibição), *Summary* (Resumo), *Icon* (Ícone), *Model value* (Valor do modelo) exigido pela CLI e se ele *Supports images* (Oferece suporte a imagens). **Create blank entry** (Criar entrada em branco) começa com uma linha vazia.
- Você pode filtrar por nome ou ID do modelo, por origem (*All sources* (Todas as origens), *Custom*, *System default*) ou exibir apenas os modelos com *Support images only* (Somente com suporte a imagens).

## Tema de documento

Corresponde à aba **Document Theme**.

![Aba Document Theme, com o tema AgentCLI Baseline como tema atual e os demais temas bloqueados](../../img/user-guide/agents/06-document-theme.png)

O tema de documento altera a linguagem da interface. **AgentCLI Baseline** (Base do AgentCLI) usa termos neutros, como *Agents*, *Jobs* (Tarefas) e *Workspace* (Workspace), e é o tema padrão. Outros temas, como o vocabulário *Fantasy Adventure* (Aventura de fantasia), exigem o TurboEngine DLC. As prévias continuam visíveis, mas bloqueadas. **Restore default theme** (Restaurar tema padrão) volta ao tema base.
