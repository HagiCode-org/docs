Esta página é a entrada unificada de instalação local dos AI Agent CLIs do HagiCode. O HagiCode atualmente oferece suporte ativo a 11 Agent CLIs: Claude Code, Codex, GitHub Copilot, OpenCode, Hermes, QoderCLI, Kiro, Kimi, Gemini, DeepAgents e Codebuddy.

:::tip[Como usar esta página]
Verifique primeiro a tabela para obter o estado de suporte atual e o modo de configuração e, em seguida, continue com os documentos de instalação, autenticação, ACP, permissão e solução de problemas mantidos pelo fornecedor. O escopo do suporte e o modo de configuração são preocupações distintas.
:::

:::note[Prepare antes o Node.js 24+]
A maioria dos CLIs com instalação com um clique depende do Node.js e do npm, e o Desktop também usa o `node` e o `npm` do seu sistema (o Desktop não inclui mais o Node.js). Prepare primeiro a versão 24 ou superior seguindo [Instalar o Node.js](/pt-BR/related-software-installation/nodejs/installation) e, depois da instalação, **conclua o login ou a autenticação**: o assistente de inicialização lista apenas os CLIs detectados na máquina.
:::

## Glossário estadual

- **Atualmente suportado** significa que a CLI pertence à faixa de suporte ativa atual do HagiCode.
- **Instalação com um clique** significa que o HagiCode fornece um ponto de entrada de instalação guiada; algumas CLIs ainda exigem login do fornecedor ou etapa de autenticação após a instalação.
- **Instalação/autenticação manual** significa que a CLI é suportada agora, mas você deve concluir a instalação local ou o fluxo de autenticação antes que o HagiCode possa detectá-la e usá-la.
- **Somente compatibilidade herdada** significa que o iFlow CLI é mantido apenas por compatibilidade com dados antigos; ele não faz parte da faixa de suporte ativo atual e não deve ser considerado uma opção recomendada hoje.
