O suporte integrado ao OmniRoute foi removido do HagiCode. O produto não tem mais etapas de instalação, configurações, teste de conexão nem sincronização do catálogo de modelos do OmniRoute.

Para conectar modelos agora:

- use um modelo conectado pelo Magpie, ou
- configure um provedor e um modelo que o seu Agent CLI suporte nativamente.

O HagiCode não migra endpoints nem chaves antigas do OmniRoute. Selecione um provedor e um modelo compatíveis na sua configuração. Para a instalação do Agent CLI, veja [Instalação do AI Agent CLI](/pt-BR/related-software-installation/ai-agent-cli/).

## Documentação independente do OmniRoute

O OmniRoute é um projeto separado com o próprio site de documentação. O HagiCode não oferece suporte a ele.
