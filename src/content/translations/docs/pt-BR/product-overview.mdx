O HagiCode evita que a IA perca o contexto ao alterar seu código: **entenda primeiro o repositório, defina o escopo e execute com um registro rastreável.** É um espaço de trabalho com IA para o desenvolvimento de projetos que conecta os Agent CLI e os modelos que você já usa, para que você não precise trocar de editor.

**[Instalar o HagiCode](/pt-BR/installation/)** · [Assistir ao vídeo de demonstração](#product-video-showcase-en)

Compatível com 11 Agent CLI (Claude Code, Codex, GitHub Copilot e outros) · Funciona no Windows, macOS e Linux · Os recursos básicos são gratuitos

## Como funciona uma tarefa de desenvolvimento

Por exemplo, considere uma mudança de funcionalidade que envolve vários repositórios:

1. **Primeiro, entenda o código:** Analise o código existente em uma [sessão de conversa](/pt-BR/quick-start/conversation-session). As sessões de conversa são somente leitura por padrão; mude para o modo de edição quando precisar alterar arquivos.
2. **Depois, defina o escopo:** Para uma mudança complexa, selecione o projeto e os repositórios em uma [sessão de proposta](/pt-BR/quick-start/proposal-session). Organize os objetivos, as tarefas e as etapas de verificação antes de executar.

   ![Gaveta de nova proposta com seleção de repositórios e prévia da proposta](../img/screenshots/shared/create-proposal-drawser/original.png)

3. **Acompanhe o resultado:** Consulte as sessões e o status de execução no espaço de trabalho. Para preparar um commit, use o [AI Compose Commit](/pt-BR/guides/ai-compose-commit).

   ![Detalhe da sessão após a conclusão da execução de um fluxo de proposta](../img/screenshots/shared/classic-proposal-view/original.png)

4. **Preserve o contexto:** Propostas e histórico de commits podem ser revisitados. Para trabalhar entre repositórios, use o [MonoSpecs](/pt-BR/guides/monospecs) para gerenciar as relações entre eles e o escopo das mudanças.

Você não precisa criar uma proposta para toda tarefa. Comece com uma sessão de conversa quando quiser apenas explorar o código ou resolver algo simples. O HagiCode oferece um caminho rastreável quando a tarefa exige mais contexto.

## Para quem é

- **Uma boa escolha:** Desenvolvedores e equipes que mantêm vários repositórios e querem planejar mudanças complexas antes de executá-las, e pessoas que já usam Agent CLI como Claude Code ou Codex e querem tê-los em um único espaço de trabalho.
- **Não essencial:** Se você só precisa completar algumas linhas no seu editor, as ferramentas que você já usa são suficientes.

## Explore os recursos conforme a necessidade

| Se você quer… | O que é | Comece por aqui |
| --- | --- | --- |
| Entender o código antes de decidir se vai alterá-lo | Sessão de conversa: somente leitura por padrão, com opção de mudar para edição quando necessário | [Criar uma sessão de conversa](/pt-BR/quick-start/conversation-session) |

O Vault reúne repositórios de referência, pastas e anotações para uso futuro; o Code Server oferece um ponto de entrada de edição no navegador. Nenhum dos dois é necessário para começar com o HagiCode. Para conhecer o contexto do projeto, leia sobre [como trabalhar com a base de conhecimento Vault](/pt-BR/blog/2026-04-10-vault-system-ai-knowledge-base/) e [a integração da edição no navegador](/pt-BR/blog/2026-04-13-vscode-web-integration-browser-editing/).

## Torne visível o progresso de longo prazo

O HagiCode transforma heróis, conquistas, relatórios diários e métricas de Token em feedback, para que o status e o progresso sejam mais fáceis de enxergar ao longo do tempo, algo que o diferencia das ferramentas comuns de programação com IA. Na [introdução à Equipe de Aventura](/pt-BR/adventure-team-introduction) você vê como os heróis são agrupados e como as masmorras avançam; para conhecer a lógica do design, leia o [artigo sobre o design da gamificação](/pt-BR/blog/2026-03-16-gamifying-ai-coding/). Isso faz parte da experiência do espaço de trabalho, e você ainda pode usar o HagiCode como uma ferramenta de desenvolvimento comum sem esses recursos.

## Edições e preços

Os recursos básicos são gratuitos. Desktop e Microsoft Store são duas formas diferentes de obter o HagiCode, não dois planos pagos. O canal da Microsoft Store também oferece o Turbo Engine, uma compra única separada que aumenta o limite de propostas simultâneas e desbloqueia melhorias como temas de documentação, atribuição personalizada, identidade visual e avatares. Consulte o [complemento Turbo Engine](/pt-BR/dlc/turbo-engine-dlc/) para saber exatamente o que ele desbloqueia.

| Seu ambiente | Opção recomendada |
| --- | --- |
| Windows com acesso à Microsoft Store | [Instalar pela Microsoft Store](/pt-BR/installation/windows-store) |
| Instalação manual no Windows ou uso local no macOS ou Linux | [Instalar o Desktop](/pt-BR/installation/desktop) |

O aplicativo principal na Steam foi descontinuado e não é mais um canal de instalação. Veja o [status da distribuição na Steam](/pt-BR/faq/steam-distribution-status/).

## Por que criar um espaço de trabalho?

Sou Kun Yu, criador do HagiCode. Uma pergunta e sua resposta podem resolver um problema imediato, mas o desenvolvimento real também exige entender o projeto, definir limites, levar mudanças adiante e revisar os resultados. Quis reunir essas etapas antes dispersas; o feedback gamificado ajuda a visualizar o progresso do trabalho de longo prazo. Você pode usar apenas parte dos recursos. Não precisa aprender todos os módulos antes de começar a programar.
