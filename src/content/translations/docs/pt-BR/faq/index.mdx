## O que esta seção cobre

A seção FAQ é o lugar para:

- advertências de inicialização e tempo de execução
- notas de compatibilidade vinculadas a plataformas, canais de distribuição, pacotes ou tempos de execução agrupados
- tópicos de solução de problemas que merecem uma página de explicação independente e estável

Se você quiser confirmar qual Node externo o Desktop usa, onde os Agent CLIs são instalados ou o que fazer quando ele avisa que não encontrou o Node, abra [Como o Desktop usa o seu ambiente Node](/pt-BR/faq/desktop-node-environment).

Se você quiser saber por que o HagiCode não está no Steam, abra [Por que o HagiCode não está disponível no Steam](/pt-BR/faq/steam-distribution-status).
