As sessões de conversa são o ponto de entrada mais leve do HagiCode. Escolha um projeto, faça uma pergunta e deixe um Agent ler o repositório e responder. Você decide, a cada sessão, se o Agent pode modificar arquivos.

## Pré-requisitos

Antes de iniciar uma sessão de conversa, confirme que você:

- concluiu qualquer método de instalação (Microsoft Store, Desktop ou Docker Compose) seguindo o [Guia de instalação](/pt-BR/installation)
- concluiu a [Configuração pelo assistente](/pt-BR/quick-start/wizard-setup), que cria seu primeiro Agent e pelo menos um projeto
- selecionou esse projeto no quadro de sessões

## Para que serve uma sessão de conversa?

Uma sessão de conversa funciona melhor quando você quer entender primeiro e editar depois. Usos típicos incluem:

- analisar rapidamente um repositório desconhecido
- fazer uma pergunta objetiva sobre um arquivo, módulo ou erro
- fazer uma pequena alteração sem planejá-la como uma proposta
- anexar imagens, frases padrão ou mensagens anteriores antes de enviar

Se a sua tarefa já passou de “entender o problema” para “planejar, revisar e arquivar uma alteração estruturada”, continue com [Criar uma sessão de proposta](/pt-BR/quick-start/proposal-session). Esta página trata apenas de sessões de conversa.

## Visão geral do fluxo

| Etapa | O que você faz | O que acontece |
| --- | --- | --- |
| Criar | Clique em **Create Normal Session** (criar sessão normal) e descreva o que você quer | O painel reúne o projeto, um título opcional, o escopo e sua primeira mensagem |
| Iniciar | Escolha um Agent em **Available Agents** (Agents disponíveis) | A sessão começa imediatamente e aparece na raia **Execution** |
| Ler | Abra o cartão da sessão | O Agent lê o repositório e responde; um cartão **Session Complete** resume a execução |
| Decidir | Use o seletor de modo ao lado da caixa de mensagem | Permaneça no modo somente leitura ou ative o modo de edição para que o Agent possa alterar arquivos |
| Adicionar contexto | Use os botões de imagem, frases padrão e histórico | Sua próxima mensagem leva um contexto mais rico |

## Etapa 1: Criar a sessão

Selecione seu projeto e clique em **Create Normal Session** (o ícone de balão de fala) na barra de ferramentas acima do quadro.

![Painel Create Normal Session com um projeto, título da sessão, escopo da tarefa, uma solicitação e o seletor Available Agents](../../img/quick-start/conversation-session/01-create-normal-session.png)

Preencha o painel:

- **Project** (obrigatório) – por padrão, é o projeto selecionado.
- **Session title** – opcional; torna-se o título do cartão no quadro.
- **Task scope** – opcional. **Repos** restringe a sessão aos repositórios de um projeto MonoSpecs, enquanto **Vault** e **Projects** anexam material de referência adicional.
- **What do you want to do?** (obrigatório) – sua primeira mensagem. **Upload Image** anexa uma imagem.

O painel **Available Agents** abre ao lado do painel de criação. Clique em um Agent e a sessão **começa imediatamente**. O primeiro cartão é o padrão de execução; a segunda lista permite escolher outro Agent apenas para esta execução. Você também pode pressionar `Ctrl/⌘ + Enter` para enviar pelo teclado.

:::tip[Comece com uma pergunta, não com uma alteração]
Uma primeira mensagem como “Em duas frases, o que este projeto faz? Não modifique nenhum arquivo.” é uma forma segura de confirmar que seu Agent e seu projeto estão configurados corretamente.
:::

## Etapa 2: Ler o resultado

A nova sessão aparece como um cartão na raia **Execution** com um selo de status. Clique nela para abrir a sessão.

![Painel da sessão mostrando a resposta do Agent, o resumo Session Complete, a caixa de mensagem e o cartão de status do Agent](../../img/quick-start/conversation-session/02-session-detail.png)

- O **cabeçalho** mostra o título e o Agent, com **Archive**, **Delete Session**, **Open Code Server** e um menu **…**.
- A **conversa** lista sua mensagem, as chamadas de ferramentas do Agent como cartões e a resposta dele.
- Um cartão **Session Complete** encerra cada execução com o número de turnos, o tempo decorrido e o custo. Clique nele para expandir os detalhes.
- O **cartão de status do Agent**, à direita da caixa de mensagem, mostra o Agent CLI, o modelo, o estado (por exemplo, *Idle*) e o tempo decorrido.

Digite uma pergunta de acompanhamento na caixa de mensagem. Pressione `Enter` para enviar e `Shift + Enter` para quebrar a linha.

## Etapa 3: Escolher somente leitura ou modo de edição

O seletor à esquerda da caixa de mensagem tem duas posições. O olho é **somente leitura**: o Agent pode inspecionar e explicar, mas não altera arquivos. O lápis é o **modo de edição**: as novas mensagens têm mais chance de modificar arquivos ou ajustar a implementação atual.

![Caixa de mensagem com o lápis (modo de edição) selecionado](../../img/quick-start/conversation-session/03-composer-edit.png)

![Caixa de mensagem com o olho (modo somente leitura) selecionado](../../img/quick-start/conversation-session/04-composer-readonly.png)

O modo vale para a sessão em que você está, e você pode alterá-lo entre as mensagens. Se as **novas** sessões normais começam no modo de edição é controlado por **Settings → Process & Interaction → Chat View → Default to Edit Mode for Normal Chats**. Consulte [Configurações](/pt-BR/user-guide/settings).

O padrão mais seguro é simples: confirme a direção primeiro no modo somente leitura e mude para o modo de edição só quando realmente quiser alterações.

## Etapa 4: Adicionar contexto antes de enviar

Três botões ao lado do seletor de modo adicionam contexto à sua próxima mensagem:

- **Insert an image attachment** (inserir um anexo de imagem) – anexe uma captura de tela, uma captura de erro ou uma referência de design. A imagem aparece acima da caixa de mensagem com o nome e o tamanho do arquivo, e você pode removê-la com o **×** antes de enviar.
- **Standard Phrases** (frases padrão) – insere uma referência `@`. O seletor oferece **Projects** (o caminho raiz canônico de um projeto), **Vaults** (o caminho de um vault registrado), **Proposal Sessions** (uma pasta de alteração do OpenSpec) e **Recent Items**.
- **Import Recent History** (importar histórico recente) – reutiliza uma das mensagens recentes desta sessão para que você não precise digitá-la de novo.

![Caixa de mensagem com uma imagem anexada exibida acima dela](../../img/quick-start/conversation-session/05-composer-image.png)

![Seletor de frases padrão aberto a partir da caixa de mensagem, com Projects, Vaults, Proposal Sessions e Recent Items](../../img/quick-start/conversation-session/06-standard-phrases.png)

As imagens são úteis quando você quer:

- pedir ao Agent que explique uma captura de tela de interface
- anexar uma captura de erro ou um mockup de design e acrescentar instruções adicionais
- dar contexto visual antes de mudar para o modo de edição

## Progressão típica

1. **Crie** a sessão pela barra de ferramentas e escolha um Agent.
2. **Comece em somente leitura** com uma pergunta sobre o projeto.
3. **Leia a resposta** e faça perguntas de acompanhamento.
4. **Ative o modo de edição** somente quando precisar de alterações diretas nos arquivos.
5. **Adicione imagens, frases padrão ou histórico** para dar mais contexto à próxima mensagem.
6. **Arquive** a sessão quando terminar, o que a move para a raia **Archived**.

Se a tarefa agora exige disciplina de planejamento, revisão e arquivamento, continue com o guia de sessões de proposta.
