description: 从 Community Gallery 或归档安装 HagiTask 任务包，并验证安装结果。

**适用对象：** 想安装社区任务并在 HagiCode 中使用的用户。

**前置条件：**

- 已能访问当前使用的 HagiCode 应用和后端服务。
- 应用版本支持 HagiTask 社区任务管理和 Community Gallery。
- 任务所需的 agent、skills 或 CLI 依赖已经准备好；这些要求可在任务详情中查看。

## 从 Community Gallery 安装

当前支持的流程是通过 HagiTask Site 的 Community Gallery 获取任务详情和 ZIP 归档，再交给应用的社区任务安装能力：

1. 在 Gallery 中按任务名称、分类或标签发现任务。
2. 打开任务详情，确认版本、发布者、兼容性和安装大小。
3. 选择安装。应用会从 `packageUrl` 获取 ZIP，并校验任务 ID、版本和 SHA-256。
4. 校验通过后，应用将包写入本地 HagiTask 数据目录并刷新任务目录。

Gallery 的发现、详情和归档入口分别是 `/index.json`、`/tasks/<taskId>.json` 和 `/packages/<taskId>.zip`。安装使用归档，不需要解析站点页面内容。

### 使用归档文件

如果你已经通过受支持的 Gallery 流程取得 ZIP，可以在应用的社区任务管理界面选择本地归档安装。归档必须包含完整的任务包目录，并且其中的 ID、版本和内容摘要要与安装请求一致。

浏览器本地文件夹上传不是当前的 Community Gallery 安装路径。服务器端的文件夹来源配置另有用途，详见[使用 HagiTask](/guides/hagitask/usage)。

## 验证是否成功

安装后，在社区任务管理界面确认：

- 任务显示正确的 `taskId`、版本和发布者。
- 任务状态为已启用，或可以手动启用。
- 任务的依赖和兼容性提示没有未满足项。
- 刷新目录后任务仍然存在，并可以打开任务面板。

安装记录会保存来源、版本、归档摘要和启用状态。内置任务只读展示，不能作为社区包卸载。

## 常见问题

### Gallery 无法访问

确认应用配置的 Gallery 地址可用且使用 HTTPS，并检查网络、超时和站点状态。首次获取目录失败时应用不会伪造空目录；已有有效缓存时可能暂时展示旧目录。

### 任务找不到或详情无效

使用详情中的规范 `taskId`，不要使用展示别名。`agentsmd` 和 `portytail` 只是 `claude-md-update` 与 `ponytail` 的人类别名，不是可安装的任务 ID。

### 完整性或版本校验失败

重新从 Gallery 获取归档，不要手动修改 ZIP 或生成的目录文件。若仍失败，应联系包维护者检查 Community Packages 的源数据和版本号。

### 安装后不可用

检查任务详情中的 agent、skills、CLI 要求，确认应用已启用任务并刷新目录。若包内容本身无效，请转到[社区贡献指南](/guides/hagitask/community)了解 Schema 和验证流程。
