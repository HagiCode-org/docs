对于 Windows 用户，Microsoft Store 是当前公开的桌面入口。本文只说明商店安装这条路径；如果你想看通用的 Desktop 下载安装、版本管理与故障排除说明，请继续阅读 [Desktop 安装](/installation/desktop)。

Steam 主应用条目已经退役，当前 Windows 渠道以 Microsoft Store 为主。相关背景可见 [为什么 HagiCode 没有上架 Steam](/faq/steam-distribution-status/)。

:::tip[适合这条路径的情况]
- 你正在使用 Windows 10 或 Windows 11，并希望直接从系统商店安装
- 你更希望由商店渠道分发应用包，而不是手动处理安装文件
:::

## 安装前确认

开始前请确认这些条件：

- 设备可以正常打开 [HagiCode for Windows 的 Microsoft Store 页面](https://apps.microsoft.com/detail/9N3PM0N3SVDW)
- 首次启动时网络可用，因为程序可能还需要下载或准备 Hagicode Server 所需组件
- 某些设备、组织策略或地区设置可能会要求你先登录 Microsoft 账户
- 如果你的公司设备禁用了商店，请改用 [Desktop 安装](/installation/desktop)

## 安装前准备

Store 版与 Desktop 使用同一套运行方式：**不内置 Node.js**，需要您自行安装并让它出现在系统 `PATH` 中。请在首次启动前准备好：

- **Node.js 24 或更高版本**（同时提供 `npm`），见 [安装 Node.js](/related-software-installation/nodejs/installation)
- **Git**，见 [安装 Git](/installation/#安装-git)
- 至少一个已安装并登录的 **Agent CLI**，见 [AI Agent CLI 安装](/related-software-installation/ai-agent-cli/)

如果在 HagiCode 已经打开之后才安装它们，请完全退出并重新启动 HagiCode，让它读取新的 `PATH`。

## 从 Microsoft Store 安装

1. 打开 [HagiCode for Windows](https://apps.microsoft.com/detail/9N3PM0N3SVDW) 页面。
2. 点击 `获取`、`安装`，或商店页面中的等效按钮。
3. 等待 Microsoft Store 完成下载与安装。
4. 安装完成后，从开始菜单或商店页面直接启动 HagiCode。

## 首次启动时会发生什么

安装完成后，HagiCode 仍会进入标准 Desktop 初始化流程。

- 首次启动会先进入 Desktop 的首次使用引导：选择语言、确认法律文档，并按需下载 Hagicode Server，因此可能比普通应用更慢
- Microsoft Store / MSIX 渠道会锁定“运行时数据存储路径”设置，这是该分发方式的预期行为
- 软件本体不会独立自更新，应用包更新由安装渠道决定；对于 Store 安装，交付方式取决于 Microsoft Store 渠道

如果你需要继续完成初始化向导，请直接阅读 [初始化向导设置](/quick-start/wizard-setup)。

## 什么时候改用其他安装方式

以下情况更适合改用别的渠道：

- 你无法访问 Microsoft Store，或公司设备明确禁止商店安装
- 你需要手动下载 `.exe` 或 `.msix` 包，并自己控制安装文件来源

## 常见问题

### 无法打开 Microsoft Store 页面

优先确认系统网络、地区设置和 Microsoft Store 登录状态。如果浏览器能打开页面但商店客户端仍不可用，通常说明当前系统策略限制了商店能力，这时请改用 [Desktop 安装](/installation/desktop)。

### 为什么某些设置是灰色的

Store / MSIX 安装会锁定“运行时数据存储路径”选项，并显示“Microsoft Store 已锁定”。这不是安装异常，而是当前分发渠道的约束。

### 为什么第一次启动还要继续下载或准备内容

商店安装只负责交付桌面应用包。首次启动时，HagiCode 仍可能下载或准备 Hagicode Server 所需组件，并完成默认初始化。请保持网络可用并等待当前步骤结束。
