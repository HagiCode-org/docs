HagiCode 提供三种安装方式。先按使用场景选一条路径，再确认这条路径需要的前置条件，最后进入对应的安装页。

## 选择安装方式

| 你的场景 | 推荐方式 |
| --- | --- |
| Windows 个人本地使用 | [Microsoft Store 安装](/installation/windows-store) |
| macOS / Linux 个人本地使用，或 Windows 无法使用商店 | [Desktop 安装](/installation/desktop) |
| 服务器、NAS、团队共享，或需要环境隔离 | [Docker Compose 安装](/installation/docker-compose) |

## 安装前准备

不同路径需要的前置条件不同：

| 安装方式 | Node.js | Git |
| --- | --- | --- |
| Microsoft Store / Desktop | 需自行安装 **24 或更高版本** | 需自行安装 |
| Docker Compose | 宿主机无需安装 | 宿主机无需安装 |

:::caution[Desktop 不再内置 Node.js]
Desktop 只内置运行 HagiCode Server 所需的 .NET 运行时，**不再提供 Node.js**。它会在系统 `PATH` 中查找 `node` 与 `npm`，并把 Agent CLI 等托管包安装到你本机 npm 的全局目录。请在首次启动 Desktop 之前先装好 Node.js 24 或更高版本，详见 [安装 Node.js](/related-software-installation/nodejs/installation)。
:::

### 安装 Git

Desktop 会在启动时检测 `node`、`npm` 与 `git`，主界面“新建项目”对话框里的“演示项目”也需要通过 Git 克隆官方示例仓库。请按你的系统选择一种方式安装：

- **Windows**：运行 `winget install --id Git.Git -e`，或从 [git-scm.com](https://git-scm.com/downloads) 下载安装程序。
- **macOS**：运行 `xcode-select --install`，或使用 Homebrew 运行 `brew install git`。
- **Debian / Ubuntu**：运行 `sudo apt-get install -y git`。
- **Fedora**：运行 `sudo dnf install -y git`。

安装完成后重新打开终端，确认命令可用：

```bash
node --version
npm --version
git --version
```

:::tip[装好之后再启动 Desktop]
Desktop 在启动时读取系统 `PATH`。如果你是在 Desktop 已经打开的情况下才安装 Node.js 或 Git，请完全退出并重新启动 Desktop。
:::

### Agent CLI

HagiCode 通过本机已安装并完成登录的 Agent CLI 工作。初始化向导只会列出本机已检测到的 CLI，所以请在进入向导之前至少装好并登录一个。当前支持的 CLI、安装方式与官方入口，统一维护在 [AI Agent CLI 安装](/related-software-installation/ai-agent-cli/)。
