OmniRoute 是一个 OpenAI 兼容的路由器与网关，可将多个上游模型提供商统一到一个本地 API。本文以官方 Desktop 应用为主要安装方式，并保留 npm 作为无桌面环境的备用路径。

:::tip[推荐路径]
从 OmniRoute 官方 GitHub Releases 下载适合 Windows、macOS 或 Linux 的 Desktop 安装包并启动应用。Desktop 会自动启动本地服务，默认仪表板和 OpenAI 兼容 API 地址分别是 `http://localhost:20128` 和 `http://localhost:20128/v1`。
:::

## 前置条件

- Desktop 用户无需单独安装 Node.js。使用 npm 备用路径时，Node.js 必须是 `>=22.0.0 <23` 或 `>=24.0.0 <27`；Node.js 21 和 23 不受支持。需要时请先完成[安装 Node.js](/related-software-installation/nodejs/installation)。
- 本地端口 `20128` 可用且未被占用。
- 你至少有一个计划通过 OmniRoute 路由的上游模型提供商账户。
- 在集成 HagiCode、CLI 或 SDK 前，请区分以下两个地址：
  - 仪表板：`http://localhost:20128`
  - OpenAI 兼容 Base URL：`http://localhost:20128/v1`

## 使用 Desktop 安装并运行

1. 打开 [OmniRoute GitHub Releases](https://github.com/diegosouzapw/OmniRoute/releases)。
2. 下载与你的操作系统匹配的 Desktop 安装包：
   - Windows：`.exe`
   - macOS：`.dmg`
   - Linux：`.AppImage` 或 `.deb`
3. 安装并启动 OmniRoute。应用会自动启动服务并打开 Desktop 窗口。

服务启动后，按以下顺序验证：

1. 在浏览器中打开 `http://localhost:20128`，确认仪表板已加载。
2. 在仪表板的 `Endpoints` 页面创建或复制 API 密钥。
3. 记录稍后提供给工具的 Base URL：`http://localhost:20128/v1`。

## 无桌面环境时使用 npm

如果运行在服务器或其他无桌面环境中，可以改用官方 npm 路径：

```bash
npm install -g omniroute
omniroute start
```

## 验证正在运行的服务

### 验证模型目录

将从 `Endpoints` 页面复制的密钥放入环境变量：

```bash
export OMNIROUTE_API_KEY="replace-with-the-key-you-copied-from-the-Endpoints-page"
```

请求 `/v1/models`：

```bash
curl http://localhost:20128/v1/models \
  -H "Authorization: ******"
```

如果返回模型列表，说明 OpenAI 兼容端点和认证流程正常。

### 发送最小聊天请求

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: ******" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "replace-with-a-model-id-from-v1-models",
    "messages": [
      { "role": "user", "content": "Reply with ok." }
    ]
  }'
```

此请求用于证明所选模型可以通过 OmniRoute 成功路由。
