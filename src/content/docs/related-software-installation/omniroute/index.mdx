HagiCode 已移除内置的 OmniRoute 支持。产品内不再提供 OmniRoute 的安装步骤、设置页面、连接测试或模型目录同步。

现在接入模型的方式：

- 使用通过 Magpie 连接的模型，或
- 在 Agent CLI 中配置它原生支持的提供商和模型。

HagiCode 不会迁移旧的 OmniRoute 地址或密钥。请在配置中重新选择受支持的提供商与模型。Agent CLI 的安装说明见 [AI Agent CLI 安装](/related-software-installation/ai-agent-cli/)。

## 独立的 OmniRoute 文档

OmniRoute 是独立项目，文档由其自身站点维护。HagiCode 不提供对它的支持。
