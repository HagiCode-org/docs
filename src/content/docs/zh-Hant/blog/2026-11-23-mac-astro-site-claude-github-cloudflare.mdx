本教學會帶你從一台乾淨的 Mac 一路做到一個已經在網際網路上線的網站。你會在兩個地方工作：Terminal（終端機），用來安裝工具；以及 Claude Code，它會替你執行重複的指令並編輯檔案。每個步驟結束時都有可以檢查的結果，讓你在進入下一步之前先確認已經成功。

完成後的流程如下：

1. 安裝 Node.js。
2. 安裝 GitHub CLI（`gh`）並登入。
3. 請 Claude 建立一個私人儲存庫並複製到本機。
4. 請 Claude 搭建一個含標題列、頁尾與響應式版面的 Astro 網站，然後提交並推送。
5. 安裝 impeccable 技能，並使用它的 `overdrive` 指令潤飾首頁。
6. 使用 GitHub Actions 工作流程，把網站發布到 GitHub Pages。
7. 在 Cloudflare 連接網域，並以 Workers 部署同一個分支。
8. 新增一個頁面、推送，然後觀察兩邊的部署都完成。

## 本教學適合誰

本教學適用於擁有 Mac 與 GitHub 帳號、想發布一個簡單靜態網站、又不想架設伺服器的人。你不需要事先了解 Astro、GitHub Actions 或 Cloudflare。但你需要能夠自在地開啟 Terminal 並貼上指令。

## 事前準備

- 執行目前版本 macOS 的 Mac。
- 一個 GitHub 帳號。
- 一個 Cloudflare 帳號。
- 一個網域名稱。你可以透過 Cloudflare 註冊，或使用你已經擁有的網域。
- 已安裝並登入的 Claude Code。在 Terminal 執行一次 `claude`，確認它可以啟動。

## 步驟一：安裝 Node.js

Astro 與 impeccable 安裝程式都是在 Node.js 上執行的。請使用目前的 LTS 版本。

最簡單的方法是到 [nodejs.org](https://nodejs.org) 下載官方安裝程式。下載 macOS 安裝套件、執行並接受預設選項即可。

如果你已經在使用 Homebrew，也可以改用 Terminal 安裝：

```bash
brew install node
```

打開一個新的 Terminal 視窗，檢查兩個工具：

```bash
node --version
npm --version
```

兩個指令都應該印出版本號碼。如果找不到 `node`，請關閉並重新開啟 Terminal，讓新的 `PATH` 載入。

## 步驟二：安裝 GitHub CLI 並登入

GitHub CLI 名為 `gh`，它讓 Claude 不必透過網站點選，就能建立與管理儲存庫。

```bash
brew install gh
gh --version
```

接著登入：

```bash
gh auth login
```

依提示這樣回答：

- **你在哪裡使用 GitHub？**（Where do you use GitHub?）`GitHub.com`
- **偏好的通訊協定？**（Preferred protocol?）`HTTPS`
- **要用你的 GitHub 憑證驗證 Git 嗎？**（Authenticate Git with your GitHub credentials?）`Yes`
- **你想用哪種方式驗證？**（How would you like to authenticate?）`Login with a web browser`

複製 Terminal 顯示的一次性代碼，按下 Enter，然後在瀏覽器中完成登入。完成後檢查結果：

```bash
gh auth status
```

輸出應該顯示你已登入 `github.com`。

## 步驟三：請 Claude 建立私人儲存庫

選一個你想存放專案的資料夾，例如 `~/Sites`，如果它還不存在就建立它：

```bash
mkdir -p ~/Sites
cd ~/Sites
claude
```

接著給 Claude 一個類似這樣的請求：

```text
使用 GitHub CLI，在我的 GitHub 帳號上建立一個名為 my-astro-site 的私人儲存庫。
請用 README 將它初始化，讓 main 分支存在，並把它複製到這個資料夾。
完成後請顯示儲存庫的網址。
```

Claude 應該會執行與下列內容相當的指令：

```bash
gh repo create my-astro-site --private --add-readme --clone --description "My Astro site"
```

完成後，你應該會有一個 `~/Sites/my-astro-site` 資料夾，裡面包含 `README.md`，而且該儲存庫在 GitHub 上是私人的。檢查預設分支：

```bash
cd ~/Sites/my-astro-site
git branch --show-current
```

它應該印出 `main`。

## 步驟四：搭建 Astro 網站

留在儲存庫資料夾中，並在那裡啟動 Claude：

```bash
cd ~/Sites/my-astro-site
claude
```

請 Claude 建立一個基本網站：

```text
請使用 Astro 官方的 basics 入門範本，在這個儲存庫中建立一個基本的 Astro 網站。
加入一個網站標題列，包含網站名稱與導覽連結；加入一個頁尾，包含版權文字；
並建立一個在手機、平板與寬螢幕桌機上都能正常顯示的版面。
設計保持簡單。請啟動開發伺服器、檢查頁面，並告訴我如何查看。
```

Claude 完成後，請自己打開本機預覽：

```bash
npm install
npm run dev
```

Astro 會印出一個本機位址，通常是 `http://localhost:4321`。在瀏覽器中打開它，調整視窗大小以檢查版面，然後按 `Control+C` 停止伺服器。

提交之前，請先確認正式版本的建置可以通過：

```bash
npm run build
```

### 提交並推送第一個版本

請 Claude 儲存這些工作：

```text
請用清楚的訊息提交這個 Astro 網站，並推送到 origin 的 main 分支。
```

Claude 應該會執行類似以下的指令：

```bash
git add .
git commit -m "Scaffold Astro site with header, footer and responsive layout"
git push origin main
```

在 GitHub 上確認你最新的提交出現在儲存庫的 `main` 分支。

## 步驟五：安裝 impeccable 並為首頁加入 Overdrive 效果

[impeccable](https://impeccable.style) 是給程式設計代理使用的設計技能。它讓 Claude 擁有一套共通的設計用語，例如 `polish`（潤飾）、`critique`（評論）與 `overdrive`。`overdrive` 指令會加入更大膽、更具表現力的效果，例如著色器、彈簧物理與捲動驅動的動態效果。

請 Claude 為這個專案安裝技能：

```text
請用官方安裝程式，在這個專案中安裝 impeccable 技能。
使用專案範圍與 Claude Code 供應商。需要重新啟動 Claude Code 時請告訴我。
```

Claude 應該會在專案根目錄執行：

```bash
npx impeccable install
```

安裝程式會詢問要為這個專案安裝還是全域安裝，並提供一個設計 hook。接受 hook，然後重新啟動 Claude Code，讓新技能載入。

在重新啟動後的工作階段中，初始化設計脈絡：

```text
/impeccable init
```

然後對首頁套用 overdrive 效果：

```text
/impeccable overdrive 首頁
```

提交之前，請檢查 Claude 做了哪些變更。Overdrive 可能加入大量動態效果，所以你可能只想保留那些有助於讀者理解頁面的效果。請 Claude 再次執行建置並推送結果：

```text
請執行 npm run build，修正所有錯誤，然後提交 overdrive 的變更並推送到 main。
```

## 步驟六：使用 GitHub Actions 發布到 GitHub Pages

GitHub Pages 可以免費託管建置完成的網站。Astro 提供一個官方的 GitHub Action，可以建置網站並將它部署上線。

### 開啟 Pages

在 GitHub 上打開你的儲存庫，然後前往 **設定 → Pages**（Settings → Pages）。在 **Build and deployment**（建置與部署）下方，將 **Source**（來源）設為 **GitHub Actions**。

### 請 Claude 新增工作流程

```text
請新增一個 GitHub Actions 工作流程，檔案位於 .github/workflows/deploy.yml，
使用 actions/checkout 與 withastro/action 建置這個 Astro 網站，並將它部署到 GitHub Pages。
保留 Astro 範本中包含的 permissions 區塊。
```

Claude 建立的工作流程看起來會與 Astro 官方文件中的範例相似：

```yaml
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
  workflow_dispatch:
jobs:
  deploy:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pages: write
      id-token: write
    steps:
      - name: Checkout your repository
        uses: actions/checkout@v7
      - name: Install, build, and upload your site
        uses: withastro/action@v6
```

### 設定網站位址

GitHub Pages 會把專案網站放在一個路徑底下，例如 `https://<your-username>.github.io/my-astro-site`。Astro 需要知道這個路徑，否則它的連結與資源會失效。請 Claude 更新 `astro.config.mjs`：

```text
請在 astro.config.mjs 中將 site 設為 https://<your-username>.github.io，並將 base 設為 /my-astro-site。
說明每個設定的作用。
```

結果應該像這樣：

```js
import { defineConfig } from 'astro/config';

export default defineConfig({
  site: 'https://<your-username>.github.io',
  base: '/my-astro-site',
});
```

將 `<your-username>` 替換成你的 GitHub 使用者名稱。之後當你改用自己的網域時，就要移除 `base`。

提交並推送工作流程與設定變更：

```text
請提交 Pages 工作流程與 Astro 設定變更，然後推送到 main。
```

### 等待第一次部署完成

打開儲存庫的 **Actions**（動作）分頁。`Deploy to GitHub Pages` 執行完成後，大約一、兩分鐘會變成綠色。然後打開 **設定 → Pages**（Settings → Pages）下方顯示的 Pages 網址。

## 步驟七：在 Cloudflare 連接網域

這一步需要一個網域。常見有兩種選擇：

- **註冊新網域**：在 Cloudflare 控制台透過 Cloudflare Registrar 註冊。
- **使用你已擁有的網域**：將它加入 Cloudflare 作為網站，然後在你的網域註冊商處，把網域的名稱伺服器改成 Cloudflare 提供的兩個名稱伺服器。

登入 [Cloudflare 控制台](https://dash.cloudflare.com)，然後註冊網域或加入你既有的網域。等到 Cloudflare 顯示網域為啟用狀態。更改名稱伺服器之後，這可能需要幾分鐘。

## 步驟八：從 GitHub 分支建立 Worker 專案

Cloudflare 目前針對 Astro 的建議是使用 Workers。在控制台中，Pages 風格的 Git 流程仍然會出現在同一個 **Workers & Pages**（Workers 與 Pages）區段下，但以下步驟會遵循 Workers 的路徑。

首先，請 Claude 為靜態 Astro 建置新增 Wrangler 設定。Wrangler 是 Cloudflare 的命令列工具。

```text
請在專案根目錄新增一個 wrangler.jsonc 檔案，用於靜態 Astro 網站。
將 name 設為 my-astro-site，將 compatibility_date 設為今天的日期，
並以靜態資產的方式提供 ./dist 資料夾。不要新增 main 進入點。
```

結果應該像這樣：

```jsonc
{
  "name": "my-astro-site",
  "compatibility_date": "2026-11-23",
  "assets": {
    "directory": "./dist"
  }
}
```

提交並推送這個檔案。然後建立 Cloudflare 專案：

1. 在 Cloudflare 控制台中，前往 **Workers & Pages**（Workers 與 Pages）。
2. 選取 **Create application**（建立應用程式），然後選擇從 GitHub 匯入儲存庫的選項。
3. 當 Cloudflare 詢問時，授權 **Cloudflare Workers & Pages** GitHub 應用程式。可以選擇所有儲存庫，或只選擇 `my-astro-site`。
4. 選取 `my-astro-site` 與 `main` 分支。
5. 將建置指令設為 `npm run build`（或 `npx astro build`），部署指令設為 `npx wrangler deploy`。
6. 開始部署。

Cloudflare 會在每次推送到已連接的分支時建置網站，因此之後的提交都會自動部署。

### 連接你的網域

在控制台中打開新的 Worker，前往 **Domains & Routes**（網域與路由），然後新增你的網域，或像 `www` 這樣的子網域。如果網域已經在同一個帳號中，Cloudflare 會替你建立 DNS 記錄。

## 步驟九：在 Cloudflare 檢查網站

第一次建置完成後，請查看 Cloudflare 控制台中的這些地方：

- **Deployments**（部署）：最新的建置應標示為成功。如果失敗，請打開建置記錄並閱讀第一個錯誤。
- **Domains & Routes**（網域與路由）：你的自訂網域應顯示為啟用。
- **Settings**（設定）：確認已連接的儲存庫與分支是你預期的那些。

然後在瀏覽器中打開你的網域。請分別在手機與寬螢幕桌機視窗上，檢查標題列、頁尾與版面。

## 步驟十：新增頁面並觀察它上線

現在你已經掌握完整的循環：在本機編輯、推送到 GitHub，然後讓代管服務建置並部署變更。

在專案資料夾中啟動 Claude，並要求新增一個頁面：

```text
在 src/pages/about.astro 建立一個新頁面，包含標題、一段簡短的文字，以及一個回到首頁的連結。
使用與其他頁面相同的標題列與頁尾。請執行 npm run build，然後提交並推送到 main。
```

Claude 應該會建立檔案、建置網站、提交並推送。接著觀察兩個部署：

- **GitHub**：打開 **Actions** 分頁。Pages 工作流程會再次執行。
- **Cloudflare**：打開 **Workers & Pages → 你的專案 → Deployments**。新的建置會自動開始。

當兩邊都顯示成功後，在瀏覽器中打開 `https://<your-domain>/about`。如果頁面不存在，請確認檔案位於 `src/pages/about.astro`、最新的部署已經完成，而且你的瀏覽器沒有顯示舊的快取副本。

## 常見問題

- **`node: command not found`**：安裝 Node.js 之後，請打開新的 Terminal 視窗。
- **`gh` 無法建立儲存庫**：執行 `gh auth status`，並確認登入的帳號有權存取你的帳號。
- **GitHub Pages 顯示空白頁面或樣式遺失**：檢查 `astro.config.mjs` 中的 `site` 與 `base`。`base` 的值必須與儲存庫名稱相符。
- **Cloudflare 建置失敗**：閱讀建置記錄中的第一個錯誤。大多數失敗是因為缺少腳本、建置指令錯誤，或 Wrangler 設定指向錯誤的資料夾。
- **網域未啟用**：名稱伺服器的變更可能需要一段時間才會生效。請在 Cloudflare 中該網域的總覽頁面檢查狀態。

## 後續步驟

網站上線之後，你可以用同樣的循環持續加入實際內容。請 Claude 新增頁面、執行 `/impeccable critique` 進行設計審查，或為預覽新增第二個 Cloudflare 環境。需要保持的主要習慣很簡單：做一個小改動、在本機建置、提交，然後讓代管服務發布它。
